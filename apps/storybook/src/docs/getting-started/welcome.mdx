# 글결 디자인 시스템

Storybook은 `@workspace/ui`의 실행 가능한 명세다. 이곳에서는 web의 comfortable 밀도와 admin의 compact 밀도가 같은 token과 component contract를 공유하는지 확인한다.

## 사용 방법

- `Theme` toolbar로 light, dark, system을 전환한다.
- `Density` toolbar로 comfortable, compact를 비교한다.
- `Motion` toolbar로 reduced motion 기준을 확인한다.
- component story는 public API와 접근성 계약을 보여준다.
- recipe story는 제품 화면을 직접 import하지 않고 공용 primitive 조합만 사용한다.
