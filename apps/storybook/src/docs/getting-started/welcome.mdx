# 글결 디자인 시스템

Storybook은 `@workspace/ui`의 실행 가능한 명세다.

## 사용 방법

- `Theme` toolbar로 light, dark, system을 전환한다.
- `Motion` toolbar로 reduced motion 기준을 확인한다.
- component story는 public API와 접근성 계약을 보여준다.
- recipe story는 제품 화면을 직접 import하지 않고 공용 primitive 조합만 사용한다.

## 기여 기준

- public component의 상태나 variant를 바꾸면 같은 변경에서 story를 갱신한다.
- keyboard interaction과 접근성 상태는 가능한 경우 play test로 검증한다.
- Storybook은 앱의 routing, 인증, API와 제품 상태를 가져오지 않는다.
- 사용자 문구는 한국어를 기본으로 하고 loading, empty, error 상태의 복구 행동을 드러낸다.

상세한 디자인·접근성 기준은 `docs/design`, Storybook 작성·검증 계약은
`docs/design/storybook.md`를 따른다. 현재 package 공개 표면과 import 경계는
각 package manifest가 소유한다.
