# 기여 절차

1. 필요한 UI 계약을 문서나 issue에 명시한다.
2. public component 또는 pattern을 추가한다.
3. Playground, variants, states, long content, interaction story를 함께 작성한다.
4. 접근성 test와 package test를 추가한다.
5. web 또는 admin pilot 화면에 적용한다.
6. migration 문서와 Storybook 상태를 갱신한다.

컴포넌트가 public export가 되는 시점에는 필수 story 묶음도 함께 들어가야 한다.
