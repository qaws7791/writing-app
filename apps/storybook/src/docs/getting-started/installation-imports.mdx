# 설치와 import

앱 전역 CSS는 Tailwind 실행 설정과 공통 스타일을 root stylesheet에서 한 번만 가져온다.

```css
@import "tailwindcss" source(none);
@import "tw-animate-css";
@import "@workspace/ui/styles";

@plugin "@tailwindcss/typography";
@custom-variant dark (&:is(.dark *));
@source "<앱 소스 glob>";
@source "<packages/ui/src glob>";
```

`@tailwindcss/typography`, `tw-animate-css`, Tailwind, PostCSS 의존성은 각 앱이 직접 선언한다.

컴포넌트는 필요한 public entrypoint에서 가져온다.

```tsx
import { Button } from "@workspace/ui/components/ui/button"
import { BookOpenIcon } from "@workspace/ui/components/icons"
```

짧은 화면이나 Storybook recipe에서는 root entrypoint를 사용할 수 있다.

```tsx
import { Button } from "@workspace/ui/components/ui/button"
import { Card } from "@workspace/ui/components/ui/card"
import { Surface } from "@workspace/ui/components/ui/surface"
```
