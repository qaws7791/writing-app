# 패키지 경계

`packages/shared/ui`는 도메인 비의존 primitive, pattern, icon, style entrypoint만 소유한다.

앱에 남는 책임은 다음과 같다.

- routing과 navigation destination
- 인증, API, server action
- 코스, 레슨, 학습자, 관리자 같은 도메인 상태 해석
- product-specific copy와 화면 조립

Storybook의 package story는 앱 코드를 import하지 않는다. recipe만 현재 제품 밀도를 재현하되 순수 UI composition으로 작성한다.
