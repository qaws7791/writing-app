# 접근성

모든 public component story는 다음 기준을 따른다.

- 보이는 label 또는 accessible name을 제공한다.
- keyboard only 흐름을 확인한다.
- focus-visible 상태가 light, dark, inverse surface에서 보여야 한다.
- 오류는 색상만으로 전달하지 않는다.
- loading, empty, error 상태를 숨기지 않는다.
- reduced motion에서도 정보가 유지되어야 한다.
