# 콘텐츠 규칙

사용자에게 보이는 문구는 한국어를 기본으로 한다. Storybook fixture는 실제 제품보다 generic하게 작성한다.

- 짧은 label만 검증하지 않고 긴 한국어 문구를 포함한다.
- 오류 문구는 복구 행동을 알려준다.
- 빈 상태는 무엇이 비어 있는지와 다음 행동을 설명한다.
- CTA는 명령형으로 짧게 쓴다.
- 날짜와 숫자는 고정값을 사용한다.
