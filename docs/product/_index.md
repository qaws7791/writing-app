# 제품 문서 인덱스

## 목적

이 문서는 제품 문서의 진입점이다. 제품이 해결하는 문제, 목표, 사용자, 요구사항, 기능, 콘텐츠, 화면, 운영 기준을 찾기 위해 사용한다.

## 탐색 순서

1. 제품의 이유와 방향은 `problem-definition.md`, `product-vision.md`에서 확인한다.
2. 사용자는 `personas.md`, `user-stories.md`, `user-flows.md`에서 확인한다.
3. 구현 범위는 `product-requirements.md`, `feature-specification.md`, `content-model.md`에서 확인한다.
4. 화면과 행동은 `screen-specification.md`, `product-behavior.md`에서 확인한다.
5. 운영과 성과 판단은 `admin-operations.md`, `metrics.md`, `product-research.md`에서 확인한다.

## 디렉토리 지도

| 경로            | 목적                                                                         |
| --------------- | ---------------------------------------------------------------------------- |
| `docs/product/` | 제품 문제, 비전, 사용자, 요구사항, 기능, 콘텐츠, 화면, 운영 기준을 관리한다. |

## 파일 지도

| 파일                       | 목적                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| `_index.md`                | 제품 문서 전체의 진입점과 탐색 지도를 제공한다.                                                  |
| `index.md`                 | 기존 제품 문서 진입점으로, 제품 문서의 목적, 근거 우선순위, 현재 기준선, 관리 규칙을 요약한다.   |
| `problem-definition.md`    | 학습자와 운영자가 겪는 핵심 문제와 제품 제약을 정의한다.                                         |
| `product-vision.md`        | 제품 비전, 사용자 가치, 제품 원칙, 비목표를 정의한다.                                            |
| `personas.md`              | 학습자, 운영자, 소유자 관리자, 제외 사용자를 정의한다.                                           |
| `product-requirements.md`  | MVP 범위, 기능 요구사항, 데이터 요구사항, 제외 범위, 성공 기준을 정의한다.                       |
| `feature-specification.md` | 학습자 기능, 어드민 기능, 현재 구현 상태를 정의한다.                                             |
| `content-model.md`         | 콘텐츠 계층, 기준 콘텐츠, 코스와 유닛과 레슨과 스텝, 확정 스텝 타입을 정의한다.                  |
| `user-stories.md`          | 학습자와 운영자 관점의 사용자 스토리를 정의한다.                                                 |
| `user-flows.md`            | 로그인, 이어서 학습, 첫 코스 시작, 코스 상세, 레슨 진행, AI 피드백, 어드민 운영 흐름을 정의한다. |
| `screen-specification.md`  | 학습자와 어드민의 라우트별 화면 목적과 핵심 구성을 정의한다.                                     |
| `product-behavior.md`      | 제품 동작의 기준과 예외 상황을 정의한다.                                                         |
| `admin-operations.md`      | 관리자 유형, 읽기와 변경 권한, 콘텐츠와 사용자와 설정 운영 기준을 정의한다.                      |
| `metrics.md`               | 현재 표시 지표, 분석 지표, 학습자 화면 지표, 운영 판단 기준, 후보 지표를 정의한다.               |
| `product-research.md`      | 조사 범위, 확인된 제품 사실, 내부 출처명, 문서 충돌과 작성 기준을 정리한다.                      |

## 관리 기준

제품 요구사항이 바뀌면 관련 사용자 흐름, 기능 명세, 화면 명세를 함께 확인한다. 디자인이나 엔지니어링 문서가 제품 기준과 충돌하면 제품 문서를 먼저 갱신하고 하위 구현 문서를 따라 맞춘다.
