# 퍼소나

## 학습자

- 한국어 글쓰기 실력을 높이고 싶은 사용자다.
- Google 계정으로 로그인한다.
- 코스를 고르고 레슨을 순서대로 진행한다.
- 짧은 읽기, 선택형 활동, 쓰기 활동, AI 코칭을 수행한다.
- 완료 레슨, 전체 진도, 연속 학습일을 확인한다.

## 운영자

- 학습자와 콘텐츠 상태를 확인하는 관리자다.
- 대시보드에서 사용자, 활성, 완료, 콘텐츠 지표를 본다.
- 코스 목록과 코스 미리보기를 확인한다.
- 사용자 목록, 사용자 상세, 분석 화면을 조회한다.
- 변경성 작업 권한이 없을 수 있다.

## 소유자 관리자

- 운영 설정과 위험 작업을 수행하는 관리자다.
- 새 코스를 생성한다.
- 코스를 보관한다.
- 사용자를 정지하거나 삭제 상태로 전환한다.
- 공지, 배너, 약관, 개인정보처리방침을 저장한다.
- 콘텐츠 초기화를 실행한다.

## 제외 사용자

- 결제 관리자.
- 외부 강사 마켓 운영자.
- 공개 API 소비자.
- 독립 저널 사용자.
