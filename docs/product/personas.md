# 퍼소나

## 학습자

- 한국어 글쓰기 실력을 높이고 싶은 사용자다.
- Google 또는 이메일·비밀번호로 로그인한다.
- 코스를 고르고 레슨을 순서대로 진행한다.
- 짧은 읽기, 선택형 활동, 쓰기 활동, AI 코칭을 수행한다.
- 쓰기 방식을 선택해 글을 작성하고 자기 점검한다.
- 완료 레슨, 전체 진도, 연속 학습일을 확인한다.

## 소유자 관리자

- 조회, 변경과 위험 작업을 수행하는 유일한 관리자 역할이다.
- 대시보드에서 첫 레슨 시작, 7일 내 재방문과 콘텐츠 지표를 확인한다.
- 새 코스를 생성한다.
- 코스 정보, 유닛, 레슨, 스텝을 편집한다.
- 콘텐츠 이미지를 등록하고 발행한다.
- 코스를 보관한다.
- 사용자를 정지하거나 삭제 상태로 전환한다.

## 제외 사용자

- 결제 관리자.
- 외부 강사 마켓 운영자.
- 공개 API 소비자.
- 범용 개인 저널 또는 문서 편집 도구 사용자.
- 조회 전용 운영자 역할.
