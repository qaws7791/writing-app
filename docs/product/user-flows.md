# 유저 플로우

## 학습자 로그인

- 학습자가 `/login`에 진입한다.
- 학습자가 `Google로 계속하기`를 선택한다.
- 인증이 성공하면 `next` 경로 또는 `/app`으로 이동한다.
- 인증이 실패하면 로그인 화면에 머문다.

## 홈에서 이어서 학습

- 학습자가 `/app`에 진입한다.
- 서버가 프로필과 진행 목록을 조회한다.
- 진행 중인 코스가 있으면 이어서 학습하기 목록을 보여준다.
- 학습자가 다음 레슨을 선택한다.
- 학습자가 `/app/lesson?lesson_id=...`로 이동한다.

## 첫 코스 시작

- 학습자가 `/app`에 진입한다.
- 진행 중인 코스가 없으면 코스 둘러보기를 보여준다.
- 학습자가 `/app/courses`로 이동한다.
- 학습자가 카테고리를 선택한다.
- 학습자가 코스 카드를 선택한다.
- 학습자가 코스 상세에서 첫 레슨을 시작한다.

## 코스 상세

- 학습자가 `/app/courses/[id]`에 진입한다.
- 서버가 코스 상세와 진행 목록을 조회한다.
- 코스가 없으면 not found 화면을 보여준다.
- 조회 실패가 있으면 오류 안내를 보여준다.
- 코스가 있으면 진행률과 유닛별 레슨 목록을 보여준다.
- 학습자가 진행 가능한 레슨을 선택한다.

## 레슨 진행

- 학습자가 레슨 화면에 진입한다.
- 레슨 ID가 없으면 안내 화면을 보여준다.
- 레슨 조회가 실패하면 오류 안내를 보여준다.
- 레슨 시작 화면을 보여준다.
- 학습자가 시작하기를 선택한다.
- 시작 마커를 저장한다.
- 학습자가 스텝을 진행한다.
- 답변 가능한 스텝은 답변을 저장한다.
- 마지막 스텝에서 완료를 저장한다.
- 완료 화면을 보여준다.

## AI 피드백

- 학습자가 AI 피드백 스텝에 도달한다.
- 학습자가 AI 코칭 받기를 선택한다.
- 요청 중 로딩 안내를 보여준다.
- 성공하면 총평, 점수, 잘된 점, 다듬을 점, 다음 시도를 보여준다.
- 실패하면 한국어 오류를 보여준다.
- 남은 시도가 있으면 다시 받기를 제공한다.

## 프로필과 로그아웃

- 학습자가 `/app/profile`에 진입한다.
- 서버가 프로필을 조회한다.
- 학습자가 가입일, 완료 레슨, 연속 학습일을 확인한다.
- 학습자가 테마를 변경한다.
- 학습자가 로그아웃을 선택한다.
- 로그아웃 후 `/`로 이동한다.

## 어드민 운영

- 관리자가 `/login`에 진입한다.
- 관리자가 이메일과 비밀번호로 로그인한다.
- 관리자가 대시보드에서 지표를 확인한다.
- 관리자가 콘텐츠, 사용자, 분석, 설정 화면으로 이동한다.
- 운영자는 조회 중심 업무를 수행한다.
- 소유자 관리자는 변경성 작업을 수행한다.
