# REQ-ADM-5 콘텐츠 유지보수

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리: `US-ADM-5 콘텐츠 유지보수`
- 관련 화면: `SCR-108 콘텐츠 유지보수`
- 관련 사용자: 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 기준 seed로 콘텐츠를 복구하는 위험 작업을 일반 운영 업무와 분리해 실행할 수 있게 한다.

## 기능 요구사항

- 콘텐츠 초기화는 확인 흐름 후 실행한다.
- seed에 있는 코스, 유닛, 레슨과 스텝은 active 상태로 되돌린다.
- seed에 없는 콘텐츠는 보관 상태로 전환한다.
- 완료 후 새 revision과 변경·보관 row 수를 반환한다.

## 화면 요구사항

- 콘텐츠 초기화를 파괴적 작업으로 표시한다.
- 확인 dialog에서 작업의 영향을 설명한다.
- 진행·완료·실패 상태를 한국어로 표시한다.

## 권한 / 접근 규칙

- 화면과 내비게이션은 소유자 관리자에게만 제공한다.
- 콘텐츠 초기화 API도 소유자 권한을 다시 검증한다.

## 비범위

- seed 편집 UI.
- 공지, 배너, 이용약관과 개인정보처리방침 관리.

## 확인 방법

- 운영자가 화면과 내비게이션에 접근할 수 없는지 확인한다.
- 소유자가 확인 dialog를 거쳐 초기화하고 결과 revision을 확인하는지 검증한다.
