# REQ-ADM-5 운영 설정

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-5` 운영 설정 관리
- 관련 화면:
  - `SCR-108` 운영 설정
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 공지, 배너, 법적 문서, 콘텐츠 초기화를 관리해 운영 메시지와 위험 작업을 명시적인 권한 경계 안에서 처리할 수 있게 한다.

## 기능 요구사항

- 운영 설정은 공지와 배너를 조회하고 저장할 수 있다.
- 운영 설정은 이용약관과 개인정보처리방침을 조회하고 저장할 수 있다.
- 콘텐츠 초기화는 확인 흐름 후 실행한다.
- 콘텐츠 초기화는 seed 기준으로 콘텐츠를 재정렬한다.
- seed에 없는 콘텐츠는 보관 상태로 전환한다.
- 콘텐츠 초기화는 seed에 있는 코스, 유닛, 레슨, 스텝을 active로 되돌린다.
- 콘텐츠 초기화 후 새 revision과 변경된 코스, 유닛, 레슨, 스텝, 보관 row 수를 반환한다.

## 화면 요구사항

- 공지와 배너 form, 법적 문서 form, 콘텐츠 초기화 패널을 분리한다.
- 저장과 초기화의 처리 상태를 한국어로 표시한다.
- 콘텐츠 초기화는 위험 작업으로 표현하고 확인 dialog를 제공한다.

## 데이터 요구사항

- 공지와 배너는 학습자에게 노출할 운영 메시지로 저장한다.
- 이용약관과 개인정보처리방침은 운영 설정으로 저장한다.
- 운영 설정은 공지, 배너, 이용약관, 개인정보처리방침을 key-value row로 저장한다.
- 콘텐츠 초기화는 콘텐츠 seed 데이터를 기준으로 수행한다.

## 권한 / 접근 규칙

- 운영 설정 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 공지와 배너 저장, 법적 문서 저장, 콘텐츠 초기화는 소유자 관리자 권한을 요구한다.

## 예외 / 오류

- 설정 조회 실패 시 한국어 오류를 표시한다.
- 저장 실패와 초기화 실패는 처리 상태 메시지로 표시한다.
- 변경 권한이 없는 사용자의 저장 또는 초기화 요청은 거절한다.

## 비범위

- 다국어 설정.
- 결제 정책 관리.
- 사용자별 공지 타기팅.
- seed 편집 UI.

## 확인 방법

- 운영 설정 조회 상태를 확인한다.
- 권한이 있는 계정으로 공지, 배너, 법적 문서 저장을 확인한다.
- 콘텐츠 초기화 확인 dialog와 처리 결과를 확인한다.
