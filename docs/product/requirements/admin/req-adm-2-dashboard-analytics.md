# REQ-ADM-2 운영 지표와 분석

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-2` 제품 상태 조회
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-107` 분석
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 학습자 활동, 가입, 완료, 콘텐츠 상태와 레슨별 성과를 확인해 운영 판단을 할 수 있게 한다.

## 기능 요구사항

- 대시보드는 총 사용자, 최근 7일 활성, 가입, 완료 레슨, 활성 콘텐츠 지표를 제공한다.
- 대시보드는 Kwep 어드민 상단과 동일하게 `총 사용자`, `신규 가입`, `총 레슨 완료`, `콘텐츠` 4개 지표 카드만 제공한다.
- 분석 화면은 최근 30일 가입과 완료 추이를 제공한다.
- 분석 화면은 `0일`, `1-3일`, `4-7일`, `8-14일`, `15일+` 연속 학습일 분포를 제공한다.
- 분석 화면은 완료율이 낮은 레슨 최대 8개를 개선 후보로 제공한다.
- 레슨별 분석은 시작 수, 완료 수, 완료율, 이탈률을 제공한다.
- 조회 기간과 목록 페이지 크기는 상한을 가진다.

## 화면 요구사항

- 대시보드 주요 지표는 빠르게 스캔할 수 있는 카드 구조로 표시한다.
- 대시보드에는 하단 차트와 최근 활동 목록을 표시하지 않는다.
- 분석 추이는 Recharts 기반 차트로 표현할 수 있다.
- 차트는 수치와 추이를 텍스트 또는 표로도 이해할 수 있게 보완한다.
- 레슨별 분석은 표로 제공한다.

## 데이터 요구사항

- 지표는 사용자, 학습 진행, 콘텐츠 상태를 집계한다.
- 삭제 상태의 학습자는 대시보드와 분석 집계에서 제외한다.
- 대시보드와 분석은 실제 저장된 사용자와 학습 진행 데이터를 기준으로 하며, 목 사용자나 난수 시계열을 운영 지표로 사용하지 않는다.
- 레슨별 완료율과 이탈률은 시작과 완료 데이터를 기준으로 계산한다.
- 시작 수는 해당 레슨에 진행 row가 있는 active 학습자 수다.
- 완료율은 시작 수가 0이면 0이고, 아니면 완료 수를 시작 수로 나눈 값을 반올림한다.
- 이탈률은 100에서 완료율을 뺀 값이다.
- 분석 기간은 현재 구현의 허용 범위 안에서 조회한다.

## 권한 / 접근 규칙

- 대시보드와 분석은 관리자 세션이 있는 운영자만 조회할 수 있다.
- 조회성 API는 변경 권한을 요구하지 않는다.

## 예외 / 오류

- 지표 조회 실패 시 한국어 오류를 표시한다.
- 분석 row가 없으면 빈 상태를 표시한다.
- 허용 범위를 넘는 기간 또는 페이지 크기는 잘못된 요청으로 처리한다.

## 비범위

- 외부 BI 연동.
- 사용자 정의 지표.
- 실시간 알림.
- 데이터 내보내기.

## 확인 방법

- 대시보드에서 상단 4개 핵심 지표 카드를 확인한다.
- 분석 화면에서 Recharts 기반 추이 차트와 레슨별 표를 확인한다.
- 허용 범위를 넘는 조회 요청이 거절되는지 확인한다.
