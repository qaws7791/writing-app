# REQ-ADM-2 운영 지표와 분석

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-2` 제품 상태 조회
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-107` 분석
- 관련 사용자:
  - 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 학습자 활동, 가입, 완료, 콘텐츠 상태와 레슨별 성과를 확인해 운영 판단을 할 수 있게 한다.

## 기능 요구사항

- 대시보드는 `총 사용자`, `최근 7일 활성 사용자`, `첫 레슨 시작`, `활성화율`, `7일 내 재방문율`, `완료 레슨` 지표를 제공한다.
- 활성화율과 7일 내 재방문율은 비율만 표시하지 않고 분자·분모와 집계 기준일을 함께 제공한다.
- 분석 화면은 조회 기간의 일별 가입, 첫 레슨 시작, 레슨 완료와 첫 시작 cohort의 7일 내 재방문 추이를 제공한다.
- 분석 화면은 완료율이 낮은 레슨 최대 8개를 개선 후보로 제공한다.
- 레슨별 분석은 시작 수, 완료 수, 완료율, 이탈률을 제공한다.
- 레슨별 분석은 서버에서 검색, 허용된 정렬, 페이지 이동을 처리한다.
- 레슨별 검색, 정렬 방향, 페이지와 페이지 크기는 URL query에 보존한다.
- AI 서비스 품질 분석은 조회 기간의 요청·성공·실패, 실패 code, latency, token과 retry 집계를 제공한다.
- 분석 화면은 조회 기간의 AI 실패율이 높은 현재 레슨을 최대 8개 제공한다.
- 분석 조회 기간과 목록 페이지 크기는 상한을 가진다.

## 화면 요구사항

- 대시보드 주요 지표는 빠르게 스캔할 수 있는 카드 구조로 표시한다.
- 대시보드에는 하단 차트와 최근 활동 목록을 표시하지 않는다.
- 분석 추이는 Recharts 기반 차트로 표현할 수 있다.
- 차트는 수치와 추이를 텍스트 또는 표로도 이해할 수 있게 보완한다.
- AI 실패율 상위 레슨은 요청 수, 실패 수와 실패율을 함께 표시하는 별도 표로 제공한다.
- 레슨별 분석은 표로 제공한다.
- 표 검색·정렬·페이지 이동은 현재 서버 조회 조건을 화면에 명확히 반영한다.

## 데이터 요구사항

- 지표는 사용자, 학습 진행, 콘텐츠 상태를 집계한다.
- 삭제 상태의 학습자는 대시보드, 분석과 AI 품질 집계에서 제외한다.
- 대시보드와 분석은 실제 저장된 사용자와 학습 진행 데이터를 기준으로 하며, 목 사용자나 난수 시계열을 운영 지표로 사용하지 않는다.
- 첫 레슨 시작, 활성화율과 7일 내 재방문의 정의·날짜 경계·성숙 cohort 판정은 `docs/product/metrics.md`를 따른다.
- 일별 재방문은 첫 시작 cohort 날짜에 귀속하며, D7 관찰 기간이 끝나지 않은 cohort는 `0`이 아니라 `immature`와 값 없음으로 표현한다.
- 레슨별 완료율과 이탈률은 시작과 완료 데이터를 기준으로 계산한다.
- 시작 수는 해당 레슨에 진행 row가 있는 active 학습자 수다.
- 완료율은 시작 수가 0이면 0이고, 아니면 완료 수를 시작 수로 나눈 값을 반올림한다.
- 이탈률은 100에서 완료율을 뺀 값이다.
- 레슨별 분석은 현재 활성 코스의 최신 published curriculum에 포함된 active 레슨을 기준으로 한다.
- AI 품질 응답에는 답안, prompt와 피드백 원문을 포함하지 않는다.
- 기간별 AI 품질은 전체 요청·성공·실패·latency·token·retry를 집계한다.
- 레슨별 AI 요청 수는 현재 활성 코스의 최신 published curriculum에 포함된 active 레슨과 같은 `courseId`·`lessonId`에 귀속되고 조회 시작일부터 종료일까지의 `Asia/Seoul` 논리 날짜에 생성된 attempt 수다. 실패 수는 상태가 `failed` 또는 `expired`인 attempt 수이며 실패율은 실패 수를 요청 수로 나눈 백분율을 소수 첫째 자리까지 반올림한다.
- 요청 수가 0이거나 실패 수가 0인 레슨은 AI 실패율 상위 표에 포함하지 않는다. 정렬은 실패율, 실패 수, 요청 수 내림차순 뒤 코스 제목, 레슨 제목, 코스 ID, 레슨 ID 오름차순으로 결정한다.
- 삭제 상태 학습자의 attempt는 전역·레슨별 AI 품질 집계에서 제외하며 active·suspended 학습자는 포함한다.

## 권한 / 접근 규칙

- 대시보드와 분석은 유효한 소유자 관리자 세션이 있어야 조회할 수 있다.

## 예외 / 오류

- 지표 조회 실패 시 한국어 오류를 표시한다.
- 분석 row가 없으면 빈 상태를 표시한다.
- 비율의 분모가 없거나 재방문 cohort가 아직 성숙하지 않았으면 `available`, `empty`, `immature` 상태를 구분한다.
- 허용 범위를 넘는 기간 또는 페이지 크기는 잘못된 요청으로 처리한다.

## 비범위

- 외부 BI 연동.
- 사용자 정의 지표.
- 실시간 알림.
- 데이터 내보내기.

## 확인 방법

- 대시보드에서 6개 핵심 지표와 각 기간·비율 근거를 확인한다.
- 분석 화면에서 일별 4개 추이와 서버 조회 기반 레슨별 표를 확인한다.
- 같은 기간과 실패율 fixture에서 AI 실패율 상위 레슨의 요청 수·실패 수·순서가 결정적으로 계산되는지 확인한다.
- AI 품질 응답과 레슨별 실패율 표에 답안, prompt, 피드백 원문과 학습자 식별 정보가 없는지 확인한다.
- 빈 데이터와 미성숙 cohort가 서로 다른 상태로 표시되는지 확인한다.
- 허용 범위를 넘는 기간·페이지 크기와 허용되지 않은 정렬이 거절되는지 확인한다.
