# REQ-ADM-1 어드민 로그인

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-1` 어드민 로그인
- 관련 화면:
  - `SCR-101` 관리자 로그인
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 학습자 앱과 분리된 관리자 인증으로 어드민 보호 화면에 접근할 수 있게 한다.

## 기능 요구사항

- 어드민 로그인은 관리자 아이디와 패스워드를 사용한다.
- 관리자 아이디는 이메일 주소 형식이다.
- 로그인 성공 시 관리자 세션을 생성한다.
- 로그인 성공 후 안전한 `next` 경로가 있으면 해당 경로로 이동하고, 없으면 어드민 대시보드로 이동한다.
- 세션이 없는 사용자가 어드민 보호 화면에 접근하면 어드민 로그인 화면으로 이동한다.

## 화면 요구사항

- 로그인 화면은 관리자 아이디 입력, 패스워드 입력, 로그인 버튼을 제공한다.
- 인증 실패는 한국어 오류로 표시한다.
- 학습자 로그인과 혼동되지 않는 어드민 화면 톤을 유지한다.

## 데이터 요구사항

- 관리자 계정은 관리자 인증 저장소의 계정 정보로 검증한다.
- 관리자 세션은 어드민 API 접근 권한 확인에 사용된다.

## 권한 / 접근 규칙

- 비로그인 사용자는 어드민 로그인 화면만 접근할 수 있다.
- 로그인한 운영자는 어드민 보호 화면에 접근할 수 있다.
- 변경성 작업은 별도 권한 확인을 따른다.

## 예외 / 오류

- 잘못된 관리자 아이디 또는 패스워드는 인증 실패로 처리한다.
- 안전하지 않은 `next` 경로는 기본 경로로 대체한다.
- 세션 검증 실패 시 보호 화면 접근을 차단한다.

## 비범위

- 학습자 Google 로그인.
- 관리자 계정 생성 UI.
- 비밀번호 재설정.

## 확인 방법

- 어드민 로그인 성공 후 대시보드 이동을 확인한다.
- 인증 실패 시 오류 표시를 확인한다.
- 비로그인 상태에서 보호 화면 접근 시 로그인 화면으로 이동하는지 확인한다.
