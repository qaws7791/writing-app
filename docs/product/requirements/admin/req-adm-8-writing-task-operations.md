# REQ-ADM-8 쓰기 과제 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-8` 쓰기 과제 운영
- 관련 화면:
  - `SCR-110` 쓰기 과제 목록
  - `SCR-111` 쓰기 과제 편집
- 관련 사용자:
  - 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 쓰기 과제를 코스와 나란히 편집하고, 학습자에게 노출할 발행본을 명시적으로 만들 수 있게 한다.

## 기능 요구사항

- 과제 목록은 제목·유형 검색, 도메인 필터, `초안 | 발행됨` 상태 필터를 제공한다.
- 과제 목록은 새 과제 생성 행동을 제공한다.
- 새 과제 생성은 기본 제목을 가진 초안을 만들고 편집 화면으로 이동한다.
- 과제 편집은 제목, 도메인, 유형, 난이도, 상황, 독자, 최소 글자 수, 목표 글자 수, 필수 요소를 초안에 저장한다.
- 도메인은 제품 enum 10개만 허용한다.
- 유형 이름은 관리자가 과제에 붙이는 문자열이다.
- 난이도는 입문, 기본, 심화만 허용한다.
- 필수 요소는 줄마다 한 항목이며 작성 브리프와 점검 비중의 기준이다.
- 저장은 현재 초안만 변경하며 `editVersion`이 일치할 때만 수행한다.
- 학습자 노출 변경은 저장과 분리된 명시적 `발행` 행동으로 수행한다.
- 발행은 현재 초안을 불변 발행본으로 복사한다.
- 이미 시작한 글의 고정 발행본은 이후 저장·발행으로 변경하거나 삭제하지 않는다.

## 화면 요구사항

- 과제 목록은 필터와 표, 새 과제 행동을 제공한다.
- 표 행은 과제 편집 화면으로 이동한다.
- 편집 화면은 초안 저장과 발행을 따로 제공한다.
- 이미 시작한 글은 이 초안을 발행해도 바뀌지 않는다는 안내를 표시한다.
- 편집 가능한 form control은 명확한 label과 오류 메시지를 가진다.

## 데이터 요구사항

- 과제 identity는 초안 필드와 `editVersion`, 최신 발행 참조를 가진다.
- 발행본은 제목, 도메인, 유형, 난이도, 상황, 독자, 최소·목표 글자 수, 필수 요소 배열을 불변 스냅샷으로 가진다.
- 생성, 초안 저장, 발행은 감사 이력에 남긴다. payload에 학습자 본문과 prompt 원문을 넣지 않는다.

## 권한 / 접근 규칙

- 모든 과제 조회와 변경은 유효한 관리자 session만 수행할 수 있다.
- 학습자 API는 발행본만 카탈로그로 제공한다.

## 예외 / 오류

- 저장 충돌은 서버 초안을 덮어쓰지 않고 한국어 충돌 안내를 반환한다.
- 값 집합에 없는 도메인·난이도, 비어 있는 제목, 최소 글자 수가 목표보다 큰 값은 저장과 발행을 거절한다.
- 조회 실패는 빈 목록으로 바꾸지 않는다.

## 비범위

- 관리자 MCP writing-task Tool.
- 과제 보관·복원 흐름.
- 학습자 글 열람.
- 실시간 공동 편집.

## 확인 방법

- 새 과제를 초안으로 저장한 뒤 학습자 카탈로그에 나타나지 않는지 확인한다.
- 발행 뒤 카탈로그에 나타나는지 확인한다.
- 글을 시작한 뒤 과제를 다시 발행해도 시작한 글의 브리프가 바뀌지 않는지 확인한다.
