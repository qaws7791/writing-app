# REQ-ADM-4 사용자 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-4` 사용자 운영
- 관련 화면:
  - `SCR-105` 사용자 관리
  - `SCR-106` 사용자 상세
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 학습자 목록과 상세 상태를 조회하고, 권한이 있는 경우 사용자 상태를 운영 기준에 맞게 변경할 수 있게 한다.

## 기능 요구사항

- 사용자 목록은 이름 또는 이메일 검색을 제공한다.
- 사용자 목록은 상태 필터와 정렬을 제공한다.
- 사용자 목록의 기본 정렬은 최근 접속이다.
- 사용자 목록 정렬은 가입일, 최근 접속, 완료 레슨, 연속 학습일 기준을 제공한다.
- 사용자 목록 화면은 페이지당 12명을 고정으로 표시한다.
- 사용자 목록 화면은 페이지 크기 선택 control을 제공하지 않는다.
- 사용자 상세는 가입일, 최근 접속일, 완료 레슨 수, 전체 진도를 제공한다.
- 사용자 상태 변경은 `active`, `suspended` 전환을 지원한다.
- 상태 변경은 삭제 시각을 비워 계정을 운영 상태로 되돌린다.
- 사용자 삭제 요청 처리는 사용자 상태를 `deleted`로 전환한다.
- 삭제 요청 처리는 삭제 시각을 기록한다.
- 삭제 요청 처리 후 학습 진행과 답변 row는 보존한다.

## 화면 요구사항

- 사용자 목록은 필터 toolbar와 사용자 목록 table을 제공한다.
- 사용자 목록 하단에는 12명 단위 페이지네이션을 제공한다.
- 상태는 pill로 표시한다.
- 상태 변경과 삭제 요청 처리는 처리 상태 메시지를 제공한다.
- 삭제 요청 처리는 확인 dialog를 거친다.

## 데이터 요구사항

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 상태가 없는 기존 프로필은 active 사용자처럼 표시한다.
- `all` 상태 필터는 deleted 사용자를 제외한다.
- 학습 진행과 답변은 사용자 상태와 별도로 보존된다.
- 사용자 상세 지표는 학습 진행 데이터를 기준으로 계산한다.

## 권한 / 접근 규칙

- 사용자 목록과 상세 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 사용자 상태 변경과 삭제 요청 처리는 소유자 관리자 권한을 요구한다.
- 학습자 본인의 API 접근 권한과 어드민 운영 권한은 분리한다.

## 예외 / 오류

- 목록 또는 상세 조회 실패 시 한국어 오류를 표시한다.
- 존재하지 않는 사용자는 not found 상태로 처리한다.
- 허용되지 않는 상태 변경 요청은 거절한다.
- 변경 권한이 없는 사용자의 상태 변경 요청은 거절한다.

## 비범위

- 사용자 완전 삭제.
- 학습 답변 편집.
- 사용자 메시지 발송.
- 관리자에 의한 학습 진행 수정.

## 확인 방법

- 사용자 목록에서 검색, 상태 필터, 정렬을 확인한다.
- 사용자 목록이 페이지당 12명 기준으로 페이지네이션되는지 확인한다.
- 사용자 상세에서 학습 요약을 확인한다.
- 권한이 있는 계정으로 상태 변경과 삭제 요청 처리를 확인한다.
