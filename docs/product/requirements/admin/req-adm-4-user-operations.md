# REQ-ADM-4 사용자 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-4` 사용자 운영
- 관련 화면:
  - `SCR-105` 사용자 관리
  - `SCR-106` 사용자 상세
- 관련 사용자:
  - 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 학습자 목록과 상세 상태를 조회하고 사용자 상태를 운영 기준에 맞게 변경할 수 있게 한다.

## 기능 요구사항

- 사용자 목록은 이름 또는 이메일 검색을 제공한다.
- 사용자 목록은 상태 필터와 정렬을 제공한다.
- 사용자 목록의 기본 정렬은 최근 접속이다.
- 사용자 목록 정렬은 가입일, 최근 접속, 완료 레슨, 연속 학습일 기준을 제공한다.
- 사용자 목록 화면은 페이지당 12명을 고정으로 표시한다.
- 사용자 목록 화면은 페이지 크기 선택 control을 제공하지 않는다.
- 사용자 상세는 가입일, 최근 접속일, 완료 레슨 수, 전체 진도를 제공한다.
- 사용자 상태 변경은 `active → suspended`, `suspended → active` 전환을 지원한다.
- 사용자 삭제 요청 처리는 `active` 또는 `suspended` 사용자를 `deleted`로 전환하고 삭제 시각을 기록한다.
- 삭제 요청 처리는 같은 command에서 해당 학습자의 모든 session을 즉시 폐기한다.
- `deleted`는 종단 상태이며 정리 전에는 관리자 상세 조회만 허용하고 상태 변경과 재삭제를 거부한다.
- 삭제 시각부터 5일 동안 인증·학습·초안·AI 사용자 소유 데이터를 보존한다.
- 삭제 시각이 5일 이상 지난 사용자의 인증·학습·초안·AI 사용자 소유 데이터는 멱등적인 정리 작업으로 삭제하고 콘텐츠 revision은 보존한다.

## 화면 요구사항

- 사용자 목록은 필터 toolbar와 사용자 목록 table을 제공한다.
- 사용자 목록 하단에는 12명 단위 페이지네이션을 제공한다.
- 상태는 pill로 표시한다.
- 상태 변경과 삭제 요청 처리는 처리 상태 메시지를 제공한다.
- 삭제 요청 처리는 확인 dialog를 거친다.

## 데이터 요구사항

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 상태가 없는 기존 프로필은 active 사용자처럼 표시한다.
- `all` 상태 필터는 deleted 사용자를 제외한다.
- deleted 사용자는 5일 보존 기간 동안 관리자 상세에서 조회할 수 있다.
- 학습 진행과 답변은 5일 보존 기간 동안 사용자 상태와 별도로 보존된다.
- 사용자 상세 지표는 학습 진행 데이터를 기준으로 계산한다.

## 권한 / 접근 규칙

- 사용자 목록과 상세 조회는 유효한 소유자 관리자 세션을 요구한다.
- 사용자 상태 변경과 삭제 요청 처리는 owner 권한을 다시 검증한다.
- 학습자 본인의 API 접근 권한과 어드민 운영 권한은 분리한다.

## 예외 / 오류

- 목록 또는 상세 조회 실패 시 한국어 오류를 표시한다.
- 존재하지 않는 사용자는 not found 상태로 처리한다.
- 허용되지 않는 상태 변경 요청은 거절한다.
- deleted 사용자의 상태 변경과 반복 삭제 요청은 거절한다.
- 유효한 owner 권한이 없는 상태 변경 요청은 거절한다.

## 비범위

- 백업 복원 후 외부 삭제 marker 재적용.
- 학습 답변 편집.
- 사용자 메시지 발송.
- 관리자에 의한 학습 진행 수정.

## 확인 방법

- 사용자 목록에서 검색, 상태 필터, 정렬을 확인한다.
- 사용자 목록이 페이지당 12명 기준으로 페이지네이션되는지 확인한다.
- 사용자 상세에서 학습 요약을 확인한다.
- 권한이 있는 계정으로 상태 변경과 삭제 요청 처리를 확인한다.
- 삭제 직후 기존 session이 폐기되고 같은 cookie의 보호 API 접근이 거절되는지 확인한다.
- 삭제 시각 기준 5일 경계에서 사용자 소유 데이터만 삭제되고, 정리 작업을 재실행해도 결과가 유지되며 콘텐츠 revision이 보존되는지 확인한다.
