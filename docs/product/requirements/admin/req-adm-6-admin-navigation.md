# REQ-ADM-6 어드민 내비게이션

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-6` 어드민 주요 메뉴 이동
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-103` 콘텐츠 관리
  - `SCR-105` 사용자 관리
  - `SCR-107` 분석
- 관련 사용자:
  - 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 화면 폭과 관계없이 어드민 콘솔의 주요 업무 화면을 빠르게 이동하고 현재 위치를 확인할 수 있게 한다.

## 기능 요구사항

- 어드민 shell은 사이드바와 본문 영역을 함께 렌더링한다.
- 사이드바는 대시보드, 콘텐츠 관리, 사용자 관리와 분석 링크를 제공한다.
- 브랜드 링크는 어드민 대시보드로 이동한다.
- 현재 화면에 해당하는 메뉴는 활성 상태로 표시한다.
- 데스크톱에서는 고정 사이드바를, 좁은 화면에서는 같은 정보 구조의 drawer를 제공한다.

## 화면 요구사항

- 사이드바는 `글결 관리자` 브랜드와 운영 콘솔 설명을 표시한다.
- 주요 메뉴는 아이콘과 텍스트를 함께 제공한다.
- 현재 메뉴는 `aria-current="page"`로 표시한다.
- drawer trigger와 닫기 행동은 키보드와 보조 기술로 조작할 수 있어야 한다.

## 데이터 요구사항

- 내비게이션은 현재 경로를 기준으로 활성 상태를 판단한다.
- 별도 운영 데이터 조회를 요구하지 않는다.

## 권한 / 접근 규칙

- 어드민 내비게이션은 관리자 세션이 있는 보호 화면 안에서 제공한다.
- 각 메뉴의 조회 또는 변경 권한은 해당 화면 요구사항을 따른다.

## 예외 / 오류

- 하위 경로에 있을 때도 상위 메뉴를 활성 상태로 본다.
- 세션이 없으면 어드민 로그인 흐름으로 이동한다.

## 비범위

- 사용자별 메뉴 커스터마이징.
- 모바일 전용으로 정보 구조가 다른 탭 내비게이션.
- 관리자 계정 관리 메뉴.

## 확인 방법

- 어드민 보호 화면에서 사이드바 링크를 확인한다.
- 콘텐츠 관리 화면 계열에서 콘텐츠 관리 메뉴가 활성 상태인지 확인한다.
- 사이드바 링크가 각 업무 화면으로 이동하는지 확인한다.
