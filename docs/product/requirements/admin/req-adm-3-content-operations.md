# REQ-ADM-3 콘텐츠 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-3` 콘텐츠 운영
- 관련 화면:
  - `SCR-103` 콘텐츠 관리
  - `SCR-104` 코스 미리보기
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 코스 목록과 코스 구성을 확인하고 권한이 있는 경우 생성과 보관 작업을 수행할 수 있게 한다.

## 기능 요구사항

- 코스 목록은 검색, 카테고리 필터, 상태 필터, 페이지 크기를 제공한다.
- 코스 목록 검색은 제목과 설명을 대상으로 한다.
- 코스 목록 페이지 크기 상한은 100이다.
- 코스 목록은 새 코스 생성 행동을 제공한다.
- 새 코스 생성은 기본 코스, 기본 유닛, 기본 레슨, 읽기 스텝, 쓰기 스텝을 포함한 active aggregate를 만든다.
- 코스 보관은 확인 흐름을 거친다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환으로 처리한다.
- 이미 보관된 코스의 보관 요청은 찾을 수 없는 대상처럼 처리한다.
- 코스 상세는 현재 코스 정보, 커리큘럼 맵, 레슨 작업대, 스텝 작업대, 레슨 미리보기를 읽기 전용으로 제공한다.
- 코스 상세는 active 코스, active 유닛, active 레슨, active 스텝만 읽기 전용으로 제공한다.
- 코스 상세는 확정 스텝 타입 10개를 타입별 읽기 전용 폼으로 표시한다.
- 읽기 전용 폼으로 표시하는 확정 스텝 타입은 `READING`, `COMPARE`, `MULTIPLE_CHOICE`, `FILL_BLANK`, `SELECT`, `ORDER`, `WRITE`, `AI_FEEDBACK`, `MATCH`, `CATEGORIZE`다.
- 전용 폼이 없는 스텝 타입은 content JSON을 읽기 전용으로 표시한다.

## 화면 요구사항

- 코스 목록은 필터 toolbar와 코스 목록 table을 제공한다.
- 처리 완료 또는 실패 메시지를 화면에 표시한다.
- 보관 실행은 위험 작업으로 표현한다.
- 코스 미리보기의 입력 요소는 disabled fieldset으로 읽기 전용임을 드러낸다.
- 스텝 미리보기는 학습자 시작 화면과 예상 시간, 스텝 수를 함께 보여준다.

## 데이터 요구사항

- 코스는 제목, 설명, 카테고리, 상태, revision을 가진다.
- 새 코스의 기본값은 제목 `새 강의`, 카테고리 `미분류`, 설명 `강의 설명을 입력하세요.`다.
- 새 레슨의 기본 예상 시간은 5분이다.
- 코스 상세는 유닛, 레슨, 스텝 계층을 포함한다.
- 스텝 content JSON은 객체 구조여야 한다.
- 보관된 코스는 학습자 경로에서 노출되지 않는다.

## 권한 / 접근 규칙

- 코스 목록과 상세 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 새 코스 생성과 코스 보관은 소유자 관리자 권한을 요구한다.

## 예외 / 오류

- 목록 조회 실패 시 한국어 오류를 표시한다.
- 코스 상세 조회 실패 또는 코스 없음은 오류 상태로 표시한다.
- 스텝 content JSON이 객체가 아니면 손상된 데이터로 처리한다.
- 변경 권한이 없는 사용자의 생성 또는 보관 요청은 거절한다.
- 페이지 크기 상한을 넘는 요청은 잘못된 요청으로 처리한다.

## 비범위

- 학습자 코스 검색.
- 공개 코스 마켓.
- 저장형 코스 상세 편집.
- 콘텐츠 완전 삭제.

## 확인 방법

- 코스 목록의 검색과 필터를 확인한다.
- 코스 상세가 읽기 전용으로 표시되는지 확인한다.
- 권한이 있는 계정으로 새 코스 생성과 보관 확인 흐름을 확인한다.
