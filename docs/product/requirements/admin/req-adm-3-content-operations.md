# REQ-ADM-3 콘텐츠 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-3` 콘텐츠 운영
- 관련 화면:
  - `SCR-103` 콘텐츠 관리
  - `SCR-104` 코스 편집
  - `SCR-109` 스텝 디버그
- 관련 사용자:
  - 운영자
- 상태: 기준

## 목적

운영자가 코스 목록과 코스 구성을 확인하고 권한이 있는 경우 콘텐츠 생성, 편집, 보관 작업을 수행할 수 있게 한다.

## 기능 요구사항

- 코스 목록은 검색, 카테고리 필터, 페이지 크기를 제공한다.
- 코스 목록 검색은 제목과 설명을 대상으로 한다.
- 코스 목록 화면의 페이지 크기 선택 옵션은 `10`, `20`, `50`이다.
- 코스 목록 페이지 크기 상한은 100이다.
- 코스 목록은 새 코스 생성 행동을 제공한다.
- 새 코스 생성은 기본 코스 정보만 가진 active 코스를 만든다.
- 새 코스 생성 직후 유닛, 레슨, 스텝 목록은 비어 있다.
- 새 코스의 유닛, 레슨, 스텝은 코스 편집 화면에서 추가한다.
- 코스 보관은 확인 흐름을 거친다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환으로 처리한다.
- 이미 보관된 코스의 보관 요청은 찾을 수 없는 대상처럼 처리한다.
- 코스 편집은 현재 코스 정보, 커리큘럼 맵, 레슨 작업대, 스텝 작업대, 학습자 미리보기를 제공한다.
- 코스 편집은 active 코스, active 유닛, active 레슨, active 스텝을 편집 대상으로 제공한다.
- 코스 정보 편집은 제목, 설명, 카테고리를 대상으로 한다.
- 유닛 편집은 유닛 추가, 제목 수정, 삭제를 제공한다.
- 레슨 편집은 레슨 추가, 삭제, 순서 변경, 제목, 카테고리, 설명, 예상 시간, 요약 수정을 제공한다.
- 스텝 편집은 스텝 추가, 삭제, 순서 변경, 타입별 content 수정을 제공한다.
- 코스 편집은 확정 스텝 타입 10개를 타입별 편집 폼으로 표시한다.
- 타입별 편집 폼으로 표시하는 확정 스텝 타입은 `READING`, `COMPARE`, `MULTIPLE_CHOICE`, `FILL_BLANK`, `SELECT`, `ORDER`, `WRITE`, `AI_FEEDBACK`, `MATCH`, `CATEGORIZE`다.
- 전용 폼이 없는 스텝 타입은 편집 불가 상태와 원본 content JSON 확인 영역을 제공한다.
- 학습자 미리보기는 현재 선택한 레슨 또는 스텝을 학습자 렌더러 기준으로 확인할 수 있게 한다.
- 스텝 디버그 도구는 어드민 내부 QA 라우트에서 확정 스텝 타입의 렌더링, 샘플 데이터, schema 검증 상태를 확인할 수 있게 한다.
- 스텝 디버그 도구는 학습자 앱 라우트에 만들지 않는다.
- 스텝 디버그 도구는 실제 학습 진행, 답변, 콘텐츠 저장 데이터를 변경하지 않는다.
- 저장은 코스 전체 편집 문서를 검증한 뒤 수행한다.
- 저장하지 않은 변경이 있으면 dirty 상태를 표시한다.
- 저장 성공과 저장 실패는 화면 메시지로 표시한다.

## 화면 요구사항

- 코스 목록은 필터 toolbar와 코스 목록 table을 제공한다.
- 페이지 크기 선택은 필터 toolbar 안에서 제공한다.
- 처리 완료 또는 실패 메시지를 화면에 표시한다.
- 보관 실행은 위험 작업으로 표현한다.
- 코스 편집은 `강의 정보`와 `커리큘럼` 단위로 편집 맥락을 분리한다.
- 레슨 작업대는 `레슨 정보`와 `스텝 편집` 단위로 편집 맥락을 분리한다.
- 편집 가능한 form control은 명확한 label과 오류 메시지를 가진다.
- 저장 버튼은 변경 사항이 있을 때 활성 상태를 드러낸다.
- 스텝 추가는 확정 스텝 타입 중 하나를 고르게 한다.
- 학습자 미리보기 dialog는 학습자 시작 화면, 예상 시간, 스텝 수, 현재 스텝 표시를 함께 보여준다.
- 스텝 디버그 화면은 스텝 타입 선택, 렌더러 미리보기, 샘플 data JSON, schema 요약, validation 결과를 분리해 보여준다.
- 스텝 디버그 화면의 schema와 샘플 data 복사 행동은 실제 데이터를 저장하지 않는 보조 행동이다.
- 삭제와 보관 실행은 확인 dialog를 거친다.

## 데이터 요구사항

- 코스는 제목, 설명, 카테고리, 상태, revision을 가진다.
- 새 코스의 기본값은 제목 `새 강의`, 카테고리 `미분류`, 설명 `강의 설명을 입력하세요.`다.
- 코스 상세는 유닛, 레슨, 스텝 계층을 포함한다.
- 스텝 content JSON은 객체 구조여야 한다.
- 보관된 코스는 학습자 경로에서 노출되지 않는다.
- 새 유닛의 기본 제목은 `새 유닛`이다.
- 새 레슨의 기본 제목은 `새 레슨`이다.
- 새 레슨의 기본 예상 시간은 5분이다.
- 새 스텝은 선택한 타입의 최소 유효 content 구조로 생성한다.
- 스텝 디버그 샘플 데이터는 확정 스텝 타입의 최소 유효 content와 대표 content를 구분해 제공할 수 있다.

## 권한 / 접근 규칙

- 코스 목록과 상세 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 코스 편집 화면 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 스텝 디버그 화면 조회는 관리자 세션이 있는 운영자가 수행할 수 있다.
- 새 코스 생성, 코스 보관, 코스 정보 저장, 유닛/레슨/스텝 변경은 소유자 관리자 권한을 요구한다.

## 예외 / 오류

- 목록 조회 실패 시 한국어 오류를 표시한다.
- 코스 상세 조회 실패 또는 코스 없음은 오류 상태로 표시한다.
- 스텝 content JSON이 객체가 아니면 손상된 데이터로 처리한다.
- 스텝 디버그 샘플 data가 schema 검증에 실패하면 저장 없이 검증 오류만 표시한다.
- 저장 검증에 실패하면 필드별 오류와 전체 오류를 한국어로 표시한다.
- 변경 권한이 없는 사용자의 생성, 보관, 저장 요청은 거절한다.
- 페이지 크기 상한을 넘는 요청은 잘못된 요청으로 처리한다.

## 비범위

- 학습자 코스 검색.
- 공개 코스 마켓.
- 실시간 공동 편집.
- 콘텐츠 버전 브랜치.
- 콘텐츠 완전 삭제.
- 학습자 앱의 `/tour` 또는 공개 디버그 페이지.
- 실제 학습자 데이터가 포함된 디버그 fixture.

## 확인 방법

- 코스 목록의 검색, 카테고리 필터, 페이지 크기 선택을 확인한다.
- 코스 목록의 페이지 크기 선택 옵션이 `10`, `20`, `50`인지 확인한다.
- 코스 편집에서 코스 정보, 유닛, 레슨, 스텝을 추가, 수정, 삭제, 순서 변경할 수 있는지 확인한다.
- 코스 편집에서 타입별 스텝 편집 폼과 학습자 미리보기가 동작하는지 확인한다.
- 스텝 디버그 화면에서 확정 스텝 타입별 렌더링, 샘플 data, schema 검증 상태를 확인한다.
- 저장 전 검증, dirty 상태, 저장 성공과 실패 메시지를 확인한다.
- 권한이 있는 계정으로 새 코스 생성과 보관 확인 흐름을 확인한다.
