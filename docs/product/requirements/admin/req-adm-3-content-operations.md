# REQ-ADM-3 콘텐츠 운영

## 문서 정보

- 영역: 어드민
- 출처 유저 스토리:
  - `US-ADM-3` 콘텐츠 운영
- 관련 화면:
  - `SCR-103` 콘텐츠 관리
  - `SCR-104` 코스 편집
- 관련 사용자:
  - 소유자 관리자
- 상태: 기준

## 목적

소유자 관리자가 코스 목록과 코스 구성을 확인하고 콘텐츠 생성, 편집, 보관 작업을 수행할 수 있게 한다.

## 기능 요구사항

- 코스 목록은 강의명 검색과 카테고리·상태 필터, 페이지 크기를 제공한다.
- 강의명 검색은 부분 일치로 좁히며 검색어의 와일드카드 문자를 조건 확장에 사용하지 않는다.
- 검색어는 길이 상한을 가지며 필터·페이지 상태와 함께 URL query에 보존한다.
- 코스 목록 썸네일은 업로드한 코스 표지를 우선 사용하고 없으면 기본 이미지를 사용한다.
- 코스 목록 화면의 페이지 크기 선택 옵션은 `10`, `20`, `50`이다.
- 코스 목록 페이지 크기 상한은 100이다.
- 코스 목록은 새 코스 생성 행동을 제공한다.
- 새 코스 생성은 기본 코스 정보만 가진 active 코스를 만든다.
- 새 코스 생성 직후 유닛, 레슨, 스텝 목록은 비어 있다.
- 새 코스의 유닛, 레슨, 스텝은 코스 편집 화면에서 추가한다.
- 코스 보관은 확인 흐름을 거친다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환으로 처리한다.
- 이미 보관된 코스의 보관 요청은 찾을 수 없는 대상처럼 처리한다.
- 보관된 코스는 보관 해제로 되돌릴 수 있다. 보관 해제는 `active` 상태로 전환하며 published revision과 학습자 고정을 바꾸지 않는다.
- 보관 상태가 아닌 코스의 보관 해제 요청은 찾을 수 없는 대상처럼 처리한다.
- 보관과 보관 해제는 모두 감사 이력에 남는다.
- 코스 편집은 현재 코스 정보, 커리큘럼 맵, 레슨 작업대, 스텝 작업대, 학습자 미리보기를 제공한다.
- 코스 편집은 active 코스, active 유닛, active 레슨, active 스텝을 편집 대상으로 제공한다.
- 코스 정보 편집은 제목, 설명, 카테고리를 대상으로 한다.
- 카테고리 저장은 정해진 값 집합만 허용하고, 값 집합에 없으면 무엇을 해야 하는지 알리는 한국어 메시지로 거절한다.
- 값 집합에 없는 카테고리를 가진 기존 코스의 조회는 막지 않는다. 편집 화면에서 카테고리를 다시 고르면 저장된다.
- 유닛 편집은 유닛 추가, 제목 수정, 삭제를 제공한다.
- 레슨 편집은 레슨 추가, 삭제, 순서 변경, 제목, 카테고리, 설명, 예상 시간, 요약 수정을 제공한다.
- 스텝 편집은 스텝 추가, 삭제, 순서 변경, 타입별 content 수정을 제공한다.
- 코스 편집은 확정 스텝 타입 10개를 타입별 편집 폼으로 표시한다.
- 타입별 편집 폼으로 표시하는 확정 스텝 타입은 `READING`, `COMPARE`, `MULTIPLE_CHOICE`, `FILL_BLANK`, `SELECT`, `ORDER`, `WRITE`, `AI_FEEDBACK`, `MATCH`, `CATEGORIZE`다.
- 전용 폼이 없는 스텝 타입은 편집 불가 상태와 원본 content JSON 확인 영역을 제공한다.
- 학습자 미리보기는 편집 중인 스텝을 학습자 앱과 같은 렌더러로 확인할 수 있게 한다. 답안·채점·AI 호출과 예상 시간은 미리보기 대상이 아니다.
- 코스 편집은 해당 코스에 업로드된 이미지 목록을 종류, 크기, 사용 상태와 함께 보여준다.
- 이미지 사용 상태는 `사용 중`과 `정리 대기`를 구분하고, 정리 대기 이미지는 보존 기간이 지나면 정리 작업이 지운다는 것을 알린다.
- 이미지 목록은 읽기 전용이며 물리 삭제 행동을 제공하지 않는다.
- 저장은 코스 전체 편집 문서를 검증한 뒤 수행한다.
- 저장은 현재 draft만 변경하며 `If-Match` 편집 버전이 일치할 때만 수행한다.
- 학습자 노출 변경은 저장과 분리된 명시적 `초안 발행` 행동으로 수행한다.
- 발행은 빈 유닛·레슨·스텝과 잘못된 step 참조를 거절하고, 성공하면 다음 revision draft를 만든다.
- 이미 발행된 커리큘럼과 기존 학습자의 고정 버전은 이후 저장·발행·보관으로 변경하거나 삭제하지 않는다.
- 저장하지 않은 변경이 있으면 dirty 상태를 표시한다.
- 저장 성공과 저장 실패는 화면 메시지로 표시한다.

## 화면 요구사항

- 코스 목록은 필터 toolbar와 코스 목록 table을 제공한다.
- 페이지 크기 선택은 필터 toolbar 안에서 제공한다.
- 처리 완료 또는 실패 메시지를 화면에 표시한다.
- 보관 실행은 위험 작업으로 표현한다.
- 코스 편집은 `강의 정보`와 `커리큘럼` 단위로 편집 맥락을 분리한다.
- 레슨 작업대는 `레슨 정보`와 `스텝 편집` 단위로 편집 맥락을 분리한다.
- 편집 가능한 form control은 명확한 label과 오류 메시지를 가진다.
- 저장 버튼은 변경 사항이 있을 때 활성 상태를 드러낸다.
- 발행 버튼은 저장되지 않은 변경이 없을 때만 활성화하며 실행 전 확인을 받는다.
- 스텝 추가는 확정 스텝 타입 중 하나를 고르게 한다.
- 학습자 미리보기는 스텝 편집 영역 안에서 접고 펼 수 있으며 읽기 전용이다.
- 업로드한 이미지 목록은 `강의 정보` 안에서 표지 업로드 아래에 배치한다.
- 삭제와 보관 실행은 확인 dialog를 거친다.

## 데이터 요구사항

- 코스 editor 문서는 `curriculumVersionId`, 발행 순서 `revision`, 저장 충돌 검증자 `editVersion`을 구분한다.
- 새 코스의 기본값은 제목 `새 강의`, 카테고리 `미분류`, 설명 `강의 설명을 입력하세요.`다.
- 코스 상세는 유닛, 레슨, 스텝 계층을 포함한다.
- 스텝 content JSON은 객체 구조여야 한다.
- 보관된 코스는 학습자 경로에서 노출되지 않는다.
- 새 유닛의 기본 제목은 `새 유닛`이다.
- 새 레슨의 기본 제목은 `새 레슨`이다.
- 새 레슨의 기본 예상 시간은 5분이다.
- 새 스텝은 선택한 타입의 최소 유효 content 구조로 생성한다.

## 권한 / 접근 규칙

- 코스 목록과 상세 조회, 코스 편집 화면 접근은 유효한 소유자 관리자 세션을 요구한다.
- 새 코스 생성, 코스 보관, 코스 정보 저장, 유닛/레슨/스텝 변경은 owner 권한을 다시 검증한다.

## 예외 / 오류

- 목록 조회 실패 시 한국어 오류를 표시한다.
- 코스 상세 조회 실패 또는 코스 없음은 오류 상태로 표시한다.
- 스텝 content JSON이 객체가 아니면 손상된 데이터로 처리한다.
- 저장 검증에 실패하면 필드별 오류와 전체 오류를 한국어로 표시한다.
- 유효한 owner 권한이 없는 생성, 보관, 저장 요청은 거절한다.
- `If-Match`가 없거나 stale인 저장·발행은 기존 draft를 변경하지 않고 거절한다.
- 페이지 크기 상한을 넘는 요청은 잘못된 요청으로 처리한다.

## 비범위

- 공개 코스 마켓.
- 실시간 공동 편집.
- 콘텐츠 버전 브랜치.
- 콘텐츠 완전 삭제.
- 학습자 앱의 `/tour` 또는 공개 디버그 페이지.
- 실제 학습자 데이터가 포함된 디버그 fixture.

## 확인 방법

- 코스 목록의 강의명 검색, 카테고리와 상태 필터, 페이지 크기 선택을 확인한다.
- 검색어에 `%`를 넣어도 전체 목록이 반환되지 않는지 확인한다.
- 코스 목록의 페이지 크기 선택 옵션이 `10`, `20`, `50`인지 확인한다.
- 코스 편집에서 코스 정보, 유닛, 레슨, 스텝을 추가, 수정, 삭제, 순서 변경할 수 있는지 확인한다.
- 코스 편집에서 타입별 스텝 편집 폼과 학습자 미리보기가 동작하는지 확인한다.
- 미리보기가 학습자 화면과 같은 렌더러를 쓰고 채점 상태를 노출하지 않는지 확인한다.
- 표지를 교체한 뒤 강의 정보의 이미지 목록에서 이전 이미지가 `정리 대기`로 보이는지 확인한다.
- 값 집합에 없는 카테고리로 저장하면 거절되고, 같은 코스의 조회는 계속 성공하는지 확인한다.
- 저장 전 검증, dirty 상태, 저장 성공과 실패 메시지를 확인한다.
- 저장 뒤 발행하면 기존 revision이 학습자에게 노출되고 동일 내용의 다음 revision draft가 생성되는지 확인한다.
- 권한이 있는 계정으로 새 코스 생성과 보관 확인 흐름을 확인한다.
