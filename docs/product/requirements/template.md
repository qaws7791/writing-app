# REQ-XXX-N 제목

## 문서 정보

- 영역: 플랫폼 또는 어드민
- 출처 유저 스토리:
  - `US-XXX-N`
- 관련 화면:
  - `SCR-N`
- 관련 사용자:
  - 사용자명
- 상태: 초안

## 목적

요구사항이 해결하는 사용자 목표와 제품 목적을 한두 문장으로 적는다.

## 기능 요구사항

- 구현해야 하는 제품 규칙을 적는다.
- 사용자가 관찰할 수 있는 동작 중심으로 적는다.

## 화면 요구사항

- 화면에서 보여야 하는 핵심 요소와 상태를 적는다.

## 데이터 요구사항

- 저장하거나 조회해야 하는 데이터의 의미를 적는다.
- 실제 테이블, 함수, DTO 세부 구현은 필요한 경우에만 링크한다.

## 권한 / 접근 규칙

- 접근 가능한 사용자와 차단 조건을 적는다.

## 예외 / 오류

- 실패, 빈 상태, 잘못된 요청의 사용자 노출 기준을 적는다.

## 비범위

- 이 요구사항에서 다루지 않는 일을 적는다.

## 확인 방법

- 구현 후 확인할 수 있는 대표 시나리오를 적는다.
