# REQ-LRN-4 레슨 진행

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-5` 레슨 스텝 완료
- 관련 화면:
  - `SCR-006` 레슨 진행
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 하나의 레슨을 시작하고 step 기반 활동을 순서대로 진행한 뒤 완료 상태를 저장할 수 있게 한다.

## 기능 요구사항

- 레슨 화면은 `lesson_id` query로 레슨을 연다.
- `lesson_id`가 없으면 코스에서 레슨을 선택하라는 안내를 보여준다.
- 시작 화면은 제목, 카테고리, 설명, 예상 시간, 스텝 수를 표시한다.
- 학습자가 시작하면 레슨 시작 상태를 저장한다.
- 저장된 진행 단계가 있으면 시작 화면 없이 해당 스텝에서 재개한다.
- 진행 단계 저장은 현재 스텝 index를 갱신하되 기존 완료 상태를 진행 중으로 되돌리지 않는다.
- 스텝은 정해진 순서대로 진행한다.
- 마지막 스텝 이후 레슨 완료 상태를 저장한다.
- 완료 저장은 최신 답변 저장이 끝난 뒤 한 번만 실행한다.
- 완료 저장이 반복 호출되어도 최초 완료 시각과 완료 카운트는 중복 증가하지 않는다.
- 완료 화면은 레슨 요약이 있으면 핵심 요약을 표시한다.
- 완료 화면은 다음 레슨 또는 코스로 돌아가기 행동을 제공한다.
- 완료 화면에서 다음 레슨을 선택하면 같은 `/app/lesson` 경로의 soft navigation이어도 이전 레슨 세션 상태를 이어받지 않고 다음 레슨을 새로 연다.

## 화면 요구사항

- 레슨 화면은 몰입형 전체 화면으로 제공한다.
- 상단 진행 헤더와 하단 주요 행동 영역은 고정한다.
- 중앙 콘텐츠 영역만 스크롤된다.
- 진행률은 시각 요소와 텍스트 또는 ARIA 값으로 함께 제공한다.
- 완료 화면의 핵심 요약은 `이번 레슨 핵심 요약` 제목 아래 목록으로 표시한다.
- 레슨 요약이 비어 있으면 핵심 요약 영역을 표시하지 않는다.

## 데이터 요구사항

- 레슨 시작과 완료는 사용자와 레슨 기준으로 저장한다.
- 레슨 시작 마커는 첫 읽기 스텝의 `lesson-started` 답변으로 저장할 수 있다.
- 레슨 시작 마커는 레슨의 첫 스텝에 대해서만 유효하다.
- 레슨 스텝은 콘텐츠 모델의 확정 스텝 타입을 따른다.
- 레슨 요약은 문자열 배열이며 완료 화면의 핵심 요약 목록으로 사용할 수 있다.
- 완료 후 코스 진행률에 반영되어야 한다.
- 레슨 진행, 답변 저장, 완료 저장은 같은 날짜의 학습 활동 row를 누적 갱신한다.

## 권한 / 접근 규칙

- 레슨 조회와 진행 저장은 로그인한 학습자만 수행할 수 있다.
- 현재 사용자의 진행 데이터만 변경할 수 있다.

## 예외 / 오류

- 레슨 조회 실패 시 한국어 오류를 표시한다.
- 시작 저장 실패 시 사용자가 다시 시도할 수 있어야 한다.
- 늦게 실패한 이전 답변 저장은 최신 성공 상태를 덮어쓰지 않는다.
- 이전 스텝의 답변 저장 실패는 다음 스텝에 표시하지 않는다.
- 완료 저장 실패 시 완료 상태로 확정하지 않는다.
- 나가기 행동은 확인 흐름을 거친다.

## 비범위

- 레슨 순서 변경.
- 오프라인 저장.
- 레슨 중 자유 노트.

## 확인 방법

- `lesson_id` 없이 레슨 화면에 접근해 안내 상태를 확인한다.
- 레슨 시작 후 스텝 진행과 완료 저장을 확인한다.
- 레슨 요약이 있는 완료 화면에서 핵심 요약 목록이 표시되는지 확인한다.
- 레슨 요약이 없는 완료 화면에서 핵심 요약 영역이 표시되지 않는지 확인한다.
- 완료 화면에서 다음 레슨 또는 코스 이동을 확인한다.
- 완료 화면에서 다음 레슨으로 이동한 뒤 시작 화면(또는 이어하기 스텝)이 열리는지 확인하고, 이전 완료 화면이 유지되지 않는지 확인한다.
