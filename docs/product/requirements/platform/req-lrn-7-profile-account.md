# REQ-LRN-7 프로필과 계정 관리

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-8` 프로필 확인과 계정 관리
- 관련 화면:
  - `SCR-007` 프로필
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 자신의 계정 정보와 학습 요약을 확인하고 테마와 로그아웃을 관리할 수 있게 한다.

## 기능 요구사항

- 프로필은 이름, 가입일, 완료한 레슨, 연속 학습일을 표시한다.
- 테마는 라이트, 다크, 시스템 옵션을 제공한다.
- 로그아웃 행동을 제공한다.
- 로그아웃 후 공개 화면으로 이동한다.

## 화면 요구사항

- 학습 요약은 완료한 레슨과 연속 학습일을 명확히 구분한다.
- 테마 선택은 현재 선택 상태를 표시한다.
- 로그아웃은 일반 학습 행동과 구분되는 낮은 위험 표현을 사용한다.

## 데이터 요구사항

- 프로필 조회는 사용자 계정과 학습 진행 요약을 결합한다.
- 가입일은 사용자 계정 기준으로 표시한다.
- 완료한 레슨 수는 완료 상태의 레슨 진행 row를 기준으로 계산한다.
- 전체 레슨 수는 active 레슨 수를 기준으로 계산한다.
- 최근 활동일과 연속 학습일은 학습 활동일을 기준으로 계산한다.
- 전체 진도율은 전체 active 레슨 대비 완료 레슨 비율로 계산한다.
- 테마 선택은 클라이언트 화면 환경에 반영된다.

## 권한 / 접근 규칙

- 프로필은 로그인한 학습자만 접근할 수 있다.
- 학습자는 자신의 프로필만 조회할 수 있다.

## 예외 / 오류

- 프로필 조회 실패 시 한국어 오류를 표시한다.
- 로그아웃 실패 시 사용자가 상태를 이해할 수 있게 표시한다.

## 비범위

- 이름 수정.
- 계정 탈퇴.
- 알림 설정.
- 학습 데이터 다운로드.

## 확인 방법

- 로그인한 상태에서 프로필 화면을 확인한다.
- 테마 변경 상태를 확인한다.
- 로그아웃 후 공개 화면으로 이동하는지 확인한다.
