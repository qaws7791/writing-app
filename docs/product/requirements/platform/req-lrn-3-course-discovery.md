# REQ-LRN-3 코스 탐색과 시작

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-3` 첫 코스 선택
  - `US-LRN-4` 코스 상세 확인
- 관련 화면:
  - `SCR-003` 학습 홈
  - `SCR-004` 코스 목록
  - `SCR-005` 코스 상세
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 관심 카테고리의 active 코스를 찾고, 코스 상세에서 첫 레슨 또는 다음 레슨을 시작할 수 있게 한다.

## 기능 요구사항

- 코스 목록은 학습자에게 active 코스만 노출한다.
- 코스 목록은 카테고리 탭으로 필터링할 수 있다.
- 코스 목록은 코스 제목, 설명, 카테고리를 대상으로 실시간 검색(디바운스 적용)을 할 수 있다.
- 코스 목록은 사용자 선택 정렬을 제공하지 않고 콘텐츠의 추천 순서를 유지한다.
- 코스 카드는 제목, 설명, 레슨 수, 이미지를 표시한다.
- 코스 상세는 제목, 설명, 진행률, 완료 수, 전체 레슨 수를 표시한다.
- 코스 상세는 첫 레슨 또는 다음 레슨 시작 행동을 제공한다.
- 유닛별 레슨 목록은 완료 여부와 이어서 학습할 위치를 구분한다.
- 모든 active 레슨은 잠금 없이 접근 가능하다.

## 화면 요구사항

- 코스 목록은 카테고리 선택 상태와 코스 없음 상태를 표현한다.
- 검색창은 kwep 스타일의 배경 없는 바닥 배치의 둥근 인풋 디자인이며, 'X' 아이콘으로 즉시 검색어를 초기화할 수 있다.
- 코스 상세는 뒤로가기, 코스 이미지, 진행률, 커리큘럼 목록을 포함한다.
- 레슨 상태는 색상만으로 의미를 전달하지 않는다.

## 데이터 요구사항

- 콘텐츠는 코스, 유닛, 레슨, 스텝 계층으로 조회된다.
- 코스와 레슨은 active 상태일 때 학습자 경로에 노출된다.
- 코스 상세 진행률은 현재 사용자 진행 데이터와 결합해 계산한다.

## 권한 / 접근 규칙

- 코스 목록과 상세는 로그인한 학습자만 접근할 수 있다.
- archived 코스와 레슨은 학습자 경로에서 숨긴다.

## 예외 / 오류

- 코스 목록 조회 실패 시 한국어 오류를 표시한다.
- 코스 목록 결과가 비어 있으면 현재 화면 기준 코스 카드를 대체 표시한다.
- 코스 상세에서 코스를 찾지 못하면 not found 상태를 표시한다.
- 진행 조회 실패는 코스 상세 오류 상태로 표시한다.

## 비범위

- 공개 코스 마켓.
- 결제와 수강 신청.
- 커리큘럼 버전 선택.

## 확인 방법

- 코스 목록에서 카테고리 필터를 선택한다.
- 코스 목록 검색창에 키워드를 입력하고 300ms 후 실시간으로 목록이 디바운스 필터링되는지 확인한다.
- 검색창 우측 'X' 버튼을 눌러 검색어가 즉시 지워지는지 확인한다.
- 코스 상세에서 진행률과 유닛별 레슨 상태를 확인한다.
- active 레슨을 선택해 레슨 화면으로 이동하는지 확인한다.
