# REQ-LRN-5 쓰기 답변

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-6` 쓰기 답변 제출
- 관련 화면:
  - `SCR-006` 레슨 진행
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 답변 가능한 레슨 스텝에서 쓰기 답변을 저장하고 이후 레슨 흐름과 AI 코칭에서 사용할 수 있게 한다.

## 기능 요구사항

- 답변 가능한 스텝은 답변 입력과 저장 행동을 제공한다.
- 쓰기 스텝은 최소 글자 수와 필요한 경우 목표 글자 수를 표시한다.
- 답변 저장은 사용자, 레슨, 스텝 기준으로 처리한다.
- 저장된 답변은 같은 레슨 흐름에서 다시 사용할 수 있다.
- 공백만 있는 쓰기 답변은 유효한 답변으로 저장하지 않는다.
- 답변 저장 결과는 사용자에게 이해 가능한 상태로 표시한다.

## 화면 요구사항

- 입력 영역은 학습자가 작성 중인 답변을 명확히 볼 수 있어야 한다.
- 최소 글자 수 기준은 입력 행동 근처에서 확인 가능해야 한다.
- 저장 실패는 레슨 흐름 안에서 한국어 오류로 표시한다.

## 데이터 요구사항

- 답변은 사용자, 레슨, 스텝 기준으로 저장한다.
- 답변 가능한 스텝 타입과 답변 불가능한 스텝 타입을 구분한다.
- 저장된 답변은 AI 피드백 요청의 입력으로 사용할 수 있다.

## 권한 / 접근 규칙

- 답변 저장은 로그인한 학습자만 수행할 수 있다.
- 학습자는 자신의 답변만 저장하거나 조회할 수 있다.

## 예외 / 오류

- 답변 저장 실패 시 사용자가 다시 시도할 수 있게 오류를 표시한다.
- 답변 불가능한 스텝에 대한 저장 요청은 거절한다.
- 유효하지 않은 레슨 또는 스텝에 대한 저장 요청은 실패로 처리한다.

## 비범위

- 독립 저널.
- 답변 공개 공유.
- 파일 첨부.
- 답변 버전 히스토리 화면.

## 확인 방법

- 쓰기 스텝에서 최소 글자 수 안내를 확인한다.
- 답변 저장 성공 후 같은 레슨 흐름에서 답변이 유지되는지 확인한다.
- 저장 실패 상태에서 오류 표시를 확인한다.
