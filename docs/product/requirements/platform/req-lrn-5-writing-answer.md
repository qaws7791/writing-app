# REQ-LRN-5 쓰기 답변

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-6` 쓰기 답변 제출
- 관련 화면:
  - `SCR-006` 레슨 진행
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 답변 가능한 레슨 스텝에서 쓰기 답변을 저장하고 이후 레슨 흐름과 AI 코칭에서 사용할 수 있게 한다.

## 기능 요구사항

- 답변 가능한 스텝은 답변 입력과 확인 행동을 제공한다.
- 쓰기 스텝은 최소 글자 수와 필요한 경우 목표 글자 수, 최대 글자 수를 표시한다.
- 쓰기 스텝은 제목, 프롬프트, 안내, 맥락, 주제, 보조 라벨을 표시할 수 있다.
- 쓰기 스텝은 참고 원문, 구조 가이드, 대상 주장, 참조 답안을 표시할 수 있다.
- 구조 가이드는 안전한 CommonMark로 목록과 강조를 표시하고, 일반 여러 줄 텍스트의 줄바꿈도 보존한다.
- 쓰기 스텝은 `counter` 모드에서 반박 쓰기 맥락을 제공한다.
- 쓰기 스텝은 `self-rebut` 모드에서 자기반박 맥락을 제공한다.
- 답변 가능한 현재 스텝은 별도 수동 저장 버튼 없이 입력 변경을 서버 드래프트로 자동 저장한다.
- 답변 가능한 현재 스텝의 드래프트는 제출 전 서버에 저장하며 학습자, 코스, 커리큘럼 revision, 레슨, 스텝별로 격리한다.
- 드래프트 저장은 서버가 반환한 version을 다음 요청의 expected version으로 사용한다. 충돌한 저장은 기존 서버 값을 덮어쓰지 않는다.
- 레슨 조회와 시작 결과는 현재 커리큘럼 revision의 서버 드래프트를 포함한다.
- 답변 저장은 사용자, 레슨, 스텝 기준으로 처리한다.
- 답변 제출 성공 시 답변 저장과 같은 스텝의 드래프트 삭제를 하나의 처리로 확정한다.
- 저장된 답변은 같은 레슨 흐름에서 다시 사용할 수 있다.
- 공백만 있는 쓰기 답변은 유효한 답변으로 저장하지 않는다.
- 드래프트 저장 결과는 레슨 화면에 표시하지 않는다.

## 화면 요구사항

- 입력 영역은 학습자가 작성 중인 답변을 명확히 볼 수 있어야 한다.
- 제목, 보조 라벨, 대상 주장, 안내, 참고 원문, 구조 가이드는 입력 영역보다 앞에서 확인 가능해야 한다.
- 최소, 목표, 최대 글자 수 기준은 입력 행동 근처에서 확인 가능해야 한다.
- 참조 답안은 답변 확인 뒤 표시할 수 있다.
- 답변 확인 실패는 레슨 흐름 안에서 작성한 내용과 다음 행동을 설명하는 한국어 오류로 표시한다.
- 저장, 동기화, 오프라인, version과 충돌 상태는 입력 영역을 포함한 레슨 화면에 표시하지 않는다.

## 데이터 요구사항

- 답변은 사용자, 레슨, 스텝 기준으로 저장한다.
- 드래프트는 사용자, 코스, 커리큘럼 revision, 레슨, 스텝 기준으로 한 건만 저장하고 음수가 아닌 version을 가진다.
- 답변 가능한 스텝 타입과 답변 불가능한 스텝 타입을 구분한다.
- 저장된 답변은 AI 피드백 요청의 입력으로 사용할 수 있다.
- 쓰기 스텝 content는 `title`, `guide`, `min`, `goal`, `max`, `badge`, `claim`, `context`, `mode`, `placeholder`, `prompt`, `reference`, `sample`, `structure`, `topic`, `draft` 필드를 사용할 수 있다.
- `min`은 필수 숫자 기준이다.
- `goal`, `max`는 선택 숫자 기준이다.
- `draft`는 선택 boolean 기준이다.
- 나머지 쓰기 스텝 필드는 선택 문자열 기준이다.
- 현재 웹 표시 보조 타입에는 `claimLabel`이 있으나, API 콘텐츠 계약 필드는 아니다.

## 권한 / 접근 규칙

- 답변 저장은 로그인한 학습자만 수행할 수 있다.
- 학습자는 자신의 답변만 저장하거나 조회할 수 있다.

## 예외 / 오류

- 답변 확인 실패 시 사용자가 작성한 내용을 유지하고 다시 시도할 수 있게 오류를 표시한다.
- 드래프트 expected version이 현재 서버 version과 다르면 충돌로 처리하고 기존 드래프트를 보존한다.
- 잠긴 레슨, 현재 학습 순서가 아닌 스텝 또는 다른 커리큘럼 revision의 드래프트 저장은 거절한다.
- 답변 불가능한 스텝에 대한 저장 요청은 거절한다.
- 유효하지 않은 레슨 또는 스텝에 대한 저장 요청은 실패로 처리한다.
- `mode` 값이 `counter` 또는 `self-rebut`이 아니면 일반 쓰기 활동처럼 처리한다.

## 비범위

- 독립 저널.
- 답변 공개 공유.
- 파일 첨부.
- 답변 버전 히스토리 화면.

## 확인 방법

- 쓰기 스텝에서 최소 글자 수 안내를 확인한다.
- 쓰기 스텝에서 반박 쓰기와 자기반박 모드의 보조 라벨, 대상 주장, placeholder가 올바르게 표시되는지 확인한다.
- 쓰기 스텝에서 참고 원문, 구조 가이드와 참조 답안이 조건에 맞게 표시되는지 확인한다.
- 구조 가이드의 CommonMark 목록과 강조, 일반 여러 줄 텍스트의 줄바꿈이 올바르게 표시되는지 확인한다.
- 답변 저장 성공 후 같은 레슨 흐름에서 답변이 유지되는지 확인한다.
- 레슨 재진입과 다른 기기 조회에서 서버 드래프트를 복구하고, stale version 저장이 기존 드래프트를 바꾸지 않는지 확인한다.
- 답변 제출 성공 뒤 같은 스텝의 드래프트가 남지 않는지 확인한다.
- 답변 확인 실패 상태에서 작성한 내용과 재시도 안내가 표시되는지 확인한다.
- 레슨 화면에 저장, 동기화, 오프라인, version과 충돌 상태가 표시되지 않는지 확인한다.
