# REQ-LRN-1 Google 로그인

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-1` Google 로그인
- 관련 화면:
  - `SCR-002` 학습자 로그인
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 Google 계정으로 로그인하여 학습 진행 상태를 자신의 계정에 연결할 수 있게 한다.

## 기능 요구사항

- 학습자 로그인은 Google 로그인을 단일 진입점으로 제공한다.
- 이메일과 비밀번호 가입 또는 로그인은 제공하지 않는다.
- 로그인 성공 시 학습자 세션을 생성한다.
- 세션에 연결된 학습자 프로필이 없으면 active 프로필을 한 번 생성한다.
- 기존 학습자 프로필 상태는 세션 해석 중 active로 되돌리지 않는다.
- 로그인 성공 후 안전한 `next` 경로가 있으면 해당 경로로 이동하고, 없으면 `/app`으로 이동한다.
- 세션이 없는 사용자가 학습자 보호 화면에 접근하면 `/login?next=...`로 이동한다.

## 화면 요구사항

- 로그인 화면은 Google 로그인 행동을 명확하게 보여야 한다.
- 이메일과 비밀번호 가입을 지원하지 않는다는 안내를 제공한다.
- 인증 실패는 한국어 오류로 표시한다.

## 데이터 요구사항

- 사용자 계정은 Google 계정 식별자와 연결된다.
- 학습자 프로필은 사용자 계정과 1:1로 연결된다.
- 학습자 프로필 상태는 `active`, `suspended`, `deleted`를 가진다.
- 학습 진행 데이터는 사용자 계정 기준으로 조회 가능해야 한다.

## 권한 / 접근 규칙

- 비로그인 사용자는 공개 화면과 로그인 화면만 접근할 수 있다.
- 로그인한 학습자는 학습자 보호 화면에 접근할 수 있다.
- 정지 또는 삭제 상태의 사용자는 보호 API에서 차단된다.

## 예외 / 오류

- Google 인증 실패 시 로그인 화면에 머무르며 오류를 표시한다.
- 세션 생성 실패 시 보호 화면으로 이동하지 않는다.
- 안전하지 않은 `next` 경로는 기본 경로로 대체한다.

## 비범위

- 이메일과 비밀번호 인증.
- 관리자 인증.
- 복수 소셜 로그인 제공자.

## 확인 방법

- 비로그인 상태에서 `/login`을 확인한다.
- Google 로그인 성공 후 보호 화면 접근을 확인한다.
- 비로그인 상태에서 `/app` 접근 시 로그인 화면으로 이동하는지 확인한다.
