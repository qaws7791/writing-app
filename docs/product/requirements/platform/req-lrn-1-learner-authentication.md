# REQ-LRN-1 학습자 인증

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-1` 학습자 인증
- 관련 화면:
  - `SCR-002` 학습자 로그인
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 Google 계정 또는 확인된 이메일 계정으로 로그인하여 학습 진행 상태를 자신의 계정에 연결할 수 있게 한다.

## 기능 요구사항

- 학습자 인증은 Google 로그인과 이메일/비밀번호 가입·로그인을 제공한다.
- 이메일 가입은 확인 메일을 발송하고, 확인이 끝날 때까지 세션을 생성하지 않는다.
- 확인 메일 재전송은 계정 존재 여부를 노출하지 않으며 남용 방지 제한을 적용한다.
- 중복 이메일 가입은 기존 계정 존재 여부를 구분할 수 없는 동일한 완료 안내를 반환한다.
- 비밀번호 재설정 요청은 계정 존재 여부와 메일 전달 결과를 구분하지 않는 동일한 완료 안내를 반환한다.
- 비밀번호 재설정 링크는 제한된 시간 동안 한 번만 사용할 수 있고, 변경이 끝나면 기존 학습자 세션을 모두 폐기한다.
- 확인된 동일 이메일의 Google 계정과 credential 계정은 기존 사용자에 연결하여 학습 진행 데이터를 유지한다.
- 비밀번호는 서버의 최소 길이 정책을 통과해야 한다.
- 로그인 성공 시 학습자 세션을 생성한다.
- 세션에 연결된 학습자 프로필이 없으면 active 프로필을 한 번 생성한다.
- 기존 학습자 프로필 상태는 세션 해석 중 active로 되돌리지 않는다.
- 로그인 성공 후 안전한 원래 목적 화면이 있으면 그 화면으로 이동하고, 없으면 학습 홈으로 이동한다.
- 세션이 없는 사용자가 학습자 보호 화면에 접근하면 로그인 화면으로 이동하고 원래 목적 화면을 보존한다.

## 화면 요구사항

- 로그인 화면은 이메일 로그인·가입과 Google 로그인 행동을 명확하게 구분한다.
- 가입 완료, 이메일 확인 성공·실패와 재전송 결과를 한국어로 안내한다.
- 비밀번호 재설정 요청과 새 비밀번호 입력·완료 화면을 제공한다.
- 잘못된 로그인 정보, 확인 전 계정, 약한 비밀번호, 과도한 재전송과 메일 전달 실패를 원문 provider 메시지 없이 한국어로 표시한다.
- Google 계정 연결 실패와 만료·사용 완료된 재설정 링크는 내부 원인을 노출하지 않는 일반화된 한국어 안내로 표시한다.

## 데이터 요구사항

- 사용자 계정은 Google 또는 credential 계정 식별자와 연결된다.
- 같은 검증 이메일의 Google·credential 식별자는 하나의 사용자 계정에 연결된다.
- 학습자 프로필은 사용자 계정과 1:1로 연결된다.
- 학습자 프로필 상태는 `active`, `suspended`, `deleted`를 가진다.
- 학습 진행 데이터는 사용자 계정 기준으로 조회 가능해야 한다.

## 권한 / 접근 규칙

- 비로그인 사용자는 공개 화면과 로그인 화면만 접근할 수 있다.
- 이메일이 확인된 로그인 학습자는 학습자 보호 화면에 접근할 수 있다.
- 확인되지 않은 이메일 계정의 session은 보호 API identity로 인정하지 않는다.
- 정지 또는 삭제 상태의 사용자는 보호 API에서 차단된다.

## 예외 / 오류

- Google 또는 이메일 인증 실패 시 로그인 화면에 머무르며 오류를 표시한다.
- 만료되거나 잘못된 확인 링크는 로그인 화면에서 재시도 가능한 상태로 표시한다.
- 만료되거나 이미 사용한 비밀번호 재설정 링크는 새 비밀번호를 변경할 수 없는 상태로 표시한다.
- 세션 생성 실패 시 보호 화면으로 이동하지 않는다.
- 안전하지 않은 `next` 경로는 기본 경로로 대체한다.

## 비범위

- 관리자 인증.
- 복수 소셜 로그인 제공자.

## 확인 방법

- 비로그인 상태에서 학습자 로그인 화면을 확인한다.
- Google 로그인 성공 후 보호 화면 접근을 확인한다.
- 이메일 가입, 확인 전 차단, 확인 링크 처리와 로그인 후 보호 화면 접근을 확인한다.
- 확인 메일 재전송 제한과 중복 가입의 비식별 응답을 확인한다.
- 존재·비존재 이메일의 비밀번호 재설정 요청 응답이 같고 token 재사용이 거절되는지 확인한다.
- 비밀번호 변경 후 기존 session이 거절되고 새 비밀번호로 로그인할 수 있는지 확인한다.
- 동일한 검증 이메일의 Google 로그인 후 사용자 ID와 기존 학습 데이터가 유지되는지 확인한다.
- 비로그인 상태에서 학습자 보호 화면 접근 시 로그인 화면으로 이동하는지 확인한다.
