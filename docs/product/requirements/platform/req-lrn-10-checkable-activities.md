# REQ-LRN-10 정답 확인형 활동

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-11` 정답 확인형 활동 풀이
- 관련 화면:
  - `SCR-006` 레슨 진행
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 답이 있는 레슨 활동을 직접 조작하고, 정답 또는 오답 피드백을 통해 글쓰기 개념을 확인할 수 있게 한다.

## 기능 요구사항

- 객관식 활동은 하나의 선택지를 선택해 답변 payload로 전달한다.
- 빈칸 활동은 단어를 선택해 정해진 개수의 답변을 만든다.
- 구간 선택 활동은 하나 이상의 문장 구간 index를 선택한다.
- 구간 선택 활동은 `inline` 또는 `block` layout으로 표시할 수 있다.
- 순서 활동은 현재 항목을 중복 없이 순서대로 배열한다.
- 순서 활동은 드래그 핸들로 항목을 재정렬할 수 있게 한다.
- 순서 활동은 키보드 사용자를 위해 항목별 위로 이동, 아래로 이동 행동을 제공한다.
- 순서 활동의 초기 항목은 스텝과 항목을 seed로 결정적으로 섞으며, 항목이 둘 이상이면 정답 순서로 시작하지 않는다. SSR과 hydration은 같은 초기 순서를 사용한다.
- 매칭 활동은 왼쪽 항목과 오른쪽 항목의 pair를 만든다.
- 매칭 활동의 오른쪽 선택지는 콘텐츠 문자열을 seed로 사용해 결정적으로 섞는다.
- 매칭 활동에서 하나의 오른쪽 선택지는 한 왼쪽 항목에만 연결된다.
- 같은 pair를 다시 선택하면 해당 연결을 해제한다.
- 분류 활동은 모든 항목을 카테고리에 배치해야 제출 가능하다.
- 확인 가능한 스텝은 확인 후 정답, 오답, 해설 상태를 제공한다.
- 읽기와 비교 스텝은 정답 확인형 답변 저장 대상으로 보지 않는다.
- 정답 확인형 활동 타입은 `MULTIPLE_CHOICE`, `FILL_BLANK`, `SELECT`, `ORDER`, `MATCH`, `CATEGORIZE`다.
- 정답 확인 없이 진행하는 스텝 타입은 `READING`, `COMPARE`다.

## 화면 요구사항

- 각 활동은 타입에 맞는 조작 UI를 제공한다.
- 클릭·터치 가능한 선택 타일과 칩은 작은 그림자로 조작 가능함을 드러낸다.
- 확인 전에는 선택 상태만 표시하고 정답 문구를 노출하지 않는다.
- 확인 후에는 정답 또는 오답 상태를 시각적으로 구분한다.
- 구간 선택 활동은 놓친 구간과 잘못 선택한 구간을 구분할 수 있어야 한다.
- `inline` 구간 선택은 문장 흐름 안에서 구간을 이어 보여주고 선택 상태를 표시한다.
- `block` 구간 선택은 각 구간을 독립된 행 또는 블록으로 보여주고 선택 상태를 표시한다.
- 순서 활동의 드래그 핸들과 위/아래 이동 행동은 항목 텍스트와 현재 위치를 구분할 수 있는 접근성 이름을 가진다.
- 확인 후 순서 활동은 재정렬 조작을 잠그고 피드백 상태를 보여준다.

## 데이터 요구사항

- 답변 payload는 스텝 타입과 일치해야 한다.
- 선택 값은 현재 스텝 콘텐츠에 존재하는 값만 허용한다.
- 구간 선택의 `layout` 값은 선택 필드이며, 지원 값은 `inline`, `block`이다.
- 구간 선택의 `layout` 값이 없거나 지원하지 않는 값이면 `inline` 표시 기준을 따른다.
- 순서, 매칭, 분류 답변은 중복되거나 존재하지 않는 값을 저장하지 않는다.
- 순서 답변은 화면에 표시된 최종 항목 순서를 `orderedItems`로 전달한다.
- 매칭 답변은 모든 왼쪽 항목에 대한 pair를 포함해야 저장된다.
- 분류 답변은 모든 항목에 대한 카테고리 배치를 포함해야 저장된다.
- 잘못된 스텝 타입과 답변 타입 조합은 저장하지 않는다.

## 권한 / 접근 규칙

- 정답 확인형 활동 답변 저장은 로그인한 학습자만 수행할 수 있다.
- 학습자는 자신의 레슨 답변만 저장할 수 있다.

## 예외 / 오류

- 스텝 타입과 답변 타입이 다르면 잘못된 요청으로 처리한다.
- 레슨에 속하지 않은 스텝의 답변 저장 요청은 거절한다.
- 답변 저장 실패는 레슨 화면 안에서 한국어 오류로 표시한다.

## 비범위

- 음성 인식 활동.
- `VOICE_RECOGNITION` 스텝 타입.
- 파일 제출 활동.
- 실시간 협업 풀이.
- 정답 확인형 활동의 별도 복습 화면.

## 확인 방법

- 객관식, 빈칸, 구간 선택, 순서, 매칭, 분류 활동에서 타입별 답변이 전달되는지 확인한다.
- 구간 선택 활동의 `inline` layout과 `block` layout이 구분되어 표시되는지 확인한다.
- 순서 활동에서 드래그 핸들로 항목 순서를 바꿀 수 있는지 확인한다.
- 순서 활동에서 키보드로 항목을 위/아래 이동할 수 있는지 확인한다.
- 확인 가능한 스텝에서 정답 또는 오답 피드백을 확인한다.
- 잘못된 payload 저장 요청이 거절되는지 확인한다.
