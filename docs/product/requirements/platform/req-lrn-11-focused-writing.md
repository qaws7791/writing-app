# REQ-LRN-11 집중형 쓰기

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-12` 글 작성과 자기 점검
- 관련 화면:
  - `SCR-008` 쓰기 홈
  - `SCR-009` 집중형 편집
  - `SCR-010` 자기 점검
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 쓰기 방식을 선택하고 일반 텍스트 글을 작성한 뒤 세 질문으로 스스로 점검할 수 있게 한다.

## 기능 요구사항

- 학습자 앱은 `배우기`와 나란한 `쓰기` 진입점을 제공한다.
- 쓰기 홈은 `새 글 쓰기` 행동과 학습자가 저장한 글 목록을 제공한다.
- 새 글은 `자유롭게 쓰기`, `설명하기`, `주장하기` 중 한 방식을 선택해 생성한다.
- 방식 선택 뒤 추가 설정 없이 편집 화면으로 이동한다.
- 편집 화면은 제목, 일반 텍스트 본문, 글자 수, 저장 상태와 `글 점검하기` 행동만 제공한다.
- 입력이 800ms 동안 멈추면 저장을 요청한다.
- 입력 영역이 focus를 잃거나 화면이 숨겨지거나 나가기 행동이 실행되면 대기 중인 저장을 즉시 요청한다.
- 저장 실패와 version 충돌에는 작성 중인 제목과 본문을 화면 상태에 유지한다.
- 자기 점검은 쓰기 방식에 맞는 세 질문을 별도 집중 화면에 표시한다.
- `다시 다듬기`는 기존 글을 유지한 채 편집 화면으로 돌아간다.
- `점검 마치기`는 점검 완료 상태와 시각을 저장한다.
- 점검 완료 뒤 본문을 수정하면 글 상태를 작성 중으로 바꾼다.
- 글 삭제는 확인 절차를 거치고 학습자가 소유한 글만 삭제한다.

## 화면 요구사항

- 쓰기 홈과 방식 선택은 학습자 `AppShell` 안에서 렌더링한다.
- 편집과 자기 점검은 글로벌 내비게이션을 숨긴 한 열 집중 화면에서 렌더링한다.
- 제목과 본문에는 보이는 한국어 label을 제공한다.
- 저장 중과 저장 완료는 `role="status"`로 전달한다.
- 저장 실패와 version 충돌은 `role="alert"`로 전달한다.
- 320px 화면과 텍스트 200% 확대에서 가로 스크롤 없이 작성과 점검을 완료할 수 있어야 한다.

## 데이터 요구사항

- 글은 학습자, 쓰기 방식, 제목, 본문, 상태, version과 생성·수정·점검 시작·점검 완료 시각을 가진다.
- 제목과 본문은 일반 텍스트로 저장한다.
- 저장은 expected version을 현재 version과 비교한다.
- version이 다르면 서버 글을 변경하지 않는다.
- event는 글 생성, 자기 점검 시작, 자기 점검 뒤 본문 수정, 자기 점검 완료와 글 삭제만 기록한다.
- event, 일반 log, 오류 payload와 운영 조회에는 제목과 본문을 포함하지 않는다.
- 자기 점검 시작률과 자기 점검 뒤 수정률은 삭제 상태가 아닌 학습자의 원문 없는 event로 계산한다.

## 권한 / 접근 규칙

- 모든 쓰기 조회와 변경은 로그인한 active 학습자만 수행할 수 있다.
- 학습자는 자신의 글만 조회, 저장, 점검 완료와 삭제할 수 있다.
- 학습자 데이터 정리는 해당 학습자의 글과 쓰기 event를 같은 정리 transaction에서 삭제한다.

## 예외 / 오류

- 조회 실패는 빈 목록으로 바꾸지 않고 다시 시도 가능한 한국어 오류로 표시한다.
- 저장 실패는 작성 내용이 화면에 남아 있음을 먼저 알린다.
- version 충돌은 로컬 작성 내용을 유지하고 서버 글 불러오기 또는 로컬 내용 재시도를 제공한다.
- 네트워크가 끊기면 현재 화면 입력을 유지하고 재연결 뒤 저장을 다시 시도한다.
- 저장하지 않은 입력이 남아 있으면 browser 화면 이탈 전에 경고한다.

## 비범위

- 레슨 `WRITE` 답안과의 연결.
- 점수, 정답 판정과 목표 글자 수.
- 리치 텍스트, 마크다운, 첨부와 인쇄 레이아웃.
- 폴더, 태그, 검색과 정렬 설정.
- 공유, 공개 발행과 실시간 협업.
- AI 생성, AI 피드백과 자동 교정.
- 오프라인 영속 저장.

## 확인 방법

- 쓰기 홈에서 방식을 한 번 선택한 뒤 편집 화면이 열리는지 확인한다.
- 입력 정지, blur, 화면 숨김과 나가기에서 저장 요청이 실행되는지 확인한다.
- 저장 실패와 version 충돌에서 로컬 제목과 본문이 유지되는지 확인한다.
- 각 쓰기 방식에 맞는 세 질문과 두 후속 행동을 확인한다.
- 삭제 확인과 학습자 데이터 정리에서 글 원문이 제거되는지 확인한다.
- 운영 조회에 제목과 본문이 포함되지 않는지 확인한다.
