# REQ-LRN-9 학습자 앱 내비게이션

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-10` 학습자 앱 주요 화면 이동
- 관련 화면:
  - `SCR-003` 학습 홈
  - `SCR-004` 코스 목록
  - `SCR-007` 프로필
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

로그인한 학습자가 학습자 앱의 홈, 배우기, 프로필 화면을 일관된 내비게이션으로 이동할 수 있게 한다.

## 기능 요구사항

- 학습자 앱 shell은 상단 내비게이션과 모바일 하단 내비게이션을 제공한다.
- 상단 브랜드 링크는 홈으로 이동한다.
- 상단 내비게이션은 홈과 배우기 링크를 제공한다.
- 프로필 메뉴는 프로필과 로그아웃 링크를 제공한다.
- 모바일 하단 내비게이션은 홈, 배우기, 프로필 링크를 제공한다.
- 현재 화면은 링크 상태로 표시한다.

## 화면 요구사항

- 데스크톱에서는 상단 내비게이션을 주요 이동 수단으로 사용한다.
- 모바일에서는 하단 내비게이션을 주요 이동 수단으로 사용한다.
- 현재 위치는 `aria-current="page"`로 표시한다.
- 이모지만 표시하는 계정 메뉴 trigger는 목적을 설명하는 한국어 접근성 이름을 제공한다.

## 데이터 요구사항

- 내비게이션은 현재 경로를 기준으로 활성 상태를 판단한다.
- 별도 사용자 설정 데이터를 요구하지 않는다.

## 권한 / 접근 규칙

- 학습자 앱 내비게이션은 로그인한 학습자 보호 화면 안에서 제공한다.
- 로그아웃 링크는 인증 흐름의 로그아웃 정책을 따른다.

## 예외 / 오류

- 현재 경로가 코스 상세이면 배우기 메뉴를 활성 상태로 본다.
- 로그아웃 후에는 로그인 또는 공개 화면 흐름을 따른다.

## 비범위

- 어드민 내비게이션.
- 사용자별 메뉴 커스터마이징.
- 알림 메뉴.

## 확인 방법

- 프로필 화면에서 상단 프로필 메뉴 링크를 확인한다.
- 코스 상세 화면에서 모바일 배우기 링크가 현재 화면 계열로 표시되는지 확인한다.
- 각 링크가 의도한 화면으로 이동하는지 확인한다.
