# REQ-LRN-8 공개 랜딩

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-9` 로그인 전 제품 이해
- 관련 화면:
  - `SCR-001` 학습자 랜딩
- 관련 사용자:
  - 처음 방문한 학습자
  - 로그인하지 않은 재방문자
- 상태: 기준

## 목적

로그인하지 않은 학습자가 제품의 학습 방식과 가치 제안을 이해하고 학습 시작 또는 코스 탐색으로 이동할 수 있게 한다.

## 기능 요구사항

- 공개 랜딩은 로그인 없이 접근할 수 있다.
- 랜딩은 hero, 주제 marquee, 특징, 시작 방법, 지표, 화면 미리보기, 최종 CTA, footer를 제공한다.
- 시작 CTA는 학습 앱 진입 경로로 이동한다.
- 코스 둘러보기 CTA는 코스 목록 경로로 이동한다.
- 상단 브랜드 행동은 공개 랜딩 루트로 이동한다.
- footer는 현재 제품이 지원하는 실제 목적지만 제공하며 목적지가 없는 메뉴를 링크로 노출하지 않는다.

## 화면 요구사항

- 핵심 CTA는 시작 행동과 코스 둘러보기 행동을 구분한다.
- 화면 미리보기 이미지는 대체 텍스트를 제공한다.
- 장식 marquee와 pebble은 정보 전달을 방해하지 않는다.
- 제품명 표기는 `SCR-001`의 현재 UI 기준과 후속 정리 대상을 따른다.

## 데이터 요구사항

- 공개 랜딩은 사용자별 학습 데이터를 요구하지 않는다.
- 랜딩의 지표와 미리보기는 현재 화면 표시 기준을 따른다.

## 권한 / 접근 규칙

- 비로그인 사용자와 로그인 사용자가 모두 접근할 수 있다.
- 보호 API 호출이 필요한 학습 데이터는 공개 랜딩에서 조회하지 않는다.

## 예외 / 오류

- 시작 CTA로 보호 화면에 진입할 때 세션이 없으면 로그인 흐름으로 이어진다.
- 코스 목록 이동 후 세션이 없으면 학습자 보호 화면 정책을 따른다.
- footer의 학습 통계와 코스 이동도 같은 보호 화면 정책을 따른다.

## 비범위

- 결제와 요금제 가입.
- 공개 코스 검색.
- 외부 마케팅 CMS.

## 확인 방법

- `/`에서 랜딩 섹션 순서와 CTA를 확인한다.
- 시작 CTA가 `/app`으로 이동하는지 확인한다.
- 코스 둘러보기 CTA가 `/app/courses`로 이동하는지 확인한다.
- footer의 코스, 학습 통계, 소개가 각각 `/app/courses`, `/app`, `/#features`로 이동하고 빈 hash 링크가 없는지 확인한다.
