# REQ-LRN-8 공개 랜딩

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-9` 로그인 전 제품 이해
- 관련 화면:
  - `SCR-001` 학습자 랜딩
- 관련 사용자:
  - 처음 방문한 학습자
  - 로그인하지 않은 재방문자
- 상태: 기준

## 목적

로그인하지 않은 학습자가 제품의 학습 방식과 가치 제안을 이해하고 학습 시작 또는 코스 탐색으로 이동할 수 있게 한다.

## 기능 요구사항

- 공개 랜딩은 로그인 없이 접근할 수 있다.
- 랜딩은 핵심 가치, 학습 방식, 실제 제품 미리보기, 최종 CTA의 네 핵심 영역과 footer를 제공한다.
- 학습 방식은 짧은 레슨, 직접 쓰기, AI 코칭의 연결을 설명한다.
- 실제 제품 미리보기는 현재 제공하는 코스 콘텐츠와 로컬 코스 썸네일을 사용한다.
- 시작 CTA는 학습 앱 진입 경로로 이동한다.
- 코스 둘러보기 CTA는 코스 목록 경로로 이동한다.
- 로그인 CTA는 로그인 경로로 이동한다.
- 상단 브랜드 행동은 공개 랜딩 루트로 이동한다.
- footer는 현재 제품이 지원하는 실제 목적지만 제공하며 목적지가 없는 메뉴를 링크로 노출하지 않는다.
- 약관과 개인정보 처리방침은 승인된 문서와 route가 마련된 뒤 footer에 노출한다.

## 화면 요구사항

- 핵심 CTA는 로그인, 학습 시작, 코스 둘러보기 행동을 구분한다.
- 화면 미리보기 이미지는 대체 텍스트를 제공한다.
- 제품명은 `글결.`로 표기한다.
- 스크롤, 포인터 이동, 반복 장식 애니메이션 없이 핵심 정보를 짧은 흐름으로 전달한다.

## 데이터 요구사항

- 공개 랜딩은 사용자별 학습 데이터를 요구하지 않는다.
- 제품 미리보기의 코스명, 설명, 분류, 썸네일은 현재 코스 콘텐츠와 에셋 계약을 따른다.
- 검증되지 않은 이용자 수, 만족도, 완료율, 후기, 무료 제공 범위를 노출하지 않는다.

## 권한 / 접근 규칙

- 비로그인 사용자와 로그인 사용자가 모두 접근할 수 있다.
- 보호 API 호출이 필요한 학습 데이터는 공개 랜딩에서 조회하지 않는다.

## 예외 / 오류

- 시작 CTA로 보호 화면에 진입할 때 세션이 없으면 로그인 흐름으로 이어진다.
- 코스 목록 이동 후 세션이 없으면 학습자 보호 화면 정책을 따른다.
- footer의 보호 화면 이동도 같은 보호 화면 정책을 따른다.

## 비범위

- 결제와 요금제 가입.
- 외부 마케팅 CMS.

## 확인 방법

- 랜딩 화면에서 네 핵심 영역과 CTA를 확인한다.
- 시작 CTA가 학습 홈으로 이동하는지 확인한다.
- 코스 둘러보기 CTA가 코스 탐색으로 이동하는지 확인한다.
- 로그인 CTA가 로그인으로 이동하는지 확인한다.
- 실제 코스 썸네일에 의미 있는 대체 텍스트가 있는지 확인한다.
- footer에 빈 링크나 승인되지 않은 약관·개인정보 링크가 없는지 확인한다.
