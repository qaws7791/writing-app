# REQ-LRN-2 이어서 학습

## 문서 정보

- 영역: 플랫폼
- 출처 유저 스토리:
  - `US-LRN-2` 이어서 학습
- 관련 화면:
  - `SCR-003` 학습 홈
  - `SCR-006` 레슨 진행
- 관련 사용자:
  - 학습자
- 상태: 기준

## 목적

학습자가 재접속 후 중단한 코스와 다음 학습 레슨을 빠르게 찾아 이어서 학습할 수 있게 한다.

## 기능 요구사항

- 홈은 학습자 프로필과 진행 중 코스를 함께 보여준다.
- 홈은 `진행중`, `완료` 탭으로 코스 목록을 분리한다.
- 진행 중인 코스는 최대 5개까지 보여준다.
- 완료 탭은 완료 전용 카드로 전체 완료 코스를 보여준다.
- 각 진행 중 코스는 다음 학습 레슨 행동을 제공한다.
- 각 진행 중 코스는 다음 학습 레슨을 최대 2개까지 보여줄 수 있다.
- 진행 중인 코스가 없으면 진행중 탭에서 코스 둘러보기 행동을 제공한다.
- 다음 학습 레슨 행동은 레슨 화면의 `lesson_id` query로 연결한다.

## 화면 요구사항

- 홈은 인사말, 연속 학습일, 완료한 레슨 수를 표시한다.
- 진행 중인 코스에는 코스 제목, 진행률, 다음 학습 레슨 정보를 표시한다.
- 다음 학습 레슨이 2개 표시될 때 각 행동은 레슨 제목을 구분해 보여준다.
- 빈 상태는 새 코스를 시작할 수 있는 행동을 포함한다.
- `GET /progress`는 선택적 `status=in_progress|completed` query로 코스 목록을 필터한다.
- query가 없으면 카탈로그 전체 코스 진행을 반환한다.

## 데이터 요구사항

- 학습 진행은 사용자와 레슨 기준으로 계산한다.
- 코스 진행률은 완료한 레슨 수와 전체 레슨 수 기준으로 표시한다.
- 학습 활동일은 서버 기준 학습 날짜로 계산한다.
- 레슨 시작, 답변 저장, 완료 저장은 학습 활동일을 갱신한다.
- 이미 완료된 레슨을 다시 완료 저장해도 완료 레슨 수는 중복 증가하지 않는다.
- 연속 학습일은 기록된 학습 활동일을 기준으로 계산한다.
- 다음 학습 레슨은 코스 안에서 아직 완료되지 않은 active 레슨을 정렬 순서 기준으로 앞에서부터 선택한다.
- 한 코스 카드에 표시하는 다음 학습 레슨 수는 2개를 넘지 않는다.
- 모든 active 레슨은 잠금 없이 접근 가능하다.

## 권한 / 접근 규칙

- 홈과 진행 조회는 로그인한 학습자만 접근할 수 있다.
- 진행 데이터는 현재 사용자 기준으로만 조회한다.

## 예외 / 오류

- 프로필 또는 진행 조회가 실패하면 한국어 오류 상태를 표시한다.
- 다음 학습 레슨이 없으면 코스 상세나 완료 상태로 이동할 수 있어야 한다.

## 비범위

- 학습 알림.
- 리마인드.
- 여러 사용자 진행 비교.

## 확인 방법

- 진행 중 코스가 있는 사용자로 홈을 확인한다.
- 진행 중 코스가 없는 사용자로 빈 상태와 코스 둘러보기를 확인한다.
- 한 코스에 다음 학습 레슨이 2개 이상 있을 때 홈 카드가 최대 2개 CTA만 표시하는지 확인한다.
- 다음 학습 레슨 CTA가 레슨 화면으로 이동하는지 확인한다.
