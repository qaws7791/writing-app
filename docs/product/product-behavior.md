# 제품 행동 명세

- 글결의 제품 행동을 Gherkin 문법으로 정리한다.
- 단일 Markdown 문서 안에 전체 기능 명세를 보관한다.
- 실행용 `.feature` 파일은 만들지 않는다.

```gherkin
Feature: 글결 제품 행동 명세
  글결은 한국어 글쓰기 학습자가 코스를 선택하고, 레슨을 진행하고, 답변에 대한 피드백을 받는 제품이다.
  운영자는 학습자 활동, 콘텐츠, 사용자, 분석, 운영 설정을 관리한다.
  이 문서는 docs/product 하위 제품 기능을 단일 Gherkin 명세로 정리한다.

  Background:
    Given 제품명은 "글결"이다
    And 콘텐츠 기준선은 코스 5개, 유닛 15개, 레슨 44개, 스텝 136개이다
    And 콘텐츠 상태는 "active"와 "archived"만 사용한다
    And 레슨 진행 상태는 "available", "completed", "locked"로 표시한다

  Rule: 제품 기준선

    Scenario: 제품 문서는 현재 구현을 기준으로 한다
      Given 코드와 기존 문서가 서로 다른 제품 상태를 설명한다
      When 제품 문서를 작성한다
      Then 현재 코드와 schema를 우선한다
      And 충돌 사항은 제품 리서치 문서에 기록한다

    Scenario: 내부 출처명은 제품명으로 쓰지 않는다
      Given seed와 프로토타입 출처명이 존재한다
      When 제품 문서가 런타임 제품을 설명한다
      Then 출처명은 제품명으로 쓰지 않는다
      And 공식 제품명은 "글결"로 쓴다

    Scenario: 랜딩 화면의 브랜드명 불일치를 기록한다
      Given 랜딩 화면이 제품 문서 기준과 다른 브랜드명을 표시한다
      When 제품 리서치 문서를 검토한다
      Then 브랜드명 불일치가 기록되어 있다
      But 제품 기준선은 바뀌지 않는다

  Rule: 공개 랜딩

    Scenario: 방문자가 공개 랜딩을 본다
      Given 방문자 세션이 없다
      When 방문자가 공개 랜딩에 진입한다
      Then 제품 소개가 표시된다
      And 학습 방식 소개가 표시된다
      And 시작 행동이 제공된다
      And 코스 둘러보기 행동이 제공된다

    Scenario: 방문자가 랜딩에서 학습을 시작한다
      Given 방문자 세션이 없다
      And 방문자가 공개 랜딩에 있다
      When 방문자가 학습 시작을 선택한다
      Then 로그인 화면으로 이동한다

    Scenario: 방문자가 랜딩에서 코스를 둘러본다
      Given 방문자 세션이 없다
      And 방문자가 공개 랜딩에 있다
      When 방문자가 코스 둘러보기를 선택한다
      Then 로그인 화면으로 이동한다
      And 로그인 성공 후 코스 목록으로 이동할 수 있다

  Rule: 학습자 인증

    Scenario: 학습자가 Google 계정으로 로그인한다
      Given 학습자가 로그인 화면에 있다
      When 학습자가 Google 로그인을 완료한다
      Then 학습자 세션이 생성된다
      And 학습자는 요청한 보호 경로로 이동한다

    Scenario: 이메일과 비밀번호 가입을 지원하지 않는다
      Given 학습자가 로그인 화면에 있다
      When 학습자가 인증 방식을 확인한다
      Then Google 로그인만 사용할 수 있다
      And 이메일과 비밀번호 가입 미지원 안내가 표시된다

    Scenario: 인증되지 않은 학습자가 보호 화면에 접근한다
      Given 학습자 세션이 없다
      When 학습자가 보호 화면에 접근한다
      Then 로그인 화면으로 이동한다
      And 로그인 성공 후 돌아갈 경로가 보존된다

  Rule: 학습자 홈

    Scenario: 진행 중인 코스가 있는 학습자가 홈을 본다
      Given 학습자가 로그인한 상태이다
      And 학습자에게 진행 중인 코스가 있다
      When 학습자가 홈에 진입한다
      Then 인사말이 표시된다
      And 연속 학습일이 표시된다
      And 완료한 레슨 수가 표시된다
      And 이어서 학습할 코스 목록이 표시된다

    Scenario: 진행이 없는 학습자가 홈을 본다
      Given 학습자가 로그인한 상태이다
      And 학습자에게 진행 중인 코스가 없다
      When 학습자가 홈에 진입한다
      Then 첫 번째 코스 선택 안내가 표시된다
      And 코스 둘러보기 행동이 제공된다

    Scenario: 홈에서 다음 레슨을 시작한다
      Given 학습자가 로그인한 상태이다
      And 홈에 진행 가능한 다음 레슨이 있다
      When 학습자가 다음 레슨을 선택한다
      Then 해당 레슨 화면으로 이동한다
      And 레슨은 선택한 레슨 ID로 열린다

  Rule: 코스 탐색

    Scenario: 학습자가 코스 목록을 카테고리별로 본다
      Given 학습자가 로그인한 상태이다
      And active 코스가 존재한다
      When 학습자가 코스 목록에 진입한다
      Then 카테고리 목록이 표시된다
      And 선택된 카테고리의 코스 카드가 표시된다

    Scenario: 코스 카드는 학습 선택에 필요한 정보를 제공한다
      Given 학습자가 코스 목록에 있다
      When 코스 카드가 표시된다
      Then 코스 제목이 표시된다
      And 코스 설명이 표시된다
      And 레슨 수가 표시된다
      And 코스 이미지가 표시된다

    Scenario: archived 코스는 학습자 경로에서 숨긴다
      Given 코스가 archived 상태이다
      When 학습자가 코스 목록을 본다
      Then 해당 코스는 표시되지 않는다

  Rule: 코스 상세

    Scenario: 학습자가 코스 상세를 본다
      Given 학습자가 로그인한 상태이다
      And active 코스가 존재한다
      When 학습자가 코스 상세에 진입한다
      Then 코스 제목과 설명이 표시된다
      And 완료 레슨 수가 표시된다
      And 전체 레슨 수가 표시된다
      And 진행률이 표시된다
      And 유닛별 레슨 목록이 표시된다

    Scenario: 미시작 코스에서 첫 레슨을 시작한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 코스를 아직 시작하지 않았다
      When 학습자가 코스 상세를 본다
      Then 첫 레슨 시작 행동이 표시된다
      And 첫 진행 가능 레슨이 선택 대상이 된다

    Scenario: 진행 중인 코스에서 다음 레슨을 이어간다
      Given 학습자가 로그인한 상태이다
      And 학습자가 코스의 일부 레슨을 완료했다
      When 학습자가 코스 상세를 본다
      Then 다음 레슨 행동이 표시된다
      And 완료된 레슨은 완료 상태로 표시된다
      And 다음 레슨은 진행 가능 상태로 표시된다
      And 이후 레슨은 잠김 상태로 표시된다

    Scenario: 존재하지 않는 코스를 연다
      Given 학습자가 로그인한 상태이다
      When 학습자가 존재하지 않는 코스 상세에 진입한다
      Then 코스 없음 상태가 표시된다

    Scenario: 코스 상세 조회가 실패한다
      Given 학습자가 로그인한 상태이다
      And 코스 상세 조회가 실패한다
      When 학습자가 코스 상세에 진입한다
      Then 코스를 열 수 없다는 오류 안내가 표시된다

  Rule: 레슨 진행

    Scenario: 레슨 ID 없이 레슨 화면에 진입한다
      Given 학습자가 로그인한 상태이다
      When 학습자가 레슨 ID 없이 레슨 화면에 진입한다
      Then 코스에서 이어갈 레슨을 선택하라는 안내가 표시된다

    Scenario: 학습자가 레슨을 시작한다
      Given 학습자가 로그인한 상태이다
      And 레슨이 존재한다
      When 학습자가 레슨 화면에 진입한다
      Then 레슨 시작 화면이 표시된다
      And 레슨 제목이 표시된다
      And 예상 시간이 표시된다
      And 전체 스텝 수가 표시된다

    Scenario: 레슨 시작 상태를 저장한다
      Given 학습자가 로그인한 상태이다
      And 레슨 시작 화면이 표시되어 있다
      When 학습자가 레슨을 시작한다
      Then 레슨 시작 마커가 저장된다
      And 첫 학습 스텝이 표시된다

    Scenario: 답변 가능한 스텝에서 답변을 저장한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 답변 가능한 스텝에 있다
      When 학습자가 답변을 변경한다
      Then 스텝 답변이 저장된다
      And 학습 활동일이 갱신된다

    Scenario: 답변 저장이 실패한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 답변 가능한 스텝에 있다
      When 답변 저장이 실패한다
      Then 한국어 오류가 표시된다
      But 학습자는 현재 스텝에 머문다

    Scenario: 학습자가 레슨을 완료한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 마지막 스텝에 있다
      When 학습자가 레슨 완료를 요청한다
      Then 레슨 완료 상태가 저장된다
      And 완료한 레슨 수가 증가한다
      And 학습 활동일이 갱신된다
      And 완료 화면이 표시된다

    Scenario: 레슨 완료 저장이 실패한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 마지막 스텝에 있다
      When 레슨 완료 저장이 실패한다
      Then 한국어 오류가 표시된다
      But 완료 화면으로 이동하지 않는다

  Rule: 레슨 스텝 타입

    Scenario Outline: 확정 스텝 타입을 표시한다
      Given 학습자가 로그인한 상태이다
      And 레슨에 "<스텝 타입>" 스텝이 있다
      When 학습자가 해당 스텝에 도달한다
      Then "<기대 행동>"이 제공된다

      Examples:
        | 스텝 타입       | 기대 행동                         |
        | READING         | 제목, 안내, 본문을 읽을 수 있다   |
        | COMPARE         | 둘 이상의 글 버전을 비교할 수 있다 |
        | MULTIPLE_CHOICE | 선택지를 고르고 해설을 볼 수 있다 |
        | FILL_BLANK     | 단어를 넣고 해설을 볼 수 있다     |
        | SELECT          | 문장 구간을 선택하고 해설을 볼 수 있다 |
        | ORDER           | 항목을 순서대로 배열할 수 있다    |
        | WRITE           | 기준에 맞는 글을 작성할 수 있다   |
        | AI_FEEDBACK     | AI 코칭을 요청할 수 있다          |
        | MATCH           | 관련 항목을 짝지을 수 있다        |
        | CATEGORIZE      | 항목을 카테고리로 분류할 수 있다  |

    Scenario Outline: 답변 payload는 현재 스텝 콘텐츠 기준으로 검증된다
      Given 학습자가 로그인한 상태이다
      And 학습자가 "<스텝 타입>" 스텝에 있다
      When 학습자가 현재 스텝에 없는 값을 제출한다
      Then 답변은 저장되지 않는다
      And 잘못된 요청으로 처리된다

      Examples:
        | 스텝 타입       |
        | MULTIPLE_CHOICE |
        | FILL_BLANK     |
        | SELECT          |
        | ORDER           |
        | MATCH           |
        | CATEGORIZE      |

  Rule: AI 피드백

    Scenario: 학습자가 AI 피드백을 받는다
      Given 학습자가 로그인한 상태이다
      And 학습자가 AI 피드백 스텝에 있다
      When 학습자가 AI 코칭을 요청한다
      Then 피드백 시도가 저장된다
      And 총평이 표시된다
      And 잘된 점이 표시된다
      And 다듬을 점이 표시된다
      And 다음 시도가 표시된다

    Scenario: AI 피드백 시도 한도를 넘는다
      Given 학습자가 로그인한 상태이다
      And 학습자가 AI 피드백 시도 한도에 도달했다
      When 학습자가 AI 코칭을 요청한다
      Then 시도 한도 초과 오류가 표시된다
      And 새 피드백 시도는 저장되지 않는다

    Scenario: AI 제공자가 실패한다
      Given 학습자가 로그인한 상태이다
      And AI 제공자가 응답하지 않는다
      When 학습자가 AI 코칭을 요청한다
      Then AI 피드백을 사용할 수 없다는 오류가 표시된다
      But 완료된 피드백 시도 수는 증가하지 않는다

  Rule: 프로필

    Scenario: 학습자가 프로필을 본다
      Given 학습자가 로그인한 상태이다
      When 학습자가 프로필에 진입한다
      Then 학습자 이름이 표시된다
      And 가입일이 표시된다
      And 완료한 레슨 수가 표시된다
      And 연속 학습일이 표시된다

    Scenario Outline: 학습자가 화면 테마를 바꾼다
      Given 학습자가 로그인한 상태이다
      And 학습자가 프로필에 있다
      When 학습자가 "<테마>" 테마를 선택한다
      Then 선택한 테마가 적용된다

      Examples:
        | 테마   |
        | 라이트 |
        | 다크   |
        | 시스템 |

    Scenario: 학습자가 로그아웃한다
      Given 학습자가 로그인한 상태이다
      And 학습자가 프로필에 있다
      When 학습자가 로그아웃한다
      Then 학습자 세션이 종료된다
      And 공개 랜딩으로 이동한다

  Rule: 관리자 인증과 권한

    Scenario: 관리자가 ID/password로 로그인한다
      Given 관리자가 로그인 화면에 있다
      When 관리자가 올바른 관리자 계정으로 로그인한다
      Then 관리자 세션이 생성된다
      And 어드민 보호 화면에 진입할 수 있다

    Scenario: 잘못된 관리자 계정으로 로그인한다
      Given 관리자가 로그인 화면에 있다
      When 관리자가 잘못된 관리자 계정으로 로그인한다
      Then 로그인 오류가 표시된다
      But 관리자 세션은 생성되지 않는다

    Scenario: 운영자가 읽기 화면을 조회한다
      Given 운영자 세션이 있다
      When 운영자가 읽기 화면에 접근한다
      Then 요청이 허용된다

    Scenario Outline: 운영자가 변경성 작업을 요청한다
      Given 운영자 세션이 있다
      When 운영자가 "<작업>"을 요청한다
      Then 요청은 권한 오류로 거절된다
      And 데이터는 변경되지 않는다

      Examples:
        | 작업                 |
        | 새 코스 생성          |
        | 코스 보관             |
        | 사용자 상태 변경       |
```
