# 화면 명세

> 디자인, 레이아웃, 컴포넌트, 접근성 기준의 단일 진실 원천은 `docs/design`이다. 이 문서는 제품 라우트와 화면 목적을 빠르게 훑는 보조 문서로 유지한다.

## 학습자 `/`

- 목적: 제품 소개와 학습 시작 유도.
- 주요 요소: 상단 내비게이션, 시작 CTA, 코스 둘러보기 CTA, 학습 방식 소개.
- 현재 이슈: 브랜드명이 제품 문서 기준과 다르다.

## 학습자 `/login`

- 목적: 학습자 인증.
- 주요 요소: 제품명, 설명, Google 로그인 버튼, 이메일/비밀번호 미지원 안내.
- 성공 행동: Google 인증 후 `next` 경로 또는 `/app`으로 이동.

## 학습자 `/app`

- 목적: 학습 홈.
- 주요 요소: 인사말, 연속 학습일, 완료한 레슨 수, 진행 중 코스, 다음 레슨.
- 빈 상태: 첫 번째 코스 선택 안내와 코스 둘러보기 행동.

## 학습자 `/app/courses`

- 목적: 코스 탐색.
- 주요 요소: 제목, 설명, 카테고리 탭, 코스 카드.
- 코스 카드: 이미지, 제목, 설명, 레슨 수.

## 학습자 `/app/courses/[id]`

- 목적: 코스 상세 확인과 레슨 진입.
- 주요 요소: 뒤로가기, 코스 이미지, 제목, 설명, 진행률, 다음 레슨 CTA, 유닛별 레슨 목록.
- 오류 상태: 코스 없음, 코스 조회 실패, 진행 조회 실패.

## 학습자 `/app/lesson`

- 목적: 몰입형 레슨 진행.
- 진입 조건: `lesson_id` query가 필요하다.
- 주요 요소: 상단 진행 헤더, 중앙 콘텐츠, 하단 주요 행동 영역.
- 시작 화면: 제목, 카테고리, 설명, 예상 시간, 스텝 수.
- 완료 화면: 완료 메시지, 레슨 요약, 다음 레슨 CTA, 코스로 돌아가기 CTA.

## 학습자 `/app/profile`

- 목적: 학습자 계정과 학습 요약 확인.
- 주요 요소: 이름, 가입일, 완료한 레슨, 연속 학습일, 테마 전환, 로그아웃.
- 테마 옵션: 라이트, 다크, 시스템.

## 어드민 `/login`

- 목적: 관리자 인증.
- 주요 요소: 이메일 입력, 비밀번호 입력, 로그인 버튼, 오류 메시지.
- 인증 방식: ID/password.

## 어드민 `/` 또는 `/dashboard`

- 목적: 운영 지표 확인.
- 주요 요소: 총 사용자, 최근 7일 활성, 가입, 완료 레슨, 콘텐츠 수, 최근 활동.

## 어드민 `/courses`

- 목적: 콘텐츠 관리.
- 주요 요소: 코스 검색, 카테고리 필터, 상태 필터, 페이지 크기, 새 코스, 코스 목록, 보관 확인.

## 어드민 `/courses/[id]`

- 목적: 코스 미리보기.
- 주요 요소: 코스 정보, 커리큘럼 맵, 레슨 작업대, 스텝 폼, 레슨 미리보기.
- 상태: 읽기 전용.

## 어드민 `/users`

- 목적: 사용자 관리.
- 주요 요소: 사용자 검색, 상태 필터, 정렬, 사용자 목록, 정지, 삭제 요청 처리.

## 어드민 `/users/[id]`

- 목적: 사용자 상세 확인.
- 주요 요소: 가입일, 최근 접속, 완료 레슨, 전체 진도, 상태 변경.

## 어드민 `/analytics`

- 목적: 학습 지표 분석.
- 주요 요소: 가입 추이, 완료 추이, 연속 학습일 분포, 레슨별 시작, 완료, 완료율, 이탈률.

## 어드민 `/settings`

- 목적: 운영 설정 관리.
- 주요 요소: 배너, 공지, 이용약관, 개인정보처리방침, 콘텐츠 초기화.
