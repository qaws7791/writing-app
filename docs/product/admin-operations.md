# 어드민 운영

## 관리자 유형

- owner 관리자 한 종류만 운영한다.

## 읽기 권한

- 대시보드 조회.
- 코스 목록 조회.
- 코스 편집 문서 조회.
- 사용자 목록 조회.
- 사용자 상세 조회.
- 분석 조회.

## 변경 권한

- 새 코스 생성.
- 코스 보관.
- 코스 정보 저장.
- 커리큘럼 draft 발행.
- 유닛 추가, 수정, 삭제.
- 레슨 추가, 수정, 삭제, 순서 변경.
- 스텝 추가, 수정, 삭제, 순서 변경.
- 콘텐츠 이미지 업로드와 연결.
- 사용자 상태 변경.
- 사용자 삭제 상태 전환.

## 콘텐츠 운영

- 학습자에게는 active 콘텐츠만 노출한다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환이다.
- 코스 편집은 현재 단일 draft의 코스 정보, 유닛, 레슨, 스텝을 저장형 편집 대상으로 다룬다.
- 콘텐츠 편집 저장은 전체 코스 editor 문서와 `If-Match` 편집 버전을 검증한 뒤 수행한다.
- 발행은 저장과 분리된 소유자 행동이며 현재 draft를 immutable published revision으로 전환하고 다음 draft를 복제한다.
- 코스 보관은 published revision과 기존 학습자 고정을 삭제하지 않는다.
- 유닛, 레슨, 스텝 삭제와 코스 보관은 확인 흐름을 거친다.

## 사용자 운영

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 사용자 목록 화면은 페이지당 12명 기준으로 페이지네이션한다.
- 관리자 상태 변경 요청은 `active`, `suspended`만 허용한다.
- 상태 전이는 `active → suspended | deleted`, `suspended → active | deleted`만 허용하며 `deleted`는 관리자 조회만 가능한 종단 상태다.
- 삭제 요청은 즉시 session을 폐기하고 프로필을 `deleted`로 전환한다. 삭제 시각 기준 5일이 지나면 사용자 소유 인증·학습·초안·AI 데이터를 삭제하고 콘텐츠 revision은 보존한다.
- 개인정보 조회와 상태 변경·삭제는 보존 class가 있는 감사 이벤트로 남긴다.

## 안전 기준

- 변경성 작업은 권한 확인 후 실행한다.
- 위험 작업은 확인 흐름을 거친다.
- 잘못된 요청은 서비스 호출 전에 거절한다.
- 과도한 목록 조회는 페이지 크기 상한으로 제한한다.
