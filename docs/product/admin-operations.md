# 어드민 운영

## 관리자 유형

- 운영자: 조회 중심 업무를 수행한다.
- 소유자 관리자: 변경성 업무를 수행한다.

## 읽기 권한

- 대시보드 조회.
- 코스 목록 조회.
- 코스 편집 문서 조회.
- 스텝 디버그 조회.
- 사용자 목록 조회.
- 사용자 상세 조회.
- 분석 조회.
- 운영 설정 조회.

## 변경 권한

- 새 코스 생성.
- 코스 보관.
- 코스 정보 저장.
- 유닛 추가, 수정, 삭제.
- 레슨 추가, 수정, 삭제, 순서 변경.
- 스텝 추가, 수정, 삭제, 순서 변경.
- 사용자 상태 변경.
- 사용자 삭제 상태 전환.
- 공지와 배너 저장.
- 이용약관과 개인정보처리방침 저장.
- 콘텐츠 초기화.

## 콘텐츠 운영

- 학습자에게는 active 콘텐츠만 노출한다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환이다.
- 코스 편집은 코스 정보, 유닛, 레슨, 스텝을 저장형 편집 대상으로 다룬다.
- 콘텐츠 편집 저장은 전체 코스 editor 문서를 검증한 뒤 수행한다.
- 유닛, 레슨, 스텝 삭제와 코스 보관은 확인 흐름을 거친다.
- 스텝 디버그 도구는 어드민 내부 QA 화면이며 실제 콘텐츠와 학습 데이터를 변경하지 않는다.
- 콘텐츠 초기화는 seed 기준으로 콘텐츠를 재정렬한다.
- seed에 없는 콘텐츠는 보관 상태로 전환한다.

## 자료실 운영

- 관리자 자료실은 운영자가 교육 자료와 운영 문서를 저장하는 영역이다.
- 자료 본문은 Tiptap JSON을 원본으로 저장하고 목록 검색용 발췌문을 별도로 저장한다.
- 모든 관리자는 자료를 생성하고 수정할 수 있다.
- 자료 보관과 삭제는 작성자만 수행한다.
- 자료 목록은 제목과 발췌문 검색, 활성/보관 상태 필터를 제공한다.
- 자료 삭제는 학습자 콘텐츠나 학습 이력에 영향을 주지 않는다.

위 항목은 현재 구현 기준이다. 확정된 전면 교체 목표는 `REQ-ADM-7`과 `ADR-0004`를 따른다. 새 자료실은 Markdown 원본, 폴더·문서 트리, 전체 관리자 공동 관리, 자체 호스팅 Yjs 실시간 편집, 재귀 휴지통·복원을 한 번에 도입하고 기존 Tiptap 자료는 이전하지 않는다.

## AI 채팅 운영

- 관리자 AI 채팅은 교육 콘텐츠 제작과 운영 문서 초안을 돕는 내부 도구다.
- 채팅 내역은 관리자별로 저장한다.
- 신규 AI 에이전트는 Mastra 기반으로 구현한다.
- 관리자 AI 채팅은 별도 런타임이 아니라 어드민 API 안에서 실행한다.
- `OPENAI_API_KEY`가 없으면 대화를 저장하지 않고 `AI_PROVIDER_UNAVAILABLE` 오류 이벤트를 반환한다.
- AI 응답 스트리밍 이벤트는 `chunk`, `done`, `error` 세 종류로 제한한다.

## 사용자 운영

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 사용자 목록 화면은 페이지당 12명 기준으로 페이지네이션한다.
- 관리자 상태 변경 요청은 `active`, `suspended`만 허용한다.
- 삭제 요청 처리는 앱 소유 프로필을 `deleted` 상태로 전환한다.
- 학습 진행과 답변 row는 보존한다.

## 설정 운영

- 공지와 배너는 학습자에게 노출할 운영 메시지다.
- 이용약관과 개인정보처리방침은 운영 설정으로 저장한다.
- 설정 저장은 소유자 관리자만 수행한다.

## 안전 기준

- 변경성 작업은 권한 확인 후 실행한다.
- 위험 작업은 확인 흐름을 거친다.
- 잘못된 요청은 서비스 호출 전에 거절한다.
- 과도한 목록 조회는 페이지 크기 상한으로 제한한다.
