# 어드민 운영

## 관리자 유형

- 운영자: 조회 중심 업무를 수행한다.
- 소유자 관리자: 변경성 업무를 수행한다.

## 읽기 권한

- 대시보드 조회.
- 코스 목록 조회.
- 코스 편집 문서 조회.
- 사용자 목록 조회.
- 사용자 상세 조회.
- 분석 조회.
- 운영 설정 조회.

## 변경 권한

- 새 코스 생성.
- 코스 보관.
- 코스 정보 저장.
- 커리큘럼 draft 발행.
- 유닛 추가, 수정, 삭제.
- 레슨 추가, 수정, 삭제, 순서 변경.
- 스텝 추가, 수정, 삭제, 순서 변경.
- 사용자 상태 변경.
- 사용자 삭제 상태 전환.
- 공지와 배너 저장.
- 이용약관과 개인정보처리방침 저장.
- 콘텐츠 초기화.

## 콘텐츠 운영

- 학습자에게는 active 콘텐츠만 노출한다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환이다.
- 코스 편집은 현재 단일 draft의 코스 정보, 유닛, 레슨, 스텝을 저장형 편집 대상으로 다룬다.
- 콘텐츠 편집 저장은 전체 코스 editor 문서와 `If-Match` 편집 버전을 검증한 뒤 수행한다.
- 발행은 저장과 분리된 소유자 행동이며 현재 draft를 immutable published revision으로 전환하고 다음 draft를 복제한다.
- 코스 보관과 seed 초기화는 published revision과 기존 학습자 고정을 삭제하지 않는다.
- 유닛, 레슨, 스텝 삭제와 코스 보관은 확인 흐름을 거친다.
- 콘텐츠 초기화는 seed 기준으로 콘텐츠를 재정렬한다.
- seed에 없는 콘텐츠는 보관 상태로 전환한다.

## 자료실 운영

- 관리자 자료실은 운영자가 코스 제작에 활용할 글쓰기 방법, 문법, 어휘, 예문과 교육 참고자료를 저장하는 학습 지식 베이스다.
- 제품 요구사항, 설계, 아키텍처, 보안, 운영·개발 정책과 팀 위키는 자료실에 저장하지 않는다.
- 자료 본문은 GFM Markdown 텍스트를 유일한 도메인 원본으로 저장한다.
- 모든 관리자는 같은 자료실에서 폴더와 문서를 생성·이름 변경·이동하고, 제목과 본문을 저장 버튼으로 명시적으로 확정한다.
- 문서를 열 때 받은 강한 ETag를 저장 요청의 `If-Match`로 보내며, `412 Precondition Failed` 충돌에서는 로컬 편집본과 최신 저장본을 함께 유지하고 자동 병합하지 않는다.
- 폴더는 최대 3단계까지 중첩하고 전체 트리를 이름순으로 표시하며 수동 정렬 순서를 저장하지 않는다.
- 휴지통 이동·복원·영구 삭제는 폴더의 전체 하위 트리에 재귀 적용한다.
- 제목과 본문 검색은 FTS5를 사용하고 결과에서 전체 경로를 확인해 해당 트리 위치로 이동할 수 있다.
- 단일 Markdown 파일 가져오기와 문서별 Markdown 내보내기를 제공한다.
- 자료실 항목의 휴지통 이동은 학습자 콘텐츠나 학습 이력에 영향을 주지 않는다.

## AI 에이전트 운영

- 관리자 AI는 어드민 사이트의 AI 에이전트 페이지에서 코스 제작과 자료실 관리를 돕는다.
- 관리자 AI는 코스와 자료실 도메인만 사용하며 Git, 코드와 프로젝트 문서에 접근하지 않는다.
- 관리자 AI의 변경안은 관리자가 내용을 확인하고 승인한 뒤 기존 어드민 도메인 규칙을 통해 반영한다.
- 관리자 AI는 코스 draft와 자료실 문서 변경안만 만들며 발행, 영구 삭제, 권한과 운영 설정 변경은 수행하지 않는다.
- 채팅 내역은 관리자별로 저장한다.
- 신규 AI 에이전트는 Mastra 기반으로 구현한다.
- 관리자 AI는 별도 런타임이 아니라 어드민 API 안에서 실행한다.
- `OPENAI_API_KEY`가 없으면 대화를 저장하지 않고 `AI_PROVIDER_UNAVAILABLE` 오류 이벤트를 반환한다.
- AI 응답 스트리밍 이벤트는 `chunk`, `done`, `error` 세 종류로 제한한다.

## 사용자 운영

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 사용자 목록 화면은 페이지당 12명 기준으로 페이지네이션한다.
- 관리자 상태 변경 요청은 `active`, `suspended`만 허용한다.
- 삭제 요청 처리는 앱 소유 프로필을 `deleted` 상태로 전환한다.
- 학습 진행과 답변 row는 보존한다.

## 설정 운영

- 공지와 배너는 학습자에게 노출할 운영 메시지다.
- 이용약관과 개인정보처리방침은 운영 설정으로 저장한다.
- 설정 저장은 소유자 관리자만 수행한다.

## 안전 기준

- 변경성 작업은 권한 확인 후 실행한다.
- 위험 작업은 확인 흐름을 거친다.
- 잘못된 요청은 서비스 호출 전에 거절한다.
- 과도한 목록 조회는 페이지 크기 상한으로 제한한다.
