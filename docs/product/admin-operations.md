# 어드민 운영

## 관리자 유형

- 운영자: 조회 중심 업무를 수행한다.
- 소유자 관리자: 변경성 업무를 수행한다.

## 읽기 권한

- 대시보드 조회.
- 코스 목록 조회.
- 코스 편집 문서 조회.
- 스텝 디버그 조회.
- 사용자 목록 조회.
- 사용자 상세 조회.
- 분석 조회.
- 운영 설정 조회.

## 변경 권한

- 새 코스 생성.
- 코스 보관.
- 코스 정보 저장.
- 유닛 추가, 수정, 삭제.
- 레슨 추가, 수정, 삭제, 순서 변경.
- 스텝 추가, 수정, 삭제, 순서 변경.
- 사용자 상태 변경.
- 사용자 삭제 상태 전환.
- 공지와 배너 저장.
- 이용약관과 개인정보처리방침 저장.
- 콘텐츠 초기화.

## 콘텐츠 운영

- 학습자에게는 active 콘텐츠만 노출한다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환이다.
- 코스 편집은 코스 정보, 유닛, 레슨, 스텝을 저장형 편집 대상으로 다룬다.
- 콘텐츠 편집 저장은 전체 코스 editor 문서를 검증한 뒤 수행한다.
- 유닛, 레슨, 스텝 삭제와 코스 보관은 확인 흐름을 거친다.
- 스텝 디버그 도구는 어드민 내부 QA 화면이며 실제 콘텐츠와 학습 데이터를 변경하지 않는다.
- 콘텐츠 초기화는 seed 기준으로 콘텐츠를 재정렬한다.
- seed에 없는 콘텐츠는 보관 상태로 전환한다.

## 사용자 운영

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 사용자 목록 화면은 페이지당 12명 기준으로 페이지네이션한다.
- 관리자 상태 변경 요청은 `active`, `suspended`만 허용한다.
- 삭제 요청 처리는 앱 소유 프로필을 `deleted` 상태로 전환한다.
- 학습 진행과 답변 row는 보존한다.

## 설정 운영

- 공지와 배너는 학습자에게 노출할 운영 메시지다.
- 이용약관과 개인정보처리방침은 운영 설정으로 저장한다.
- 설정 저장은 소유자 관리자만 수행한다.

## 안전 기준

- 변경성 작업은 권한 확인 후 실행한다.
- 위험 작업은 확인 흐름을 거친다.
- 잘못된 요청은 서비스 호출 전에 거절한다.
- 과도한 목록 조회는 페이지 크기 상한으로 제한한다.
