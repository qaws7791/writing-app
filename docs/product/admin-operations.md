# 어드민 운영

## 관리자 유형

- owner 관리자 한 종류만 운영한다.

## 읽기 권한

- 대시보드 조회.
- 코스 목록 조회.
- 코스 편집 문서 조회.
- 사용자 목록 조회.
- 사용자 상세 조회.
- 분석 조회.
- 감사 이력 조회.

## AI 에이전트 위임

- owner 관리자는 승인된 AI 에이전트에 관리자 MCP 조회 권한을 부여할 수 있다.
- 관리자 MCP는 코스 목록, 코스 편집 문서, 대시보드, 분석, 레슨별 분석, 원문 없는 AI 코칭 품질 집계와 IP를 제외한 감사 이력만 제공한다.

| 단계 | 변경 범위                                      | 실행 정책                                                                                                                                 |
| ---- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | 운영 조회                                      | 데이터를 변경하지 않는다.                                                                                                                 |
| 2    | 코스 초안 생성, 코스 초안 저장, 코스 보관 해제 | 별도 OAuth scope를 요구한다. 멱등 키, 입력 digest와 대상 버전·상태를 검증한다. 콘텐츠 변경과 실행 영수증을 같은 transaction에서 확정한다. |
| 3    | 코스 발행, 코스 보관, 사용자 상태 변경·삭제    | 별도 OAuth scope를 요구한다. owner 관리자는 서버에 저장된 요청을 매번 승인하거나 거절한다. 승인 뒤 대상 버전·상태를 다시 검증한다.        |

- 같은 2단계 요청은 저장된 결과를 재생한다.
- 같은 3단계 승인 요청은 동일한 실행 결과로 수렴한다.
- 코스 초안 저장은 기존 이미지 참조의 추가, 교체, 이동과 제거를 거부한다.
- 사용자 변경 Tool은 opaque 사용자 ID와 상태만 입력·출력한다.
- 관리자 MCP는 사용자 목록과 사용자 상세를 제공하지 않는다.
- 관리자 MCP는 이미지 업로드와 이미지 연결을 제공하지 않는다.
- 관리자는 외부 MCP client와 모델의 데이터 처리 조건을 승인한 뒤 staging에서 변경 기능을 활성화한다.
- 관리자 MCP와 변경 기능은 기본으로 비활성화한다.
- 관리자 MCP는 production에서 활성화하지 않는다.

## 변경 권한

- 새 코스 생성.
- 코스 보관.
- 코스 보관 해제.
- 코스 정보 저장.
- 커리큘럼 draft 발행.
- 유닛 추가, 수정, 삭제.
- 레슨 추가, 수정, 삭제, 순서 변경.
- 스텝 추가, 수정, 삭제, 순서 변경.
- 콘텐츠 이미지 업로드와 연결.
- 사용자 상태 변경.
- 사용자 삭제 상태 전환.

## 콘텐츠 운영

- 학습자에게는 active 콘텐츠만 노출한다.
- 코스 보관은 row 삭제가 아니라 `archived` 상태 전환이다.
- 코스 보관은 보관 해제로 되돌릴 수 있다. 보관을 되돌릴 수 없으면 사실상 삭제와 같으므로 `active` 복귀 경로를 유지한다.
- 코스 편집은 현재 단일 draft의 코스 정보, 유닛, 레슨, 스텝을 저장형 편집 대상으로 다룬다.
- 콘텐츠 편집 저장은 전체 코스 editor 문서와 `If-Match` 편집 버전을 검증한 뒤 수행한다.
- 발행은 저장과 분리된 소유자 행동이며 현재 draft를 immutable published revision으로 전환하고 다음 draft를 복제한다.
- 코스 보관은 published revision과 기존 학습자 고정을 삭제하지 않는다.
- 유닛, 레슨, 스텝 삭제와 코스 보관은 확인 흐름을 거친다.

## 사용자 운영

- 사용자는 `active`, `suspended`, `deleted` 상태를 가진다.
- 사용자 목록은 기본 20명 기준으로 페이지네이션하며 페이지 크기 상한은 100이다.
- 관리자 상태 변경 요청은 `active`, `suspended`만 허용한다.
- 상태 전이는 `active → suspended | deleted`, `suspended → active | deleted`만 허용하며 `deleted`는 관리자 조회만 가능한 종단 상태다.
- 삭제 요청은 즉시 session을 폐기하고 프로필을 `deleted`로 전환한다. 삭제 시각 기준 5일이 지나면 사용자 소유 인증·학습·초안·AI 데이터를 삭제하고 콘텐츠 revision은 보존한다.
- 개인정보 조회와 상태 변경·삭제는 보존 class가 있는 감사 이벤트로 남긴다.

## 안전 기준

- 변경성 작업은 권한 확인 후 실행한다.
- 위험 작업은 확인 흐름을 거친다.
- 잘못된 요청은 서비스 호출 전에 거절한다.
- 과도한 목록 조회는 페이지 크기 상한으로 제한한다.
