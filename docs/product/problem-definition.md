# 문제 정의

## 핵심 문제

- 한국어 글쓰기 학습은 시작 부담이 크다.
- 학습자는 긴 글쓰기보다 작은 활동이 필요하다.
- 학습자는 자신의 진행 위치를 잃지 않고 이어서 학습해야 한다.
- 운영자는 콘텐츠와 학습 현황을 같은 제품 안에서 확인해야 한다.

## 학습자 문제

- 무엇부터 써야 하는지 알기 어렵다.
- 문장, 문단, 논증, 독자 이해, 퇴고를 한 번에 배우기 어렵다.
- 작성한 답변에 즉시 피드백을 받기 어렵다.
- 학습을 중단한 뒤 이어갈 위치를 찾기 어렵다.

## 운영자 문제

- 현재 활성 코스와 레슨 수를 빠르게 확인해야 한다.
- 사용자 상태와 최근 학습 활동을 확인해야 한다.
- 완료율과 이탈률이 낮은 레슨을 찾아야 한다.
- 첫 레슨 시작과 7일 내 재방문 변화를 확인해야 한다.

## 제약

- 학습자 인증은 Google과 이메일·비밀번호를 지원한다.
- 어드민 인증은 별도 아이디/패스워드를 사용한다.
- 관리자는 owner 한 종류만 지원한다.
- 코스, 유닛, 레슨, 스텝은 보관으로 노출을 중단한다.
- 학습 답안과 AI 피드백은 동일한 사용자 삭제 수명주기를 따른다.
- 제품 문서에는 현재 구현되지 않은 기능을 확정 범위로 쓰지 않는다.
