# 제품 범위

## 제품 기준

글결은 한국어 글쓰기를 작은 레슨과 목적이 정해진 과제로 연습하는 성인 학습 서비스다. 핵심 사용자는 한국어 글쓰기 실력을 높이고 싶은 일반 성인이며, 첫 출시의 핵심 지표는 첫 레슨 시작과 첫 레슨 시작 후 7일 안의 재방문이다. 쓰기 기능은 점검 성공률과 점검 뒤 수정률을 보조 성공 지표로 사용한다.

## 유지하는 흐름

- 공개 랜딩에서 한국어 글쓰기 학습의 가치와 방식을 확인한다.
- Google 또는 이메일·비밀번호로 가입하고 로그인한다.
- 학습자 홈에서 코스를 선택하고 레슨을 이어서 학습한다.
- 발행된 쓰기 과제를 고르고 일반 텍스트 글을 작성한 뒤 AI 점검으로 다듬고 마친다.
- 8개 활동 유형을 완료하고 서버에 진행과 초안을 저장한다.
- 프로필과 라이트·다크·시스템 테마를 관리한다.
- owner 관리자가 코스와 쓰기 과제, 콘텐츠 이미지, 사용자 상태와 핵심 지표를 관리한다.
- owner 관리자가 승인된 AI 에이전트에 운영 조회를 위임한다.
- owner 관리자가 승인된 AI 에이전트에 코스 초안 생성·저장·보관 해제를 제한적으로 자동 실행하도록 위임한다.
- owner 관리자가 AI 에이전트의 코스 발행·보관과 사용자 상태 변경·삭제를 요청마다 승인한다.

8개 활동 유형은 `READING`, `COMPARE`, `MULTIPLE_CHOICE`, `FILL_BLANK`, `SELECT`, `ORDER`, `MATCH`, `CATEGORIZE`다.

## 명시적 비범위

- 관리자 자료 라이브러리와 자료 문서 편집기
- 어드민에 내장된 AI 채팅과 범용 AI agent 화면
- 관리자 콘텐츠 초기화 화면
- 결제·구독, 강사 마켓과 범용 학습 카테고리
- PWA 설치 기능과 사용자 프로필 이미지 직접 업로드
- AI 답안·피드백을 모델 학습 데이터셋으로 전환하는 기능
- 리치 텍스트 문서 편집, 학습자 글의 공개 발행과 실시간 공동 작성

비범위 기능은 범위 변경 티켓에서 제품 가치, 개인정보·보안 영향과 운영 책임을 승인하기 전에는 구현하지 않는다.
