# US-XXX-N 제목

## 문서 정보

- 영역: 플랫폼 또는 어드민
- 주 사용자: 학습자 또는 운영자
- 관련 퍼소나: 퍼소나명
- 상태: 초안
- 관련 요구사항:
  - `REQ-XXX-N`
- 관련 화면:
  - `SCR-N`

## 유저 스토리

사용자로서, 나는 목표를 달성하고 싶다. 그래야 사용자 가치가 생긴다.

## 사용자 가치

- 이 스토리가 사용자에게 주는 직접 가치를 적는다.
- 제품이나 운영자에게 주는 부수 가치는 필요한 경우에만 적는다.

## 인수 기준

- 사용자가 완료 조건을 확인할 수 있다.
- 실패나 빈 상태가 사용자에게 이해 가능하게 드러난다.
- 관련 화면 또는 흐름으로 이동할 수 있다.

## 비범위

- 이 스토리에서 해결하지 않는 일을 적는다.

## 메모

- 기획 판단, 논의 중인 사항, 후속 확인이 필요한 내용을 적는다.
