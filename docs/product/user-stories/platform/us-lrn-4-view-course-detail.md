# US-LRN-4 코스 상세 확인

## 문서 정보

- 영역: 플랫폼
- 주 사용자: 학습자
- 관련 퍼소나: 학습자
- 상태: 기준
- 관련 요구사항:
  - `REQ-LRN-3` 코스 탐색과 시작
- 관련 화면:
  - `SCR-005` 코스 상세

## 유저 스토리

학습자로서, 나는 코스의 설명과 커리큘럼을 확인하고 싶다. 그래야 지금 시작할 레슨과 전체 학습 범위를 이해할 수 있다.

## 사용자 가치

- 학습자는 코스의 목적과 진행률을 확인하고 진입 여부를 판단할 수 있다.
- 학습자는 완료 여부와 다음 학습 위치를 보고 다음 행동을 결정할 수 있다.

## 인수 기준

- 코스 상세에서 제목, 설명, 진행률, 완료 수, 전체 레슨 수를 볼 수 있다.
- 유닛별 레슨 목록을 볼 수 있다.
- 레슨 상태가 완료와 미완료 또는 이어서 학습으로 구분된다.
- active 레슨을 선택하면 레슨 화면으로 이동한다.
- 코스 조회 실패나 코스 없음 상태가 한국어로 표시된다.

## 비범위

- 코스 리뷰.
- 코스 검색.
- 여러 커리큘럼 전환.
