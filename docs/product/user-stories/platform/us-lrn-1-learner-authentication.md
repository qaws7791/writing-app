# US-LRN-1 학습자 인증

## 문서 정보

- 영역: 플랫폼
- 주 사용자: 학습자
- 관련 퍼소나: 학습자
- 상태: 기준
- 관련 요구사항:
  - `REQ-LRN-1` 학습자 인증
- 관련 화면:
  - `SCR-002` 학습자 로그인

## 유저 스토리

학습자로서, 나는 Google 계정 또는 확인된 이메일 계정으로 로그인하고 싶다. 그래야 내 학습 진행 상태를 내 계정에 안전하게 연결할 수 있다.

## 사용자 가치

- 학습자는 같은 계정으로 다시 접속해도 진행 상태를 이어갈 수 있다.
- 학습자는 상황에 따라 Google 또는 이메일 가입 방식을 선택할 수 있다.
- 학습자는 비밀번호를 잊어도 계정 존재 여부를 외부에 드러내지 않고 계정을 복구할 수 있다.
- 같은 이메일의 Google 로그인을 추가해도 기존 학습 진행 상태를 이어갈 수 있다.

## 인수 기준

- 학습자 로그인 화면에서 Google 로그인과 이메일 가입·로그인을 선택할 수 있다.
- 이메일 가입 후 확인 메일을 받고, 확인 전에는 로그인하거나 보호 API에 접근할 수 없다.
- 확인 메일을 다시 요청할 수 있으며 과도한 요청은 제한된다.
- 중복 가입 요청은 계정 존재 여부를 드러내지 않는 같은 확인 안내를 받는다.
- 비밀번호 재설정 요청은 이메일 등록 여부와 무관하게 같은 안내를 받는다.
- 재설정 링크는 만료 전 한 번만 사용할 수 있고, 변경 후 기존 로그인은 종료된다.
- 확인된 동일 이메일 Google 로그인은 새 사용자를 만들지 않고 기존 계정에 연결된다.
- 잘못된 로그인 정보, 확인 전 계정과 약한 비밀번호는 구분된 한국어 안내를 받는다.
- 로그인 성공 후 안전한 원래 목적 화면 또는 학습 홈으로 이동한다.
- 세션이 없는 사용자가 보호 화면에 접근하면 로그인 화면으로 이동한다.

## 비범위

- Google 외 소셜 로그인.
- 어드민 로그인.
