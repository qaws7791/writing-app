# US-LRN-5 레슨 스텝 완료

## 문서 정보

- 영역: 플랫폼
- 주 사용자: 학습자
- 관련 퍼소나: 학습자
- 상태: 기준
- 관련 요구사항:
  - `REQ-LRN-4` 레슨 진행
- 관련 화면:
  - `SCR-006` 레슨 진행

## 유저 스토리

학습자로서, 나는 레슨 스텝을 순서대로 완료하고 싶다. 그래야 하나의 글쓰기 개념을 작은 활동으로 익힐 수 있다.

## 사용자 가치

- 학습자는 레슨 시작, 스텝 진행, 완료 흐름을 끊기지 않고 수행할 수 있다.
- 학습자는 현재 위치와 남은 진행을 이해할 수 있다.

## 인수 기준

- 레슨 시작 화면에서 제목, 카테고리, 설명, 예상 시간, 스텝 수를 볼 수 있다.
- 시작 행동을 선택하면 레슨 시작 상태가 저장된다.
- 상단 진행 헤더와 하단 주요 행동 영역을 볼 수 있다.
- 마지막 스텝 이후 레슨 완료가 저장된다.
- 레슨을 다시 완료해도 최초 완료 기록과 완료 수가 중복되지 않는다.
- 완료 화면에서 다음 레슨 또는 코스로 돌아가기 행동을 볼 수 있다.

## 비범위

- 오프라인 학습.
- 레슨 순서 재배치.
- 레슨 중 자유 노트.
