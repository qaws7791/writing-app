# US-LRN-1 Google 로그인

## 문서 정보

- 영역: 플랫폼
- 주 사용자: 학습자
- 관련 퍼소나: 학습자
- 상태: 기준
- 관련 요구사항:
  - `REQ-LRN-1` Google 로그인
- 관련 화면:
  - `SCR-002` 학습자 로그인

## 유저 스토리

학습자로서, 나는 Google 계정으로 로그인하고 싶다. 그래야 내 학습 진행 상태를 내 계정에 연결할 수 있다.

## 사용자 가치

- 학습자는 같은 계정으로 다시 접속해도 진행 상태를 이어갈 수 있다.
- 학습자는 별도 가입 양식을 작성하지 않고 학습 앱에 진입할 수 있다.

## 인수 기준

- 학습자 로그인 화면에서 Google 로그인 버튼을 볼 수 있다.
- 이메일과 비밀번호 가입은 지원하지 않는다고 안내한다.
- 로그인 성공 후 안전한 원래 목적 화면 또는 학습 홈으로 이동한다.
- 세션이 없는 사용자가 보호 화면에 접근하면 로그인 화면으로 이동한다.

## 비범위

- 이메일과 비밀번호 가입.
- Google 외 소셜 로그인.
- 어드민 로그인.
