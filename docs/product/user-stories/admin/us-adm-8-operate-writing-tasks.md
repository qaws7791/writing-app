# US-ADM-8 쓰기 과제 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-8` 쓰기 과제 운영
- 관련 화면:
  - `SCR-110` 쓰기 과제 목록
  - `SCR-111` 쓰기 과제 편집

## 유저 스토리

소유자 관리자로서, 나는 쓰기 과제를 코스와 나란히 만들고 초안을 저장한 뒤 발행하고 싶다. 그래야 학습자가 목적이 있는 과제로 글을 시작할 수 있다.

## 사용자 가치

- 소유자 관리자는 도메인과 발행 상태로 과제를 찾을 수 있다.
- 소유자 관리자는 제목, 도메인, 유형, 난이도, 상황, 독자, 분량, 필수 요소를 초안에 저장할 수 있다.
- 소유자 관리자는 초안 저장과 학습자 대상 발행을 따로 할 수 있다.

## 인수 기준

- 콘텐츠 그룹에서 코스와 나란히 `쓰기 과제`로 이동할 수 있다.
- 과제 목록에서 검색, 도메인 필터, 상태 필터를 사용할 수 있다.
- 새 과제를 만들면 초안 편집 화면으로 이동한다.
- 초안 저장은 학습자에게 노출하지 않는다.
- 발행하면 학습자 카탈로그가 그 발행본을 본다.
- 이미 시작한 글은 이후 초안 발행으로 바뀌지 않는다.
- 저장하지 않은 변경과 저장 충돌을 화면에서 확인할 수 있다.

## 비범위

- 관리자 MCP writing-task Tool.
- 실시간 공동 편집.
- 둘 이상의 동시 mutable draft.
- 학습자 글 조회와 수정.
