# US-ADM-3 콘텐츠 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 관련 퍼소나: 운영자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-3` 콘텐츠 운영
- 관련 화면:
  - `SCR-103` 콘텐츠 관리
  - `SCR-104` 코스 편집
  - `SCR-109` 스텝 디버그

## 유저 스토리

운영자로서, 나는 코스 목록과 코스 구성을 확인하고 필요한 콘텐츠 편집 작업을 수행하고 싶다. 그래야 학습자에게 노출되는 콘텐츠 상태와 품질을 관리할 수 있다.

## 사용자 가치

- 운영자는 코스를 검색하고 카테고리별로 확인할 수 있다.
- 운영자는 코스 구조와 학습자 미리보기를 확인하며 콘텐츠 상태를 판단할 수 있다.
- 운영자는 어드민 내부 QA 화면에서 스텝 타입별 렌더링과 schema 검증 상태를 확인할 수 있다.
- 권한이 있는 운영자는 새 코스를 만들고 코스 정보, 유닛, 레슨, 스텝을 편집하거나 코스를 보관할 수 있다.

## 인수 기준

- 코스 목록에서 검색, 카테고리 필터, 페이지 크기 `10`, `20`, `50`을 사용할 수 있다.
- 코스 편집에서 코스 제목, 설명, 카테고리를 수정할 수 있다.
- 코스 편집에서 유닛을 추가, 수정, 삭제할 수 있다.
- 코스 편집에서 레슨을 추가, 삭제, 순서 변경하고 제목, 카테고리, 설명, 예상 시간, 요약을 수정할 수 있다.
- 코스 편집에서 스텝을 추가, 삭제, 순서 변경하고 확정 스텝 타입별 content를 수정할 수 있다.
- 코스 편집에서 학습자 미리보기 dialog로 현재 레슨 또는 스텝 표시를 확인할 수 있다.
- 스텝 디버그 화면은 어드민 보호 영역 안에서만 접근 가능하며 학습자 앱에는 노출되지 않는다.
- 스텝 디버그 화면에서 확정 스텝 타입별 샘플 data, schema 검증 결과, 렌더러 미리보기를 볼 수 있다.
- 코스 편집은 저장하지 않은 변경 상태, 저장 성공, 저장 실패를 표시한다.
- 새 코스를 만들면 기본 코스 정보만 가진 빈 커리큘럼 코스가 생성된다.
- 새 코스의 유닛, 레슨, 스텝은 코스 편집에서 추가할 수 있다.
- 새 코스 생성, 코스 보관, 코스 편집 저장은 변경 권한이 있을 때 수행된다.
- 보관은 삭제가 아니라 `archived` 상태 전환으로 처리된다.

## 비범위

- 학습자 코스 검색.
- 공개 코스 마켓.
- 실시간 공동 편집.
- 콘텐츠 버전 브랜치.
- 학습자 앱의 투어 또는 공개 디버그 페이지.
