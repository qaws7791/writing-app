# US-ADM-3 콘텐츠 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 관련 퍼소나: 운영자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-3` 콘텐츠 운영
- 관련 화면:
  - `SCR-103` 콘텐츠 관리
  - `SCR-104` 코스 미리보기

## 유저 스토리

운영자로서, 나는 코스 목록과 코스 구성을 확인하고 필요한 콘텐츠 작업을 수행하고 싶다. 그래야 학습자에게 노출되는 콘텐츠 상태를 관리할 수 있다.

## 사용자 가치

- 운영자는 코스를 검색하고 상태별로 확인할 수 있다.
- 운영자는 코스 구조를 미리보고 콘텐츠 상태를 판단할 수 있다.
- 권한이 있는 운영자는 새 코스를 만들거나 코스를 보관할 수 있다.

## 인수 기준

- 코스 목록에서 검색, 카테고리 필터, 상태 필터, 페이지 크기를 사용할 수 있다.
- 코스 상세에서 코스 정보, 커리큘럼 맵, 레슨과 스텝 미리보기를 확인할 수 있다.
- 새 코스를 만들면 기본 유닛, 기본 레슨, 읽기 스텝, 쓰기 스텝이 함께 생성된다.
- 새 코스 생성과 코스 보관은 변경 권한이 있을 때 수행된다.
- 보관은 삭제가 아니라 `archived` 상태 전환으로 처리된다.

## 비범위

- 학습자 코스 검색.
- 공개 코스 마켓.
- 저장형 코스 상세 편집.
