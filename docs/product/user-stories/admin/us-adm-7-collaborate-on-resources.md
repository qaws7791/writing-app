# US-ADM-7 관리자 자료실 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 상태: 기준
- 관련 요구사항: `REQ-ADM-7 관리자 자료실`
- 관련 화면: `SCR-110 관리자 자료실`

## 유저 스토리

운영자로서, 나는 프로젝트가 소유한 자료를 익숙한 문서 편집 화면에서 정리하고 싶다. 그래야 관리자 AI가 저장된 최신 자료를 검색해 출처가 있는 답변을 제공할 수 있다.

## 사용자 가치

- 운영자는 최대 3단계 폴더로 자료를 정리한다.
- 운영자는 Notion형 Lexical 편집기에서 GFM 문서를 작성한다.
- 명시적으로 저장된 Markdown만 AI가 읽으므로 AI 입력 상태가 예측 가능하다.
- 여러 탭이나 기기의 저장 충돌이 다른 변경을 덮어쓰지 않는다.
- 운영자는 실수로 삭제한 하위 구조를 휴지통에서 복원할 수 있다.
- 운영자와 AI는 같은 활성 문서 검색 경계를 사용한다.

## 인수 기준

- 제목과 본문이 한 번의 명시적 저장으로 갱신된다.
- 오래된 문서 버전의 저장은 거부되고 로컬 편집 내용은 유지된다.
- 지원 Lexical 블록은 Markdown으로 손실 없이 저장되고 다시 열린다.
- 폴더는 최대 3단계이며 드래그 앤 드롭으로 다른 폴더에 이동할 수 있다.
- 형제 항목은 이름순이고 수동 순서는 저장하지 않는다.
- 폴더의 휴지통 이동·복원·영구 삭제는 전체 하위 구조에 적용된다.
- JPEG·PNG·WebP 이미지를 최대 5MB로 R2에 업로드하고 대체 텍스트를 입력한다.
- 단일 Markdown 파일을 가져오고 문서별로 내보낼 수 있다.
- AI는 활성 문서를 검색·조회하고 사용한 문서 링크를 표시한다.
