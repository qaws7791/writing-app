# US-ADM-7 자료실 공동 편집

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-7` 자료실 공동 편집
- 관련 화면:
  - `SCR-110` 관리자 자료실

## 유저 스토리

운영자로서, 나는 폴더로 자료를 정리하고 다른 관리자와 같은 문서를 실시간으로 편집하고 싶다. 그래야 별도 파일과 저장본을 주고받지 않고 최신 운영 자료를 한곳에서 관리할 수 있다.

## 사용자 가치

- 운영자는 무제한 폴더 계층으로 자료를 찾기 쉽게 정리할 수 있다.
- 운영자는 최종 문서처럼 보이는 편집 화면에서 GFM 문서를 작성할 수 있다.
- 여러 관리자가 같은 본문을 동시에 편집해도 변경이 자동으로 병합된다.
- 운영자는 휴지통 이동과 전체 복원으로 폴더 트리를 안전하게 관리할 수 있다.
- 운영자는 제목과 본문을 검색하고 Markdown 파일을 가져오거나 내보낼 수 있다.

## 인수 기준

- 폴더와 문서를 생성하고 무제한 깊이로 이동·정렬할 수 있다.
- 폴더를 휴지통으로 이동하거나 복원하면 전체 하위 트리에 같은 동작이 적용된다.
- 문서 본문은 Markdown 텍스트를 원본으로 저장한다.
- Lexical 편집기는 분할 미리보기 없이 WYSIWYG 방식으로 GFM을 편집한다.
- 슬래시 커맨드, Markdown 입력 단축 문법, 블록 재정렬, 선택 서식 도구가 동작한다.
- 같은 문서를 편집하는 관리자들의 본문 변경이 저장 버튼 없이 실시간으로 병합된다.
- 연결이 일시적으로 끊겨도 현재 탭에서 작성한 본문은 재연결 후 병합된다.
- 검색 결과에서 전체 경로를 확인하고 해당 트리 위치로 이동할 수 있다.
- 단일 Markdown 파일 가져오기와 문서별 Markdown 다운로드가 동작한다.
