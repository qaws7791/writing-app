# US-ADM-2 제품 상태 조회

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 관련 퍼소나: 운영자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-2` 운영 지표와 분석
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-107` 분석

## 유저 스토리

운영자로서, 나는 제품의 학습자 활동과 콘텐츠 상태를 조회하고 싶다. 그래야 운영 상황과 개선 대상을 빠르게 파악할 수 있다.

## 사용자 가치

- 운영자는 핵심 지표로 현재 제품 상태를 파악할 수 있다.
- 운영자는 레슨별 완료율과 이탈률을 보고 콘텐츠 개선 대상을 찾을 수 있다.

## 인수 기준

- 대시보드에서 사용자, 활성, 가입, 완료 레슨, 콘텐츠 지표를 볼 수 있다.
- 최근 활동 사용자를 볼 수 있다.
- 분석 화면에서 최근 가입 추이와 완료 추이를 볼 수 있다.
- 레슨별 시작 수, 완료 수, 완료율, 이탈률을 볼 수 있다.
- 완료율이 낮은 레슨과 연속 학습일 분포를 볼 수 있다.

## 비범위

- 외부 BI 연동.
- 실시간 알림.
- 지표 사용자 정의.
