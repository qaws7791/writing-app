# US-ADM-2 제품 상태 조회

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-2` 운영 지표와 분석
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-107` 분석

## 유저 스토리

소유자 관리자로서, 나는 제품의 학습자 활동과 콘텐츠 상태를 조회하고 싶다. 그래야 운영 상황과 개선 대상을 빠르게 파악할 수 있다.

## 사용자 가치

- 소유자 관리자는 핵심 지표로 현재 제품 상태를 파악할 수 있다.
- 소유자 관리자는 레슨별 완료율과 이탈률을 보고 콘텐츠 개선 대상을 찾을 수 있다.

## 인수 기준

- 대시보드에서 총 사용자, 최근 7일 활성, 첫 레슨 시작, 활성화율, 7일 내 재방문율과 완료 레슨을 볼 수 있다.
- 비율의 분자·분모, 집계 기간과 빈 데이터 또는 미성숙 cohort 상태를 구분할 수 있다.
- 분석 화면에서 일별 가입, 첫 레슨 시작, 완료와 첫 시작 cohort의 7일 내 재방문 추이를 볼 수 있다.
- 레슨별 시작 수, 완료 수, 완료율, 이탈률을 볼 수 있다.
- 완료율이 낮은 레슨을 보고 전체 레슨을 서버 검색·정렬·페이지 이동으로 탐색하며 조회 상태를 URL로 다시 열 수 있다.
- AI 서비스의 요청·성공·실패, latency, token과 retry 집계를 원문 노출 없이 볼 수 있다.
- 삭제 상태 학습자는 모든 운영 지표에서 제외된다.

## 비범위

- 외부 BI 연동.
- 실시간 알림.
- 지표 사용자 정의.
