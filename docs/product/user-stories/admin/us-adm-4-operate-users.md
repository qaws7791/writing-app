# US-ADM-4 사용자 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 운영자
- 관련 퍼소나: 운영자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-4` 사용자 운영
- 관련 화면:
  - `SCR-105` 사용자 관리
  - `SCR-106` 사용자 상세

## 유저 스토리

운영자로서, 나는 학습자 목록과 상세 상태를 확인하고 필요한 상태 변경을 수행하고 싶다. 그래야 운영 위험을 권한 경계 안에서 처리할 수 있다.

## 사용자 가치

- 운영자는 사용자 상태와 학습 요약을 조회할 수 있다.
- 권한이 있는 운영자는 사용자 상태를 정지하거나 삭제 상태로 전환할 수 있다.

## 인수 기준

- 사용자 목록에서 이름 또는 이메일 검색, 상태 필터, 정렬을 사용할 수 있다.
- 사용자 상세에서 가입일, 최근 접속, 완료 레슨, 전체 진도를 볼 수 있다.
- 상태 변경은 사용자를 active 또는 suspended 상태로 전환할 수 있다.
- 상태 변경 결과가 한국어로 표시된다.
- 삭제 요청 처리는 사용자 상태만 `deleted`로 바꾸고 학습 진행과 답변은 보존한다.

## 비범위

- 사용자 완전 삭제.
- 학습 답변 편집.
- 사용자 메시지 발송.
