# US-ADM-4 사용자 운영

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-4` 사용자 운영
- 관련 화면:
  - `SCR-105` 사용자 관리
  - `SCR-106` 사용자 상세

## 유저 스토리

소유자 관리자로서, 나는 학습자 목록과 상세 상태를 확인하고 필요한 상태 변경을 수행하고 싶다. 그래야 운영 위험을 권한 경계 안에서 처리할 수 있다.

## 사용자 가치

- 소유자 관리자는 사용자 상태와 학습 요약을 조회할 수 있다.
- 소유자 관리자는 사용자 상태를 정지하거나 삭제 상태로 전환할 수 있다.

## 인수 기준

- 사용자 목록에서 이름 또는 이메일 검색, 상태 필터, 정렬을 사용할 수 있다.
- 사용자 목록은 기본 20명씩 표시하고 페이지 크기를 바꿀 수 있다.
- 사용자 상세에서 가입일, 최근 접속, 완료 레슨, 전체 진도를 볼 수 있다.
- 사용자 상세에서 학습 요약을 확인한 자리에서 바로 상태 변경과 삭제 요청을 할 수 있다.
- 상태 변경은 active 사용자를 suspended로, suspended 사용자를 active로 전환할 수 있다.
- 상태 변경 결과가 한국어로 표시된다.
- active 또는 suspended 사용자의 삭제 요청은 모든 session을 즉시 폐기하고 상태를 `deleted`로 바꾼다.
- `deleted`는 종단 상태이며 5일 보존 기간에는 관리자 조회만 허용한다.
- 삭제 시각이 5일 이상 지나면 인증·학습·초안·AI 사용자 소유 데이터를 멱등적으로 삭제하고 콘텐츠 revision은 보존한다.

## 비범위

- 백업 복원 후 외부 삭제 marker 재적용.
- 학습 답변 편집.
- 사용자 메시지 발송.
