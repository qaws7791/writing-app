# US-ADM-5 콘텐츠 유지보수

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항: `REQ-ADM-5 콘텐츠 유지보수`
- 관련 화면: `SCR-108 콘텐츠 유지보수`

## 유저 스토리

소유자 관리자로서, 나는 기준 seed로 콘텐츠를 복구하고 싶다. 그래야 잘못된 운영 콘텐츠를 명시적인 확인 절차 안에서 기준 상태로 되돌릴 수 있다.

## 사용자 가치

- 위험한 복구 작업이 일반 운영 화면과 분리된다.
- 초기화 결과와 새 revision을 즉시 확인할 수 있다.

## 인수 기준

- 운영자는 유지보수 메뉴와 화면에 접근할 수 없다.
- 소유자는 확인 dialog를 거쳐 콘텐츠 초기화를 실행한다.
- seed 밖 콘텐츠는 보관되고 seed 콘텐츠는 active 상태로 정렬된다.
