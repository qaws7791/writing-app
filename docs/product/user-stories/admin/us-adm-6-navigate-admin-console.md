# US-ADM-6 어드민 주요 메뉴 이동

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-6` 어드민 내비게이션
- 관련 화면:
  - `SCR-102` 어드민 대시보드
  - `SCR-103` 콘텐츠 관리
  - `SCR-110` 쓰기 과제 목록
  - `SCR-105` 사용자 관리
  - `SCR-107` 분석

## 유저 스토리

소유자 관리자로서, 나는 데스크톱 또는 노트북에서 어드민의 주요 업무 화면을 사이드바로 이동하고 싶다. 그래야 대시보드, 콘텐츠, 사용자와 분석 업무를 빠르게 전환할 수 있다.

## 사용자 가치

- 소유자 관리자는 현재 위치를 잃지 않고 주요 운영 화면을 오갈 수 있다.
- 소유자 관리자는 어드민 콘솔이 학습자 앱과 분리된 업무 공간임을 이해할 수 있다.

## 인수 기준

- 사이드바에서 대시보드, 콘텐츠 관리, 사용자 관리와 분석 링크를 볼 수 있다.
- 현재 메뉴는 `aria-current`로 표시된다.
- 사이드바와 본문 영역이 함께 렌더링된다.

## 비범위

- 사용자별 메뉴 커스터마이징.
- 모바일 전용 어드민 상단 bar 또는 탭 내비게이션.
- 관리자 계정 관리 메뉴.
