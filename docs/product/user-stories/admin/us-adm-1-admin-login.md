# US-ADM-1 어드민 로그인

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-1` 어드민 로그인
- 관련 화면:
  - `SCR-101` 관리자 로그인

## 유저 스토리

소유자 관리자로서, 나는 관리자 계정으로 어드민에 로그인하고 싶다. 그래야 운영 콘솔의 보호 화면에 접근할 수 있다.

## 사용자 가치

- 소유자 관리자는 학습자 앱과 분리된 인증 경계로 운영 업무에 진입할 수 있다.
- 소유자 관리자는 안전한 다음 경로로 이동해 업무 흐름을 이어갈 수 있다.

## 인수 기준

- 관리자 로그인 화면에서 관리자 아이디와 패스워드 입력을 볼 수 있다.
- 로그인 성공 후 안전한 `next` 경로 또는 대시보드로 이동한다.
- 로그인 실패 시 한국어 오류를 볼 수 있다.
- 세션이 없는 사용자가 어드민 보호 화면에 접근하면 로그인 화면으로 이동한다.

## 비범위

- 학습자 Google 로그인.
- 관리자 계정 생성 화면.
- 비밀번호 재설정.
