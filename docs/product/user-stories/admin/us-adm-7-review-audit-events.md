# US-ADM-7 감사 이력 확인

## 문서 정보

- 영역: 어드민
- 주 사용자: 소유자 관리자
- 관련 퍼소나: 소유자 관리자
- 상태: 기준
- 관련 요구사항:
  - `REQ-ADM-7` 감사 이력 조회
- 관련 화면:
  - `SCR-108` 감사 이력

## 유저 스토리

소유자 관리자로서, 나는 내가 수행한 개인정보 조회와 고위험 변경의 이력을 콘솔에서 확인하고 싶다. 그래야 운영 사고가 생겼을 때 무엇이 언제 어떤 결과로 실행됐는지 추적할 수 있다.

## 사용자 가치

- 소유자 관리자는 사용자 상세 조회, 상태 변경, 삭제 처리, 콘텐츠 발행과 보관 이력을 한 화면에서 확인할 수 있다.
- 소유자 관리자는 각 작업의 결과가 성공인지 실패인지 구분할 수 있다.
- 소유자 관리자는 조사 대상 요청을 요청 식별자로 로그와 연결할 수 있다.

## 인수 기준

- 감사 이력 화면에서 최근 이력을 최신순으로 확인할 수 있다.
- 각 이력은 실행 시각, 작업, 대상 종류, 결과를 한국어로 보여준다.
- 결과는 시작, 성공, 실패를 구분해 표시한다.
- 이력이 없으면 빈 상태를 보여준다.
- 조회에 실패하면 한국어 오류를 보여준다.
- 이력에는 이메일, 이름, 학습 답안, AI 피드백 원문이 나타나지 않는다.

## 비범위

- 기간·작업·대상별 필터와 페이지 이동.
- 감사 이력 내보내기.
- 학습자 본인에게 이력 공개.
- 감사 이력 삭제와 수정.
