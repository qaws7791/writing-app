# 기능 명세

## 학습자 기능

- 랜딩
  - 제품 소개와 시작 CTA를 제공한다.
  - 코스 둘러보기 CTA를 제공한다.
- 로그인
  - Google 로그인만 제공한다.
  - 이메일/비밀번호 가입은 지원하지 않는다고 안내한다.
- 홈
  - 사용자 이름을 인사말에 표시한다.
  - 연속 학습일과 완료한 레슨 수를 표시한다.
  - 진행 중인 코스를 최대 5개까지 표시한다.
  - 진행이 없으면 코스 둘러보기 행동을 제공한다.
- 코스 목록
  - 카테고리 탭을 제공한다.
  - 코스 카드에 제목, 설명, 레슨 수, 이미지를 표시한다.
- 코스 상세
  - 제목, 설명, 진행률, 완료 수, 전체 레슨 수를 표시한다.
  - 첫 레슨 또는 다음 레슨 시작 행동을 제공한다.
  - 유닛별 레슨 목록을 표시한다.
  - 레슨 상태는 완료, 진행 가능, 잠김으로 표시한다.
- 레슨
  - `lesson_id` query로 레슨을 연다.
  - 레슨 ID가 없으면 코스에서 레슨을 선택하라고 안내한다.
  - 시작 화면에서 제목, 카테고리, 설명, 예상 시간, 스텝 수를 표시한다.
  - 학습 스텝에서 답변 가능한 활동을 저장한다.
  - 마지막 스텝 이후 레슨 완료를 저장한다.
  - 완료 화면에서 다음 레슨 또는 코스로 돌아가기를 제공한다.
- AI 피드백
  - 사용자가 요청할 때 피드백을 생성한다.
  - 총평, 점수, 잘된 점, 다듬을 점, 다음 시도를 표시한다.
  - 시도 한도를 넘으면 오류를 표시한다.
- 프로필
  - 이름, 가입일, 완료 레슨, 연속 학습일을 표시한다.
  - 라이트, 다크, 시스템 테마 전환을 제공한다.
  - 로그아웃을 제공한다.

## 어드민 기능

- 로그인
  - 관리자 이메일과 비밀번호로 로그인한다.
- 대시보드
  - 총 사용자, 최근 7일 활성, 가입, 완료 레슨, 활성 콘텐츠를 표시한다.
  - 최근 활동 사용자를 표시한다.
- 콘텐츠 관리
  - 코스 검색, 카테고리 필터, 상태 필터, 페이지 크기를 제공한다.
  - 새 코스 생성을 제공한다.
  - 코스 보관 확인 흐름을 제공한다.
  - 코스 상세는 읽기 전용 미리보기로 제공한다.
- 사용자 관리
  - 이름 또는 이메일 검색을 제공한다.
  - 상태 필터와 정렬을 제공한다.
  - 사용자 정지와 삭제 상태 전환을 제공한다.
- 분석
  - 최근 30일 가입과 완료 추이를 표시한다.
  - 연속 학습일 분포를 표시한다.
  - 레슨별 시작, 완료, 완료율, 이탈률을 표시한다.
- 운영 설정
  - 공지와 배너를 저장한다.
  - 이용약관과 개인정보처리방침을 저장한다.
  - 콘텐츠 초기화를 실행한다.

## 현재 구현 상태

- 학습자 앱과 학습자 API는 현재 구현되어 있다.
- 어드민 앱과 어드민 API는 현재 구현되어 있다.
- 어드민 코스 상세는 저장형 편집기가 아니라 읽기 전용 미리보기다.
- 제품 런타임은 테스트용 fake API 모드를 사용하지 않는다.
