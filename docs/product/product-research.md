# 제품 리서치

## 조사 범위

- 현재 코드베이스.
- `docs` 하위 문서.
- OpenAPI 정적 계약.
- 콘텐츠 seed 데이터.

## 문서 동기화 기록

- 2026-06-20 시작: `apps`와 `packages`의 API 라우트, core 서비스, 도메인 정책, 저장소 구현, web/admin 기능 화면을 기준으로 유저 스토리와 요구사항 누락 여부를 역추적한다.
- 2026-06-20 완료: 보강한 요구사항과 전체 순회 결과를 `codebase-sync-audit.md`에 연결했다.
- 2026-06-20 완료: 쓰기 스텝의 고급 필드와 반박/자기반박 모드를 제품 요구사항과 콘텐츠 모델에 반영했다.

## 확인된 제품 사실

- 공식 제품명은 제품 문서에서 `글결`로 사용한다.
- 학습자 로그인 화면은 `글결.`을 표시한다.
- 학습자 인증은 Google 로그인을 단일 진입점으로 둔다.
- 학습자 보호 라우트는 세션이 없으면 `/login?next=...`로 이동한다.
- 학습자 앱은 `/app`, `/app/courses`, `/app/courses/[id]`, `/app/lesson`, `/app/profile`을 제공한다.
- 학습자 API는 코스, 레슨, 진행, 프로필과 레슨 단위 상태 전이·AI 피드백을 제공한다.
- 어드민 앱은 대시보드, 콘텐츠 관리, 사용자 관리, 분석, 운영 설정을 제공한다.
- 어드민 변경성 API는 소유자 관리자 권한을 요구한다.
- 현재 제품 기준의 코스 상세 어드민 화면은 저장형 코스 편집기다.
- 쓰기 스텝은 최소/목표/최대 글자 수 외에도 반박 쓰기 맥락, 참고 원문, 구조 가이드, 참조 답안, 드래프트 저장 보조 행동을 제공할 수 있다.
- 콘텐츠 seed는 5개 코스, 15개 유닛, 44개 레슨, 136개 스텝이다.

## 문서 충돌

- 랜딩 화면은 `Kernel`을 표시하지만 로그인 화면과 어드민 화면은 `글결`을 사용한다.
- 제품 문서에서는 `글결`을 기준으로 쓰고, 랜딩 화면 이름은 UI 불일치로 기록한다.
- 일부 오래된 문서는 프로필 제거를 말하지만 현재 코드에는 `/app/profile`과 `GET /profile`이 있다.
- 일부 오래된 문서는 코스 검색을 말하지만 현재 학습자 앱에는 코스 검색 화면이 없다.
- 일부 오래된 문서는 여러 커리큘럼 모델을 말하지만 현재 schema는 단일 현재 커리큘럼을 기준으로 한다.
- 코스 상세 어드민 화면은 현재 제품 기준에 따라 저장형 코스 편집기로 제품 문서에 포함한다.
- 일부 가이드 문서는 reset 단계 문구를 포함하지만 현재 제품 source는 구현되어 있다.
- 과거 단일 제품 문서였던 유저 스토리, 요구사항, 기능 명세, 사용자 흐름, 화면 요약, 제품 행동 명세는 개별 유저 스토리와 요구사항 문서로 이관했다.

## 문서 작성 기준

- 확정 기능은 현재 코드로 확인되는 기능만 적는다.
- 제거된 기능은 확정 기능 목록에 넣지 않는다.
- 오래된 문서의 문구는 새 제품 문서로 옮기지 않는다.
- 계속 증가하는 유저 스토리와 요구사항은 개별 파일로 관리한다.
- 충돌은 이 문서에만 짧게 기록한다.
