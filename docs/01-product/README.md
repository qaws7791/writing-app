## 현재 기준

- 현행 PRD: [[00-prd/v3]]
- 핵심 루프: 사진 업로드 → 표현 재료 선택 → 문장 씨앗 조립 → 한 문장 작성 → 표현 카드 저장
- MVP 목표: 사용자가 5~10분 안에 직접 작성한 한 문장을 문체 정원에 저장한다.
