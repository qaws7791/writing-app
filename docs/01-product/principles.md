## 1. 사용자가 문장의 주인이다

AI는 사용자의 문장을 대신 완성하지 않는다. 사용자가 직접 문장을 만들 수 있도록 관찰 가능성, 선택지, 피드백, 리듬, 문체 기억을 제공한다.

판단 기준:

- 완성문 삽입이 기본 행동이면 제거한다.
- 사용자가 직접 고르고 쓰는 단계가 없다면 다시 설계한다.
- 저장 문장은 직접 작성 여부와 출처를 가진다.

## 2. 깊이는 유지하되 표면은 조용하게 만든다

제품은 많은 표현 자산을 가질 수 있다. 그러나 한 화면에 많은 표현 자산을 동시에 보여주면 안 된다.

기본 화면에는 현재 행동에 필요한 최소 정보만 둔다. 더 깊은 자산은 사용자가 명시적으로 열 때만 보여준다.

## 3. 한 화면에는 하나의 의도만 둔다

사용자는 한 번에 하나의 일을 한다. 보기, 고르기, 수집하기, 조립하기, 쓰기, 듣기, 저장하기는 단계적으로 분리한다.

판단 기준:

- Primary CTA는 한 화면에 하나다.
- 보조 행동은 최대 두 개다.
- 우측 패널과 하단 패널은 동시에 열리지 않는다.

## 4. 생성보다 선택을 먼저 둔다

AI가 완성문을 생성하기 전에 사용자가 먼저 관찰하고 선택해야 한다. 선택 데이터가 쌓인 뒤에야 AI 제안이 개인화된다.

첫 문장 루프의 기본 순서는 다음이다.

> 사진 보기 → 표현 재료 선택 → 문장 씨앗 조립 → 직접 쓰기 → 저장

## 5. 정답이 아니라 뉘앙스를 다룬다

글숨 Labs는 국어 문법 퀴즈 앱이 아니다. 맞다/틀리다보다 어떤 느낌이 생기는지를 보여준다.

조사, 어미, 쉼표, 줄바꿈, 완충어는 평가 대상이 아니라 사용자가 직접 만질 수 있는 표현 재료다.

## 6. Calm Mode를 기본값으로 둔다

모든 창작 화면의 기본 상태는 Calm Mode다. 전체 자산, 진행 지도, 보상, 최근 항목, 도움말, 빠른 액션은 기본 화면에 동시에 노출하지 않는다.

Focus Mode는 쓰기와 듣기에만 사용한다. Expanded Mode는 상세 자산 보기처럼 사용자가 명시적으로 열 때만 제공한다.

## 7. 보상은 점수가 아니라 표현 자산이다

배지, 랭킹, 출석체크로 리텐션을 만들지 않는다. 사용자가 세션을 끝낸 뒤 남는 것은 단어 카드, 문장 카드, 장면 카드, 리듬 버전, 문체 변화여야 한다.

MVP에서는 문체 정원 Lite에 저장되는 표현 카드가 보상이다.

## 8. 사용자를 단정하지 않는다

문장 지문과 피드백은 사용자를 평가하지 않는다. "당신은 표현력이 부족합니다"가 아니라 "최근 문장에서는 완충어가 자주 보입니다"처럼 관찰한다.

민감 속성 추론과 인물 식별은 하지 않는다.
