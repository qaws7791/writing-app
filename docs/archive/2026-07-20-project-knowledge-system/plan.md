# 프로젝트 지식 시스템 정리 계획

## 목적

코드·설정이 소유하는 현재 사실을 사람이 작성한 현재 문서에서 제거한다. 문서는 제품 의도, 설계 원칙, 운영 절차만 소유하고, 현재 구조·값·목록은 해당 코드와 설정에서만 확인한다.

## 범위

- 루트 `README.md`와 문서 인덱스·권위 지도·문서 작업 안내를 정리한다.
- `workspace-inventory.md`를 제거하고 관련 검증을 코드 인벤토리 검증으로 축소한다.
- 시스템 개요, 런타임 설정, 배포, 기술 스택, API 계약에서 topology·port·route·버전·service 목록을 제거한다.
- 제품·디자인 문서의 구현 경로 표기는 화면·사용자 흐름의 의미를 보존하며 후속 단위에서 정리한다.
- 과거 ADR·archive는 현재 사실의 근거로 사용하지 않으므로 역사 기록으로 보존한다.

## 완료 조건

- 현재 값과 구조를 선언하는 living 문서가 없다.
- 문서는 해당 코드 권위 소스를 직접 링크해 탐색 경로만 제공한다.
- `docs/work`에는 기준 commit과 작업 판단만 남고, 검증 결과는 commit·환경·명령이 고정된 archive 기록으로 이동할 수 있다.
- 문서 검증은 코드 사실 문구를 강제하지 않고 문서 구조·링크·실행 진입점만 확인한다.
