# 학습자 코스 상세 UI/UX 개선

## 목표

[`US-LRN-4`](../../product/user-stories/platform/us-lrn-4-view-course-detail.md)와 [`REQ-LRN-3`](../../product/requirements/platform/req-lrn-3-course-discovery.md), [`SCR-005`](../../design/screens/SCR-005-learner-course-detail.md)의 목적(코스 내용·진행 확인 후 다음 레슨 진입)을 유지하면서, 코스 상세 화면의 정보 위계·현재 위치·잠금/진행 empty 상태·접근성 표현을 개선한다.

이 문서는 한시 계획이다. 현재 사실의 권위 소스가 아니며, 구현 전에 합의된 결론을 `SCR-005`와 필요한 product 문서에 반영한 뒤 코드를 변경한다.

## 비범위

- 코스 목록(`SCR-004`), 레슨 플레이어, 학습 홈의 전면 UI 개편
- 썸네일 일러스트 재제작·신규 에셋 파이프라인
- 다크 모드·디자인 토큰 체계 전면 개편
- 잠금 정책 자체의 제품 규칙 변경(아래 미결 항목이 확정되기 전까지 UI만으로 정책을 바꾸지 않음)
- API wire schema·DTO 필드 추가는 조사 결과 클라이언트 합산으로 부족할 때만 후속 작업으로 분리

## 승인 범위 (2026-07-29 후속)

승인: 2(잠금 스타일만), 4, 5, 6, 7, 9, 10, 11, 13, 14, 16(완료 시 CTA 없음).

미승인·되돌림: 1(단독), 3, 8, 12, 15, 17, 2의 잠금 해제 안내 문구, 16의 복습 CTA·완료 카피.

## 미결 해소

승인 범위만 반영한다. 잠금 해제 안내·시작 전 라벨·총 예상 시간·elevated surface·단일 유닛 Accordion 단순화는 적용하지 않는다.

## 실행 결과

최초 구현은 17항목 전부였으나, 승인 목록만 남기고 나머지를 되돌렸다. 유지: 잠금 opacity, 상태 아이콘·aria-label, 썸네일 레이아웃, 유닛 진도, “코스 목록으로”, 커리큘럼 `h2`, 현재 레슨 강조, 행 hit area, 아이콘 스케일, `bg-accent` 진행바, 완료 시 CTA 없음.

## 실행 순서

1. **A. 명세 고정** — 위 미결 3항을 결정한 뒤 `SCR-005`에 현재 레슨 강조, 시작 전 진행 표현, 잠금/active 규칙, back 라벨, 헤딩 계층, 완료 히어로를 명문화한다. 제품 규칙이 바뀌면 `REQ-LRN-3` / `US-LRN-4`를 최소 수정한다.
2. **B. 히어로** — empty/진행 중/완료 진행 UI, 썸네일 레이아웃, CTA 문구·다음 레슨 정렬(`course-detail-page`).
3. **C. 커리큘럼** — 현재 행 강조, 잠금·완료·가능 상태의 접근성 이름, 행 밀도·아이콘 스케일, 유닛 메타(`course-curriculum`).
4. **D. 내비·스캔** — back 라벨, 커리큘럼 `h2`, (조건부) 총 예상 시간.
5. **E. 폴리시** — surface 대비, Accordion 단일 유닛, 토큰 정렬. A–C와 충돌하지 않는 범위만.
6. **F. 검증·마무리** — 아래 완료 조건 충족 후, 영구 결론이 권위 문서에 반영됐는지 확인하고 이 작업 단위를 `docs/archive/2026-07-29-learner-course-detail-ux/`로 이동한다.

## 완료 조건

- `SCR-005`(및 변경된 product 문서)가 구현과 일치한다.
- 시작 전·진행 중·전체 완료·조회 실패/없음 상태가 화면에서 구분된다.
- 현재(다음) 레슨이 히어로 CTA와 커리큘럼에서 같은 대상으로 식별된다.
- 레슨 상태가 색만으로 전달되지 않으며, 키보드 포커스와 스크린리더로 잠김/완료/이동 가능이 구분된다.
- 기존 course-detail 관련 테스트가 새 관찰 가능 행동을 반영하고, `bun run typecheck`와 해당 workspace lint가 통과한다.
- `docs/work/_index.md`에서 이 작업을 archive로 옮긴다.

## 검증 관점

- 데스크톱·모바일 뷰포트에서 히어로·커리큘럼 위계
- 키보드만으로 back, CTA, 유닛 disclosure, active 레슨 진입
- reduced motion 환경에서 불필요한 모션 없음
- 잠금 정책 확정안에 맞는 상호작용(클릭 불가 vs 전체 개방)

자동화는 동작·상태 회귀에 필요한 최소 범위만 확장한다. 정적 마크업 스냅샷 남발은 하지 않는다.
