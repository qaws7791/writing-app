가장 시급한 3가지

1. **권한 경계 테스트 3곳이 실제로 아무 분기도 지키지 않는다.** [`src/server/auth/get-admin-session-token.test.ts:25-38`](../../../apps/admin/src/server/auth/get-admin-session-token.test.ts)은 구현이 읽지 않는 `NODE_ENV`를 stub해 입력·기대가 완전히 동일한 테스트 2건이고, [`src/app/(admin)/users/[id]/page.test.ts`](<../../../apps/admin/src/app/(admin)/users/[id]/page.test.ts>)에는 미인증 분기가 없으며, 로그인 후 open-redirect 방어를 실제로 수행하는 [`admin-auth-client.ts:19`](../../../apps/admin/src/features/authentication/api/admin-auth-client.ts)의 `resolveSafeAdminNextPath` 호출은 어느 테스트도 고정하지 않는다. 그 한 줄을 지워도 112개 테스트가 모두 통과한다.
2. **유일한 network 경계 통합 테스트가 프로덕션 조립을 우회한다.** [`src/test/admin-api-ui.integration.test.tsx:220-237`](../../../apps/admin/src/test/admin-api-ui.integration.test.tsx)이 `uploadAdminContentAssetAction`이 소유한 FormData → generated multipart 변환을 테스트 안에서 다시 구현한다(D-3). 실제 Server Action이 깨져도 이 테스트는 통과한다.
3. **환경 설정이 스위트 시간을 지배한다.** [`vitest.config.ts:35`](../../../apps/admin/vitest.config.ts)가 전역 `environment: "jsdom"`이라 DOM이 필요 없는 `.test.ts` 21개까지 jsdom을 지불한다. 실측 32.34s 중 environment가 32.39s인데 실제 test 실행은 8.69s다(A-11, C-11).
