## 사용 기준

- 기본 프로젝트 탐색과 현재 사실 판정에서는 이 디렉터리를 읽지 않는다.
- 과거 결정의 실행 증거, 회고 또는 재현 맥락이 필요할 때만 해당 작업을 연다.
- 검증 보고서는 기준 commit, 실행 시각과 환경, 실행 명령, 결과와 artifact 위치를 고정한다.
- 보관 문서는 보안상 삭제, 민감 정보 제거나 깨진 링크 보정 외에는 수정하지 않는다.
