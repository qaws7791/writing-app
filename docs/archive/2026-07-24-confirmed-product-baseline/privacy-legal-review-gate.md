# 개인정보·약관 외부 법률 검토 gate

## 상태

- 상태: 외부 검토 대기 — production launch 차단
- 제품·법률 책임자: 미지정
- 외부 검토자·의뢰일·결과일: 미확정
- 결과 증거와 변경 티켓: 없음

이 문서는 검토 준비와 출시 gate를 추적하는 작업 기록이며 법률 자문이 아니다. 저장소 구현만으로 한국 서비스 운영 의무 충족을 판정하지 않는다.

## 검토 입력

- [개인정보·AI 데이터 맵](../../engineering/privacy.md)의 범주, 목적, 보존·파기와 외부 처리 경계
- 탈퇴 후 active system 5일, request log 30일, security IP·User-Agent 90일, 감사 1년·3년, backup 최대 30일, marker 30일 초과 정책
- Resend, OpenAI, Google OAuth와 S3 호환 storage의 계약, 처리 지역, 재위탁, 국외 이전, 보존·삭제 자료
- 실제 외부 log class retention과 private marker·backup lifecycle 설정 및 실행 증거

## 약관·개인정보처리방침 검토 항목

- 운영 주체·연락처, 수집 항목·출처·목적·적법 근거와 필수·선택 구분
- 회원 탈퇴, 5일 유예, backup·marker와 법정 보존 예외를 포함한 기간·파기 절차
- 처리위탁, 제3자 제공, 국외 이전, 재위탁과 정보주체 고지·동의 요건
- 열람·정정·삭제·처리정지·동의 철회 절차, 미성년자 적용 여부와 침해 대응
- cookie·session·보안 로그, AI 코칭 입력·출력·한계와 자동화된 결정 해당 여부
- 이용 자격, 금지 행위, 사용자 콘텐츠 권리, 서비스 변경·중단, 계정 종료, 책임 제한, 분쟁·준거법
- 승인 문서의 version·시행일·변경 고지와 공개 route. 승인 전 footer link는 노출하지 않는다.

## gate 해제 조건

- [ ] 외부 검토자의 식별자, 검토 범위, 날짜와 서면 결과 링크가 기록됐다.
- [ ] 필수 변경마다 owner·우선순위·수용 기준을 가진 별도 티켓이 연결됐다.
- [ ] 승인된 약관·개인정보처리방침과 공개 route가 검증됐다.
- [ ] 외부 log sink의 30일·90일 class 파기 증거와 backup 최대 30일 lifecycle 증거가 검증됐다.
- [ ] 삭제 marker lifecycle이 backup 최대 수명보다 길고 public asset과 분리됐다는 증거가 검증됐다.
- [ ] 법률 검토가 별도 AI 동의를 요구하면 승인된 별도 제품 범위와 구현·철회·증거 계약이 완료됐다.

하나라도 충족하지 못하면 gate는 닫힌 상태다. 현재는 모든 항목이 미완료이며 production launch를 허용할 근거가 없다.
