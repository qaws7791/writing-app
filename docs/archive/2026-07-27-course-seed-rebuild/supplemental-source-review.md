# 추가 후보 자료 전수 검토

## 검토 범위와 기준

사용자가 제공한 [`korean_adult_literacy_evidence_collection_2026-07-27.md`](./korean_adult_literacy_evidence_collection_2026-07-27.md)의 294건을 기존 활성 출처 43건과 제목·DOI·URL·동일 원자료 기준으로 대조했다.

채택 자료는 결제·기관 구독·로그인 없이 공식 기관, 공개 학술지, 저자·기관 저장소에서 합법적인 전문을 실제로 열 수 있고, 기존 자료에 없는 개념·측정·중재·절차·상충 결과·적용 한계를 제공해야 한다. 유료 원문, 초록·서지만 공개된 자료, 동일 원자료, 최신판이나 더 강한 근거가 대체하는 자료와 일반 성인 한국어 문해로의 적용 거리가 큰 자료는 수집에서 제외했다.

후보 문서의 `원문` 표시는 그대로 믿지 않고 다시 확인했다. 실제 원문과 다른 제목·DOI·연도·대상 표기는 각 전수 판정 문서에서 교정했으며, 교정된 실제 원자료만 출처 노트에 사용한다.

## 상세 추출 완료

채택한 125건은 무료 전문을 다시 열어 본문·표·그림·부록에서 확인한 내용을 표준 14절 출처 노트로 추출했다. 기존 43건과 합친 활성 출처는 168건이며, 신규 125건은 모두 직접 근거다. 오픈 액세스 서지만 확인하고 전문을 직접 검증하지 못한 `src-0114`는 미활성으로 보존했으며 다음 신규 ID는 `src-0175`다.

파일명–출처 ID, 절 이름·순서, 접근일, 원문 URL, 공식 역량 ID, 위치가 서로 다른 추출 행, 정규화 제목·DOI 중복과 로컬 링크는 [`source-extraction-audit.md`](./source-extraction-audit.md)에서 전수 검사한다. 이 완료는 2단계 자료 수집의 판정이며 자료 간 주장 분석과 역량 체계 확정은 시작하지 않았다.

## 판정의 한계

무료로 열 수 있다는 사실은 연구의 질이나 한국어 모어 일반 성인에 대한 직접 일반화를 보증하지 않는다. 학생·저문해 성인·특정 국가·제2언어·직장 훈련 자료의 대상 차이, 관찰연구의 비인과성, 중재의 지연·전이 부족과 메타분석의 이질성은 개별 출처 노트에서 별도로 제한한다.
