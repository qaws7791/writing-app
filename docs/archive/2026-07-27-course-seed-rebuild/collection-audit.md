# 전체 자료 수집 감사

## 이전 판정과 재검토

2026-07-27의 최초 감사에서는 26개 초기 역량이 모두 복수 출처로 포괄되고 각 영역의 핵심 원리가 독립 출처로 교차 확인되었다는 이유로 2단계를 완료 처리했다. 그러나 같은 날 사용자 검토에서 원문을 직접 확인해 학습에 사용할 내용을 충분히 추출하지 못했다는 문제가 확인되어 완료 판정을 보류했다.

기존 43건을 표준 14절로 확장한 뒤 추가 후보 294건을 전수 판정했다. 무료 전문과 차별적 학습 근거를 모두 확인한 125건을 같은 형식으로 상세 추출해 활성 출처 168건을 완성했다. [`source-extraction-audit.md`](./source-extraction-audit.md)의 전수 감사 결과에 따라 2단계 완료로 판정한다.

이 판정은 확인 가능한 원문에서 학습 설계에 사용할 내용을 충분히 추출했다는 뜻이다. 코스 구조, 특정 교수법의 효과나 26개 초기 역량의 최종 독립성을 확정하지 않는다.

## 종료 조건 확인

- 모든 초기 역량에 20건 이상의 관련 출처가 있다.
- 한국어 규범·국어 능력·국어교육 원리는 국립국어원과 교육부 자료를 포함한 국내 권위 자료로 확인했다.
- 168개 활성 출처 노트에 원문 위치·확인 범위와 표준 14절의 상세 학습 내용이 있다.
- 신규 125개 노트는 서로 다른 원문 위치의 추출 행을 5개 이상 갖는다.
- 전문을 확인하지 못한 `src-0005`, `src-0011`, `src-0030`, `src-0034`는 확인한 초록·첫 면·보충 자료와 미확인 본문의 경계를 구체적으로 기록했다.
- 추가 후보 294건의 포함·제외·미해결 판정과 무료 전문 접근 경로를 모두 기록했다.
- 활성 노트의 정규화 제목·DOI 중복, 카탈로그 누락·초과와 끊어진 로컬 링크는 0건이다.
- 반복 검색에서 새 핵심 원리보다 기존 원리의 반복이나 특정 학교급·직업·창작 맥락 자료가 주로 확인되어 영역별 포화로 판정했다.
- 원문 전체를 확인하지 못한 자료는 제한적 근거로 낮췄고 간접 근거만으로 채택한 출처는 없다.

영역별 세부 근거는 [한국어·읽기](./korean-reading-collection.md), [사고·정보·매체](./reasoning-information-collection.md), [쓰기 과정·조직·수정](./writing-process-collection.md), [표현·수사·독자·장르](./rhetoric-audience-collection.md) 수집 기록에서 확인한다.

## 3단계에 넘길 판단

- 서로 다른 대상·언어·과제·연구 설계의 결과를 한국어 모어 일반 성인에게 어느 강도로 적용할 수 있는지 판단해야 한다.
- 연결 수가 많은 임시 역량을 그대로 독립 역량으로 확정하지 않고 주장 단위 중복·충돌과 관찰 가능한 학습 성과를 분석해야 한다.
- 제한적 근거 4건은 확인한 범위를 넘는 세부·통계·효과 주장의 근거로 사용할 수 없다.
- `src-0114`와 추가 후보의 미해결 2건은 무료 전문을 직접 검증하기 전에는 활성 근거로 승격할 수 없다.

이 판단은 3단계 입력만 정의한다. 주장 분해, 상충 분석, 최종 역량 확정과 코스 설계는 이번 작업에서 시작하지 않았다.
