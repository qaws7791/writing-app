# 전체 코스 유닛·레슨 목차

## 상태와 설계 기준

- 상태: 2026-07-28 사용자 승인 완료
- 대상: 4단계에서 승인된 14개 코스
- 범위: 코스 종료 성과, 제외 범위, 유닛 성과, 레슨별 관찰 가능한 목표
- 비범위: 스텝 타입, 문항, 예문, 해설, 학습자용 본문과 AI 피드백

각 코스의 종료 성과를 독립적으로 관찰할 수 있는 하위 성과로 나누고, 이를 다시 하나의 목표를 가진 레슨으로 분해했다. 레슨에서 유닛과 코스 성과까지 역으로 검토해 누락과 중복을 조정했으며 수량을 먼저 정해 내용을 채우지 않았다. 모든 코스는 다른 코스를 선수 조건으로 요구하지 않는다.

이 문서는 작업 판단을 기록하는 비권위 산출물이다. 최종 콘텐츠 값의 권위 소유자는 [`content-seed-data.json`](../../../../packages/modules/content/src/infrastructure/persistence/content-seed-data.json)이다.
