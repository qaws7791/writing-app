# 5단계 전체 목차 설계와 코스별 구축 현황

## 운영 기준

4단계에서 승인된 14개 코스 전체의 유닛·레슨 목차를 설계하고 2026-07-28 승인된 기준선으로 고정했다. 각 코스는 유닛 4개 이상과 코스 전체 레슨 20~100개를 가지며, 종료 성과를 유닛 성과와 하나의 관찰 가능한 레슨 목표로 분해한 결과를 사용했다.

승인 목차를 기준으로 전체 시드를 구축하고 DTO·격리 시드·브라우저 전이를 검증했다. 구조와 실행 계약은 통과했다. 목표별 사례 구체성의 한계는 후속 콘텐츠 부채로 기록했으며, 2026-07-28 사용자의 전체 커밋·종료 결정에 따라 현재 기준선을 동결했다.

전체 목차는 [`all-course-outlines.md`](./all-course-outlines.md), 수량·해시는 [`content-build-audit.json`](./content-build-audit.json), 실행 결과와 한계는 [`validation-report.md`](./validation-report.md)에 기록했다.
