## 5단계 재설정 내용

- 이번 시드의 각 코스에 유닛 4개 이상과 코스 전체 레슨 20~100개의 경계를 적용한다.
- 수량을 목표값이나 고정 템플릿으로 사용하지 않고 코스 종료 성과를 유닛 성과와 하나의 관찰 가능한 레슨 목표로 재귀적으로 분해·통합한다.
- 14개 코스를 69개 유닛과 321개 레슨으로 설계하고 수량·ID·역량 포괄성·코스 경계를 일괄 감사했다.
- 최종 역량 24개를 주역량으로 정확히 한 번씩 배정했고 전역 계층 ID 404개와 레슨 제목·목표에서 중복을 발견하지 않았다.
- 전체 목차와 성과·목표에 대한 사용자 승인을 받기 전에는 스텝 집필을 재개하지 않는다.
- 첫 코스의 기존 3개 유닛·8개 레슨 구조는 새 기준에 미달하므로 호환성을 보존하지 않고 전면 재설계한다.
- 이 수량 경계는 이번 시드 재구축의 편집 제약이며 제품 전체의 영구 불변식이나 런타임 계약으로 확장하지 않는다.

전체 목차와 감사 결과는 [`stage-5/all-course-outlines.md`](./stage-5/all-course-outlines.md)에 기록했다.

- 모든 코스에 1~3개 주역량과 필요한 보조 역량, 핵심 주장, 현행 스텝으로 가능한 대표 활동을 연결했다.
- 최종 역량 24개는 각각 정확히 한 코스의 주역량으로 배정했다.
- 범용성과 진입 용이성을 우선해 제목, 설명, 카테고리, `visualKey`와 추천 순서를 제안했다.
- 빈 published 코스를 피하기 위해 승인 카탈로그는 4단계 작업 문서에 고정하고, JSON은 5단계에서 검수 완료된 코스부터 반영하기로 했다.

- 격리 SQLite 시드: published·draft 합계 유닛 6개, 레슨 16개, 스텝 82개이며 재실행 뒤 수량 불변
- 테스트 인증·격리 DB 브라우저 검증: 8개 레슨과 41개 스텝 완료, 코스 진행률 8/8, 최종 세션 콘솔 오류 0건

## 현재 범위 경계

14개 코스의 구조·DTO·시드·학습 전이는 검증했다. 다만 브라우저 표본 검토에서 일부 사례가 레슨 목표를 직접 연습시키기보다 공통적인 근거–판단 절차에 머무는 한계를 확인했다. 이는 타입이나 런타임 결함이 아니라 교육 콘텐츠 정렬 문제다. 2026-07-28 사용자가 전체 변경의 커밋과 작업 종료를 결정했으므로 이 한계를 후속 콘텐츠 부채로 명시한 채 현재 기준선을 확정하고 작업 디렉터리를 `docs/archive`로 이동한다. 이 종료 결정은 외부 전문가 검수나 실제 학습 효과를 검증했다는 뜻이 아니다.
