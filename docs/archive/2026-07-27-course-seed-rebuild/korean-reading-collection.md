# 국어·독해 역량 전체 자료 수집

## 수집 범위와 선정 기준

- 대상 역량: `cmp-001-vocabulary`, `cmp-002-sentence-comprehension`, `cmp-003-grammar-orthography`, `cmp-004-reading-comprehension`, `cmp-005-main-idea-identification`, `cmp-006-inference`, `cmp-022-background-knowledge`
- 수집 단위: 서로 다른 출처 12개, `src-0001`~`src-0012`
- 우선순위: 국내 공공 기관의 규범·교육과정·성인 실태 조사, 국내 학술 연구, 국제 성인 문해력 평가틀, 독해 구성 요인별 해외 학술 연구
- 제외 원칙: 블로그·커뮤니티, 원출처를 대체하지 못하는 2차 요약, 선정 자료와 핵심 근거가 중복되는 자료, 대상 집단이 다르면서 고유한 근거를 추가하지 못하는 자료

## 검색 경로와 검색어

검색 서비스·데이터베이스는 국립국어원 연구 보고서·한국어 어문 규범, 교육부·국가교육과정정보센터, 한국교육과정평가원·NKIS, KCI·KOAJ, OECD iLibrary, RAND·JSTOR, ERIC·PubMed, 학술지 출판사 DOI 페이지와 저자·대학 공개 저장소를 사용했다. 일반 웹 검색은 원출처 발견에만 사용했다.

주요 검색어는 `국민의 국어능력 실태 조사 2024 읽기 문법 규범`, `한글 맞춤법 표준어 규정 해설`, `2022 개정 국어과 교육과정 읽기 문법`, `PISA 2018 대한민국 읽기 결과 보고서`, `읽기교육 어휘지도 의미망`, `PIAAC cycle 2 literacy framework reading components`, `RAND Reading for Understanding reader text activity`, `Active View of Reading vocabulary inference`, `lexical quality hypothesis reading comprehension`, `comprehension inference making background knowledge`, `teaching main idea expository text`, `text coherence background knowledge reading comprehension`이다.

## 원문 확인 범위와 분량 산정

### 산정 방법

- `전체 분량`은 출처 파일 또는 학술지 인쇄면의 물리적 쪽수다. 공식 HWP와 이를 대조한 동일 고시 PDF처럼 내용이 같은 복제본은 한 번만 센다.
- `고유 확인량`은 각 출처 노트의 `원문 확인 기록`에 명시된 범위를 합집합으로 세었다. 같은 출처 안에서 범위가 겹치면 중복 제거했다.
- `전체 구조 확인`과 `관련 범위 정독`을 구분한다. 긴 보고서의 목차와 장 배열을 확인했어도 읽지 않은 장을 고유 확인량에 넣지 않았다.
- 표·그림이 본문 쪽 안에 있으면 별도 쪽수로 더하지 않았다. 웹 초록처럼 쪽이 없는 자료도 쪽수 합계에서 제외했다.

## 개념 종합

### 언어 기반과 상위 이해

- `src-0001`·`src-0002`는 한국어의 형태, 조사·어미, 문장 호응, 띄어쓰기와 표기 규칙을 정한다. 규범의 정답과 규칙 설명은 권위가 높지만 독해 향상 효과를 직접 보여 주지는 않는다.
- `src-0008`은 낱말 인식과 언어 이해 사이에 어휘 지식, 유창성, 형태 인식, 철자-소리-의미의 유연한 연결을 둔다. 실행 기능, 전략, 동기·참여는 읽기를 능동적으로 조절하는 요소다.
- `src-0009`는 어휘를 “아는 단어 수”가 아니라 철자·음운·문법·의미가 정확하고 안정적으로 결속된 표상으로 본다. 표 1은 고·저품질 표상을 대비하고, 그림 6은 한 번 맞힌 정확도와 회차 간 형태 회수 안정성이 다름을 보여 준다.
- `src-0009` 표 4의 단어–텍스트 통합 과제에서는 같은 어근이 반복된 명시 조건, 문맥상 같은 사건을 다른 말로 표현한 환언 조건, 예측 추론 조건, 무관련 조건을 비교한다. 숙련 차이는 단어 반복보다 문맥 의존적 환언을 앞 사건 표상과 잇는 데서 분명했다. 어휘 질은 독해에 중요하지만 충분조건은 아니다.

### 이해의 상호작용과 목적

- `src-0007`은 이해를 의미의 추출과 구성으로 정의하고 독자·텍스트·활동을 사회문화적 맥락 안에 둔다. 텍스트 난도는 문장 길이 같은 고정 속성만이 아니라 독자의 지식과 읽기 목적의 관계에서 생긴다.
- `src-0006`은 성인 문해력을 텍스트에 접근하고, 이해하고, 평가하며 사회 참여와 목표 달성에 사용하는 능력으로 조직한다. 목적·맥락·텍스트·인지 전략을 함께 보되 이는 평가 청사진이지 교수 순서가 아니다.
- `src-0004`는 디지털·복수 문서 환경에서 관련 정보 찾기, 이해, 질·신뢰성 평가, 갈등 조정을 구분한다. 만 15세 평가이므로 성인 코스의 생활·직무 맥락은 `src-0006`을 우선한다.
- `src-0003`의 국내 성인 조사는 읽기를 정보 확인·추론·평가·재구성으로 나누고 문법·규범을 어휘·문장·담화·규범으로 나눈다. 전국 분포를 보여 주지만 개인의 원인 진단이나 특정 수업 효과를 입증하지 않는다.

### 중심 내용, 추론과 배경지식

- `src-0002`·`src-0004`·`src-0006`·`src-0007`은 목적과 구조를 고려한 핵심 정보 선택, 요약, 재구성을 공통으로 요구한다. 중심 내용은 눈에 띄는 한 문장이나 반복 단어가 아니라 중요한 아이디어의 관계를 압축한 표현이다.
- `src-0011`의 목표 논문 초록과 별도 보충 원문은 세부 사항을 범주화하고 범주 관계를 문장으로 만드는 중심 내용 지도를 제안한다. 그러나 목표 논문의 표본·통계·수업 절차는 미확인이라 효과 근거는 제한적이다.
- `src-0010`은 추론 실패를 관련 지식의 부재, 추론 필요성 감지 실패, 관련 지식 회수 실패, 텍스트와 지식 통합 실패로 나눌 수 있음을 보여 준다. 지식을 가지고 있다는 사실만으로 필요한 순간의 추론을 보장하지 않는다.
- `src-0012`는 낮은 배경지식 독자에게 높은 응집성 글이 도움을 주는 한편, 높은 지식 독자는 일부 낮은 응집성 글의 관계 공백을 메우면서 깊은 이해가 높아질 수 있음을 보였다. 이는 “쉬운 글일수록 항상 좋다”와 “어려움이 학습을 만든다”를 모두 제한한다.

## 통합 수행 절차

다음은 여러 출처의 구인과 실험 과제를 성인 한국어 코스의 한 흐름으로 통합한 설계안이다. 출처들이 이 전체 순서의 효과를 직접 비교한 것은 아니므로 코스 안에서 별도 검증해야 한다.

1. **목적과 산출물을 정한다.** 정보 확인, 요약, 실제 적용, 주장 검증 중 무엇을 위해 읽는지와 읽은 뒤 만들 결과물을 명시한다.
2. **독자 자원을 짧게 진단한다.** 핵심 어휘의 형태·뜻·용법, 복잡한 문장 이해, 주제 지식, 동기·자신감, 화면 읽기 접근성을 분리해 확인한다.
3. **텍스트 장벽을 표시한다.** 낯선 어휘, 형태가 비슷한 단어, 조사·어미와 호응, 지시·접속 관계, 생략된 인과, 장르 구조와 출처 신뢰성 단서를 찾는다.
4. **단어 표상을 정교화한다.** 표기·발음·문법 정보·의미·연어를 연결하고 가까운 경쟁어와 예·비예로 구별한다. 정의 한 번의 정답이 아니라 지연 뒤 안정성과 새 문맥 사용을 본다.
5. **문장을 관계 단위로 풀어 읽는다.** 성분 호응과 연결 표현을 이용해 누가 무엇을 했고 어떤 조건·인과·대조가 성립하는지 환언한다.
6. **중심과 구조를 외현화한다.** 세부 사항을 관계별로 묶고 중심 개념과 근거를 도식화한 뒤 목적에 맞는 한 문장으로 압축한다.
7. **추론의 병목을 진단한다.** 필요한 정보가 없는지, 추론 필요성을 못 알아차렸는지, 관련 지식을 회수하지 못했는지, 회수한 지식을 본문과 잇지 못했는지 구분한다.
8. **평가·재구성한다.** 한 문서 안의 표현·근거를 평가하고, 복수 문서에서는 관련성·신뢰성·충돌을 조정한다. 얻은 정보를 체크리스트·설명·결정처럼 새 목적에 맞게 바꾼다.
9. **전략 지원을 줄인다.** 교사 시범, 완성된 구조표, 부분 단서, 독립 수행 순서로 지원을 점진적으로 제거하고 학습자가 필요한 전략을 스스로 선택하게 한다.
10. **병렬 과제로 전이를 확인한다.** 같은 문항 반복이 아니라 새 주제·장르·형식에서 어휘 안정성, 중심 내용, 추론, 실제 적용과 자기 점검을 다시 평가한다.

## 통합 오개념과 교정

- **어휘량이 충분하면 독해도 자동으로 충분하다.** `src-0009`의 해리 자료와 `src-0010`의 추론 실패는 어휘가 중요하지만 충분하지 않음을 보여 준다. 형태·의미 결속과 문장·추론·점검을 따로 진단한다.
- **빠른 읽기가 곧 효율적 읽기다.** 어휘 처리의 효율은 적은 노력으로 정확하고 안정적인 단어 정체성을 회수하는 것이다. 속도 때문에 근거·정확성이 무너지면 숙달로 보지 않는다.
- **배경지식을 많이 제공할수록 항상 좋다.** 필요한 지식을 활성화하되 본문을 대신 설명하지 않는다. 지식이 높은 학습자에게는 관계를 스스로 구성할 여지도 남긴다.
- **응집성이 낮은 글이 생산적 어려움을 만들어 항상 더 좋다.** `src-0012`의 효과는 지식 수준과 이해 측정 유형에 따라 달랐다. 낮은 지식 독자에게는 연결이 명시된 글이 더 안전하다.
- **중심 내용은 주제와 같은 한 단어나 첫 문장이다.** 목적·구조·핵심 관계를 반영해 자기 언어로 문장화하고 근거 세부를 함께 제시하게 한다.
- **추론은 자유롭게 상상하는 능력이다.** 추론 필요성, 본문 단서, 회수한 지식, 통합 결과를 표시해 검증 가능한 연결만 인정한다.
- **규범상 맞으면 자연스럽고 이해하기 좋은 글이다.** 규범 정확성, 문장 의미, 장르·독자 적합성과 가독성을 서로 다른 평가 층위로 둔다.
- **전략 목록을 모두 수행하면 이해가 향상된다.** 전략은 목적과 내용 이해의 수단이다. 새 텍스트에서 학습자가 필요한 전략을 스스로 선택하는지 확인한다.
- **국가 평균과 수준 분포가 개인의 결핍 원인을 알려 준다.** `src-0003`·`src-0004`의 대규모 조사는 집단 분포용이다. 개인 피드백은 실제 수행 근거로 작성한다.
- **PISA·PIAAC 평가틀이 효과적인 수업 순서다.** 평가 구인은 내용 누락 방지와 과제 설계에 쓰고, 교수 순서와 효과는 형성 평가로 별도 검증한다.

## 통합 평가와 피드백

- 평가 청사진은 `언어 기반`, `텍스트 이해`, `추론·평가`, `목적별 적용`, `자기조절`을 포함한다. 하나의 포괄 점수 외에 가장 가까운 병목을 기록한다.
- 어휘는 정의 정답, 형태 변별, 문법·용법, 문맥별 의미, 회차 간 안정성, 단어–텍스트 통합을 나눈다. `src-0009` 그림 6의 특정 비율을 숙달 컷으로 쓰지 않고 “한 번의 정답과 안정성은 다르다”는 원리만 사용한다.
- 중심 내용은 핵심 개념 선택, 세부의 관계화, 정확한 문장화, 새 목적에 맞춘 재구성을 본다. `src-0011`의 효과 크기나 표본 정보는 전문 미확인 상태에서 사용하지 않는다.
- 추론은 정답뿐 아니라 필요성 감지, 근거 선택, 지식 회수, 텍스트 통합을 관찰한다. 틀린 답을 “추론력 부족”으로 뭉개지 않는다.
- 실제 읽기 결과는 지식 증가, 문제 해결·적용, 참여를 구분한다. 선택형 문항만으로 실제 문서 수행이나 읽기 참여를 대표하지 않는다.
- 동일 학습자에게 텍스트·목적·응집성·형식을 바꾸어 독자 내 변이를 확인한다. 총점 비교보다 조건에 따라 강점과 약점이 어떻게 달라지는지 피드백한다.
- 피드백은 “독해력이 낮다”가 아니라 “핵심 조건은 찾았지만 지시 표현의 대상을 잘못 연결해 적용 단계가 누락됐다”처럼 다음 행동을 명시한다.
- 수업 전후에는 같은 문항 기억 효과를 피한 병렬 과제를 쓰고, 즉시 수행·지연 유지·새 장르 전이를 구분한다.

## 성인 한국어 전이 원칙과 한계

- 한국어 규범·교육 범위는 `src-0001`·`src-0002`, 국내 성인 수행 분포는 `src-0003`, 성인 생활·직무 문해력 구인은 `src-0006`을 우선한다.
- `src-0002`는 초·중등 교육과정, `src-0004`는 만 15세 국제 평가, `src-0007`·`src-0008`·`src-0011`은 아동·학교 연구 비중이 크다. 학년별 발달 순서와 효과 크기를 일반 성인에게 직접 옮기지 않는다.
- `src-0009`는 성인 대학생을 포함하지만 영어 희귀어·동음어·철자-음운 과제를 사용했다. 한글 음절 블록, 조사·어미, 음운 변동, 띄어쓰기와 한국어 다의성에 맞게 자극을 다시 설계한다.
- `src-0010`·`src-0012`의 통제된 짧은 글 실험은 기제를 분리하는 데 강하지만 긴 업무 문서, 모바일 화면, 복수 출처 읽기로의 장기 전이를 직접 보여 주지 않는다.
- 국가 조사 표본에서 제외된 외국인, 일부 장애인·시설 거주자와 저문해 성인에게 결과를 그대로 일반화하지 않는다. 화면·시간 제한·응답 방식의 접근성을 별도로 확인한다.
- 규범과 평가틀은 권위·내용 타당도의 근거, 실험은 조건부 인지 기제의 근거, 제한적 학술 자료는 아이디어 후보로 사용한다. 서로 다른 근거 역할을 섞어 교수 효과를 과장하지 않는다.
- 실제 코스에서는 생활·직무 문서를 우선하고, 짧은 피드백 주기와 병렬 과제로 자체 효과를 누적 검증한다.

## 충돌 쟁점과 해석 원칙

- 낱말 인식·어휘·문장 처리는 독해의 필수 기반이지만, 능동적 읽기 모형과 RAND 모형은 이를 독해 전체와 동일시하지 않는다. 코스에서는 기초 처리와 상위 의미 구성을 연결한다.
- 높은 응집성은 지식이 적은 독자에게 대체로 유리하지만, 지식이 많은 독자에게 생략된 관계를 추론하게 하는 글이 깊은 이해를 높인 결과도 있다. 이를 일반적인 저응집성 권장으로 확대하지 않고 독자 지식·과제·이해 수준을 조건으로 명시한다.
- 배경지식은 이해에 강하게 기여하지만, 관련 지식의 보유만으로는 충분하지 않다. 현재 글에 맞는 정보를 회수하고 텍스트 근거와 통합하는 수행을 함께 다룬다.
- 중심 내용은 세부 정보의 범주화·문장화로 지도할 수 있으나, 짧은 설명문 중재 결과를 성인 복수 문단·논증문 전체에 일반화할 수 없다.
- 공식 어문 규범은 표기의 정오를 판단하는 권위 자료이지만, 실제 사용의 자연스러움이나 문체 적절성까지 단독으로 결정하지 않는다.
- 학교 교육과정·PISA와 성인 대상 국어능력 조사·PIAAC는 모집단과 목적이 다르다. 전자는 내용 범위와 과제 형식의 참고, 후자는 성인 코스의 상위 구인과 진단 맥락에 우선 사용한다.
- `src-0009`의 ERP·반응시간 차이는 처리 경로를 검토하는 증거이지 특정 어휘 활동의 교수 효과가 아니다. 교실에서는 오류 설명·지연 회수·새 문맥 통합으로 관찰한다.
- `src-0003`의 읽기 평균은 초록·표의 `197.93`과 본문 한 곳의 `197.53`이 충돌한다. 반복된 `197.93`을 사용하되 내부 불일치를 남긴다.

## 포화 판단, 남은 공백과 재개 지점

일곱 역량 모두 복수의 독립 출처로 포괄했고, 규범·교육 범위·성인 평가·인지 기제를 서로 다른 기관과 연구가 보완한다. 직접 근거도 10개로 확보했으며 후속 검색에서 기존 원리를 반복하는 변형 자료가 주로 발견되어 2단계 수집은 포화로 종료한다.

남은 공백은 한국 성인을 대상으로 한 중심 내용 식별 중재, 한국어 문장 이해의 인과적 중재, 한글의 철자·음운·형태가 결속된 어휘 표상 질과 독해의 직접 관계, 실제 생활·직무 문서에서의 장기 전이다. `src-0005`와 `src-0011`은 제한적 근거이므로 원문 전문을 확보하기 전에는 구체적 교수 절차·효과 크기·표본 정보를 주장하지 않는다.

작업이 중단되면 12개 출처 노트의 `접근 수준`, `원문 확인 기록`, `적용 조건과 전이 한계`, `교차 검증과 충돌`을 먼저 확인한다. 다음 단계에서는 이 문서의 합의·긴장 표를 바탕으로 주장마다 `직접 사실`, `연구진 해석`, `코스 설계 추론`을 구분한 주장 원장을 작성한다.
