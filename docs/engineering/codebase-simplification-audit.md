# 코드베이스 단순화 감사

## 문서 상태

- 작성일: 2026-07-16
- 상태: 진행 중
- 대상 런타임: Bun `1.3.10`, Node.js `24.x`
- 대상 범위: 레거시 실험 디렉터리를 제외한 전체 제품 코드, 테스트, 저장소 도구, 배포 구성, 문서

## 목적

AI 코딩 에이전트가 구현 시간을 줄여 주더라도 사람이 이해하고 검증하고 운영해야 하는 비용은 사라지지 않는다. 이 감사는 현재 제품 가치와 위험에 비해 코드, 패키지, 런타임, 검증 장치와 문서가 필요 이상으로 커졌는지 확인하고 제거·통합·단순화 후보를 근거와 함께 제시한다.

## 판정 기준

- 현재 사용자 가치나 운영 위험을 직접 지지하는가
- 독립 배포, 독립 장애 격리, 보안 경계 또는 재사용 요구가 실제로 존재하는가
- 추상화가 소비자 수와 변경 빈도에 비해 충분한 이득을 제공하는가
- 자동 검증의 유지비가 실제로 방지하는 회귀 위험과 비례하는가
- 같은 사실을 코드, 설정, 테스트와 문서에서 중복 관리하지 않는가
- 더 작은 가역적 구조로 같은 동작과 품질을 유지할 수 있는가

## 조사 방법

1. 워크스페이스, 의존성, 소스 파일과 코드량을 계측한다.
2. 앱·패키지·런타임 경계와 실제 import 소비 관계를 대조한다.
3. Next.js·React 구현, Hono API, 도메인·DB 계층, 테스트와 저장소 자동화를 표본이 아니라 경계별로 조사한다.
4. 제거 후보는 실제 참조와 실행 경로를 확인하고, 단순화 후보는 보존해야 할 계약을 명시한다.
5. 후보를 기대 효과, 위험, 선행 조건과 검증 방법으로 우선순위화한다.
