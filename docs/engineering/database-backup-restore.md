# 데이터 백업·복구 기준

현재 저장소는 로컬 D1 개발 환경을 지원한다. 상태 위치는 [로컬 binding 코드](../../apps/api/src/scripts/local-bindings.ts)가 소유한다. 개발 서버 재시작은 상태를 유지한다.

로컬 상태 디렉터리를 삭제하면 개발 데이터가 사라진다. 보존할 데이터가 있으면 모든 개발 서버를 종료한 뒤 상태 디렉터리 전체를 별도 경로에 복사한다. 복사본을 복원할 때도 개발 서버를 종료한다. 이 절차는 운영 백업이 아니다.

기존 SQLite 파일과 Litestream replica를 자동으로 D1에 복구하지 않는다. 원격 D1 백업·복구와 삭제 marker 재적용의 운영 검증은 보류 상태다. 운영 전환 전에 복구 시점, 보존 기간, 개인정보 삭제 반영과 실제 복원 결과를 확인해야 한다.
