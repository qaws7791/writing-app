# 디자인 브리프

이 문서는 writing-app의 브랜드 톤, 무드, 아트 디렉션, 미적 원칙의 단일 진실 원천이다. 구현 기준은 `apps/web`, `apps/admin`, `packages/ui`, `apps/storybook`의 현재 코드와 기존 제품 문서다.

## 제품 정체성

writing-app은 한국어 글쓰기 학습 플랫폼이다. 학습자는 작은 레슨을 매일 진행하며 문장, 문법, 논증, 독자 중심 글쓰기, 퇴고를 익힌다. 운영자는 별도 어드민에서 코스, 유닛, 레슨, 스텝, 사용자, 분석, 운영 설정을 관리한다.

학습자 제품의 화면 브랜드명은 현재 `글결.`을 우선 기준으로 삼는다. 랜딩 일부 코드에는 `Kernel` 문구가 남아 있으므로 신규 화면과 문서에서는 `글결.`을 사용하고, 랜딩 문구는 후속 UI 정리 때 맞춘다.

## 브랜드 톤

- 따뜻하고 명료하다. 학습자를 가르치기보다 함께 써보도록 초대한다.
- 한국어 문장 감각을 존중한다. 버튼, 오류, 빈 상태, 접근성 문구는 모두 한국어로 쓴다.
- 과장된 성취 보상보다 조용한 지속감을 강조한다. 연속 학습일, 완료 레슨, 다음 레슨처럼 실제 진행을 보여준다.
- 운영자 화면은 감성보다 정확성과 반복 업무 효율을 우선한다.

## 아트 디렉션

학습자 앱은 따뜻한 종이 배경, 두꺼운 글자, 둥근 표면, 실제 코스 썸네일, 손에 잡히는 인터랙션을 사용한다. 핵심 이미지는 추상 장식보다 코스와 학습 상태를 식별하게 해야 한다.

어드민 앱은 흰색 표면, 슬레이트 텍스트, 티얼 액센트, 명확한 표와 필터를 사용한다. 장식 요소보다 스캔 가능성, 밀도, 상태 구분이 중요하다.

## 미적 원칙

- 학습자 화면은 모바일 우선, 카드 중심, 큰 터치 타깃, 하단 주요 행동을 기본으로 한다.
- 어드민 화면은 사이드바, 헤더, 툴바, 테이블, 패널의 반복 가능한 작업 구조를 유지한다.
- 단일 색상 계열만으로 화면을 만들지 않는다. 학습자 앱은 크림, 차콜, 노랑, 코럴, 민트를 함께 쓰고, 어드민은 슬레이트, 흰색, 티얼, 위험색을 기능적으로 쓴다.
- 카드 안에 또 다른 카드처럼 보이는 중첩 표면을 만들지 않는다. 반복 아이템, 모달, 도구 패널에만 카드성 표면을 쓴다.
- 화면 설명 텍스트를 기능 사용법처럼 늘어놓지 않는다. UI는 스스로 이해되어야 하고, 보조 문구는 사용자의 다음 판단을 돕는 경우에만 둔다.
- 애니메이션은 학습자의 흐름을 가볍게 만드는 데만 쓴다. 레슨 CTA처럼 위치 안정성이 중요한 요소에는 transform 기반 진입 애니메이션을 걸지 않는다.

## 제품별 디자인 방향

### 학습자 웹

- 배경은 `cream`, 본문은 `charcoal`, 주요 CTA는 `charcoal` 또는 `primary`를 쓴다.
- 코스 카드와 학습 요약은 `surface` 위에 큰 radius를 사용한다.
- 레슨은 몰입형 전체 화면으로 글로벌 내비게이션을 숨기고, 진행 헤더와 하단 CTA를 고정한다.
- 학습 완료, 정답, 오답, AI 코칭은 즉각적이고 한국어 중심의 피드백으로 표현한다.

### 어드민 웹

- 좌측 사이드바와 본문 그리드를 유지한다.
- 화면 제목과 설명은 `PageHeader` 패턴을 따른다.
- 목록 화면은 필터 툴바와 테이블을 기준으로 구성한다.
- 위험 작업은 즉시 실행하지 않고 확인 dialog를 거친다.
- 상태 메시지는 `role="status"`, 오류는 `role="alert"`로 노출한다.
