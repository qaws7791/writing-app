# IA 명세

이 문서는 사용자 관점의 정보 구조와 네비게이션 의미를 정의한다. 현재 URL, runtime, port와 API 연결은 코드·설정이 소유하므로 [사실별 권위 지도](../authority-map.md)를 따른다.

## 정보 구조

### 학습자 영역

- 공개 영역: 제품 가치 이해와 학습 시작 결정
- 인증 영역: 학습자 인증과 원래 의도한 화면으로의 복귀
- 학습 영역: 학습 홈, 코스 탐색, 코스 상세와 프로필 관리
- 몰입형 레슨 영역: 글로벌 navigation을 숨기고 현재 레슨 완료에 집중

### 관리자 영역

- 관리자 인증: 운영 콘솔 진입 전 신원 확인
- 운영 개요: 제품 상태와 주요 지표 파악
- 콘텐츠 관리: 코스와 커리큘럼의 생성·편집·발행
- 사용자 관리: 사용자 상태 확인과 운영 조치
- 분석: 학습·콘텐츠 지표 해석

## 화면 식별자

| 영역   | 화면                                                                                                                                         |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 학습자 | `SCR-001` 랜딩, `SCR-002` 로그인, `SCR-003` 학습 홈, `SCR-004` 코스 탐색, `SCR-005` 코스 상세, `SCR-006` 레슨, `SCR-007` 프로필              |
| 관리자 | `SCR-101` 로그인, `SCR-102` 대시보드, `SCR-103` 코스 관리, `SCR-104` 코스 편집, `SCR-105` 사용자 관리, `SCR-106` 사용자 상세, `SCR-107` 분석 |

각 화면의 현재 구현 위치는 해당 screen 문서가 직접 링크하는 route source에서 확인한다.

## 네비게이션 원칙

- 학습자 desktop navigation은 홈, 배우기, 프로필 진입점을 제공한다.
- 학습자 모바일 navigation은 같은 정보 구조를 더 작은 화면에 맞게 제공한다.
- 레슨은 몰입형 흐름이므로 글로벌 navigation을 표시하지 않는다.
- 관리자 navigation은 대시보드, 콘텐츠 관리, 사용자 관리와 분석을 제공한다.
- 활성 상태는 현재 화면이 속한 정보 구조를 명확히 보여야 하며, 구현 URL 비교 규칙은 route source가 소유한다.
- 정의되지 않은 화면에 도달하면 사용자가 안전한 상위 진입점으로 돌아갈 수 있는 오류 화면을 제공한다.

## 경계

- 학습자와 관리자는 서로 다른 사용자 목적과 인증 정책을 가진다.
- 화면 명세는 사용 목적·정보·상태·접근성을 소유하며, HTTP path나 framework file 구조를 소유하지 않는다.
- 새 화면은 먼저 화면 식별자와 사용자 흐름을 정의하고, 구현 route는 코드 변경에서 결정한다.
