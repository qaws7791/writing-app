# SCR-002 학습자 로그인

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 Google 인증으로 학습 앱에 진입한다.

## 주요 사용자

- 로그인하지 않은 학습자

## 정보 구조

- 제품명
- 로그인 안내
- Google 로그인 버튼
- 이메일/비밀번호 미지원 안내
- 오류 메시지

## UI 기준

- 학습자 앱의 `cream`, `surface`, `charcoal`, `primary` 토큰을 따른다.
- 주요 행동은 하나만 강조한다.
- 실패 메시지는 사용자가 다시 시도할 수 있게 한국어로 표시한다.

## 상태

- 기본
- 인증 요청 중
- 인증 실패
- 안전한 `next` 경로 확인 후 이동

## 접근성

- 로그인 버튼은 키보드로 실행 가능해야 한다.
- 오류는 `role="alert"`로 노출한다.
- 외부 OAuth 동작을 설명하는 텍스트는 한국어로 제공한다.
