# SCR-111 쓰기 과제 편집

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

## 목적

소유자 관리자가 쓰기 과제 초안을 저장하고 학습자에게 노출할 발행본을 만든다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- 콘텐츠 > 쓰기 과제 > 과제 제목 breadcrumb
- 초안·발행됨 상태
- 이미 시작한 글은 이 초안을 발행해도 바뀌지 않는다는 안내
- 초안 저장, 발행
- 제목, 도메인, 유형, 난이도, 상황, 독자, 최소 글자 수, 목표 글자 수, 필수 요소

## UI 기준

- 편집 가능한 control은 명확한 label을 가진다.
- 필수 요소는 줄마다 한 항목이다.
- 발행은 저장과 분리된 명시적 행동이다.
- 저장 성공, 저장 실패, 충돌은 화면 메시지로 표시한다.

## 상태

- 초안 조회 중
- 편집 중
- 저장 중
- 발행 중
- 저장 충돌
- 조회 실패

## 접근성

- 모든 필드는 보이는 label을 가진다.
- 저장과 발행은 키보드로 실행할 수 있어야 한다.
- 실패는 `role="alert"`로 전달한다.
