# SCR-009 작성 세션

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 고정된 과제 브리프를 보고 본문을 쓴 뒤, 같은 화면에서 AI 점검을 받고 고친다.

## 주요 사용자

- 글을 작성하는 학습자

## 정보 구조

- 쓰기 홈으로 돌아가기
- 과제 제목
- 과제 패널 열기
- 최근 점검이 있으면 결과 패널 열기
- 예외 저장 상태
- 본문 입력
- 글자 수
- `점검하기`
- 과제 브리프
- 점검 결과: 잘된 점, 과제 미충족(있으면), 고칠 일
- 첫 점검 전 외부 AI 전달 고지 dialog

## UI 기준

- `AppShell`을 사용하지 않는 몰입 화면이다.
- 기본 상태는 전면 캔버스다. 본문은 `bg-background` Canvas에 직접 놓인다. 과제와 점검 결과는 한 번에 하나만 연다.
- 본문 읽기 폭은 가운데 `max-w-3xl`을 유지한다. 종이 카드(`bg-card`, 둥근 모서리, 테두리)는 쓰지 않는다. 입력 중 포커스는 control `ring-3`이 아니라 캐럿으로 전달한다.
- 본문은 Luma `ComposeCanvas`에 일반 텍스트만 입력한다. 문단 간격을 제공한다. 첫·마지막 줄은 플로팅 chrome 아래로 스크롤되며, 스크롤 여백으로 가리지 않는다.
- 브리프는 Luma `WritingBrief` anatomy를 사용한다. 패널 안을 카드로 다시 감싸지 않는다.
- 점검 결과는 Luma `FeedbackSummary`와 `Insight`를 사용한다.
- 평시 chrome은 본문 열 위에 떠 있는 분리된 pill 클러스터다. 왼쪽은 나가기·과제 제목, 가운데는 `lg` 이상에서 글자 수, 오른쪽은 과제/피드백 세그먼트 패널 캡슐과 `lg` 이상에서 초슬림 점검 버튼이다. 제목은 누르지 않는다.
- 저장 상태는 헤더 텍스트 뱃지 없이 제목 옆 미세 Dot 인디케이터(저장 중: 파란 펄스 점, 실패: 빨간 점)로 전달한다. 실패·충돌·오프라인의 상세 안내는 본문 위 `Insight`와 `role="alert"`로 커진다. 평시 저장 완료는 시각 chrome 없이 `role="status"`로만 전달한다.
- 글자 수 및 한국어 지표는 `ComposeMeter`로 현재 자 및 어절 수(`1,240자 (140어절)`)를 표시한다. `ComposeMeter`를 클릭하면 `WritingStatsPopover`가 열려 공백 제외 글자 수, 어절 수, 문단 구성, 문장 호흡(평균 문장 길이/긴 문장 개수), 예상 읽기 시간을 시각적 카드로 제공한다. 최소 미달일 때만 최소 기준을 붙인다. 목표·최대는 과제 패널 안에만 둔다.
- `점검` 버튼은 `SparklesIcon`과 함께 보이는 한국어 동사('점검')를 가진 초슬림(`size="sm"`) 채운 주요 버튼이다. 최소 글자 수 미달 상태에서 점검을 누르면 본문 상단 배너 대신 점검 버튼에 부착된 인라인 컨텍스추얼 팝오버로 남은 필요 글자 수와 최소 기준을 안내한다.
- 들어올 때 과제는 닫혀 있다. 과제와 결과 트리거는 세그먼트 캡슐 안의 아이콘 버튼이며 접근성 이름은 한국어다.
- 열린 패널은 본문 옆(`lg` 이상) 또는 아래(`lg` 미만)에 붙는다. 열린 동안 본문을 입력할 수 있다. 닫기는 패널 안과 헤더 토글에 둔다. 플로팅 chrome은 본문 열에만 두고 열린 패널을 가리지 않는다.
- `lg` 미만은 상단 왼쪽·오른쪽 클러스터와 하단 글자 수·점검 클러스터를 나눈다. 열린 패널은 본문 아래 세로 분할이다. 소프트 키보드가 열리면 패널을 한 줄 미리보기로 접는다. 상·하단 chrome을 유지하고, 하단만 키보드 위로 올린다.
- `lg` 이상은 하단 없이 상단 세 클러스터다. 왼쪽은 나가기·제목 및 Micro Dot 저장 상태, 가운데는 글자 수, 오른쪽은 세그먼트 패널 캡슐과 초슬림 점검 버튼이다. 열린 패널은 본문 오른쪽 가로 분할이다.
- 점검 성공 직후 결과 패널을 연다. 과제가 열려 있으면 닫는다.
- 최근 성공 점검이 있으면 결과 아이콘으로 다시 연다. `점검하기`는 현재 본문으로 새 점검을 요청한다.
- 저장하지 않은 입력이 있으면 쓰기 홈 이동 전에 저장을 시도한다.

## 상태

- 작성 중
- 저장 중
- 저장됨
- 점검 중
- 점검 결과 있음
- 오프라인·저장 실패
- version 충돌
- 글 조회 실패
- 고지 확인 전

## 접근성

- 뒤로 가기, 본문, 과제 보기, 결과 보기, 점검은 키보드로 실행할 수 있어야 한다.
- 열린 패널은 보이는 제목 `과제` 또는 `이번 점검`을 가진다. Escape는 고지·나가기 dialog가 없을 때 패널을 닫는다.
- 저장 중과 저장 완료, 점검 중은 `role="status"`로 전달한다.
- 저장 실패, version 충돌, 점검 실패는 `role="alert"`로 전달한다.
- 고지 dialog는 제목과 설명을 제공한다.
- 320px 화면과 텍스트 200% 확대에서 가로 스크롤이 생기지 않아야 한다.
