# SCR-106 사용자 상세

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

## 목적

관리자가 특정 학습자의 상태와 학습 요약을 확인한다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- `AdminPageHeader`
- 사용자 기본 정보
- `StatusBadge`
- 운영 액션
- 가입일
- 최근 접속
- 완료 레슨
- 전체 진도
- 학습 요약 정의 목록

## UI 기준

- 상세 정보는 Luma `Card` 안에 배치한다.
- 수치 요약은 `dl` 구조를 사용한다.
- 상태는 app-local `StatusBadge`가 Luma `Badge` variant로 표시한다.
- 운영 액션은 사용자 기본 정보 카드 안에 둔다. 판단 근거와 실행을 같은 화면에 둔다.
- 상태 변경과 삭제 요청은 [SCR-105](./SCR-105-admin-users.md)와 같은 확인 대화상자를 쓴다. 두 화면이 같은 컴포넌트를 공유한다.
- 삭제 상태 사용자에게는 액션 대신 읽기 전용임을 알린다.

## 상태

- 사용자 조회 성공
- 사용자 조회 실패
- 운영 액션 성공
- 운영 액션 실패

## 접근성

- 정의 목록 `dl`, `dt`, `dd`로 지표 의미를 보존한다.
- 오류는 `role="alert"`로 표시한다.
- 운영 액션 결과는 `role="status"`로 알린다.
