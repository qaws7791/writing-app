# SCR-109 MCP 변경 승인

## 구현 탐색

현재 route는 [MCP 승인 route source](../../../apps/admin/src/app/mcp-approvals)에서 확인한다.

## 목적

owner 관리자가 AI 에이전트가 요청한 코스 발행·보관과 사용자 상태 변경·삭제를 실행 전에 검토한다.

owner 관리자는 요청을 승인하거나 거절한다.

## 주요 사용자

- owner 관리자

## 정보 구조

- 브랜드와 AI 변경 승인 표식
- 변경 종류, 영향과 현재 상태
- 코스 대상의 제목·ID와 편집 버전
- 사용자 대상의 opaque 사용자 ID, 현재 상태와 목표 상태
- OAuth client ID, 요청 시각과 만료 시각
- 승인과 거절 행동
- 관리자 홈 복귀

## UI 기준

- 화면은 외부 client의 deep link 흐름에 집중하고 전체 관리자 navigation을 표시하지 않는다.
- 승인 요청 ID, access token과 MCP 원문을 승인 근거로 해석하지 않는다.
- 코스 발행·보관, 사용자 정지와 삭제는 파괴적 확인 표현을 사용한다.
- 사용자 활성화는 기본 확인 표현을 사용한다.
- 사용자 이메일, 이름과 학습 데이터는 표시하지 않는다.
- 승인과 거절은 확인 대화상자를 거친다.
- 만료되거나 처리된 요청은 행동을 비활성화하고 현재 상태를 표시한다.

## 상태

- 검토 대기
- 승인됨 또는 실행 중
- 거절됨 또는 만료됨
- 실행 성공 또는 실패
- 조회·결정 실패
- 인증 후 원래 승인 요청 복귀

## 접근성

- 상태는 텍스트와 색상을 함께 사용한다.
- 결정 오류는 `role="alert"`로 표시한다.
- 승인 완료와 실행 상태는 `role="status"`로 표시한다.
- 확인 대화상자는 취소와 결정 행동을 구분한다.
