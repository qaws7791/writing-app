# SCR-011 쓰기 카탈로그

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 도메인과 유형으로 발행된 쓰기 과제를 좁히고 미리보기에서 새 글을 시작한다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 화면 제목
- 도메인 칩
- 유형 칩 (도메인을 고른 뒤에만)
- 과제 카드: 제목, 유형, 난이도, 목표 글자 수
- 미리보기 오버레이: 상황, 독자, 목표 글자 수, `시작하기`

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 과제가 없는 도메인과 유형 칩은 숨긴다.
- 카드는 미리보기 오버레이를 연다.
- 미리보기는 Sheet 하나다. 768px 미만은 `side="bottom"`, `md` 이상은 `side="center"`다.
- `시작하기`는 항상 새 글을 만든다.
- 빈 상태는 Luma `Empty`로 안내한다.

## 상태

- 과제 목록 조회 중
- 과제 있음
- 필터 결과 없음
- 조회 실패
- 시작 중·시작 실패

## 접근성

- 칩과 카드, `시작하기`는 키보드로 실행할 수 있어야 한다.
- 선택된 칩은 `aria-pressed`로 표시한다.
- 미리보기는 제목과 설명을 제공한다.
