# SCR-008 쓰기 홈

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 자신의 글을 이어 쓰거나, 과제 카탈로그로 새 글을 시작한다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 화면 제목 `이어 쓸 글`
- 글이 있을 때 카탈로그로 가는 `과제 둘러보기`
- 과제별 묶음: 도메인, 유형, 난이도, 과제 제목
- 글 카드: 본문 미리보기, 최근 수정 시각, 글자 수
- 글이 없을 때 카탈로그 초대 카드
- 삭제 확인 dialog

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 본문 열은 `max-w-2xl`이다.
- 작성 중·완료 탭을 두지 않는다. 목록은 최근 수정 순이며, 같은 과제의 글은 한 묶음으로 둔다.
- 과제 제목은 묶음 헤더에 한 번만 둔다. 글 카드는 Luma `Card` `surface`와 본문 미리보기를 사용한다.
- 난이도는 묶음 헤더의 `Badge`로 표시한다.
- 글이 없으면 학습 홈 빈 상태와 같은 초대 카드로 카탈로그를 연다. 헤더의 `과제 둘러보기`는 글이 있을 때만 둔다.
- 글 이동은 `Link`를 사용한다.
- 삭제는 `AlertDialog` 확인 뒤 실행한다.
- 처리 결과는 Luma `Insight`로 표시한다.

## 상태

- 글 목록 조회 중
- 글 있음·없음
- 조회 실패
- 삭제 확인 전·삭제 중·삭제 완료·삭제 실패

## 접근성

- 글 이동과 삭제는 키보드로 실행할 수 있어야 한다.
- 같은 과제 제목의 글은 삭제 접근 이름에 최근 수정 시각을 포함한다.
- 삭제 dialog는 제목과 설명을 제공한다.
- 처리 완료는 `role="status"`, 실패는 `role="alert"`로 전달한다.
- 과제 묶음은 보이는 제목을 제공한다.
