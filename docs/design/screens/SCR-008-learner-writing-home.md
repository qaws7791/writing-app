# SCR-008 쓰기 홈

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 작성 중·완료 글을 이어 쓰거나, 과제 카탈로그로 새 글을 시작한다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 화면 제목
- 카탈로그로 가는 `과제 둘러보기` 주요 행동
- `작성 중` / `완료` 탭
- 글 카드: 과제 제목, 도메인, 유형, 난이도, 시작 시각, 글자 수
- 삭제 확인 dialog

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 글 카드는 Luma `Card`와 `Badge`로 구성한다.
- 빈 상태는 Luma `Empty`로 안내한다.
- 글 이동은 `Link`를 사용한다.
- 삭제는 `AlertDialog` 확인 뒤 실행한다.
- 처리 결과는 Luma `Insight`로 표시한다.

## 상태

- 글 목록 조회 중
- 작성 중 글 있음·없음
- 완료 글 있음·없음
- 조회 실패
- 삭제 확인 전·삭제 중·삭제 완료·삭제 실패

## 접근성

- 탭, 글 이동, 삭제는 키보드로 실행할 수 있어야 한다.
- 삭제 dialog는 제목과 설명을 제공한다.
- 처리 완료는 `role="status"`, 실패는 `role="alert"`로 전달한다.
