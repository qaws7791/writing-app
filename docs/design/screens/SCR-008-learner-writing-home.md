# SCR-008 쓰기 홈

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 새 글을 시작하거나 저장한 글을 다시 연다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 화면 제목
- `새 글 쓰기` 주요 행동
- 쓰기 방식 선택
- 저장한 글 목록
- 삭제 확인 dialog

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 첫 화면의 주요 행동은 `새 글 쓰기` 하나다.
- 새 글 행동 뒤 세 쓰기 방식을 한 번에 하나만 선택할 수 있다.
- 방식 항목은 이름과 한 문장 안내를 제공한다.
- 저장한 글은 제목, 쓰기 방식, 최근 수정 시각과 상태만 표시한다.
- 빈 상태는 새 글을 시작하는 행동만 제공한다.
- 글 이동은 `Link`를 사용한다.
- 삭제는 `AlertDialog` 확인 뒤 실행한다.

## 상태

- 글 목록 조회 중
- 글 있음
- 글 없음
- 조회 실패
- 글 생성 중·실패
- 삭제 확인 전·삭제 중·삭제 완료·삭제 실패

## 접근성

- 방식 선택과 글 이동은 키보드로 실행할 수 있어야 한다.
- 현재 선택한 방식은 `aria-pressed`로 표시한다.
- 삭제 dialog는 제목과 설명을 제공한다.
- 처리 완료는 `role="status"`, 실패는 `role="alert"`로 전달한다.
