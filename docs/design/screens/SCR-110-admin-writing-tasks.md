# SCR-110 쓰기 과제 목록

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

## 목적

소유자 관리자가 쓰기 과제를 찾고 편집 화면으로 이동한다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- 페이지 제목
- 검색, 도메인 필터, 상태 필터
- 새 과제 행동
- 과제 표: 제목, 도메인, 유형, 난이도, 상태, 수정 시각

## UI 기준

- 콘텐츠 그룹의 `쓰기 과제` 메뉴에서 연다.
- 표 행은 과제 편집 화면으로 이동한다.
- 상태는 `초안`과 `발행됨`을 `Badge`로 구분한다.

## 상태

- 목록 조회 성공
- 필터 결과 없음
- 조회 실패
- 생성 중·생성 실패

## 접근성

- 검색과 필터, 새 과제, 행 이동은 키보드로 실행할 수 있어야 한다.
- 표는 열 머리글을 제공한다.
