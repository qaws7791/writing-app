# SCR-009 집중형 편집

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 제목과 일반 텍스트 본문에 집중해 초고를 작성한다.

## 주요 사용자

- 글을 작성하는 학습자

## 정보 구조

- 쓰기 홈으로 돌아가기
- 쓰기 방식
- 제목 입력
- 본문 입력
- 글자 수와 저장 상태
- `글 점검하기` 주요 행동

## UI 기준

- `AppShell`을 사용하지 않는 한 열 집중 화면이다.
- 화면은 중첩 카드, 도구 모음, 사이드바와 반복 애니메이션을 사용하지 않는다.
- 제목과 본문에는 보이는 label을 제공한다.
- 본문은 일반 텍스트만 입력한다.
- 저장 상태와 글자 수는 입력 영역 가까이에 표시한다.
- 하단 주요 행동은 모바일 safe area와 소프트 키보드를 가리지 않아야 한다.
- 저장하지 않은 입력이 있으면 쓰기 홈 이동 전에 저장을 시도한다.

## 상태

- 작성 중
- 저장 중
- 저장됨
- 오프라인·저장 실패
- version 충돌
- 글 조회 실패

## 접근성

- 뒤로 가기, 제목, 본문과 점검 행동은 키보드로 실행할 수 있어야 한다.
- 저장 중과 저장 완료는 `role="status"`로 전달한다.
- 저장 실패와 version 충돌은 `role="alert"`로 전달한다.
- 320px 화면과 텍스트 200% 확대에서 가로 스크롤이 생기지 않아야 한다.
