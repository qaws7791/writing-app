# SCR-010 자기 점검

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 작성한 글을 세 질문으로 다시 읽고 다듬거나 점검을 마친다.

## 주요 사용자

- 초고를 점검하는 학습자

## 정보 구조

- 글 제목과 본문
- 쓰기 방식에 맞는 세 질문
- `다시 다듬기` 보조 행동
- `점검 마치기` 주요 행동

## UI 기준

- 글로벌 내비게이션과 편집 form을 숨긴 별도 집중 화면이다.
- 작성한 글과 세 질문만 본문에 표시한다.
- 질문은 점수나 정답 입력 control을 제공하지 않는다.
- `다시 다듬기`는 저장된 본문을 유지하고 편집 화면으로 이동한다.
- `점검 마치기`는 서버 저장 성공 뒤 완료 상태를 표시한다.

## 상태

- 점검 전
- 점검 완료 저장 중
- 점검 완료
- 저장 실패
- 글 조회 실패

## 접근성

- 글과 질문은 논리적인 heading 순서를 사용한다.
- 두 행동은 키보드로 실행할 수 있어야 한다.
- 저장 완료는 `role="status"`, 실패는 `role="alert"`로 전달한다.
- 320px 화면과 텍스트 200% 확대에서 글과 주요 행동이 잘리지 않아야 한다.
