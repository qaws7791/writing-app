# SCR-101 관리자 로그인

## 라우트

- `apps/admin`: `/login`

## 목적

관리자가 ID/password 인증으로 운영 콘솔에 진입한다.

## 주요 사용자

- 관리자

## 정보 구조

- 브랜드
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 오류 메시지

## UI 기준

- 어드민 로그인 카드는 `admin-auth-card` 기준을 따른다.
- 학습자 앱의 큰 장식성 레이아웃을 사용하지 않는다.
- 오류는 명확한 한국어로 표시한다.

## 상태

- 기본
- 로그인 진행 중
- 인증 실패
- 안전한 `next` 경로 이동

## 접근성

- 입력에는 label 또는 `aria-label`을 제공한다.
- 오류는 `role="alert"`로 노출한다.
- 로그인 성공 후 이동은 `router.replace`를 사용한다.
