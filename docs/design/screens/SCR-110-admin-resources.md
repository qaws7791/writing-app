# SCR-110 관리자 자료실

## 화면 목적

운영자가 프로젝트 소유의 GFM 문서를 최대 3단계 폴더로 정리하고 Notion형 편집기에서 명시적으로 저장한다. 저장된 활성 문서는 관리자 AI의 읽기 전용 지식 원본이 된다.

## 라우트

- `/resources`: 활성 자료 트리와 문서 선택 안내
- `/resources/[documentId]`: 활성 문서 편집
- `/resources/trash`: 휴지통 트리
- `/resources/[documentId]?scope=trash`: 휴지통 문서 읽기

## 레이아웃

- 데스크톱은 왼쪽 자료 트리와 오른쪽 문서 영역의 두 열 구조다.
- 트리는 접고 너비를 조절할 수 있다.
- 문서가 선택된 경우에만 Lexical 편집기 bundle을 동적 로드한다.
- 작은 화면에서는 읽기 전용 문서 또는 데스크톱 편집 안내를 표시한다.
- 모바일 트리 드로어와 모바일 편집 도구는 제공하지 않는다.

## 자료 트리

- 활성·휴지통 범위를 명시적으로 전환한다.
- 전체 트리는 한 번에 조회하며 폴더와 문서를 이름순으로 표시한다.
- 폴더 중첩은 최대 3단계다.
- 드래그 앤 드롭은 항목을 대상 폴더로 이동할 때만 사용한다.
- 형제 사이 삽입 위치와 수동 순서 변경은 표시하지 않는다.
- 항목 메뉴는 드래그 앤 드롭과 같은 대상 폴더 선택 이동을 제공한다.
- 문서 제목은 편집 화면에서만 변경하고 폴더 이름은 트리에서 변경한다.
- 탭이 다시 활성화되면 전체 트리를 재조회한다.

## 문서 편집

- 제목 입력, breadcrumb, 생성·수정 메타데이터, 본문 편집기와 저장 영역을 표시한다.
- 슬래시 메뉴, 블록 추가·드래그, 텍스트 선택 플로팅 툴바를 제공한다.
- 지원 블록과 인라인 서식은 `REQ-ADM-7`의 고정 목록을 따른다.
- 표는 기본 직사각형 GFM 기능만 제공한다.
- 이미지 삽입은 JPEG·PNG·WebP 파일, 5MB 이하와 필수 대체 텍스트를 요구한다.
- 이미지 라이브러리, 외부 URL 직접 삽입, 이미지 변환과 썸네일은 제공하지 않는다.

## 저장 상태

- `저장되지 않은 변경`: 제목이나 본문이 마지막 서버 버전과 다르다.
- `저장 중`: 조건부 저장 요청이 진행 중이다.
- `저장됨`: 현재 화면과 서버 버전이 같다.
- `충돌`: 다른 탭이나 기기가 먼저 저장했다.
- `저장 실패`: 네트워크 또는 서버 오류로 저장하지 못했다.

저장 버튼은 변경이 있고 요청 중이 아닐 때 활성화한다. 충돌 시 자동 병합하거나 강제 덮어쓰지 않고 다음 행동을 제공한다.

- 내 Markdown 복사
- 최신 문서 불러오기
- 다른 제목의 새 문서로 저장

페이지를 떠나기 전에 미저장 변경이 있으면 브라우저 이탈 경고를 표시한다.

## 휴지통

- 직접 휴지통으로 이동한 최상위 항목만 첫 목록에 표시한다.
- 폴더를 펼치면 함께 이동한 하위 구조를 읽기 전용으로 표시한다.
- 복원과 영구 삭제는 최상위 항목에서만 제공한다.
- 영구 삭제는 하위 문서와 이미지가 함께 제거된다는 확인 문구를 표시한다.
- 자동 만료와 초기 범위의 휴지통 비우기는 제공하지 않는다.

## 검색

- 활성 문서의 제목과 본문만 검색한다.
- 폴더와 휴지통 범위 검색은 제공하지 않는다.
- 결과에는 제목, 경로와 본문 발췌를 표시한다.
- 결과 선택 시 문서를 열고 해당 조상 폴더를 펼친다.

## 상태

- 문서가 선택되지 않음
- 빈 자료실
- 검색 결과 없음
- 휴지통 비어 있음
- 문서·트리 조회 실패
- 미저장·저장 중·저장됨·충돌·저장 실패
- 이미지 업로드 중·검증 실패·업로드 실패

실시간 연결, 재연결, 공동 편집자 수와 문서 동기화 상태는 표시하지 않는다.

## 접근성

- 트리는 `tree`, `treeitem`, `group` 의미와 펼침·선택 상태를 제공한다.
- 화살표 키, Home, End, Enter, Space로 트리를 탐색한다.
- 드래그 앤 드롭 이동은 항목 메뉴로도 수행할 수 있다.
- 슬래시 메뉴와 플로팅 툴바는 키보드로 조작하고 Escape로 닫을 수 있다.
- 저장·충돌·업로드 오류는 `role="status"`와 `role="alert"`를 구분한다.
- 이미지 업로드는 대체 텍스트 없이는 완료할 수 없다.
