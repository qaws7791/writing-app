# SCR-110 관리자 자료실

## 문서 상태

- 기준

## 라우트

- `apps/admin`: `/resources`
- `apps/admin`: `/resources/[documentId]`
- `apps/admin`: `/resources/trash`

## 목적

관리자가 폴더 트리에서 운영 자료를 탐색하고 GFM 문서를 여러 관리자와 실시간으로 편집한다.

## 주요 사용자

- 운영 자료를 작성하고 정리하는 관리자
- 같은 문서를 동시에 검토하고 수정하는 관리자

## 정보 구조

- 자료실 shell
  - 전역 검색
  - 새 문서, 새 폴더, Markdown 가져오기
  - 접기와 너비 조절이 가능한 자료 트리
  - 휴지통 진입
- 문서 편집 영역
  - 점진적으로 공개하는 폴더 경로 breadcrumb
  - 제목
  - 마지막 수정 메타데이터
  - 아이콘 애니메이션과 텍스트 동기화 상태
  - Lexical WYSIWYG 본문
  - 블록 핸들, `+` 행동, 슬래시 메뉴
  - 선택 서식 플로팅 툴바
- 검색 결과
  - 폴더와 문서 유형
  - 전체 경로
  - 문서 일치 문맥
- 휴지통
  - 직접 이동된 최상위 항목
  - 펼칠 수 있는 하위 트리
  - 복원 행동

## UI 기준

- 데스크톱은 자료 트리와 편집 영역을 나란히 표시한다.
- 자료 트리 너비는 사용자가 조절할 수 있고 완전히 접을 수 있다.
- 태블릿과 모바일은 자료 트리를 오버레이 드로어로 표시한다.
- 모바일에서 문서를 선택하면 드로어를 닫고 편집 영역으로 이동한다.
- 트리는 reui Tree를 공통 프리미티브로 사용하고 폴더·문서 표현과 비즈니스 행동은 자료실 feature가 소유한다.
- 폴더 chevron은 펼침 상태를 바꾸고 폴더 선택은 새 항목의 부모 맥락을 정한다.
- 문서 선택은 `/resources/[documentId]`로 이동한다.
- `/resources`는 최근 문서 목록 없이 문서 선택 안내와 새 문서 행동을 표시한다.
- breadcrumb가 길면 첫 항목과 마지막 항목을 유지하고 가운데를 줄임표로 축약한다.
- 축약된 breadcrumb는 hover 또는 click 시 팝오버에서 전체 경로를 표시한다.
- 본문은 별도 미리보기 없이 편집 영역 자체가 최종 결과처럼 보인다.
- 상시 서식 toolbar는 두지 않는다. 블록 행동은 슬래시 메뉴와 핸들 메뉴, 인라인 서식은 선택 플로팅 툴바에서 제공한다.
- 휴지통 이동은 항상 확인 대화상자를 사용한다.
- 현재 편집자가 있으면 확인 대화상자에 인원수만 표시하고 이름은 표시하지 않는다.
- 휴지통의 문서는 읽기 전용 표현과 복원 행동을 함께 표시한다.

## 상태

- 문서 미선택
- 트리 비어 있음
- 트리 자식 로딩 중과 실패
- 검색 중, 결과 있음, 결과 없음, 실패
- 문서 초기화 중
- 동기화 중
- 동기화됨
- 오프라인과 재연결 중
- 동기화 오류
- 휴지통 문서 읽기 전용
- 휴지통 비어 있음
- 이름 충돌과 빈 이름 복구
- Markdown 가져오기 검증 실패
- 휴지통 이동 확인과 복원 완료

작업 공간 실시간 연결 상태와 현재 문서 동기화 상태는 서로 독립적이다. 문서의 연결 준비·동기화·재연결은 자료 트리의 구조 행동을 잠그거나 트리 안에 경고를 추가하지 않는다. 작업 공간 실시간 연결이 끊기면 구조 행동은 즉시 잠기지만 750ms 안에 복구되는 짧은 단절은 전역 경고로 표시하지 않는다. 문서 동기화 상태 영역은 최소 높이와 데스크톱 고정 폭을 유지한다.

## 상호작용

- 폴더와 문서는 pointer 드래그 앤 드롭과 메뉴 기반 이동을 모두 지원한다.
- 폴더에 hover한 채 이동하면 지연 후 폴더를 펼칠 수 있다.
- 문서는 폴더 안으로 또는 형제 사이로만 이동할 수 있다.
- 폴더는 자기 자신과 하위 폴더 안으로 이동할 수 없다.
- 새 문서는 생성 즉시 제목 입력에 포커스를 둔다.
- 제목 변경은 서버 확정 전 동기화 중 상태를 표시하고 충돌하면 이전 이름으로 되돌린다.
- `/` 입력은 한국어 명령명과 검색 별칭을 가진 슬래시 메뉴를 연다.
- 블록 핸들의 `+` 행동은 같은 슬래시 메뉴를 연다.
- 다른 관리자의 본문 변경은 현재 선택을 가능한 범위에서 보존하며 병합한다.
- 실행 취소는 현재 탭에서 현재 사용자가 만든 변경만 대상으로 한다.

## 접근성

- 트리는 tree, treeitem, group 의미와 펼침·선택 상태를 보조 기술에 제공한다.
- 화살표 키, Home, End, Enter, Space로 트리를 탐색하고 펼칠 수 있다.
- 드래그 앤 드롭의 모든 행동은 항목 메뉴에서도 수행할 수 있다.
- 슬래시 메뉴와 플로팅 툴바는 화살표 키, Enter, Escape로 조작할 수 있다.
- 동기화 상태와 오류는 과도한 반복 알림 없이 `role="status"` 또는 `role="alert"`로 구분한다.
- breadcrumb 축약 팝오버는 hover에만 의존하지 않고 click과 키보드 focus를 지원한다.
- 아이콘 애니메이션은 reduced motion 설정에서 정적인 상태 아이콘으로 대체한다.
- 이미지 삽입은 대체 텍스트 입력을 요구한다.
