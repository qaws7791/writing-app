# SCR-107 분석

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

## 목적

관리자가 가입에서 첫 시작·완료·D7 재방문까지의 흐름과 개선할 레슨을 분석한다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- `PageHeader`
- 가입·활성화, 시작·완료, D7 재방문 차트
- 차트와 같은 값의 일별 데이터 표
- AI 코칭 서비스 품질 집계
- AI 실패율 상위 레슨 표
- 검색·정렬·페이지 이동이 가능한 레슨별 성과 표

## UI 기준

- 세 차트는 데스크톱 3열 responsive grid와 공통 `Surface variant="panel"` shell을 사용한다.
- Recharts는 분석 화면의 하나의 지연 로딩 client boundary에서만 불러온다.
- 각 차트는 기간 합계와 데이터 의미를 텍스트로 먼저 제공하고, 세 차트에 공통인 일별 데이터 표를 한 번만 제공한다.
- AI 코칭 서비스 품질은 차트와 같은 조회 기간의 요청·성공·성공률·실패·평균 지연·재시도와 token 사용량, 정규화한 실패 code별 건수를 제공한다. 답안·prompt·피드백 원문은 표시하지 않는다.
- AI 품질 집계는 요청이 없는 기간을 성과 0과 구분해 별도 상태로 표시하고, 조회 실패는 다른 영역을 유지한 채 해당 영역에만 오류로 표시한다.
- AI 실패율 상위 표는 레슨·강의, 요청 수, 실패 수와 실패율을 함께 제공하며 기간 내 실패가 없으면 한국어 빈 상태를 표시한다.
- 레슨별 성과의 검색어, 정렬, 방향, 페이지와 페이지 크기는 URL query에 보존하며 변경 시 서버에서 다시 조회한다. 기본 정렬은 이탈률 내림차순이다.
- 허용되지 않은 URL query는 canonical 기본값으로 복구한다.
- 모바일에서도 표의 열과 정렬 행동을 숨기지 않고 최소 폭과 가로 스크롤을 유지한다.

## 상태

- 분석 요약 조회 성공
- 분석 요약 조회 실패
- AI 품질 집계 조회 성공·실패
- AI 품질 집계 요청 없음
- 차트 또는 화면 렌더링 실패 후 다시 시도
- 레슨별 분석 조회 실패
- 분석 row 없음
- D7 cohort 집계 중 또는 표본 없음
- route 로딩

## 접근성

- 차트와 같은 값을 가진 단일 일별 표와 레슨별 성과 표에 각각 식별 가능한 한국어 이름을 제공한다.
- AI 코칭 서비스 품질 영역은 식별 가능한 한국어 이름을 가진 region으로 제공한다.
- 정렬 열은 `aria-sort`, 페이지 이동은 목적을 설명하는 한국어 이름을 제공한다.
- 수치 단위는 `%`, `명`, `개`처럼 텍스트에 포함한다.
- 오류는 `role="alert"`로 표시한다.
