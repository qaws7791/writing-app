# SCR-004 코스 목록

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 카테고리별 코스를 살펴보고 시작할 코스를 선택한다.

## 주요 사용자

- 코스를 처음 찾는 학습자
- 다음 코스를 찾는 학습자

## 정보 구조

- 화면 제목
- 설명
- 카테고리 섹션
- 코스 카드 캐러셀
- 코스 더 보기

## UI 기준

- 제목은 `코스`, 설명은 `주제별로 코스를 살펴보세요`를 사용한다.
- 코스 목록은 카테고리별 섹션으로 나누어 보여 주며 제목·레슨 수 정렬 control과 카테고리 필터를 제공하지 않는다.
- 카테고리 섹션 순서는 코스 카테고리 계약 값 순서를 따르고, 코스가 없는 카테고리는 숨긴다.
- 코스 카드는 모든 뷰포트에서 세로형이다.
- 카테고리 섹션의 코스 목록은 화면 너비 전체를 차지하는 가로 캐러셀이다. 첫 카드는 카테고리 제목과 왼쪽을 맞추고, 캐러셀 트랙은 화면 전체로 확장되어 좌우 가장자리에 이전/다음 카드가 살짝 보이도록 배치하여 추가 카드가 있음을 안내한다. 마지막 카드에 도달하면 카드 오른쪽은 카테고리 제목과 같은 본문 여백을 둔다.
- 캐러셀은 터치 스와이프와 데스크톱 마우스 드래그로 스크롤한다. 이전·다음 버튼과 스크롤 위치 막대를 함께 제공한다. 한 화면에 모든 카드가 보이면 컨트롤을 숨긴다.
- 코스 카드 너비는 화면 너비 640px 미만에서 다음 카드가 보이도록 줄이고, 640px 이상에서는 320px을 기본으로 한다. 높이는 정사각 미디어와 텍스트 고유 높이를 따른다. 고정 340×520 비율을 쓰지 않는다. 카드 간격은 화면 너비 640px 미만에서 12px, 640px 이상에서 24px이다. 이미지 영역은 28px inset의 정사각이다. 안쪽 radius는 카드보다 작은 `3xl`을 쓰고 별도 배경 면을 두지 않는다. 하단 텍스트 영역은 좌우·아래 24px padding을 사용한다.
- 코스 카드에는 이미지, 제목, 설명, 레슨 수를 포함한다. 카테고리는 섹션 제목으로만 보여 주고 카드에는 반복하지 않는다. 설명은 제목 아래 두 줄까지 표시한다.
- 코스 카드 이미지는 `resolveCourseImage`를 사용한다.
- 추가 페이지가 있으면 `코스 더 보기`로 cursor 목록을 이어 받는다.

## 상태

- 코스 없음
- 코스 목록 조회 실패
- 코스 더 보기 로딩 / 실패

## 접근성

- 카테고리 섹션은 `section`과 카테고리 제목 `h2`로 구분한다.
- 코스 카드는 목적지가 있으므로 `Link`를 사용한다.
- 캐러셀은 이전·다음 버튼과 카드 `Link`로 키보드 탐색을 제공한다. 포인터 드래그만으로 탐색이 끝나지 않게 한다.
- 이미지 alt는 코스 제목이다.
