# SCR-004 코스 목록

## 라우트

- `apps/web`: `/app/courses`

## 목적

학습자가 관심 카테고리를 고르고 시작할 코스를 선택한다.

## 주요 사용자

- 코스를 처음 찾는 학습자
- 다음 코스를 찾는 학습자

## 정보 구조

- 화면 제목
- 설명
- 카테고리 pill 탭
- 코스 카드 grid

## UI 기준

- 제목은 `무엇을 써볼까요?` 톤의 질문형 문구를 유지한다.
- 카테고리 활성 탭은 `bg-charcoal text-cream`을 사용한다.
- 코스 카드는 모바일에서 가로형, 데스크톱에서 세로형으로 전환한다.
- 코스 카드에는 이미지, 제목, 설명, 레슨 수를 포함한다. 모바일에서는 설명을 생략할 수 있다.

## 상태

- 카테고리 선택
- 코스 없음
- 코스 목록 조회 실패

## 접근성

- 카테고리 버튼은 `button`으로 구현한다.
- 코스 카드는 목적지가 있으므로 `Link`를 사용한다.
- 이미지 alt는 코스 제목이다.
