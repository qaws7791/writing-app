# SCR-004 코스 목록

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 카테고리별 코스를 살펴보고 시작할 코스를 선택한다.

## 주요 사용자

- 코스를 처음 찾는 학습자
- 다음 코스를 찾는 학습자

## 정보 구조

- 화면 제목
- 설명
- 카테고리 섹션
- 코스 카드 grid
- 코스 더 보기

## UI 기준

- 제목은 `코스`, 설명은 `주제별로 코스를 살펴보세요`를 사용한다.
- 코스 목록은 카테고리별 섹션으로 나누어 보여 주며 제목·레슨 수 정렬 control과 카테고리 필터를 제공하지 않는다.
- 카테고리 섹션 순서는 코스 카테고리 계약 값 순서를 따르고, 코스가 없는 카테고리는 숨긴다.
- 코스 카드는 모든 뷰포트에서 세로형이다.
- 코스 카드에는 이미지, 제목, 설명, 레슨 수를 포함한다. 설명은 두 줄까지 표시한다.
- 코스 카드 이미지는 `resolveCourseImage`를 사용한다.
- 추가 페이지가 있으면 `코스 더 보기`로 cursor 목록을 이어 받는다.

## 상태

- 코스 없음
- 코스 목록 조회 실패
- 코스 더 보기 로딩 / 실패

## 접근성

- 카테고리 섹션은 `section`과 카테고리 제목 `h2`로 구분한다.
- 코스 카드는 목적지가 있으므로 `Link`를 사용한다.
- 이미지 alt는 코스 제목이다.
