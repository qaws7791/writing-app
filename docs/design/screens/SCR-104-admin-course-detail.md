# SCR-104 코스 편집

## 라우트

- `apps/admin`: `/courses/[id]`

## 목적

관리자가 현재 코스 editor 문서를 열어 코스 정보, 커리큘럼, 레슨, 스텝을 편집하고 학습자 표시를 확인한다.

## 주요 사용자

- 콘텐츠 관리자

## 정보 구조

- `AdminHeader`
- 저장 상태 bar
- 코스 정보 편집 패널
- 커리큘럼 맵
- 레슨 편집 작업대
- 스텝 편집 작업대
- 스텝 타입 추가 menu
- 학습자 미리보기 dialog
- 삭제 확인 dialog
- 오류 banner

## UI 기준

- 화면 제목은 `코스 편집`이다.
- 코스 정보는 제목, 설명, 카테고리 form control을 제공한다.
- 커리큘럼 맵은 유닛, 레슨, 스텝 계층과 현재 선택 상태를 보여준다.
- 유닛은 추가, 제목 수정, 삭제 행동을 제공한다.
- 레슨은 추가, 삭제, 순서 변경, 제목, 카테고리, 설명, 예상 시간, 요약 수정을 제공한다.
- 스텝은 추가, 삭제, 순서 변경, 타입별 content 편집을 제공한다.
- 저장 버튼은 dirty 상태가 있을 때 활성 상태를 드러낸다.
- 학습자 미리보기 dialog는 현재 선택한 레슨 또는 스텝을 학습자 렌더러 기준으로 보여준다.
- 위험한 삭제 행동은 확인 dialog 이후 실행한다.
- 패널 구조는 어드민 8px radius와 border 기준을 따른다.

## 상태

- 코스 조회 성공
- 코스 조회 실패
- 레슨 없음
- 스텝 없음
- dirty 상태
- 저장 중
- 저장 성공
- 저장 실패
- 검증 오류
- 학습자 미리보기 열림
- 삭제 확인 열림

## 접근성

- 모든 편집 control은 한국어 label을 가진다.
- 저장 상태는 `role="status"`로 알린다.
- 오류는 `role="alert"`로 표시한다.
- dialog는 제목과 닫기 행동을 제공한다.
- preview 텍스트는 학습자에게 보이는 실제 콘텐츠와 동일한 한국어를 사용한다.
