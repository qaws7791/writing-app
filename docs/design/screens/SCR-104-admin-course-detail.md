# SCR-104 코스 미리보기

## 라우트

- `apps/admin`: `/courses/[id]`

## 목적

관리자가 현재 코스 editor 문서를 읽기 전용으로 확인한다.

## 주요 사용자

- 콘텐츠 관리자

## 정보 구조

- `AdminHeader`
- 읽기 전용 fieldset
- 코스 정보 패널
- 커리큘럼 맵
- 레슨 작업대
- 스텝 작업대
- 레슨 미리보기

## UI 기준

- 현재 구현 기준 제목은 `코스 미리보기`다.
- form control은 비활성화된 읽기 전용 미리보기로 표시한다.
- 편집/저장 가능 UI처럼 보이지 않게 한다.
- 패널 구조는 어드민 8px radius와 border 기준을 따른다.

## 상태

- 코스 조회 성공
- 코스 조회 실패
- 레슨 없음
- 읽기 전용 disabled 상태

## 접근성

- 읽기 전용 영역은 disabled fieldset으로 묶는다.
- 오류는 `role="alert"`로 표시한다.
- preview 텍스트는 관리자에게 보이는 실제 콘텐츠와 동일한 한국어를 사용한다.
