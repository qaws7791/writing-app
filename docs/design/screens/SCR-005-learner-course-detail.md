# SCR-005 코스 상세

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 코스의 내용과 진행률을 확인하고 다음 레슨으로 진입한다.

## 주요 사용자

- 코스를 시작하려는 학습자
- 진행 중 코스를 이어 하려는 학습자

## 정보 구조

- 코스 목록으로 돌아가는 `Link`(목적지 명시 라벨)
- 코스 썸네일
- 코스 제목(`h1`)
- 설명
- 진행률(`완료 수/전체 레슨 수` 단위와 코스 총 예상 분)
- 다음 레슨 CTA(`nextLesson`이 있을 때만). 다음 레슨 제목은 CTA 부제로 붙인다. 커리큘럼 현재 행은 위치 지도다.
- 커리큘럼 섹션 제목(`h2`)
- 유닛별 커리큘럼(유닛 완료/전체, 레슨 상태)

## UI 기준

- 상세 hero는 `Card variant="muted"` 조합을 사용한다.
- 코스 썸네일은 모바일에서 히어로 상단 전폭 정사각으로 두고, 데스크톱에서는 텍스트 열 높이를 채우는 208–256px 미디어 열로 둔다. 다크 히어로는 `shadow-xs` inset highlight로 우물 윤곽을 읽히게 한다.
- 코스 제목(`h1`), 커리큘럼 제목(`h2`), 유닛 제목은 `foundations.md`의 한국어 제목 tracking(`-0.01em` 이하)을 따른다. 유닛 제목은 heading이 아니므로 `word-break: keep-all`과 `overflow-wrap: anywhere`를 명시한다.
- 코스 진행률은 공용 `Progress`, `ProgressLabel`, `ProgressValue`를 사용한다. indicator는 실제 비율 너비만 쓰고 최소 너비 캡슐을 만들지 않는다.
- 설명은 `foreground/80` 본문이다. 진행 분수·예상 분·레슨 시간은 muted 메타다. 다음 레슨 CTA 부제는 `foreground` medium이다.
- CTA는 공유 `Button`의 기본 조합을 사용하며 히어로 텍스트 열 전폭을 차지한다. primary 면은 CTA에만 두고, 현재 행은 왼쪽 위치 막대와 비-primary play로 ‘여기’만 표시한다.
- 히어로 CTA는 유지한다. 커리큘럼을 읽는 동안에도 현재 행이 `이어서 학습` 또는 `학습 시작` 라벨로 같은 과업을 제공한다.
- `nextLesson`이 없으면 CTA를 표시하지 않는다.
- `learning.nextLesson`이 속한 유닛을 Accordion 기본 열림으로 둔다. 없으면 첫 유닛을 연다.
- 유닛 패널은 Accordion의 height·opacity motion을 그대로 사용한다. 레슨 행 `Link`는 Accordion 본문 기본 밑줄을 덮어 끈다.
- 유닛은 별도 배경 surface를 사용하지 않고 공용 `AccordionItem`의 `border`로 구분하며, 좌우 패딩을 제거(`px-0`)하여 커리큘럼 섹션 제목 텍스트와 광학 정렬을 맞춘다. 각 레슨 행은 패딩과 부드러운 모서리 셰이프(`rounded-2xl px-3 py-3`)를 통해 하이라이트 및 호버 배경을 단독 알약 셰이프로 형성한다.
- 유닛 헤더는 서수, 제목과 `완료 수/전체 레슨 수`를 보여 주며, 모든 레슨 완료 시 완료 상태 텍스트(`X/X개 레슨 완료`)와 완료 아이콘을 강조하여 표시한다.
- 레슨 행은 제목과 함께 예상 시간을 표시하고, 접근성 이름에도 예상 시간을 포함한다. 유닛·레슨 제목은 말줄임하지 않고 `keep-all`로 감싸며 최대 두 줄까지 허용한다.
- `learning.nextLesson`과 id가 같은 레슨 행은 불투명 `card` 면과 왼쪽 위치 막대로 강조하며, 레슨 항목의 우측 뱃지는 모두 제거한다.
- 모든 active 레슨 행은 선택 가능해야 한다.
- 레슨 상태 아이콘 원은 글리프가 한눈에 읽히도록 유지한다.
- 레슨 행은 충분한 최소 높이와 focus ring을 제공한다.

## 상태

- 첫 레슨 시작
- 이어서 학습
- 모든 레슨 완료(CTA 없음)
- 코스 없음
- 코스 또는 진행 조회 실패

## 접근성

- 코스 목록 복귀는 `Link`로 구현한다. 높이는 40px, 색은 `foreground/80`이다.
- 진행률은 텍스트 분수와 시각 bar를 함께 제공한다.
- 레슨 상태는 색상만이 아니라 아이콘, 제목 명도, 접근 가능한 이름(완료·다음·학습 가능)으로 구분한다. 완료 제목은 muted, 현재는 foreground, 미완은 foreground/80이다.
