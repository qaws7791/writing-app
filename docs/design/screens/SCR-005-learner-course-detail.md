# SCR-005 코스 상세

## 라우트

- `apps/web`: `/app/courses/[id]`

## 목적

학습자가 코스의 내용과 진행률을 확인하고 다음 레슨으로 진입한다.

## 주요 사용자

- 코스를 시작하려는 학습자
- 진행 중 코스를 이어 하려는 학습자

## 정보 구조

- 돌아가기 링크
- 코스 썸네일
- 코스 제목
- 설명
- 진행률
- 다음 레슨 CTA
- 유닛별 커리큘럼

## UI 기준

- 상세 hero 카드는 `bg-surface rounded-4xl`을 사용한다.
- 진행 bar는 `charcoal/20` track과 `primary` indicator를 사용한다.
- CTA는 `bg-charcoal text-cream rounded-full`이다.
- 커리큘럼은 완료, 진행 가능, 잠금 상태를 구분한다.

## 상태

- 첫 레슨 시작
- 이어서 학습
- 모든 레슨 완료
- 코스 없음
- 코스 또는 진행 조회 실패

## 접근성

- 돌아가기는 `Link`로 구현한다.
- 진행률은 텍스트 분수와 시각 bar를 함께 제공한다.
- 잠금 상태는 색상만이 아니라 텍스트나 아이콘 의미로도 구분한다.
