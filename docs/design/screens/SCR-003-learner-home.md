# SCR-003 학습 홈

## 구현 탐색

현재 route는 [학습자 앱 route source](../../../apps/web/src/app)에서 확인한다.

## 목적

학습자가 오늘 이어서 할 학습을 빠르게 찾고 현재 학습 상태를 확인한다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 인사말
- 연속 학습일
- 완료한 레슨 수
- 최근 5일 학습 기록
- 이어서 학습하기 목록
- 진행중 / 완료 탭
- 진행중 탭 빈 상태 CTA

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 넓은 뷰포트는 왼쪽 인사·요약을 좁히고 오른쪽 진행 탭을 넓힌 2열 grid로 배치한다. 열 간격은 32px이다.
- `이어서 학습하기` 섹션은 보이는 제목과 `진행중`, `완료` 탭을 항상 표시한다.
- 탭 레이블은 진행 중 코스 수와 완료 코스 수를 함께 표시한다.
- `진행중` / `완료` 탭은 공유 `Tabs`의 기본 조합을 쓴다.
- 진행중 탭은 최대 5개 코스를 보여준다.
- 완료 탭은 전용 간소 카드를 사용하고, 첫 진입 시 완료 코스 목록을 조회한다.
- 진행 중 코스 카드는 `resolveCourseImage` 썸네일, 제목, 진행률과 다음 학습 레슨 CTA를 표시한다.
- 가장 최근 진행 코스는 Hero Resume로 올리고 첫 다음 레슨만 Primary 행동으로 강조한다.
- 카드의 주 목적지는 다음 학습 레슨이다. 코스 상세는 `코스 보기` 텍스트 링크로 둔다.
- 다음 학습 레슨은 최대 2개다. 둘째는 텍스트 행이다.
- 좁은 화면에서 한 카드의 보이는 행동은 Primary와 텍스트 행동 둘을 넘지 않는다. 다음 레슨이 2개이면 `코스 보기`는 넓은 뷰포트에서만 보인다.
- 다음 학습 레슨 CTA는 레슨 제목과 예상 시간을 포함하고 해당 레슨 화면으로 이동한다.
- 진행중 탭이 비어 있으면 `Card variant="muted"` 조합과 코스 둘러보기 CTA를 사용한다.
- CTA 제목은 `새로운 코스를 / 선택해 보세요`를 사용한다.
- 진행률은 공용 `Progress`를 사용한다.
- 요약 지표는 `Card variant="muted"` 조합을 쓰며, 아이콘과 수치를 한 행으로 압축한다.
- 요약 지표 아래에는 공용 `Cadence`로 최근 5일 학습 여부를 표시한다.
- 모바일에서는 Cadence 제목·힌트를 숨기고 5칸 마크만 표시한다.
- 진행 코스와 완료 코스는 공용 `Card` 조합을 사용한다.

## 상태

- 진행 중 코스 있음
- 진행 중 코스 없음 (진행중 탭 CTA)
- 완료 코스 목록 조회 중 / 실패 / 없음
- 프로필 또는 진행 조회 실패
- 홈 첫 조회 로딩은 인사·요약·Cadence와 이어서 학습 카드 자리를 같은 2열 비율로 예고한다

## 접근성

- 코스 이동은 `Link`를 사용한다.
- 제목 옆 코스 썸네일은 장식 요소이며 빈 `alt`와 `aria-hidden`으로 처리한다.
- 진행 숫자는 시각 장식 없이 텍스트로도 이해되어야 한다.
- 최근 5일 학습 기록의 일별 마크는 요일과 상태 이름을 `aria-label`로 전달한다.
