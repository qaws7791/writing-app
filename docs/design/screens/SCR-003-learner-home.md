# SCR-003 학습 홈

## 라우트

- `apps/web`: `/app`

## 목적

학습자가 오늘 이어서 할 학습을 빠르게 찾고 현재 학습 상태를 확인한다.

## 주요 사용자

- 로그인한 학습자

## 정보 구조

- 인사말
- 연속 학습일
- 완료한 레슨 수
- 이어서 학습하기 목록
- 진행중 / 완료 탭
- 진행중 탭 빈 상태 CTA

## UI 기준

- `AppShell` 안에서 렌더링한다.
- 데스크톱은 왼쪽 요약 영역을 sticky로 두고, 오른쪽에 `이어서 학습하기` 섹션과 탭을 배치한다.
- `이어서 학습하기` 섹션은 `진행중`, `완료` 탭을 항상 표시한다.
- 진행중 탭은 최대 5개 코스를 보여준다.
- 완료 탭은 전용 간소 카드를 사용하고, 첫 진입 시 완료 코스 목록을 조회한다.
- 모바일 진행 코스는 가로 스크롤 카드 패턴을 사용할 수 있다.
- 진행 중 코스 카드는 다음 학습 레슨 CTA를 최대 2개까지 표시할 수 있다.
- 다음 학습 레슨 CTA는 레슨 제목을 포함하고 각 CTA는 `/app/lesson?lesson_id=...`로 이동한다.
- 진행중 탭이 비어 있으면 `bg-surface rounded-panel` 카드와 코스 둘러보기 CTA를 사용한다.
- CTA 제목은 `새로운 코스를 / 선택해 보세요`를 사용한다.
- 이어서 학습 코스 이미지는 `next/image`를 사용한다.
- 진행률은 공용 `Progress`, 요약 지표는 `StatCard`를 사용한다.

## 상태

- 진행 중 코스 있음
- 진행 중 코스 없음 (진행중 탭 CTA)
- 완료 코스 목록 조회 중 / 실패 / 없음
- 프로필 또는 진행 조회 실패

## 접근성

- 코스 이동은 `Link`를 사용한다.
- 이미지 alt는 코스 제목을 사용한다.
- 진행 숫자는 시각 장식 없이 텍스트로도 이해되어야 한다.
