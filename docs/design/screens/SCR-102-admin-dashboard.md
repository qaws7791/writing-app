# SCR-102 어드민 대시보드

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

- 과거 대시보드 경로 표기는 현재 화면의 근거로 사용하지 않는다.

## 목적

소유자 관리자가 제품의 활성화와 학습 유지 상태를 빠르게 확인한다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- `AdminPageHeader`
- 주요 지표 5개

## UI 기준

- 주요 지표는 responsive grid 안의 Luma `Card`를 사용한다.
- 카드는 `활성화율`, `7일 내 재방문`, `최근 7일 활성`, `점검 성공률`, `점검 뒤 수정률` 순서로 배치한다.
- 비율 카드는 분자·분모를 함께 표시하고 표본 없음과 미성숙 cohort를 각각 `표본 없음`, `집계 중`으로 구분한다.
- `AdminPageHeader`에는 집계 기준일을, 최근 7일 활성 카드에는 집계 기간을 표시한다.
- 하단 차트와 최근 활동 영역은 표시하지 않는다.

## 상태

- 데이터 조회 성공
- 조회 실패
- 비율 표본 없음
- D7 cohort 집계 중

## 접근성

- 주요 지표 section에 `aria-label="주요 지표"`를 제공한다.
- 오류는 `role="alert"`를 사용한다.
