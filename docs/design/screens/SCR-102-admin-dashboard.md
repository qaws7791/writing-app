# SCR-102 어드민 대시보드

## 라우트

- `apps/admin`: `/`
- 문서상 `/dashboard`와 병기 가능

## 목적

운영자가 학습자 활동과 콘텐츠 상태를 빠르게 확인한다.

## 주요 사용자

- 관리자
- 운영자

## 정보 구조

- `PageHeader`
- 주요 지표 4개

## UI 기준

- 주요 지표는 `StatGrid`와 `StatCard`를 사용한다.
- metric card는 Kwep 어드민과 동일하게 아이콘과 라벨을 한 줄에 배치하고, 값과 보조 설명을 아래에 둔다.
- 카드 구성은 `총 사용자`, `신규 가입`, `총 레슨 완료`, `콘텐츠` 순서다.
- 콘텐츠 카드는 큰 값으로 활성 레슨 수를 보여주고, 보조 설명으로 활성 강의 수를 제공한다.
- 이 화면은 우선 Kwep 어드민 상단 지표 카드 정렬만 맞추며, 하단 차트와 최근 활동 영역은 표시하지 않는다.

## 상태

- 데이터 조회 성공
- 조회 실패

## 접근성

- 주요 지표 section에 `aria-label="주요 지표"`를 제공한다.
- 오류는 `role="alert"`를 사용한다.
