# SCR-102 어드민 대시보드

## 라우트

- `apps/admin`: `/`
- 문서상 `/dashboard`와 병기 가능

## 목적

운영자가 학습자 활동과 콘텐츠 상태를 빠르게 확인한다.

## 주요 사용자

- 관리자
- 운영자

## 정보 구조

- `AdminHeader`
- 주요 지표 4개
- 최근 활동
- 운영 흐름 막대 요약

## UI 기준

- 주요 지표는 `.admin-metric-grid` 4열을 사용한다.
- metric card는 아이콘, 라벨, 값, 보조 설명 순서다.
- 운영 흐름은 Recharts 기반 차트 또는 간단한 CSS bar로 표현할 수 있다.
- 차트가 제공하는 수치는 텍스트 보조 설명으로도 확인 가능해야 한다.

## 상태

- 데이터 조회 성공
- 최근 활동 없음
- 조회 실패

## 접근성

- 주요 지표 section에 `aria-label="주요 지표"`를 제공한다.
- 최근 활동 list는 빈 상태를 텍스트로 제공한다.
- 오류는 `role="alert"`를 사용한다.
