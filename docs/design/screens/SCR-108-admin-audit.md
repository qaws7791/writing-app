# SCR-108 감사 이력

## 구현 탐색

현재 route는 [관리자 앱 route source](../../../apps/admin/src/app)에서 확인한다.

## 목적

소유자 관리자가 개인정보 조회와 고위험 변경의 이력을 최신순으로 확인한다.

## 주요 사용자

- 소유자 관리자

## 정보 구조

- `AdminPageHeader`
- 필터: 시작일, 종료일, 작업 종류
- 감사 이력 table: 실행 시각, 작업, 대상, 결과, 요청 출처, 요청 식별자
- 페이지 이동

## UI 기준

- 목록은 Luma `Card` 안의 공유 `Table`로 표시한다.
- 작업과 대상 종류는 한국어 표기로 옮겨 보여준다.
- 결과는 텍스트 라벨을 가진 상태 pill로 표시하고 색상만으로 의미를 전달하지 않는다.
- 요청 식별자는 로그 연결용 값이므로 줄바꿈 없이 그대로 보여준다.
- MCP 변경은 실행 ID와 MCP credential ID를 표시한다.
- MCP 자동 실행과 MCP 승인 실행은 서로 다른 요청 출처로 표시한다.
- MCP 승인 실행은 승인 요청 링크를 표시한다.
- 일반 관리자 요청은 관리자 화면으로 구분한다.
- 필터는 GET form으로 제출해 현재 조건이 주소에 남고 새로고침·공유에도 유지된다.
- 페이지 이동은 현재 필터 조건을 유지하고 페이지가 하나면 표시하지 않는다.

## 상태

- 이력 조회 성공
- 이력 조회 실패
- 이력 없음
- 필터 조건에 맞는 이력 없음

## 접근성

- table은 식별 가능한 한국어 이름과 `th scope="col"`을 제공한다.
- 필터는 식별 가능한 한국어 이름을 가지며 각 입력에 보이는 라벨을 연결한다.
- 페이지 이동은 식별 가능한 한국어 이름을 가진 `nav`로 제공한다.
- 오류는 `role="alert"`로 표시한다.
- 실행 시각은 사람이 읽을 수 있는 한국어 형식으로 제공한다.
