# 앱 내비게이션 활성 상태

## 2026-05-27 작업 시작

- `/app/courses` 경로에서 상단 내비게이션의 `홈`과 `배우기`가 동시에 활성 상태처럼 보이는 문제를 조사한다.
- 활성 상태는 `GlobalNav`의 현재 경로와 메뉴 `href` 비교 로직을 기준으로 결정된다.
- 회귀 테스트와 브라우저 시각 검증으로 수정 결과를 확인한다.

## 2026-05-27 작업 완료

- 원인은 `/app` 홈 항목에도 하위 경로 prefix 매칭이 적용되어 `/app/courses`가 홈의 하위 경로처럼 처리된 것이다.
- `GlobalNav`에서 `/app` 홈 항목은 정확히 `/app`에서만 활성화하고, `/app/courses` 같은 섹션 메뉴는 기존처럼 하위 경로까지 활성화되도록 수정했다.
- 회귀 테스트는 `/app/courses`에서 데스크톱/모바일 `홈` 링크에 `aria-current`가 없고 `배우기` 링크에만 `aria-current="page"`가 붙는지 검증한다.
- 브라우저 시각 검증은 로그인된 테스트 세션으로 `http://localhost:3000/app/courses`에서 수행했다.
