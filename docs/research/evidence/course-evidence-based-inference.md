# 코스 근거 연결: 근거를 연결해 추론하기

## 판정 기준

- 예문·지문·문항·해설·참조 답안은 모두 자체 집필했다.
- 각색하거나 짧게 인용한 외부 콘텐츠는 없다.
- 주장 연결은 설계 판단의 근거이며 개별 활동의 효과를 보장하지 않는다.
