# 교육 활동 공백 인덱스

## 책임

이 디렉터리는 교육적으로 필요하지만 현재 스텝 계약으로 자연스럽게 구현하기 어려운 활동과 제품 기능 공백을 기록한다. 공백 기록은 새 기능 요구사항이나 구현 승인이 아니다.

## 기록 형식

- 공백 ID와 제목
- 관련 역량·주장 ID
- 교육 목적과 근거
- 현재 스텝으로 표현하기 어려운 이유
- 억지로 대체할 때 잃는 학습 효과
- 가능한 후속 검토 질문

현재 스텝으로 충분히 표현할 수 있는 활동은 기록하지 않는다. 실제 기능으로 채택할 때는 별도 제품 요구사항과 기술 계약 검토를 거친다.
