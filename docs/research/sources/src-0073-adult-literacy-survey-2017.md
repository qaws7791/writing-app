## 원문 확인 기록

- 공식 PDF 34쪽 전체의 정의, 43문항 구성, 표본·가중치, 수준분류, 집단·영역 결과, 참여의향과 2014 비교를 확인했다.
- 2017년 9월 15일~11월 17일 전국 17개 시도 만 18세 이상 4,004명을 가구 방문 면접했다. 국가기초구역 400개, 가구 계통추출, 개인 grid 방식이며 가중치는 설계·무응답·사후층화를 반영했다.
- 95% 최대허용 표집오차는 설계효과를 반영해 ±2.3%p다. 섬·기숙·특수시설·관광호텔 가구는 조사모집단에서 제외됐다.
- A 3, B 20, C 20의 43문항은 산문 21, 문서 14, 수리 8문항이며 주관식 27, 객관식 16문항이다.
- 실제 문항 자극과 정답 전체는 이 요약보고서에 공개되지 않고 문항명·분류·분기규칙만 제공된다. 따라서 비공개 문항 내용을 추정하지 않는다.

## 상세 내용 지도

1. **정의·도구(5~13쪽)**: 문해를 생활 문제해결로 정의하고 산문·문서·수리와 가정·경제·공공·여가·미디어를 교차한다.
2. **표본(14~15쪽)**: 모집단, 52개 층, 국가기초구역-가구-개인 추출, 가중치·대체를 설명한다.
3. **수준·격차(16~23쪽)**: 네 수준과 성·연령·소득·지역, 영역점수·정답률, 사회인식·참여의향을 보고한다.
4. **파동 비교(27~29쪽)**: 2014와 2017 환산점수·수준·집단변화를 표집오차와 함께 비교한다.

## 가르칠 개념과 원리

- 문해는 글자 해독을 넘어 일상에서 산문·표·서식·수량 정보를 찾아 이해하고 사용하는 능력이다.
- 같은 읽기라도 가정·미디어보다 경제·공공 문서가 복잡할 수 있어 텍스트 형식과 생활영역을 교차해 난이도를 설계한다.
- 수준 1은 기본 읽기·쓰기·셈이 어려운 단계, 수준 2는 기본기능은 있으나 생활 적용이 미흡, 수준 3은 단순 생활 적용은 가능하나 복잡한 공공·경제 적용이 미흡하다.
- 저수준에서 문서문해 정답률이 특히 낮았으므로 연속 산문만으로 생활문해를 가르치지 않는다.
- 집단격차는 접근성·경험·교육기회의 문제를 탐색할 신호이지 개인 능력의 고정 특성이 아니다.

## 수행 절차와 전략

1. 실제 생활 목표를 가정·경제·공공·여가·미디어 중에서 고른다.
2. 산문, 서식·표·그래프, 수량 정보를 한 과제 안에서 식별한다.
3. 필요한 정보 위치를 찾고 제목·범례·단위·조건을 표시한다.
4. 질문을 자신의 말로 바꾸고 관련 정보만 추출한다.
5. 정보를 비교·계산·재구성해 실제 결정이나 서식 작성으로 사용한다.
6. 결과가 원문 조건과 맞는지 역으로 검산한다.
7. 같은 구조를 새로운 기관·매체 문서에 적용해 전이를 확인한다.

## 예시·과제·관찰 지표

- 문항 목록에는 버스시간표, 택배서식·요금, 약 복용법·복용량, 전기요금, 인터넷 정보 재구성, 전입신고서, 국민연금, 계약서, 암검진 표, 최저임금 그래프, 근로계약서, 사전투표 안내가 포함된다.
- 전체 분포는 수준 1 7.2%, 수준 2 5.1%, 수준 3 10.1%, 수준 4 이상 77.6%다.
- 수준 1 정답률은 산문 4.2%, 수리 4.9%, 문서 0.0%; 수준 2는 33.2%, 20.2%, 12.0%로 문서가 가장 낮았다.
- 수준 1은 여성 9.9%/남성 4.5%, 60대 14.2%, 70대 28.7%, 80대 이상 67.7%, 농산어촌 16.2%였다.
- 관찰 지표는 정보 찾기 성공, 표·서식 경로, 단위와 조건 확인, 계산·재구성 정확성, 실제 행동 선택과 도움 요청이다.

## 흔한 오류·오개념과 교정

- **소리 내 읽으면 생활문해가 충분하다**: 표·서식·수량을 실제 결정에 사용하는 과제를 추가한다.
- **수준 3까지 모두 같은 비문해다**: 각 수준의 가능한 수행과 필요한 발판을 구분한다.
- **인터넷 이용 자체가 미디어 문해다**: 찾은 정보를 재구성·사용하는 과정을 본다.
- **여성·고령·농촌이 본질적으로 낮다**: 교육기회·소득·건강·접근성의 교차를 확인하고 집단 라벨을 개인에게 적용하지 않는다.
- **2014~2017 변화가 모두 유의하다**: 수준 1·2 변화는 ±2.3%p 표집오차 안이라 저자도 유의하지 않다고 명시했다.

## 평가와 피드백

- 입문 진단은 A형처럼 짧고 쉬운 과제로 시작해 실패 부담을 낮추고 필요한 경우 더 복잡한 형으로 분기한다.
- 산문·문서·수리와 생활영역별 프로파일을 따로 기록한다.
- 정답뿐 아니라 어디서 멈췄는지, 범례·단위·조건을 어떻게 추적했는지 관찰한다.
- 피드백은 한 번에 한 문서 기능을 모델링하고 유사한 실제 문서에서 즉시 재연습하게 한다.
- 수준은 프로그램 입구와 지원량을 정하는 기준으로만 쓰고 공개 낙인이나 학력등급 대체로 쓰지 않는다.

## 적용 조건과 전이 한계

- 2017년 문서·미디어 환경이며 현재 모바일 앱·QR·알고리즘 정보환경은 충분히 반영하지 않는다.
- 시설·도서지역 일부가 제외되어 가장 취약한 성인을 과소포착할 수 있다.
- 문항 전체가 비공개라 수업에서 동일 검사를 복제할 수 없고 공개 문항명으로 새 과제를 만들어야 한다.
- 수준과 사회인식·참여의향 관계는 횡단 상관이다.
- 학교학년 대응 표기는 설명용 근사이며 성인의 생활경험과 존엄을 아동 교육과 동일시하지 않는다.

## 상세 요약

2017년 조사는 문해를 생활 문제해결로 정의하고 43개 과제를 산문·문서·수리와 다섯 생활영역으로 교차했다. 수준 1~3은 22.4%였고, 특히 수준 1·2에서 문서문해가 산문보다 낮았다. 연령·소득·지역·성별 격차가 컸으며, 수준 1 약 311만 명 중 프로그램 참여의향은 10.9%로 추정됐다.

학습 설계에서는 읽기 자료를 짧은 산문에 한정하지 않고 표·서식·그래프·공공 안내를 실제 결정과 작성으로 이어야 한다. 표본 결과는 지원규모를 정하는 근거이지 개인의 고정 능력이나 교수법의 효과가 아니다.
