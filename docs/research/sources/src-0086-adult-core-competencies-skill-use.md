## 상세 내용 지도

1. **문제와 연구질문(137~140쪽)**: 핵심역량을 초기교육 결과가 아니라 생애의 형식·비형식·무형식학습과 연결하고 스킬활용 관계를 묻는다.
2. **핵심역량 이론(140~144쪽)**: 지식 보유에서 실제 적용·전이·새 산출로 확장된 역량과 PIAAC 문해·수리·컴퓨터 문제해결을 설명한다.
3. **교육경험·격차(144~145쪽)**: 개인배경, 본인·부모 교육, 비형식교육, 연령과 역량의 선행관계를 검토한다.
4. **스킬활용·무형식학습(145~146쪽)**: 업무·일상에서 학습한 자원을 반복 사용하며 다시 배우는 경험으로 스킬활용을 개념화한다.
5. **표본(146~147쪽)**: 6,667명에서 최근 5년 임금노동 경험 5,298명을 고른 이유와 배경분포를 제시한다.
6. **변수(147~150쪽)**: 세 역량 PV, 업무·일상 문해·수리·ICT 사용문항, 개인·교육 통제변수를 상세히 열거한다.
7. **모형과 결과(150~154쪽)**: 3단계 위계회귀, 설명량 변화, 표 6~8의 계수와 배경요인 변화를 보고한다.
8. **해석·한계(154~157쪽)**: 일상 사용의 큰 관련성, 컴퓨터 역량의 수행기회, 경험인정 정책과 2013 자료의 시의성 한계를 논의한다.

## 가르칠 개념과 원리

- 역량은 지식을 기억하는 상태가 아니라 실제 상황에서 읽고, 계산하고, 디지털 도구로 문제를 해결해 목적을 달성하는 수행이다.
- 스킬활용은 학습 결과의 단순 “사용”이면서 동시에 반복·변형·피드백을 통해 다시 배우는 무형식학습 기회가 될 수 있다.
- 문해 사용은 작업지시·이메일·뉴스·전문자료·책·참고자료·금융문서·도표를 읽고, 메모·기사·보고서·양식을 쓰는 활동을 아우른다.
- 수리 사용은 가격·비용, 분수·소수·백분율, 계산기, 그래프·표, 공식, 고급 수학·통계를 실제 문제에 쓰는 정도다.
- ICT 사용은 이메일·검색·거래·스프레드시트·문서작성·프로그래밍·실시간 토의 등 디지털 매체로 과업을 수행하는 빈도와 숙련을 포함한다.
- 업무에서 같은 좁은 절차만 반복하는 것과 여러 생활 맥락에서 목적에 맞게 전략을 선택하는 것은 전이 폭이 다르다. 수업은 반복과 변형을 함께 제공한다.
- 사용-역량 관계는 선순환일 수 있다. 사용이 연습을 만들 가능성과 높은 역량이 더 복잡한 활동·직업을 선택할 가능성을 모두 고려한다.
- 형식수업만으로 끝내지 않고 실제 문서를 사용한 뒤 결과·오류·전략을 성찰해야 수행이 학습경험으로 바뀐다.

## 수행 절차와 전략

1. 학습자의 업무·가정·공공서비스에서 지난 한 달에 실제로 한 읽기·쓰기·수리·ICT 활동을 구체적 문서와 함께 조사한다.
2. 각 활동을 빈도만 아니라 목적, 난도, 독립 수행, 오류 결과, 피드백 유무로 기록해 실질 노출량을 만든다.
3. 한 실제 과제를 “이해→계획→수행→검산/검증→설명”의 공통 루틴으로 해결한다.
4. 문해 과제에서는 지시·조건·마감·근거를 표시하고 핵심을 메모·이메일·양식으로 다시 쓴다.
5. 수리 과제에서는 단위와 필요한 값을 고르고 식·표·계산기를 사용한 뒤 대략값과 역산으로 확인한다.
6. 디지털 과제에서는 검색어, 출처, 입력자료, 도구 기능, 결과 검증과 개인정보 위험을 차례로 점검한다.
7. 같은 전략을 업무와 일상 두 맥락에 적용한다. 예를 들어 업무 일정표 읽기를 병원 예약표·교통표로 변형한다.
8. 주간 사용일지와 동형 수행과제를 함께 보며 사용기회가 늘었는지, 정확도·독립성·전이가 실제로 변했는지 확인한다.

## 예시·과제·관찰 지표

- 문해 읽기: 작업설명서에서 순서·경고를 찾고, 이메일에서 요청·기한을 추출하며, 금융명세와 지도 정보를 결합한다.
- 문해 쓰기: 긴 공지를 대상별 짧은 메모로 바꾸고, 정해진 양식에 근거를 빠짐없이 적으며, 보고서 핵심을 제목·소제목으로 조직한다.
- 수리: 할인율과 최종가격을 계산하고, 월별 지출표를 그래프로 만들어 이상값을 설명하며, 계산기 결과를 대략값으로 검산한다.
- ICT: 기관 사이트에서 신뢰할 자료를 검색하고, 스프레드시트로 합계를 계산하며, 온라인 양식을 안전하게 제출하고 접수증을 보관한다.
- 빈도 척도는 전혀 하지 않음, 몇 달에 한 번, 월 1~2회, 주 몇 회, 매일의 5단계다. 교육에서는 빈도와 성공 품질을 별도 기록한다.
- 관찰 지표는 실제 사용 횟수, 장르·맥락 다양성, 혼자 완료한 비율, 오류탐지, 도구 선택 이유, 결과 설명, 새 과제로의 전이다.
- 일상 사용을 늘릴 때 단순 스크롤·복사보다 정보 비교, 의사결정, 산출물 작성처럼 목표와 피드백이 있는 활동을 우선한다.

## 흔한 오류·오개념과 교정

- **자주 하면 자동으로 역량이 오른다**: 활동의 난도·전략·피드백과 실제 수행 전후를 함께 측정한다.
- **회귀계수가 인과효과다**: 사용과 역량을 같은 시점에 측정했으므로 역인과·직업선택·미측정 교란을 명시한다.
- **일상 사용계수가 더 크니 업무사용은 중요하지 않다**: 두 지수의 분산·문항·결측과 공선성이 다르며 둘 다 최종모형에서 정적 관련이었다.
- **배경계수가 줄었으니 격차를 완화했다**: 매개분석·상호작용·종단변화 없이 계수 감소만으로 실제 집단격차 감소를 확정하지 않는다.
- **형식교육은 컴퓨터 역량에 쓸모없다**: 이 표본의 최종학력 계수가 비유의였을 뿐 특정 교육프로그램 효과를 시험하지 않았다.
- **스킬 사용량만 높이면 된다**: 좁은 반복숙련과 넓은 문제해결 전이를 구분하고 새 조건·새 도구를 추가한다.
- **계수 절댓값으로 중요한 요인을 순위화한다**: 연령범주·더미·학력·1~5 사용척도의 단위가 달라 비표준 계수는 직접 비교하지 않는다.
- **컴퓨터 평가 표본이 전체 5,298명이다**: 직접평가·ICT 사용은 기기경험과 결측 때문에 각각 N=3,675·3,033·4,133으로 작다.

## 평가와 피드백

- 문해·수리·디지털을 한 총점으로 합치지 않고 실제 생활과제별 강점·병목 프로필을 만든다.
- 사용일지에는 날짜, 맥락, 자료, 목적, 도움, 결과, 어려움, 다음 전략을 짧게 기록한다.
- 피드백은 정답뿐 아니라 “조건 한 개 누락”, “단위 불일치”, “출처 미확인”, “제출 증거 미보관”처럼 실패지점을 행동으로 제시한다.
- 같은 기능을 업무와 일상에서 번갈아 평가해 한 맥락에 묶인 숙련과 전이를 구별한다.
- 자기보고 빈도는 실제 문서·화면·산출물 표본과 삼각검증한다. 프라이버시가 필요한 자료는 비식별 모형자료로 대체한다.
- 기초수준에는 안내와 예시를 제공하고, 숙달되면 단서·템플릿·교사 도움을 단계적으로 줄여 독립 수행을 본다.
- 교육효과를 평가할 때 노출 전후 동형과제, 비교조건, 유지검사와 실제 사용 변화를 함께 기록해 단면 상관을 넘는 근거를 만든다.

## 적용 조건과 전이 한계

- PIAAC는 단면 관찰자료이므로 사용이 역량을 높였는지, 높은 역량이 사용기회를 얻었는지 시간 순서를 판별하지 못한다.
- 최근 5년 임금노동 경험자만 포함해 장기 비취업자, 무급 돌봄·자영업·은퇴자와 가장 취약한 저문해 성인의 대표성이 낮다.
- 2011년경 조사·2013년 공개 자료를 2022년에 분석했다. 현재 디지털 도구·노동환경으로 그대로 일반화하기 어렵다.
- 업무·일상 사용은 자기보고 빈도 평균이며 과제 난도, 시간, 정확도, 전략과 학습 의도를 직접 측정하지 않는다.
- 세 종속변수의 10개 plausible values를 평균내어 일반 SPSS 회귀에 사용했다. 원문에는 최종가중치·반복가중치와 PV별 결합 절차가 제시되지 않아 PIAAC 표준오차를 과소추정할 수 있다.
- 최종 모형의 분석 N을 표 6~8에 명시하지 않았고 변수별 유효 N이 크게 달라 세 역량 계수·설명량을 동일표본 비교로 볼 수 없다.
- 단계별 R² 증가는 예측정보의 추가를 뜻할 뿐 인과적 무형식학습 효과나 실제 격차 완화를 직접 증명하지 않는다.

## 상세 요약

연구는 PIAAC 한국 6,667명 중 최근 5년 임금노동 경험자 5,298명을 골라 문해력·수리력·컴퓨터 기반 문제해결력과 업무·일상의 관련 스킬 사용을 분석했다. 1단계 배경·교육, 2단계 업무 사용, 3단계 일상 사용의 위계회귀에서 최종 사용계수는 문해력 2.94/8.01, 수리력 3.79/6.31, 컴퓨터 문제해결력 4.27/5.65였다. 업무 사용은 R²를 각각 1.6%·1.5%·2.3%, 일상 사용은 추가로 1.5%·1.0%·1.1% 높였다. 저자들은 실제 수행이 학습전이를 만들고 역량을 유지·개발하는 무형식학습이라고 해석한다.

과정 설계에는 업무와 일상의 실제 사용기회를 연결하되 빈도만 채우지 않는 것이 핵심이다. 지시·기사·금융문서 읽기, 메모·양식·보고서 쓰기, 수치·표 검산, 검색·스프레드시트·온라인 거래를 목적 있는 과제로 수행하고 결과를 검증·성찰한다. 다만 단면 자기보고, 임금노동 경험자 선택, 오래된 데이터, 서로 다른 유효표본, PIAAC 가중치·PV 처리 불명확성이 있다. 따라서 본 자료는 실제 사용을 교육에 포함할 근거이지, 사용빈도를 올리면 특정 점수만큼 상승한다는 효과 추정치가 아니다.

## 교차 검증과 충돌

- 3단계 확정 주장 ID: `clm-reading-meaning-construction-006`

- `src-0077`·`src-0079`는 같은 PIAAC 한국자료의 국가·심층 맥락을 제공하며, 이 연구는 그중 최근 임금노동 경험자로 표본을 좁혔다.
- `src-0083`의 8개 문서 사용빈도와 동일한 사용-역량 문제를 확장하지만 두 연구 모두 횡단자료라 “유지·지체” 인과를 확정하지 못한다.
- `src-0082`의 실제 공공문서 이해 실패는 빈도 높은 사용이 자동으로 정확한 이해를 보장하지 않음을 보여준다.
- 논문은 계수 감소를 “배경·교육 격차 완화”라고 설명하지만 집단×사용 상호작용이나 격차의 종단감소를 분석하지 않아 통계적 주장과 해석 사이 간극이 있다.
- PIAAC의 PV·복합표본을 단순 평균·SPSS 회귀로 처리한 설명은 표준 국제분석 관행과 충돌할 수 있으므로 정확한 p값보다 방향·과제목록을 우선 활용한다.
