## 원문 확인 기록

- KCI가 제공한 PDF 33쪽, 학술지 인쇄면 179–211쪽을 직접 확인했다.
- 연구문제·이론적 분류(179–184쪽), 문헌 선별·코딩·효과크기 산출(185–187쪽), 분석 방법별 대상과 도구(188–198쪽), 평균효과·동질성·개별 연구표(198–201쪽), 통합적 논의·제언(201–205쪽)을 확인했다.
- 국내 문헌은 검색된 81편에서 양적 연구 34편을 거쳐 최종 10편으로 줄었다. 작문교사 연구자 박사 3인의 협의를 거쳤으나 검색 데이터베이스·검색식 전체, 중복 선별, 제외 사유 목록과 수치화한 코더 간 신뢰도는 보고하지 않았다.
- 표 1과 표 4의 개별 연구 표본·효과크기·종속변수를 대조했다. 포함 연구의 결과는 쓰기 점수뿐 아니라 만족도, 자기효능감, 수정 빈도와 학습자 반응까지 섞여 있다.
- 평균효과 `0.41`, 95% 신뢰구간 `[0.26, 0.57]`, `Q(9)=9.248, p=.4147`을 원문 표·본문에서 확인했다. 연구 수가 10편뿐이므로 비유의 Q를 강한 동질성 증거로 해석하지 않았다.
- 이 논문은 쓰기 ‘교수법’보다 쓰기 ‘과정 연구법’을 다룬다. 활동·루브릭으로 옮긴 내용은 저자의 방법론 제언을 학습자의 자기관찰에 전환한 설계 추론임을 구분했다.

## 가르칠 개념과 원리

- 학문적 글쓰기는 정보를 읽고 더하거나 상대적 관점에서 비판하며 새로운 지식을 만드는 과정이다. 결과물만으로는 계획, 읽기, 멈춤, 수정, 협의가 어떤 순서와 이유로 일어났는지 알 수 없다.
- 능숙한 필자의 특징으로 제시된 `회귀성`은 앞 단계로 단순히 되돌아가는 것이 아니라 쓰면서 다시 읽고, 평가하고, 계획·내용·표현을 조정하는 자기규제 순환이다.
- 텍스트 자료는 초고–중간본–최종본의 삽입·삭제·이동·재표현을 보여 주지만, 변화가 일어난 이유나 자동화된 사고를 단독으로 설명하지 못한다.
- 물리적 자료는 멈춤의 빈도·지속·위치, 막힘, 쓰기 실행 구간을 보여 준다. 멈춤은 유창성 부족만 뜻하지 않고 상위 수준의 계획·평가·수정에서 길어질 수 있다.
- 구어 자료인 사고구술과 회상 인터뷰는 선택 이유와 목표를 드러내지만, 말하기가 원래의 쓰기 과정을 바꾸거나 자동 처리 과정을 놓칠 수 있다.
- 이원·3원 분석은 키 입력·행동 기록에 사고구술, 시선 또는 다른 인지 자료를 결합해 단일 자료의 모호함을 줄인다. 더 많은 센서가 곧 더 타당한 해석을 보장하지는 않는다.
- 다차원 분석은 개인 인지뿐 아니라 동료·교사 피드백, 담화공동체 관습, 상호작용과 텍스트 변화를 함께 본다. 사회적 자료도 맥락을 기록하지 않으면 피드백 양과 학습을 혼동할 수 있다.
- 분석 자료는 통제 수단이 아니라 학습자가 자신의 과정에 관해 설명하고 다음 전략을 선택하도록 돕는 피드백 근거여야 한다.

## 수행 절차와 전략

1. 과제의 목적·독자·장르와 성공 준거를 쓰고, 예상하는 계획–자료 읽기–초고–수정 경로를 표시한다.
2. 초고부터 최종본까지 각 버전을 보존하고, 삽입·삭제·이동·재표현을 내용·조직·표현 수준으로 분류한다.
3. 짧은 대표 구간에서 작성 시간, 긴 멈춤의 위치, 다시 읽기, 검색, 실행 구간을 기록한다. 멈춤을 즉시 실패로 판정하지 않는다.
4. 기록 직후 핵심 사건을 골라 `무엇을 하려 했는가`, `무엇을 보고 바꿨는가`, `왜 멈췄는가`를 짧게 회상한다.
5. 텍스트 변화와 행동·회상 자료를 시간축에 맞춘다. 자료가 일치하는 사건과 서로 다른 해석을 허용하는 사건을 구분한다.
6. 동료·교사·도구 피드백의 발신자, 초점, 채택·기각, 실제 수정 결과를 연결한다.
7. 반복되는 병목을 어휘·문장 생성, 내용 지식, 자료 선택, 조직, 독자 고려, 평가·수정으로 분류한다.
8. 다음 글에서 시험할 전략 하나와 관찰 지표를 정한다. 예를 들어 문단 전환에서만 멈춤이 길다면 개요 보완 후 실행 구간이 늘어나는지 확인한다.
9. 교사는 과정 자료 전체를 상시 수집하기보다 진단 목적의 짧은 구간과 주요 버전만 사용하고, 사생활·감시 부담을 명시적으로 제한한다.

## 평가와 피드백

- 원연구의 10개 효과크기는 `d=0.017–0.881`이었다. 전체 평균 `0.41`, 95% CI `[0.26, 0.57]`은 서로 다른 산출물을 섞은 수치이므로 단일 쓰기 능력 효과로 읽지 않는다.
- Type 1은 6편이고 만족도·자기효능감·수정 빈도·점수가 혼재했다. Type 2와 Type 4는 포함 연구가 없고, Type 3은 1편, Type 5는 3편뿐이었다. 방법 간 우열 검정에 충분한 구조가 아니다.
- 과정 평가는 `산출물 품질`, `전략 선택 이유`, `과정 조정`, `피드백 판단`, `새 과제 전이`를 분리해야 한다. 작성 속도나 멈춤 수만으로 종합 점수를 만들지 않는다.
- 버전 루브릭은 수정의 수보다 기능을 본다. `문제 해결에 기여`, `주장–근거 관계 개선`, `독자 안내 개선`, `표면 정확성 개선`, `새 오류 발생`을 기록한다.
- 과정 피드백은 관찰과 해석을 분리한다. 예: `근거 문단 앞 32초 멈춘 뒤 출처로 돌아갔다`는 관찰이고, `근거가 부족해 계획했다`는 확인이 필요한 해석이다.
- 학습자에게는 한 번에 하나의 병목과 다음 실험을 돌려준다. `수정이 부족하다`보다 `초고 이후 주장 수준 변경이 0건이므로 다음에는 반대 근거를 읽고 핵심 주장 한 문장을 다시 쓰라`가 실행 가능하다.
- 동료 피드백은 익명 점수 합산보다 준거 보정 사례, 논평 근거, 작성자의 채택 판단을 포함해야 한다. 교사는 잘못된 합의를 교정하고 고위험 사실·출처 판단을 검증한다.

## 적용 조건과 전이 한계

- 원문이 종합한 국내 연구는 주로 대학 교양·학문적 글쓰기 상황이다. 직장인·고령 학습자·기초 문해 성인의 작업기억, 디지털 접근, 과제 목적에는 그대로 일반화할 수 없다.
- 국내 메타분석은 데이터베이스·검색식·선별 흐름·출판편향·연구 질 평가·종속 효과 처리·민감도 분석을 충분히 보고하지 않았다.
- 만족도, 자기효능감, 수정 빈도, 텍스트 점수를 한 평균으로 결합했기 때문에 평균 `0.41`의 교육적 의미가 불명확하다.
- 분석 방법 유형이 실제 수업 처치와 결합돼 있다. 관찰 도구가 효과를 만든 것인지, 동료 피드백·첨삭·모바일 협업이 만든 것인지 분리할 수 없다.
- Type 5 세 효과는 `0.601`, `0.880`, `0.017`로 서로 크게 다르다. ‘가장 효과적’이라는 서술은 소수·이질 자료에 비해 강하다.
- 사고구술·키 입력·시선 기록은 학습자의 자연스러운 수행을 바꾸고 개인정보를 노출할 수 있다. 동의, 목적 제한, 최소 수집, 삭제 시점과 비평가적 사용을 보장해야 한다.
- 손글씨·모바일 음성입력·보조기술 사용자는 같은 멈춤·키 입력 기준이 맞지 않는다. 매체별 행동 신호를 동등한 능력 척도로 취급하지 않는다.
- 과정 기록에서 발견한 전략이 새 장르·독자·시간 제약에서도 작동하는지 지연·전이 과제로 확인해야 한다.

## 상세 요약

이 논문은 학문적 글쓰기 과정을 연구하는 자료가 결과 텍스트에서 물리적 행동, 구어, 인지 신호, 사회적 상호작용으로 확장돼 왔다고 정리한다. 텍스트 분석은 버전 사이 변화를, 물리적 분석은 멈춤·막힘·실행을, 구어 분석은 사고구술을 다룬다. 이원·3원 분석은 이를 시선·뇌 영상 등과 결합하고, 다차원 분석은 동료·교사·담화공동체와의 상호작용 및 메타담화까지 포함한다.

학습 설계에서 중요한 원리는 자료의 양이 아니라 해석 가능성이다. 멈춤은 부족함과 계획을 모두 뜻할 수 있고, 초고–최종본의 차이는 변경 이유를 말해 주지 않으며, 사고구술은 자동 처리와 반응성에 취약하다. 따라서 대표 구간의 행동 기록, 버전, 짧은 회상, 피드백 반응을 연결하고 관찰과 추론을 구분해야 한다. 이러한 과정 증거는 점수화보다 학습자가 다음 전략을 고르는 형성 피드백에 더 적합하다.

저자는 81편을 찾아 양적 연구 34편을 거쳐 10편을 메타분석했다. 전체 평균효과는 `0.41 [0.26, 0.57]`, `Q(9)=9.248, p=.4147`이었다. 그러나 종속변수는 만족도·자기효능감·수정 빈도·점수 등으로 다르고, 방법 유형과 수업 처치가 얽혀 있다. Type 2·4 연구는 없고 Type 3은 한 편, Type 5는 세 편이다. 그러므로 이 수치는 글쓰기 과정 관찰법의 교육 효과를 확정하지 않으며, 다차원 분석의 우월성도 가설 수준이다.

채택할 수 있는 핵심은 결과물 중심 평가를 넘어서 쓰기 중의 읽기·계획·재독·수정·협력 경로를 보라는 방법론적 경고다. 성인 한국어 과정에서는 개인정보를 최소화하고, 학습자에게 짧고 이해 가능한 과정 기록을 돌려주며, 텍스트 품질과 자기조절·피드백 판단을 분리해 평가해야 한다.

## 교차 검증과 충돌

- 3단계 확정 주장 ID: `clm-writing-process-self-regulation-001`, `clm-writing-process-self-regulation-006`
- `src-0018`과의 관계: 분석·평가·자기조절을 산출물뿐 아니라 수행 과정에서 관찰해야 한다는 방향을 보완한다.
- `src-0120`, `src-0121`, `src-0127`, `src-0136`, `src-0137`, `src-0139`, `src-0140`과의 관계: 피드백의 존재보다 발신자·내용·수용 판단·수정 결과를 연결해야 한다는 후속 근거로 교차 확인한다.
- `src-0128`, `src-0129`, `src-0132`, `src-0141`과의 관계: 자동·생성형 AI 피드백도 텍스트 변화만으로 효과를 판단하지 말고 이용 과정, 과신·거부, 교사·동료의 조정 역할을 추적해야 한다.
- 내부 충돌: 포함 기준은 쓰기 질·능력 향상을 종속변수로 명시하지만 실제 표에는 만족도·자기효능감·수정 빈도·학습자 반응이 포함된다.
- 내부 충돌: 저자는 비유의 Q를 동질 모집단의 근거로 보고 다차원 분석이 가장 효과적이라고 결론 내리지만, 유형별 연구 수가 불균형하고 Type 5 효과는 `0.017–0.880`으로 넓다.
- 저자 주장과 이 노트의 판단: 다자료·사회인지 관찰의 필요성은 유용한 방법론 제언으로 채택한다. 분석 방법이 쓰기 학습을 직접 향상시킨다는 인과 주장은 근거 부족으로 제외한다.
