## 상세 내용 지도

원문의 장·절별 논지와 서로의 관계를 적는다. 단순 목차 복사가 아니라 각 부분이 어떤 질문에 답하고 무엇을 근거로 삼는지 설명한다.

## 가르칠 개념과 원리

학습자가 알아야 할 정의, 구분, 인과 관계, 판단 원리와 조건을 빠짐없이 재서술한다. 서로 혼동하기 쉬운 개념은 비교한다.

## 수행 절차와 전략

학습자가 실제 읽기·사고·쓰기 과제에서 따를 수 있는 단계, 단계별 판단 질문, 필요한 선행 지식과 멈춤 조건을 정리한다.

## 예시·과제·관찰 지표

원문에 포함된 사례, 자극, 과제, 루브릭과 관찰 결과를 저작권을 침해하지 않는 범위에서 재서술한다. 그대로 사용할 수 있는 원문 자료와 새로 집필해야 할 학습용 예시를 구분한다.

## 흔한 오류·오개념과 교정

자료가 직접 보고하거나 논지상 경계하는 실패 유형을 적고, 오류를 진단할 단서와 교정 방법을 연결한다.

## 평가와 피드백

관찰 가능한 수행, 평가 질문, 성공 기준, 피드백 초점과 한 번의 과제로 판정하기 어려운 요소를 적는다.

## 적용 조건과 전이 한계

연구 대상, 언어, 학교급·연령, 과제와 매체, 연구 설계, 효과의 범위와 한국어 모어 일반 성인에게 전이할 때의 불확실성을 적는다.

## 역량별 학습 설계 시사점

관련 역량마다 가르칠 내용, 권장 활동, 평가 가능한 결과와 다른 역량과의 경계를 구체적으로 적는다.

## 상세 요약

원문을 다시 열지 않아도 분석 범위, 논증 구조와 학습 설계에 사용할 내용을 이해할 수 있게 작성한다. 직접 확인한 내용, 저자의 해석과 이 노트 작성자의 적용 추론을 구분한다.
