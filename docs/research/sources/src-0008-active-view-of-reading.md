## 가르칠 개념과 원리

- **단순 읽기 모형의 역할과 경계**: `낱말 인식 × 언어 이해 = 읽기 이해`는 두 토대가 모두 필요함을 간명하게 보여 주지만, 가능한 어려움의 원인을 두 범주로 제한하거나 두 과정이 완전히 독립·순차적이라고 가르치는 근거는 아니다(S25~S28).
- **구성요소와 독자 프로필**: 같은 낮은 읽기 결과라도 음운 인식, 철자 원리, 해독, 문화·내용 지식, 언어 구조, 추론, 실행 기능 등 병목이 다를 수 있다. 범주 이름은 진단의 종점이 아니라 더 세분할 출발점이다(S27~S28, S35~S36).
- **연결 과정**: 어휘, 유창성, 형태 인식, 인쇄물 개념과 철자-소리-의미 인지 유연성은 낱말 인식 또는 언어 이해 중 한쪽에만 속하지 않는다. 두 영역을 실제 읽기에서 조정하는 과정으로 본다(S28~S31).
- **어휘와 지식의 구분**: 어휘는 단어·구의 외연적·함축적 의미 지식이며, 문화·내용 지식은 경험을 통해 조직된 개념·사건 지식이다. 어휘가 지식의 개념에 이름을 붙이지만 두 변인을 같은 것으로 취급하지 않는다(S27~S29, S35~S36).
- **유창성과 속도의 구분**: 유창성은 정확성, 자동성, 운율을 함께 포함한다. 빠르기만 측정하면 구문·의미와 문장부호를 반영하는 표현적 읽기를 놓친다(S29~S30, S35).
- **일반 실행 기능과 읽기 특화 실행 기능**: 주의, 작업기억, 억제, 전환, 계획은 목표 지향 읽기를 지원한다. 읽기 특화 인지 유연성은 인쇄 단어의 철자-소리와 의미 특징을 동시에 고려하고 전환하는 능력이다(S30~S31).
- **전략과 기능의 구분**: 전략은 목표를 위해 읽기 노력을 의도적으로 통제·수정하는 시도다. 이미 자동화된 기능이나 활동 이름을 전략이라고 부르지 않고, 선택 이유와 결과 점검을 포함한다(S32).
- **마음 이론과 일반 추론의 구분**: 마음 이론은 인물의 생각·감정·믿음·의도를 고려하는 사회적 추론이다. 모든 추론을 마음 이론으로 묶지 않는다(S34~S36).
- **구성요소별 교수 근거와 전체 모형 효과의 구분**: 표 2는 각 요소를 가르친 연구 예를 제시하지만, 능동적 읽기 모형 전체를 한 묶음으로 적용한 효과를 입증하지는 않는다(S34~S39).

## 수행 절차와 전략

아래 절차는 원문의 모형과 비교 논증을 성인 학습 진단·수업 설계에 옮긴 것이다. 논문이 하나의 표준 진단 순서나 수업안을 검증한 것으로 해석하지 않는다.

1. **읽기 결과와 조건을 특정한다.** 어떤 텍스트를 어떤 목적·시간·매체에서 읽었는지, 이해가 막힌 위치와 요구된 산출물을 기록한다. 모형 밖의 텍스트·과제·사회문화 조건을 먼저 고정한다.
2. **두 토대를 확인하되 여기서 멈추지 않는다.** 낱말을 정확하고 자동적으로 알아보는지, 문장과 담화를 언어적으로 이해하는지 각각 관찰한다.
3. **큰 범주 안을 세분한다.** 낱말 인식에서는 음운 인식·철자 원리·해독·낱말 자동 인식을, 언어 이해에서는 문화·내용 지식·읽기 관습 지식·언어 구조·언어적 추론·마음 이론을 구분한다.
4. **연결 과정을 점검한다.** 어휘의 문맥 적합성, 정확성·자동성·운율을 갖춘 유창성, 형태소 단서, 철자-소리-의미 전환이 실제 이해를 잇는지 확인한다.
5. **능동적 자기조절을 점검한다.** 목표 유지, 주의 전환, 방해 정보 억제, 작업기억 부담, 참여 지속, 이해 실패 감지와 전략 변경을 관찰한다.
6. **가장 좁고 영향력 있는 병목을 선택한다.** 모든 구성요소를 동일하게 훈련하지 않고 관찰 증거가 있는 한두 목표와 그 근거에 맞는 연습을 선택한다.
7. **같은 요소를 다른 조건에서 재확인한다.** 난도나 배경지식 요구가 다른 글에서 결과를 비교하고, 향상이 없으면 최초 프로필이나 텍스트·과제 조건을 다시 검토한다.

학습자가 사용할 수 있는 자기조절 순환은 `목표 확인 → 제목·도식과 기존 지식 활성화 → 읽으며 의미 연결 → 막힘의 원인 명명 → 재읽기·질문·형태 분석·속도 조절 중 전략 선택 → 목표에 맞게 이해가 회복됐는지 확인`으로 재구성할 수 있다. 막힘의 원인을 말할 증거가 없거나 선택한 전략이 의미 회복과 연결되지 않으면 반복 수행을 멈추고 교사와 함께 진단 단계를 되돌아간다.

## 적용 조건과 전이 한계

- 논문은 미국 읽기 교육 실천가에게 전달할 모형을 목적으로 하며, 종합한 연구의 다수가 영어권 아동·청소년 대상이다. 일부 성인 예측 연구가 포함되지만 일반 한국어 성인의 교수 효과를 직접 검증하지 않았다.
- 알파벳 원리, 파닉스, 영어의 철자-소리 불규칙, `magic`–`magician`과 같은 형태 사례는 한국어 조사·어미·음운 변동·띄어쓰기 체계와 같지 않다. 구성요소의 관계만 가설로 옮기고 구체 교수법은 국내 근거로 다시 설계한다.
- 낱말 인식과 언어 이해의 공유 분산은 표본 수준의 통계 관계다. 한 개인의 실패 원인을 곧바로 특정하는 진단 결과로 사용하지 않는다.
- 표 2는 구성요소마다 읽기 이해를 개선한 연구 예를 제시하지만 연구 대상, 비교 조건, 측정과 효과 크기가 동일하지 않다. 요소별 근거를 단순 합산하지 않는다.
- 능동적 읽기 모형 전체는 통합 검증되지 않았고, 요소 간 화살표와 중첩을 포함한 하나의 교수 프로그램 효과도 검증되지 않았다.
- 모형은 텍스트, 과제, 사회문화 맥락을 직접 표현하지 않으며 시간에 따른 발달 변화도 보여 주지 않는다. 성인 교육에서는 직무·생활 문서의 목적, 디지털 매체, 기존 문해 경험과 문화적 지식을 별도 층위로 기록한다.
- 저자들은 새 연구에 따라 모형이 갱신되거나 대체되어야 한다고 명시한다. 이 노트를 고정된 최종 읽기 이론으로 사용하지 않는다.

## 상세 요약

논문은 단순 읽기 모형을 폐기하기보다 그 교육적 유용성을 인정한 채 세 가지 연구 진전을 반영해 확장한다. 첫째, 읽기 곤란은 낱말 인식과 언어 이해의 낮음만으로 모두 설명되지 않으며 두 큰 범주 안에도 다양한 프로필이 있다. 둘째, 낱말 인식과 언어 이해는 완전히 독립적이지 않고 상당한 공유 분산을 가지며 어휘, 유창성, 형태 인식, 인쇄물 개념과 철자-소리-의미 인지 유연성이 둘을 잇는다. 셋째, 실행 기능, 동기·참여와 전략 사용 같은 능동적 자기조절이 읽기 과정 전반에 영향을 준다.

그림 2의 능동적 읽기 모형은 낱말 인식, 연결 과정, 언어 이해와 능동적 자기조절을 하나의 지도에 놓는다. 낱말 인식에는 음운 인식, 알파벳 원리, 파닉스, 해독과 낱말 자동 인식이 포함된다. 언어 이해에는 문화·내용 지식, 읽기 특화 배경지식, 언어적 추론, 언어 구조와 마음 이론이 포함된다. 자기조절은 다른 세 영역에 영향을 주며, 표 2는 각 요소의 정의와 교수로 읽기 이해가 향상된 연구 예를 연결한다.

이 모형의 실천적 가치는 `해독인가 이해인가`라는 이분법에서 멈추지 않고 관찰 가능한 병목과 교수 대상을 더 세밀하게 찾도록 돕는 데 있다. 그러나 전체 모형은 통합 검증되지 않았고 텍스트·과제·사회문화 맥락과 발달 변화를 직접 표현하지 않는다. 따라서 한국어 성인 수업에서는 모형을 고정 진단표로 사용하지 않고, 언어·연령·목적·매체 조건을 별도로 기록하면서 최소한의 교수 가설을 세우고 다시 확인하는 도구로 사용해야 한다.

## 교차 검증과 충돌

- 연결된 주장 ID: 3단계 분석 전이므로 아직 없음
- `src-0006`은 읽기 평가를 텍스트, 인지 과정과 사회적 맥락의 결합으로 다뤄 이 논문이 모형 밖 한계로 둔 조건을 보완한다.
- `src-0007`은 독자·텍스트·활동과 더 넓은 사회문화 맥락의 상호작용을 전면에 두므로 독자 요인을 상세히 나눈 능동적 읽기 모형과 초점이 다르다. 두 자료는 대체 관계보다 상호 보완 관계로 사용한다.
- `src-0009`의 어휘 질 가설은 단어 형태·음운·의미 표상의 질과 연결을 강조해 어휘를 연결 과정으로 둔 설명을 세부화한다.
- `src-0010`은 배경지식이 충분해도 연결 추론을 자동으로 생성하지 못할 수 있음을 보여 주어 지식과 전략·실행 과정의 구분을 지지한다.
- 단순 읽기 모형과의 쟁점은 두 토대의 필요성을 부정하는 것이 아니라 `독립된 두 요인만으로 충분하다`는 실천적 해석을 확장하는 데 있다.
- 남은 공백은 구성요소별 한국어 성인 진단 기준, 요소 간 교수 우선순위, 능동적 읽기 모형 전체를 사용한 통합 개입 효과다.
