## 원문 확인 기록

- PDF 363쪽 전체의 이론·구인, 영역별 명세, 가교문항, 행렬표집, 두 예비조사, 문항분석, 최종 문항카드를 확인했다.
- 1차는 2017년 8~9월 16~65세 948명, 2차는 11~12월 760명이다. 서울·인천·경기 동·읍면 네 층에서 집락 뒤 개인을 할당 추출했다.
- 문항 풀은 2018년 본조사 목표의 2배수→1차 뒤 1.6배수→2차 뒤 1.2배수로 축소했다.
- 1차 영역별 표본은 말하기·쓰기 200, 읽기 500, 문법·듣기 240명이다. 2차는 각각 200, 400, 160명이다.
- Android Nfield CAPI를 사용했고 쓰기는 컴퓨터 입력을 원칙으로 하되 손글씨를 선택하게 했다. BIB 행렬표집과 공통구획으로 읽기 문항 수와 피로를 절충했다.
- 최종 선정은 듣기 13, 말하기 5, 읽기 25, 쓰기 4, 문법 12문항이다.

## 상세 내용 지도

1. **이론과 국외 사례(1~52쪽)**: 국어능력과 다섯 영역의 구인, 국내외 자국어 평가를 검토한다.
2. **문항 명세(53~91쪽)**: 영역별 평가요소, 2013년 가교, 형식, 실제 텍스트·디지털 입력을 설계한다.
3. **1차 예비조사(92~145쪽)**: 2배수 문항, CAPI 시행 문제, 채점자 효과, IRT·배경변인 분석으로 1.6배수를 선별한다.
4. **2차 예비조사(146쪽 이후)**: 수정 도구를 독립 표본에 다시 투입해 1.2배수를 정한다.
5. **최종안과 문항카드**: 문항 출처·구인·정답·척도·통계를 공개하고 본조사 시행·채점·환류 조건을 제안한다.

## 가르칠 개념과 원리

- 변화하는 실제 문식성과 시점 간 비교 가능성은 새 문항과 가교문항을 함께 두어 균형을 맞춘다.
- 행렬표집은 개인에게 전체 문항을 풀게 하지 않고 공통구획으로 집단 수준 능력을 추정해 피로를 줄인다.
- 읽기는 실용 텍스트와 다양한 독서 환경, 쓰기는 빈도 높은 생활 상황과 키보드·손글씨 접근성, 문법은 다른 영역과 연결된 언어운용으로 설계한다.
- 문항 통계만으로 선별하지 않고 구인 대표성, 실제성, 전문가 판단, 조사방식 문제를 함께 본다.
- 수행형의 내용·조직·표현 하위척도는 서로 다른 병목을 드러내며 채점자 엄격도도 측정오차의 일부다.

## 수행 절차와 전략

1. 역량별 개념과 하위요소를 정의하고 이전 판본의 가교문항을 검토한다.
2. 실제 성인 담화와 매체에서 목표의 2배수 문항을 만든다.
3. 공통구획이 겹치는 여러 검사형에 배치하고 장치·시간·이동을 파일럿한다.
4. 1차 자료에서 IRT 난이도·변별도, 정답·오답 분포, 채점자 효과와 표본별 편향을 본다.
5. 1.6배수로 수정하고 새 표본에 2차 검사한다.
6. 수치와 전문가 내용 검토를 합쳐 1.2배수와 예비문항을 확정한다.
7. 본조사 뒤 효과가 아니라 도구 성능과 집단분포를 보고하고 후속 중재를 별도 검증한다.

## 예시·과제·관찰 지표

- 읽기 1차는 5개 검사형에 18~19문항씩 배치해 500명에게 실시했다. 관찰 지표는 공통구획 연결, 문항정보, 피로와 탐색 문제다.
- 쓰기는 실제 생활에서 자주 마주치는 상황을 컴퓨터로 작성하되 기기 숙련도가 산출을 가리지 않도록 손글씨 선택권을 둔다.
- 1차에서 듣기 3문항과 문법 3문항의 변별도가 매우 낮았고, 쓰기 1문항은 조직·표현 변별도가 낮아 수정·삭제 후보가 됐다.
- 2차 읽기 약 4문항은 변별도 약 .3이면서 유용한 능력범위를 벗어난 난이도를 보여 제외 검토됐다.
- 관찰 지표는 원점수 분포뿐 아니라 IRT 정보, 하위척도, 채점자 일치, 무응답·장치 사건, 특정 집단 유불리다.

## 흔한 오류·오개념과 교정

- **문항 수가 많을수록 개인 진단이 정확하다**: 집단 실태조사와 개인 진단 목적을 구분하고 피로를 통제한다.
- **통계 기준 하나로 자동 삭제한다**: 내용 대표성과 가교 가치, 공정성을 전문가가 함께 검토한다.
- **키보드 검사가 현대적이므로 모두에게 공정하다**: 손글씨 대안을 주고 방식 간 차이를 분석한다.
- **한 번의 파일럿이면 충분하다**: 수정 뒤 독립 표본에서 재검증한다.
- **배경집단 평균차가 문항 편향이다**: 능력차와 DIF를 구분하고 문항 내용·반응모형을 추가 분석한다.

## 평가와 피드백

- 총점보다 하위요소와 문항정보곡선으로 현재 검사가 어느 수준을 잘 측정하는지 확인한다.
- 수행형 채점은 훈련·공통척도·복수채점과 채점자 효과 분석을 사용한다.
- 문항 피드백은 “틀림” 외에 오답 매력도, 자료 오독, 과제조건 누락, 조직·표현 중 병목을 표시한다.
- 장치 접근성, 글자크기, 문항 이동, 시간 배분을 평가 타당도의 일부로 기록한다.
- 최종 문항만 남기지 말고 삭제·수정 이유와 예비문항을 보존해 다음 주기 복구와 교체가 가능하게 한다.

## 적용 조건과 전이 한계

- 예비표본은 수도권 16~65세라 2018년 전국 20~69세 모집단을 직접 추정하지 않는다.
- 행렬표집은 집단 수준 추정에 효율적이나 개인에게 모든 역량의 세밀한 피드백을 주기 어렵다.
- CAPI와 2017년 디지털 환경은 현재 모바일·생성형 AI 쓰기 환경과 다르다.
- 읽기·쓰기 실제성을 높였지만 평가 상황에서 만든 짧은 산출이며 장기 프로젝트·협업·독자 반응은 포함하지 않는다.
- 손글씨·키보드 선택이 접근성을 높여도 두 방식이 완전히 동등하다는 증거는 별도 필요하다.

## 상세 요약

이 연구의 고유 자료는 2018년 결과가 아니라 도구가 실패하고 수정된 과정이다. 두 예비표본에 2배수와 1.6배수 문항을 차례로 투입하고 IRT, 오답분포, 채점자 효과, 실제성·공정성 검토로 최종 1.2배수를 만들었다. 읽기에는 BIB 행렬표집, 쓰기에는 키보드와 손글씨 선택, 전 영역에는 2013년 가교문항을 사용했다.

과정 설계에서는 동일한 원리로 많은 초안을 만든 뒤 작은 실제 학습자 표본에서 난이도·오개념·사용성·채점 일치를 보고 수정본을 다시 시험해야 한다. 다만 예비조사의 집단 평균은 학습효과가 아니며, 행렬표집은 국가 실태에는 적합해도 개인별 완전한 진단에는 별도 문항이 필요하다.

## 교차 검증과 충돌

- 3단계 확정 주장 ID: `clm-reading-meaning-construction-005`

- `src-0069`는 이 도구의 2018년 전국 본조사 결과다. 예비 성능과 본조사 성능을 구분한다.
- `src-0071`의 2013년 문항이 가교 역할을 하며 `src-0068`은 같은 2단계 개발 절차를 제3차 듣기·말하기에 확장했다.
- 행렬표집의 효율성은 `src-0068`이 지적한 긴 통합검사 피로와 일치하지만 개인별 전체 프로파일 요구와 충돌한다.
- 손글씨와 키보드의 동등성은 의도했지만 본 연구만으로 완전한 측정동일성이 확정되지는 않는다.
