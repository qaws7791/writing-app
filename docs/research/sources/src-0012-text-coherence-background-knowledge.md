## 가르칠 개념과 원리

1. **텍스트 기반**: 글에 직접 표현된 명제와 그 국소·전역 관계를 조직한 표상이다. 진술 확인, 글 기반 질문, 회상과 요약에 주로 필요하다.
2. **상황 모형**: 글의 정보를 기존 지식과 통합하고 주제 영역의 관계로 재조직한 표상이다. 새로운 상황에 적용하는 문제해결, 연결·정교화 추론과 개념 분류에 더 크게 필요하다.
3. **수준의 구분이지 완전한 분리 아님**: 두 표상은 서로 관련되며 한 과제가 한 수준만 순수하게 측정하지 않는다. 원문도 측정 차이는 절대적 구분이 아니라 정도의 차이라고 명시한다.
4. **국소 응집성**: 인접하거나 가까운 문장의 지시 대상과 논항, 인과·대조 관계를 연결할 수 있는 정도다. 명확한 명사구, 접속어, 논항 반복과 친숙한 설명으로 높일 수 있다.
5. **전역 응집성**: 각 문단이 글 전체 목적과 거시구조에 연결되는 정도다. 제목, 거시 명제와 문단의 역할을 드러내는 문장으로 높일 수 있다.
6. **명시성과 능동적 구성의 교환관계**: 관계를 명시하면 저지식 독자의 연결 실패를 줄이지만, 이미 관련 지식이 충분한 독자에게는 스스로 관계를 생성할 기회를 줄일 수 있다.
7. **보상적 처리**: 공백을 감지한 독자가 배경지식을 회수해 누락된 관계를 구성하는 처리다. 글이 어렵다는 사실만으로 일어나는 것이 아니라 필요한 지식, 감지와 추론 성공이 모두 요구된다.
8. **이해 수준과 평가의 정렬**: 자유 회상이나 글 기반 질문 점수가 높아도 관계를 활용하는 상황 모형이 충분하다고 단정할 수 없다. 목표가 전이라면 추론·문제해결·재분류를 함께 보아야 한다.
9. **적응적 난도**: 최적 응집성은 하나의 고정값이 아니다. 독자가 관계를 성공적으로 추론할 만큼 쉽고, 이미 자동 처리할 만큼 쉽지는 않은 범위가 필요하다는 것이 저자들의 결론이다.

## 수행 절차와 전략

원문의 실험 절차는 다음과 같다.

1. 실험 1은 36명의 참여자를 원문 590단어, 전역 구조를 수정한 821단어, 설명을 확장한 1,167단어 글에 12명씩 배정했다.
2. 글을 읽기 전에 포유류 특성과 비포유류 특성이 섞인 16개 카드 분류와 32개 질문 중 한 세트를 실시했다.
3. 글을 두 번 읽힌 뒤 구두 자유 회상, 두 번째 카드 분류와 나머지 질문 세트를 실시했다. 사전·사후 질문 세트는 역균형화했다.
4. 실험 2는 56명을 국소·전역 응집성이 모두 높은 `CM`, 국소만 높은 `Cm`, 전역만 높은 `cM`, 둘 다 낮은 `cm`에 14명씩 배정했다.
5. 사전 카드 분류와 세 부분의 배경지식 검사를 시행하고, 지식 점수 중앙값으로 고·저지식 집단을 구분했다.
6. 첫 읽기 뒤 자유 회상과 첫 질문 세트, 두 번째 읽기 뒤 자유 회상과 두 번째 질문 세트, 마지막 카드 분류를 실시했다.
7. 질문은 한 문장의 직접 정보를 묻는 글 기반 9문항, 둘 이상의 글 문장을 연결하는 연결 추론 9문항, 글과 외부 지식을 결합하는 정교화 추론 13문항, 여러 정보와 새 상황을 통합하는 문제해결 10문항으로 구성했다.
8. 회상은 거시·미시 명제로, 분류는 포유류나 심장 질환에 관한 의미 있는 범주 변화로 분석해 표상 수준별 결과를 비교했다.

이를 학습 활동으로 옮길 때의 권고 흐름은 `목표 수행 결정 → 관련 배경지식 진단 → 텍스트의 국소·전역 공백 표시 → 지식에 맞춘 명시성 제공 → 추론 근거 외현화 → 텍스트 기반·상황 모형 과제를 함께 평가 → 지원 수준 갱신`이다. 이는 원문의 상호작용을 보존한 설계 해석이며, 검증된 고정 수업 순서가 아니다.

## 평가와 피드백

- **텍스트 기반 지표**: 자유 회상은 거시·미시 명제 비율로, 글 기반 질문은 직접 표현된 사실의 정확도로 본다. 실험 1에서 전역 수정 글의 전체 회상 평균은 .53으로 원문 .38, 설명 확장 .43보다 높았고, 차이는 주로 거시 명제에서 나타났다.
- **상황 모형 지표**: 연결 추론, 정교화 추론, 새로운 문제해결과 카드 재분류를 사용한다. 실험 2의 고지식 독자는 `cm`에서 연결 추론 .68, 문제해결 .61이었고 `CM`에서는 각각 .48, .46이었다. 저지식 독자는 같은 비교에서 `cm` .31·.17, `CM` .40·.30이었다.
- **점수의 용도 제한**: 위 평균은 작은 영어권 아동 표본의 특정 심장 질환 문항 결과이며 코스의 합격선이나 기대 효과 크기로 사용하지 않는다.
- **배경지식 진단**: 원문은 심장 부위·기능 자유 기술, 실제 부위 8개와 방해 항목 2개의 그림 표지, 빈칸 6개와 단답 6개를 사용했다. 수업에서는 목표 글에 실제로 필요한 관계 지식을 별도로 확인한다.
- **과정 피드백**: `어느 두 문장을 연결했는가`, `글 밖의 어떤 지식을 사용했는가`, `관계가 직접 쓰였는가 추론했는가`, `이 관계를 새 사례에 어떻게 적용했는가`를 묻는다.
- **도움 수준 기록**: 무지원 추론, 관계 표시 뒤 추론, 접속어·거시 명제 제공 뒤 이해를 구분한다. 지원 뒤 정답을 최초 독립 수행과 합치지 않는다.
- **분류 해석의 주의**: 카드 분류는 지식 조직 변화를 포착할 수 있지만, 실험 1에서는 항목 단위 분석과 참여자 단위 분석이 일치하지 않았다. 완전하거나 직접적인 상황 모형 측정으로 간주하지 않는다.
- **평가 도구의 취약성**: 실험 1의 추론 문항은 세트당 4~5개에 불과해 저자들도 기대한 차이를 찾기에 부적절했을 수 있다고 논의했다. 문항 수와 표집 범위를 충분히 확보해야 한다.

## 적용 조건과 전이 한계

- 실험 1은 11~15세 36명, 실험 2는 10~15세 56명으로 조건별 12명 또는 14명이다. 표본이 작고 영어권 중학생 중심이므로 성인·한국어 독해에 효과 크기를 직접 적용할 수 없다.
- 포유류 특성과 심장 질환이라는 두 과학 설명문만 사용했다. 서사, 논증, 문학, 복수 문서와 실제 업무 글로 장르 전이가 검증되지 않았다.
- 각 참여자는 특정 글 판본 하나만 읽었다. 사람별 차이를 완전히 제거한 반복 측정 설계가 아니며, 실험 2의 배경지식 집단은 사전 지정이 아니라 중앙값 분할이다.
- 실험 2의 고지식 집단은 저지식 집단보다 평균 나이가 약 0.9세 높았다. 학년 차이는 유의하지 않았지만 지식 효과에 발달 차이가 전혀 섞이지 않았다고 단정하지 않는다.
- 글 판본은 단어 수가 달랐다. 특히 실험 1의 설명 확장 판본은 원문보다 거의 두 배 길고 정보를 추가·삭제했으므로 응집성만의 순수 효과로 보기 어렵다.
- 참여자는 같은 글을 두 번 읽고 즉시 회상·질문·분류를 수행했다. 장기 유지, 지연 전이와 자연스러운 한 번 읽기 상황은 검증하지 않았다.
- 낮은 응집성의 이점은 충분한 관련 지식이 있고 공백을 성공적으로 메울 수 있으며 과제가 관계 기반 이해를 요구할 때 관찰되었다. 저자들은 너무 어렵거나 너무 쉬운 자료에서는 이점이 사라질 수 있다고 명시한다.
- 글이 익숙해 공백 메우기가 자동화되면 낮은 응집성 판본도 독자에게는 사실상 높은 응집성처럼 처리될 수 있다.
- 저자들의 맞춤형 하이퍼텍스트 제안은 실험 결과에서 도출한 교육적 전망이다. 실시간 진단·자동 조절 시스템 자체의 효과, 안전한 난도 조절 규칙과 운영 비용은 이 논문에서 검증하지 않았다.
- 실험은 의도적으로 글을 덜 응집되게 만드는 장기 교수 중재가 아니다. 낮은 응집성 글을 일반 자료 제작 규칙이나 학습자 선별 근거로 사용하지 않는다.

## 상세 요약

이 논문은 이해를 글에 직접 표현된 명제를 조직하는 텍스트 기반과, 그 정보를 배경지식에 통합해 관계 중심으로 재조직하는 상황 모형으로 구분한다. 높은 응집성은 관계를 명시해 텍스트 기반 구축을 돕지만, 지식이 충분한 독자에게는 생략된 관계를 스스로 메우는 과정이 더 깊은 상황 모형을 만들 수 있다는 가설을 두 실험으로 검토했다.

실험 1에서는 포유류 특성 글의 원문, 전역 구조 수정, 설명 확장 판본을 비교했다. 전역 수정 글은 특히 거시 명제 회상을 높였으나 질문과 카드 분류의 상황 모형 증거는 분석 단위에 따라 불안정했다. 실험 2에서는 심장 질환 글의 국소·전역 응집성을 각각 높고 낮게 조작했다. 저지식 독자는 관계가 명시된 글에서 이득을 얻었고, 고지식 독자는 두 수준의 응집성이 모두 낮은 글에서 연결 추론·문제해결·분류가 더 좋았다. 반면 글 기반 질문은 지식 수준과 무관하게 높은 응집성의 이점을 보였다.

따라서 `좋은 글은 항상 더 명시적이다`와 `어려운 글이 항상 깊은 학습을 만든다`는 두 규칙 모두 원문이 지지하지 않는다. 관계 공백은 관련 지식이 충분하고 독자가 성공적으로 메울 수 있는 난도이며 목표가 상황 모형 구축일 때만 잠재적으로 생산적이다. 실제 수업에서는 배경지식을 진단하고, 저지식 학습자에게 연결을 명시하며, 고지식 학습자에게는 통제된 공백과 근거 설명을 제공한 뒤 회상뿐 아니라 추론·문제해결로 이해를 확인해야 한다.

- 독립적으로 확인할 출처: `src-0006`, `src-0007`, `src-0010`
- `src-0010`은 필요한 지식을 보유해도 텍스트 전제 회수·통합·추론 필요성 감지에서 실패할 수 있음을 보여 준다. 이는 이 논문의 `고지식이면 낮은 응집성에서 자동으로 이득을 얻는다`는 해석을 막는 보완 근거다.
- `src-0006`의 성인 문해 틀은 정보 접근·이해·평가를 실제 과제와 문서 맥락에서 다룬다. 이 논문의 즉시 과학 글 실험보다 전이 범위가 넓지만, 응집성과 지식의 인과 상호작용을 직접 검증한 자료는 아니다.
- 실험 1의 회상 이점과 실험 2의 상황 모형 상호작용은 충돌이 아니라 목표 과제와 지식 수준이 다르면 최적 명시성이 달라진다는 원문의 핵심 구분이다.
- 낮은 응집성의 장기 유지·전이 이점은 이 실험에서 직접 측정하지 않았다. 결론에서 인용한 생성 효과와 훈련 난도 연구는 이론적 유사성이지 본 실험의 지연 전이 증거가 아니다.
- 한국어 성인 학습자, 다양한 장르, 지연 검사와 실제 적응형 텍스트 중재에서 이 상호작용이 재현되는지 추가 확인해야 한다.

## 짧은 인용

> “the same text cannot be optimal for everyone”
