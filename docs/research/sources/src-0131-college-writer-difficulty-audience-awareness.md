## 가르칠 개념과 원리

- **쓰기 어려움은 단계 이름이 아니라 조정 과제로 진단한다.** “계획이 어렵다”보다 주제 적합성·독창성·독자 흥미·과제 난도를 동시에 맞추기 어렵다고 구체화한다.
- **독자 분석과 독자 반응 예측은 다르다.** 전자는 독자의 목적·관심·배경을 파악하는 일이고, 후자는 현재 문장을 읽을 때 무엇을 이해·오해·의심할지 예상하는 일이다.
- **교수자와 실제 독자를 구별한다.** 평가자를 만족시키는 글만 쓰면 실제 정보 요구와 효용을 놓칠 수 있다. 과제마다 평가자, 실제 사용자, 제3의 공개 독자를 분리해 적는다.
- **자료 찾기와 자료 사용을 분리한다.** 검색 결과 확보, 신뢰성 판단, 주장과의 관련성, 인용·변형·통합을 각각 연습한다.
- **조직은 목차 양식 암기가 아니다.** 분류 기준, 상하 관계, 순서 원리, 중복·누락 검사와 독자의 이동 경로를 포함한다.
- **불완전한 초고를 허용한다.** 초고의 목표는 생각을 보이게 만드는 것이며, 정확성과 우아함은 뒤의 수정 패스에서 높인다.
- **수정은 진단-대안-선택-실행-검증의 과정이다.** 피드백을 그대로 적용하는 것이 아니라 어떤 문제를 어떤 목표 아래 어떻게 바꿀지 결정한다.
- **어려움 자기보고는 출발점이지 성취 판정이 아니다.** 실제 산출물, 과정 로그, 독자 반응과 삼각 검증한다.

## 수행 절차와 전략

다음은 원문 범주를 성인 문해 수업의 진단·비계 순서로 변환한 `과정 설계 추론`이다.

1. **다섯 단계 자가진단을 한다.**
   - 주제, 자료, 조직, 초고, 수정에서 가장 막히는 순간을 구체적 행동으로 적는다.
   - “못한다” 대신 “A와 B 중 무엇을 기준으로 골라야 할지 모르겠다”처럼 관찰 가능한 문장으로 바꾼다.
2. **독자 카드를 만든다.**
   - 실제 독자, 이 글을 읽는 이유, 이미 아는 것, 알고 싶어 하는 것, 반대하거나 오해할 지점을 적는다.
   - 교수자·채점자는 별도 카드로 분리한다.
3. **주제를 제약과 함께 좁힌다.**
   - 필자 관심, 독자 유용성, 과제 목적, 이용 가능한 증거, 분량·시간을 5열에 놓고 후보를 비교한다.
   - 모든 조건을 완벽히 만족시키려 하지 말고 필수와 선호를 구분한다.
4. **자료를 찾고 판정한다.**
   - 검색어를 만들고, 각 자료의 출처·날짜·근거 종류·주장과의 관련성을 기록한다.
   - 읽은 내용을 복사하지 않고 자신의 질문에 어떤 답을 주는지 한 문장으로 요약한다.
5. **자료를 묶고 순서를 정한다.**
   - 같은 기준으로 분류한 카드끼리 묶고, 원인-결과·문제-해결·일반-구체 중 순서 원리를 선택한다.
   - 각 묶음이 독자의 다음 질문에 답하도록 배열한다.
6. **낮은 위험의 초고를 쓴다.**
   - 8-10분 동안 서두를 완성하려 하지 말고 핵심 단락부터 쓴다.
   - 모르는 표현은 `[표현 보완]`, 출처는 `[출처 확인]`으로 표시하고 계속 진행한다.
7. **실제 독자 반응을 받는다.**
   - 동료에게 요약, 가장 이해 안 된 지점, 더 필요한 정보만 요청한다.
   - 취향 평가나 전면 교정 대신 독자의 실제 반응을 수집한다.
8. **피드백을 판정표에 넣는다.**
   - `채택`, `변형`, `보류`, `거절` 중 하나를 고르고 이유를 독자·목적·근거로 쓴다.
   - 상충 피드백은 어떤 독자 집단에 더 중요한지를 비교한다.
9. **큰 것에서 작은 것으로 수정한다.**
   - 목적·주장·정보 누락→조직·단락→문장 명료성→맞춤법 순으로 패스를 나눈다.
   - 수정 뒤 실제 독자가 다시 요약할 수 있는지 확인한다.
10. **전이 일지를 남긴다.**
    - 다음 장르에서 반복된 막힘, 도움이 된 전략, 비계 없이 수행 가능한 부분을 기록한다.

## 흔한 오류·오개념과 교정

- **오개념: 가장 빈도가 높은 범주가 모든 학습자의 첫 수업이어야 한다.**  
  교정: 코드 빈도는 개인 진단이 아니다. 짧은 실제 과제와 면담으로 개인의 병목을 확인한다.
- **오개념: 독자를 고려한다는 것은 공손한 어조를 쓰는 것이다.**  
  교정: 독자의 배경지식, 관심, 사용 목적, 예상 질문, 이해 가능성을 정보 선택과 구조에 반영해야 한다.
- **오개념: 주제는 독창적일수록 좋다.**  
  교정: 증거와 범위가 없는 새로움은 수행 불가능하다. 적합성·검증 가능성·독자 효용을 함께 본다.
- **오개념: 자료를 많이 찾으면 내용 생성이 해결된다.**  
  교정: 자료의 신뢰성·관련성·통합·자기 주장과의 관계를 적게 한다.
- **오개념: 개요 형식을 알면 조직 능력이 있다.**  
  교정: 실제 카드 분류, 순서 이유 설명, 중복·누락 수정으로 수행을 확인한다.
- **오개념: 첫 문장이 완성돼야 본문을 쓸 수 있다.**  
  교정: 핵심 단락부터 쓰고 서두는 독자와 중심이 분명해진 뒤 작성한다.
- **오개념: 피드백은 모두 받아들여야 한다.**  
  교정: 피드백은 독자 반응 자료다. 목표·독자·근거로 채택 여부를 판단하고 이유를 남긴다.
- **오개념: 맞춤법을 많이 고치면 충분히 수정했다.**  
  교정: 목적, 정보, 조직, 문단, 문장, 표기의 위계를 사용해 상위 문제부터 본다.
- **오개념: 어려움을 많이 보고한 사람은 능력이 낮다.**  
  교정: 높은 기준과 자기점검 능력이 어려움 인식을 높일 수도 있다. 수행 자료와 함께 해석한다.

## 평가와 피드백

### 진단 평가

- 15분 쓰기와 함께 단계별 생각을 짧게 기록한다.
- 초고 후 `가장 어려웠던 결정`, `독자를 위해 바꾼 것`, `자료를 믿은 이유`, `수정하지 못한 것`을 묻는다.
- 자기보고와 실제 글의 누락·조직·독자 이해를 대조한다.

### 수행 루브릭

| 차원           | 기초                     | 진행                        | 독립                                     |
| -------------- | ------------------------ | --------------------------- | ---------------------------------------- |
| 독자 분석      | 막연히 “일반인”으로 적음 | 관심·배경 중 일부를 구체화  | 목적·배경·예상 질문을 정보 선택에 연결   |
| 독자 반응 예측 | 어조만 조정              | 이해 어려운 용어를 찾음     | 실제 독자 반응으로 정보·구조·문장을 수정 |
| 자료 사용      | 관련 자료를 나열         | 신뢰성과 관련성을 일부 설명 | 여러 자료를 비교·종합해 자기 주장에 배치 |
| 조직           | 형식적 목차만 작성       | 분류와 순서 원리를 설명     | 중복·누락을 스스로 진단하고 재구성       |
| 초고 조절      | 완벽주의로 정체          | 표시를 남기고 계속 씀       | 목적에 맞는 임시 초고를 시간 안에 완성   |
| 수정 판단      | 표면 오류만 고침         | 상위 문제를 발견            | 상충 피드백을 판정하고 수정 효과를 검증  |

피드백은 한 번에 하나의 병목에 집중한다. 예를 들어 “독자를 고려하라” 대신 “이 안내를 처음 보는 독자는 신청 자격을 어디서 확인해야 하는지 2문단에서 찾을 수 없다”처럼 위치·반응·다음 행동을 제시한다.

## 적용 조건과 전이 한계

- 참여자는 글쓰기 수업을 이수한 2·3학년 인문계열 대학생이며 국어교육·교육대학교 비중이 높다. 성인 기초문해 학습자의 전사·문장 생성 부담을 직접 보여주지 않는다.
- 자료는 자기보고이고 실제 초고, 수정 이력, 독자 반응, 점수와 연결되지 않았다. 어려움 인식이 실제 결함인지 검증하지 못한다.
- 575는 응답 수이며 824 또는 표의 다른 합계는 복수 코드 수다. 사람 수나 발생률로 바꾸지 않는다.
- 연구자가 각 응답을 관련 단계로 분류했지만 실제 쓰기 과정은 재귀적이다. 예를 들어 자료 찾기와 주제 조정은 여러 단계에서 반복된다.
- CQR-M 합의 절차는 제시되지만 독립 코더 간 수치 신뢰도는 보고되지 않는다. 같은 연구팀의 합의가 다른 팀에서도 재현될지는 알 수 없다.
- 여러 장르가 한데 섞였으며 장르별 빈도·차이는 충분히 분석되지 않았다.
- 독자 고려 범주에서도 실제 독자가 누구였는지, 과제가 공개·실제 목적을 가졌는지 일관되지 않다.
- 한국 성인 과정에 적용할 때는 구체적 생활 독자를 먼저 사용하고, 말하기·읽기·디지털 검색 능력과 정서적 안전을 함께 지원한다.
- 전이는 도움 없는 새 장르에서 독자 카드를 스스로 만들고, 실제 독자가 핵심을 이해하는지로 확인한다.

## 상세 요약

이 연구는 대학생 115명에게 주제 선정부터 고쳐쓰기까지 다섯 시점의 어려움을 자유롭게 적게 하고, 575개 응답을 CQR-M으로 분석했다. 그 결과 어려움은 한두 기능에 모이지 않았다. 주제 선정에서는 적합성·새로움·난도·필자 흥미의 조정, 내용 생성에서는 자료 찾기와 평가, 조직에서는 전반적 응집성과 범주화, 초고에서는 완벽주의와 서두·결말, 수정에서는 무엇을 어떻게 어느 범위까지 고칠지와 피드백 수용이 나타났다.

독자 고려는 계획에서 특히 많이 보고됐고, 유형도 시간에 따라 달라졌다. 계획 단계에서는 독자의 흥미와 배경을 분석하는 문제가 중심이고, 초고와 수정에서는 가독성과 이해 같은 반응 예측이 중요해졌다. 따라서 독자 고려를 마지막 문체 교정으로 가르치지 않고, 주제·정보 선택·조직·문장·수정 전 과정의 다른 판단으로 나누는 것이 핵심이다.

교육적으로 가장 직접적인 시사점은 어려움을 세분화한 진단 언어다. “글쓰기가 어렵다”를 `적합한 주제 선택`, `자료 신뢰성 판단`, `범주화`, `불완전 초고 허용`, `상충 피드백 판정` 같은 수행 단위로 바꾸면 작고 명시적인 비계를 제공할 수 있다. 구체적 독자가 있는 편지·안내·제안에서 실제 반응을 받은 뒤 추상적 학술 독자로 확장하는 순서도 유용하다.

다만 이 결과는 어려움의 자기보고 빈도이지 인과효과나 능력 측정이 아니다. 코드 합계가 본문과 표에서 불일치하고, 복수 코드 때문에 빈도를 사람 비율로 환산할 수 없다. 과정 설계에서는 실제 산출물·수정 이력·독자 이해를 함께 측정해 자기보고를 검증해야 한다.

## 교차 검증과 충돌

- 3단계 확정 주장 ID: `clm-audience-purpose-genre-rhetoric-002`

- `src-0119`의 수사적 맥락 피드백 연구와 연결하면 독자·목적 제시는 단순 과제 조건이 아니라 실제 수정 판단을 유도하는 피드백 준거가 돼야 한다.
- `src-0136`과 `src-0137`은 동료 피드백의 가능성과 한계를 종합한다. 0131에서 나타난 피드백 수용 어려움은 동료 검토 전에 피드백 문해를 가르쳐야 한다는 근거와 일치한다.
- `src-0139`는 문제 위치·요약·해결책이 피드백 이해와 관련된다고 보고한다. “무엇을 어떻게 고칠지 모르겠다”는 0131의 자기보고를 더 구체적인 피드백 형식으로 보완한다.
- `src-0035`의 학생·숙련 필자 수정 차이는 표면 교정에 머무는 위험을 보여준다. 0131의 맞춤법·문장 어려움이 많다는 사실을 수정 전체의 우선순위로 오해하지 않아야 한다.
- 원문 내부 충돌: 본문 p. 15의 `824=648+92+84`와 표 3 p. 16의 글쓰기 642·독자 91이 일치하지 않는다. 이 노트는 각 표의 세부값은 위치와 함께 쓰되 전체 합계를 확정 통계로 재사용하지 않는다.
- 최종 판정: 단계별 어려움 범주는 진단·피드백 어휘로 채택하고, 빈도 기반 교육 순서나 성인 전체의 발생률 주장은 제외한다.
