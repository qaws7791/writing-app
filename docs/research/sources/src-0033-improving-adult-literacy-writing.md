## 상세 내용 지도

1. **문해 발달(1-6쪽)**: 학습자, 텍스트·도구, 활동, 학습 맥락이 상호작용하며 읽기·쓰기는 지식과 인지·언어 과정을 공유한다고 설명한다.
2. **쓰기 구성 모형(13-14쪽)**: 기초 기능, 전문 쓰기 지식, 전략·과정, 동기와 이를 조율하는 실행 통제를 제시한다. 쓰기 목적 간 능력은 자동 일반화되지 않는다고 명시한다.
3. **효과적 쓰기 지도(14-16쪽)**: 명시적·체계적 지도, 목적 있는 확장 연습, 기초 기능 자동화, 동기·지속을 돕는 환경, 읽기-쓰기 통합 원리를 제시한다.
4. **구체 교수 관행(16쪽)**: 계획·수정·편집 전략, 요약, 동료 지원, 구체 목표, 워드프로세싱, 문장 결합, 과정 접근, 탐구, 사전쓰기, 모델 분석을 권한다.
5. **학습자별 조정(17-20쪽)**: 어려움을 겪는 학습자에게 더 강하고 명시적인 연습·전이 지원·개별화를, 영어 학습자에게 언어·문해·교육·문화 배경별 차별화를 요구한다.
6. **동기와 성인 연구(21-23쪽)**: 성인의 시간·돌봄·교통·일 같은 참여 장벽, 가치·자율성·효능감·진도 점검을 다룬다. 성인 집단별 효과를 반복 평가·개선하라고 결론낸다.

## 가르칠 개념과 원리

- **목적 특정성**: 기록·설득·학습·소통·오락·자기표현·성찰 중 한 목적의 숙련이 다른 목적에 자동 전이되지 않는다.
- **구성 요소의 조율**: 손글씨·철자·키보드·문장 같은 기초 기능, 장르·독자·주제 지식, 전략, 동기를 실행 통제가 과제별로 결합한다.
- **명시성 + 실제 사용**: 전략을 직접 설명하고 시범 보이는 것과 가치 있는 목적의 장시간 실제 쓰기를 결합해야 한다.
- **자동화와 판단의 구분**: 철자·키보드 등은 자동화해 주의를 확보하지만 계획·문장 구성처럼 판단이 필요한 과정은 유창하고 유연하게 만들되 완전 자동화를 목표로 하지 않는다.
- **개별화**: 같은 원리를 쓰더라도 장애, 첫 언어 문해, 교육 배경, 목표와 현재 수준에 따라 강도·자료·피드백을 조정한다.

## 수행 절차와 전략

1. 학습자의 실제 목표, 현재 장르 경험, 기초 기능과 참여 장벽을 진단한다.
2. 과제 목적과 결과물 특징을 구체 목표로 합의한다.
3. 필요한 장르·독자·내용 지식과 기초 기능을 짧고 명시적으로 지도한다.
4. 교사가 계획·초고·자기평가·수정 전략을 생각 말하기로 모델링한다.
5. 목록·도식·탐구·모델 분석, 동료 계획·수정 같은 지원으로 안내 연습한다.
6. 실제 생활·직업·교육 과제로 충분히 쓰고, 피드백과 자기평가로 전략을 조정한다.
7. 지원을 줄인 새 목적·매체 과제에서 전이를 확인하고, 일정·접근성·지원 서비스를 조정한다.

## 예시·과제·관찰 지표

- **목적별 과제**: 직장 요청 메일, 생활 절차 설명, 교육 과정 요약, 지역 문제 설득문, 개인 성찰 기록처럼 실제 사용 맥락을 둔다.
- **읽기-쓰기 통합**: 목표 장르의 글을 읽고 구조·어휘·독자 신호를 찾은 뒤 같은 목적의 글을 쓴다.
- **기초 기능 발판**: 철자·키보드가 병목이면 별도 짧은 연습과 보조 도구를 제공해 계획·수정에 쓸 주의를 확보한다.
- **관찰 지표**: 목적·장르별 성취, 전략의 독립 사용, 피드백 반영, 새 매체에서의 적용, 진도·효능감·참여 지속, 실제 생활에서의 사용.

## 흔한 오류·오개념과 교정

- **오개념: 성인에게는 아동과 완전히 다른 교수법이 필요하다.** 교정: 기본 원리는 공유하되 강도·내용·맥락을 성인 목표와 결손에 맞춘다.
- **오개념: 성인이므로 기초 기능을 다루면 안 된다.** 교정: 실제 병목이면 존중하는 방식으로 자동화를 지원한다.
- **오개념: 전략 설명만으로 충분하다.** 교정: 실제 목적의 확장 연습과 독립 사용까지 연결한다.
- **오개념: 한 장르를 잘 쓰면 전반적 글쓰기 능력이 생긴다.** 교정: 새 목적·형식·디지털 매체에서 별도 전이를 확인한다.
- **오개념: 중도 이탈은 동기 부족이다.** 교정: 시간, 일, 돌봄, 교통, 비용과 수업 접근성 같은 환경 장벽을 먼저 점검한다.

## 평가와 피드백

- 진단은 기초 기능, 장르·독자·주제 지식, 전략, 동기·자기 효능감과 실제 참여 조건을 분리해 본다.
- 수행 평가는 계획·초고·수정 과정과 최종 글을 함께 보고, 목적·장르별 기준을 사용한다.
- 피드백은 진도를 보이게 하고 다음 목표를 조정할 정보여야 하며, 고정 능력보다 노력·전략·지원 조건에 귀속한다.
- 어려움을 겪는 학습자에게는 더 빈번하고 명시적인 피드백, 적정 도전의 자료와 더 많은 연습을 제공한다.
- 권고의 성인 효과를 확정하지 말고 집단별 과정·산출·지속 자료를 모아 교육과정과 평가를 반복 개선한다.

## 적용 조건과 전이 한계

- 연구 종합의 다수가 K-12에서 왔고 성인 특화 엄격 연구가 부족하다.
- 미국 저문해 성인 집단은 한국어 모어 일반 성인과 목표·교육 배경·기초 기능 분포가 다르다.
- 영어 학습자 권고도 젊은 학습자·대학생 경험에서 추론한 부분이 있어 추가 연구가 필요하다.
- 성인의 참여는 수업 품질 외에 일정, 돌봄, 교통, 건강, 직업, 문화와 비용의 영향을 받는다.
- 디지털 쓰기를 포함하라고 권하지만 특정 플랫폼·협업·생성형 도구의 효과는 다루지 않는다.
- 전이는 새로운 목적·장르·매체와 교실 밖 실제 사용에서 검증해야 한다.

## 상세 요약

보고서는 성인 쓰기 지도를 계획, 초고 작성, 평가, 수정의 상호작용하는 과정으로 설명하고, 명시적 전략 교수와 모델링·안내 연습·독립 연습을 권한다. 글쓰기 목적과 실제 생활·직업·교육 과제를 연결하고, 학습자의 기존 지식과 목표에 맞게 과제 난이도와 지원을 조정해야 한다. 동기 측면에서는 가치 있는 목표 설정, 자기 효능감, 진도 관찰과 행동 조절을 함께 지원한다.

가장 중요한 한계는 성인 문해 교육에 특화된 엄격한 연구가 적다는 점이다. 따라서 아동·청소년 연구에서 도출한 원리를 성인에게 그대로 적용하지 말고, 문해 수준, 학습 목표, 문화·언어·교육 배경에 맞춰 조정하고 평가해야 한다. 본 프로젝트의 핵심 학습자는 일반 성인 모어 화자이므로, 기초 문해 결손을 전제하지 않되 실제 목적과 자율성, 이질적 숙련도라는 적용 조건을 보존한다.
