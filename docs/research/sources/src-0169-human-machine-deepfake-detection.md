## 가르칠 개념과 원리

1. **딥페이크 탐지와 메시지의 진실 판정은 다르다.** 진짜 영상도 거짓 주장을 담을 수 있고, 합성 영상도 풍자·교육처럼 명시된 맥락에서 사실을 전달할 수 있다.
2. **시각적 진위는 한 증거 층이다.** 픽셀·얼굴 움직임 외에 최초 게시자, 원본 계보, 발언 맥락, 독립 보도, 날짜·장소·언어, 음성·자막을 함께 본다.
3. **사람과 기계의 전체 평균만 비교하면 상보성을 놓친다.** 모델은 저화질 특징에, 사람은 두 인물·유명 인물의 배경지식 같은 맥락에 상대 강점을 보였다.
4. **같은 시험 자료에서 비교해야 한다.** 실험 1의 82% 수치는 참가자 성능을 같은 56쌍에서 모델과 직접 비교한 것이 아니라 모델의 전체 holdout 65%와 비교했다. 56쌍은 오히려 모델이 높은 확신으로 틀렸던 후보에서 골랐다.
5. **표본에 따라 모델 점수가 크게 달라진다.** 우승 모델은 전체 4,000개에서 65%였지만 무작위 추출한 실험 2의 50개에서는 80%였다. 작은 벤치마크 한 번을 고정 성능으로 보지 않는다.
6. **개인 정확도, 군중 평균, 모델 정확도는 서로 다른 단위다.** 86% 군중 결과는 1,879명의 응답을 영상별로 평균한 것이지 한 사람이 86%를 맞혔다는 뜻이 아니다.
7. **군중 지혜에는 독립성과 다양성이 필요하다.** 다른 사람의 답이나 모델 점수를 먼저 보면 오류가 상관되어 단순 평균의 장점이 줄 수 있다.
8. **자기선택된 군중은 대표 표본이 아니다.** 자연 유입 참가자 중 10개 이상 본 사람은 관심·능력·인내가 다른 사람일 수 있다. 높은 86%를 일반 시민 개인의 성능으로 바꾸지 않는다.
9. **전체 정확도는 오류 방향을 숨긴다.** 모집 참가자는 실제 영상은 75% 맞혔지만 딥페이크는 57%만 맞혔다. 실제를 진짜로 보는 경향과 가짜를 놓치는 비용을 분리한다.
10. **기저율은 오경보의 실제 의미를 바꾼다.** 실험은 실제·가짜를 50/50으로 보여 주고 참가자에게도 알렸다. 현실에서 딥페이크가 드물면 같은 민감도·특이도라도 “가짜” 판정 중 진짜 영상의 비율이 커질 수 있다.
11. **모델의 높은 확신은 분포 밖 신뢰를 보장하지 않는다.** 정치인 lip-sync 영상에서 모델은 가짜 확률을 2%·8%로 낮게 주며 자신 있게 틀렸다.
12. **자동화 조언은 사람 판단을 개선하기도 오염시키기도 한다.** 평균 정확도는 66%에서 73%로 올랐지만 모델이 틀린 영상에서는 사람이 더 틀리게 수정했다.
13. **조언 전 독립 판단을 보존해야 한다.** 최초 판정·확신·근거를 먼저 받고 모델 출력을 나중에 보여 주면 자동화 앵커와 실제 정보 이득을 분리해 볼 수 있다.
14. **확신도는 조건부 신호이지 진실 보증이 아니다.** 보충 ROC에서 중·고확신 군중은 저확신보다 좋았지만, 모델도 정치인 영상에서 고확신 오답을 냈다.
15. **판정 지원은 점수만 제시해서는 부족하다.** 모델이 어떤 영상 유형에서 검증됐고 흐림·두 인물·lip-sync·훈련 분포 밖 조건에서 어떻게 실패하는지 함께 보여 줘야 한다.
16. **사람의 맥락 지식은 강점이자 편향원이 될 수 있다.** “그 인물이 영어로 그런 말을 할 법한가”라는 점검은 도움이 될 수 있지만 고정관념과 잘못된 배경지식도 결론을 왜곡할 수 있다.
17. **관찰 상관과 무작위 실험을 구분한다.**
    - 응답 시간이 10초 늘 때 정확도가 1%p가량 낮았다는 결과는 어려운 영상 때문에 오래 걸렸을 수 있어 “빨리 답하라”는 인과 근거가 아니다.
    - 역전·어긋남·눈 가림은 무작위 배정되어 해당 시각 변형의 인과 효과를 더 강하게 말할 수 있다.
18. **얼굴의 전체적 처리가 사람 탐지에 기여할 수 있다.** 역전·어긋남·눈 가림은 사람 성능을 낮췄고 모델에는 같은 방식으로 작동하지 않았다.
19. **시각 결함 체크리스트는 수명이 짧다.** 깜박임 같은 단서는 연구 자극에서 유용했지만 생성 기술이 개선되거나 다른 합성 방식이면 사라질 수 있다.
20. **공정성 결과는 표본 크기와 불확실성을 함께 읽는다.** 어두운 피부 인물이 나온 영상은 12개뿐이고 모델 감소는 통계적으로 유의하지 않았다. “모델은 편향이 없다”도 “항상 12% 낮다”도 근거를 넘는다.
21. **감정 효과는 확정되지 않았다.** 실험 1의 유도는 감정 자체를 바꾸지 못했고, 실험 2 전체 효과는 없었으며 실제 영상 하위 분석만 경계 수준 차이가 났다. 두 결과가 일치하지 않아 저자도 강한 결론을 피한다.
22. **내용 경고와 탐지기 출력을 같은 것으로 보지 않는다.** “이 영상은 가짜일 확률 X%”는 사람을 특정 방향으로 이동시키며 잘못되면 오히려 판별을 낮춘다.
23. **결합 시스템은 사람+AI라는 이름만으로 우월하지 않다.** 어느 하위 유형에서 누구를 더 신뢰할지, 오류가 날 때 사람이 거부할 정보와 근거를 제공해야 한다.
24. **불일치는 학습 자원이다.** 사람·모델·독립 출처가 다르면 평균으로 즉시 닫지 말고 합성 방식, 영상 품질, 맥락, 원본 계보를 추가 조사한다.
25. **최종 목표는 “가짜를 맞히기”보다 책임 있는 판단이다.** 공유·신고·삭제·징계는 피해가 다르므로 판정 확신, 출처, 반론 가능성, 되돌릴 수 있는 조치를 고려한다.

## 수행 절차와 전략

### 일반 학습자용 영상 검증 절차

1. **주장을 분리한다.** `영상 파일이 조작되었는가`, `등장인물이 실제 인물인가`, `그가 실제로 이 말을 했는가`, `메시지 내용이 사실인가`를 각각 적는다.
2. **최초 접한 곳을 기록한다.** 계정, 게시 시각, 설명, 편집·재업로드 표시, 링크와 화면을 보존한다.
3. **원본 계보를 찾는다.** 핵심 프레임 역검색, 영상 제목·문구 검색, 최초 업로드·고해상도 판본·전체 길이 영상으로 거슬러 올라간다.
4. **맥락을 확인한다.** 날짜, 장소, 행사, 언어, 등장인물, 앞뒤 발언, 풍자·광고·재연 표시를 확인한다.
5. **독립 출처를 찾는다.** 당사자 공식 채널, 행사 원본, 신뢰할 만한 복수 보도, 검증기관을 대조하고 같은 원출처 복제를 독립 증거로 세지 않는다.
6. **영상·음성 단서를 관찰한다.** 얼굴 경계, 입술–음성 동기, 눈·치아·안경·그림자, 프레임 간 깜박임, 배경·몸 움직임, 오디오 전환을 기록한다. 단서 하나로 결론 내리지 않는다.
7. **도구의 적용 범위를 확인한다.** 사용한 탐지기가 정지 얼굴, face swap, lip-sync, 전체 영상, 해당 압축·해상도 중 무엇으로 검증됐는지 본다.
8. **도구를 쓰면 원출력을 보존한다.** 이름·버전·시간·입력 파일·확률·불확실·오류를 기록하고 개인정보·민감 영상의 업로드 조건을 확인한다.
9. **사람 판단을 먼저 쓴다.** `진짜/가짜/판단 불가`, 확신도, 근거를 모델 점수를 보기 전에 적는다.
10. **모델 출력을 본 뒤 변경을 기록한다.** 무엇 때문에 어느 방향으로 바꿨는지, 모델이 제공한 실질 근거가 있는지 적는다.
11. **불일치를 조사한다.** 사람과 모델이 다르면 영상 유형·품질·훈련 분포·맥락 증거를 추가 확인한다.
12. **판정을 단계화한다.** `원본 확인`, `조작 근거 강함`, `일부 편집`, `출처 불명`, `판단 불가`처럼 근거 강도를 표시한다.
13. **행동을 판정과 분리한다.** 판단 불가·고위험이면 공유를 보류하고, 신고·삭제·공개 반박에는 원본과 검증 근거를 첨부한다.
14. **새 근거가 나오면 수정한다.** 최초 판정과 수정 이력을 남겨 학습자가 어떤 단서에 과도하게 끌렸는지 검토한다.

### 군중–AI 검토 시스템을 설계하는 절차

1. 같은 영상을 여러 검토자가 서로의 답을 모른 채 독립적으로 본다.
2. 이진 답뿐 아니라 확신, 관찰한 단서, 맥락 조사 여부, `판단 불가`를 받는다.
3. 봇·중복·주의 부족을 통제하되 어려운 영상에서의 신중한 보류를 실패로 제거하지 않는다.
4. 단순 평균과 함께 응답 분포·양극화·하위집단·근거 다양성을 표시한다.
5. 모델 출력은 독립 판단 뒤에 공개하고 모델이 검증된 자료 유형·오류율·현재 영상과의 차이를 함께 보여 준다.
6. 사람의 판단 변화량과 방향을 기록한다. 모델이 맞을 때의 이득과 틀릴 때의 손실을 따로 계산한다.
7. 흐림, 어둠, 두 인물, lip-sync, face swap, 유명 인물, 압축 등 하위 유형별 사람·모델 성능을 추적한다.
8. 사람·모델이 모두 불확실하거나 충돌하면 원출처 조사·포렌식 전문가·당사자 확인 단계로 보낸다.
9. 실제 기저율에 맞춰 오경보·누락의 비용과 임계값을 조정한다.
10. 집단별·영상 피부색·언어·장애 접근성 차이를 정기적으로 감사한다.
11. 자동 삭제·제재는 단일 확률에 연결하지 않고 사람이 근거와 반론을 검토하는 가역적 절차를 둔다.

| 결합 인터페이스 비평          | 점수만 보이는 UI와 하위 유형·한계·근거가 보이는 UI 비교    | 모델 권위를 키우는 요소, 독립 판단 보존, 오류 시 거부 가능성을 설명하는가         | 저자의 설명 가능한 지원 제안      |
| 판단 불가 사례 처리           | 공유 보류·추가 조사·수정 공지 계획                         | 모호한 영상을 억지 이진 판정하거나 근거 없는 공개 고발로 확대하지 않는가          | 연구 한계를 안전 절차로 확장      |

관찰할 행동은 픽셀 조작과 주장 진실을 분리하는가, 원본·맥락을 찾는가, 사람과 모델을 같은 자료에서 비교하는가, 개인과 군중 단위를 구분하는가, 최초 판단을 모델 전에 보존하는가, 모델 오답에서 자신의 판단을 지킬 근거를 요구하는가, 불일치를 추가 조사의 신호로 쓰는가, 판단 불가와 수정 가능성을 허용하는가이다.

## 평가와 피드백

- **진단 평가:** 짧은 영상에 대해 조작 여부, 발언 여부, 내용 사실성, 공유 적절성을 네 개의 별도 질문으로 답하게 한다.
- **핵심 지표:** 전체 정확도와 함께 딥페이크 민감도, 실제 영상 특이도, 정밀도, 음성예측도, 확신 보정, 판단 불가율을 보고한다.
- **과정 지표:** 최초 출처 찾기, 전체 영상 열기, 핵심 프레임 검색, 독립 출처 대조, 모델 적용 범위 확인, 조언 전 판단 기록, 불일치 추가 조사, 수정 이력을 본다.
- **자동화 영향 지표:** 모델 보기 전후 정확도·확신 변화, 모델 정답 조건의 이득, 모델 오답 조건의 손실, 50% 경계 통과 방향을 따로 계산한다.
- **군중 평가:** 평균만이 아니라 참가자 수, 한 영상당 응답 수, 독립성, 자연 유입/모집, 주의점검, 응답 분산, 고확신 불일치를 보고한다.
- **현실형 평가:** 가짜가 50%인 균형 묶음과 가짜가 드문 묶음을 모두 사용한다. 첫 묶음은 민감도 비교, 둘째는 오경보 비용과 실제 판정 행동을 본다.
- **하위 유형 평가:** face swap, lip-sync, 압축, 흐림, 두 사람, 유명/비유명, 언어, 피부색, 오디오 유무별 성능을 충분한 문항으로 측정한다.
- **피드백 예시:** “86%를 개인 점수로 읽었지만 이는 선택된 군중 평균이다”, “모델의 2%라는 확신보다 공식 원본과 발언 맥락이 강한 근거다”, “가짜라고 판단했지만 내용의 사실성은 아직 확인하지 않았다”, “두 검토자가 갈린 이유를 영상 유형과 근거로 설명했다.”
- **불확실성 피드백:** 판단 불가를 무능으로 감점하지 않고 필요한 추가 자료와 안전한 다음 행동을 구체화했는지 평가한다.
- **전이 평가:** 낯선 인물 face swap에서 유명 인물 lip-sync, 짧은 영상에서 잘린 실제 영상, 영상에서 합성 음성으로 옮겨 원본 계보 절차가 유지되는지 본다.
- **지연 평가:** 1–2주 뒤 새 영상과 새로운 모델 출력 형식으로 조언 전후 판단을 반복한다. 기간과 교육 효과는 원문에서 검증하지 않은 수업 설계다.
- **운영 안전:** 실제 사람을 가짜 제작자로 공개 지목하는 과제 대신 동의된 공개 연구 자극을 사용하고, 확정되지 않은 판정이 검색 가능한 기록으로 남지 않게 한다.

## 적용 조건과 전이 한계

- 연구가 평가한 영상은 총 167개, 딥페이크 84개·실제 83개다. 참가자 수는 크지만 자극 수가 상대적으로 작아 영상 수준의 일반화가 제한된다.
- DFDC 영상은 10초 길이, 낯선 배우, 비논쟁 발화, 단순 배경이다. 설득적 편집, 긴 서사, 밈, 자막, 합성 음성, 실제 소셜 피드의 맥락과 다르다.
- 167개 중 lip-sync 조작은 정치인 딥페이크 2개뿐이다. 정치·사기에서 흔한 합성 방식 전체의 성능 근거가 아니다.
- 비교 모델은 2020년 DFDC 우승 모델이다. 최신 탐지 모델과 현재 생성 기술의 상대 성능은 알 수 없다.
- 실험 1의 자극은 모델이 높은 확신으로 틀린 3% 후보에서 뽑은 뒤 명백한 빠른 얼굴 깜박임을 제외했다. 이 선택은 일반 DFDC 분포를 대표하지 않는다.
- 실험 1의 “82%가 모델보다 우수”는 같은 자극의 직접 대결이 아니다. 저자도 직접 비교는 실험 2에 둔다.
- 실험 2의 50개 표본에서 모델 80%는 전체 4,000개 65%보다 높다. 50개 결과에는 영상 표본 변동이 크다.
- 자연 유입자는 전 세계에서 자발적으로 사이트를 찾았고 시청 영상 수도 달랐다. 10개 이상 본 사람의 높은 군중 평균은 관심·실력 자기선택의 영향을 받을 수 있다.
- 모집 표본은 Prolific의 미국 연령·민족·성별 대표 할당을 사용했지만 미국 인구 전체나 한국 성인을 대표하는 확률 표본은 아니다.
- 참가자는 절반이 딥페이크라는 사실을 들었다. 현실에서는 합성물 기저율을 모르고 훨씬 낮을 수 있어 판정 기준과 정밀도가 달라진다.
- 군중 평균은 각 영상에 많은 독립 응답이 필요한 집단 성과다. 교실의 소수 학습자나 한 명의 개인이 같은 성능을 낼 것이라고 기대할 수 없다.
- 정치인 영상은 실제·가짜 각 2개다. 사람의 맥락 일반화와 모델의 lip-sync 실패에 대한 흥미로운 사례이지 정치 딥페이크 전체의 효과 추정이 아니다.
- 영상 특성 7개는 연구진이 손으로 라벨링한 관찰 분석이다. 흐림·피부색·두 사람 자체가 정확도 차이를 일으켰다는 인과 결론에는 혼란 변수가 남는다.
- 어두운 피부 관련 모델 차이는 통계적으로 유의하지 않았고 영상 수도 12개다. 공정성 문제를 부정하거나 정량 일반화하지 않고 후속 균형 평가의 필요로 사용한다.
- 얼굴 역전·어긋남·눈 가림 처치는 인과 해석이 더 가능하지만 자연 발생 딥페이크가 이런 방해를 같은 방식으로 포함한다는 뜻은 아니다.
- 감정 실험은 두 실험의 처치 성공과 결과가 일치하지 않는다. 감정 조절 훈련의 효과 근거로 사용하지 않는다.
- 모델 조언 후 개선은 동일 모델·UI·50/50 과제에서의 결과다. 설명 형식, 경고 문구, 다른 오류율, 고위험 결정에서 효과가 달라질 수 있다.
- 연구는 탐지·확신을 측정했지 실제 공유·신고·삭제, 명예훼손 피해, 장기 학습, 한국어 수업 효과를 측정하지 않았다.
- 시각 판정은 한 도구다. 원문 자체가 최종적으로 맥락, 세계지식, 비판적 추론, 믿음 갱신을 함께 사용할 것을 강조한다.

## 상세 요약

이 연구는 딥페이크 영상 판정에서 일반인, 일반인의 집단 평균, 2020년 DFDC 대회 우승 컴퓨터 비전 모델, 그리고 그 모델의 예측을 본 일반인의 성과를 비교했다. 두 온라인 실험의 참가자는 모두 15,016명이다. DFDC 자료는 960명의 동의된 원본 23,654개와 7개 합성 기술로 만든 딥페이크 104,500개를 포함하며, 핵심 영상은 낯선 배우가 비논쟁적인 말을 하는 10초짜리 영상이라 사람도 배경지식을 거의 쓰지 못한다.

실험 1은 자연 유입 5,524명이 실제–딥페이크 56쌍 중 어느 쪽이 가짜인지 골랐다. 10쌍 이상 본 882명 중 82%가 우승 모델의 전체 holdout 정확도 65%보다 높았다. 그러나 이는 같은 56쌍에서의 직접 비교가 아니다. 보충자료에 따르면 56쌍은 모델이 높은 확신으로 틀린 딥페이크 3% 후보에서 뽑았고, 명백한 빠른 깜박임도 제외했다. 사람은 28쌍에서 83% 넘게 맞혔지만 3쌍에서는 절반 미만이 맞혔다. 영상 역전은 무작위로 사람 정확도를 5.6%p 낮췄다. 응답 시간이 10초 더 길수록 1.1%p 낮았다는 관계는 관찰 상관이고, 600ms 추가 반성 처치는 유의한 개선이 없었다.

실험 2는 단일 영상을 보고 50–100% 확신도를 표시한 뒤 우승 모델의 가짜 확률을 보고 답을 바꿀 수 있게 했다. Prolific 모집 304명과 자연 유입 9,188명이 참여했다. 핵심 비교는 holdout에서 무작위로 뽑은 실제 25개·딥페이크 25개다. 주의점검을 통과한 모집 참가자는 시행의 66%, 자연 유입 참가자는 69%, 그중 10개 이상 본 사람은 72%를 맞혔다. 같은 50개에서 모델은 80%를 맞혔는데 전체 holdout 65%보다 높았다. 모집 참가자는 실제 영상은 75% 맞혔지만 딥페이크는 57%였고, 모델은 각각 76%·84%였다. 따라서 전체 정확도만 보면 사람이 가짜를 진짜로 보는 오류를 놓친다.

응답을 영상별로 평균한 군중은 모집 집단 74%, 자연 유입 전체 80%, 10개 이상 본 자연 유입자 86%였다. 모델은 80%였다. 군중만 맞고 모델이 50% 이하인 영상은 8개였고, 모델만 맞고 군중이 50% 이하인 영상은 집단 선택에 따라 5–13개였다. 둘 다 실패한 딥페이크도 2개였다. 이는 사람과 모델의 오류가 완전히 같지 않아 결합 가능성이 있음을 보여 주지만, 86%는 한 개인의 능력이 아니라 자기선택된 많은 응답의 집계다.

모델 예측을 본 뒤 참가자는 24%의 시행에서 확신을 바꾸고 12%에서 진짜/가짜 50% 경계를 넘었다. 모집 참가자의 정확한 식별은 66%에서 73%로 상승했다. 모델이 맞은 40개에서는 평균 10.4% 더 정확한 쪽으로 움직였지만, 모델이 틀리거나 애매한 10개에서는 평균 2.7% 덜 정확해졌고 한 흐린 영상에서는 18% 악화했다. 특히 김정은·푸틴 lip-sync 딥페이크에 모델은 가짜 확률을 2%·8%로 주었다. 그 조언 뒤 사람 정확도는 56%에서 34%, 70%에서 55%로 떨어졌다. 평균적인 인간–AI 결합 향상이 고확신 분포 밖 오류의 피해를 지우지 못한다.

모델 AUC는 .957, 모집 군중은 .936이었고, 모델 조언 뒤 군중 ROC가 둘보다 높았다. 보충자료에서 독립 군중의 저·중·고확신 AUC는 .622·.952·.936, 모델 조언 뒤에는 .711·.987·.992였다. 다만 50개 영상의 사후 집계이고 운영 임계값·확률 보정을 직접 보장하지 않는다. 보충 혼동행렬의 통제 영상에서는 모집 참가자 민감도 60%, 특이도 75%, 정확도 67%; 자연 유입자는 68%, 78%, 73%였다. 눈 가림에서는 정확도 63%·68%, 얼굴 어긋남 60%·65%, 역전 62%·67%로 내려갔다.

무작위 얼굴 방해 실험에서 모집 참가자의 정확도는 역전 −4.3%p, 눈 가림 −4.4%p, 어긋남 −6.3%p였다. 모델은 역전에서 −12.1%p였지만 어긋남·눈 가림에는 유의한 변화가 없었다. 이 차이는 사람과 모델이 다른 특징에 의존할 가능성을 뒷받침한다. 영상 특성 관찰에서는 모델이 흐림·입자·어두운 영상에서 약간 강했고, 사람은 두 사람이 등장하거나 유명 인물의 맥락을 쓸 때 강했다. 깜박이는 얼굴은 둘에게 단서였다. 피부색 관련 참가자 차이는 관찰되었지만 영상이 12개뿐이고 모델 차이는 유의하지 않아 확대 해석할 수 없다.

연구의 실용적 결론은 “사람 또는 모델 중 하나를 고르라”가 아니다. 조언 전 사람의 독립 판단을 받고, 모델이 검증된 합성 유형과 실패하는 영상 하위 유형을 보여 주며, 불일치 시 원본·맥락·세계지식·출처 조사로 넘기는 결합 시스템이 필요하다. 수업에서도 얼굴 결함 맞히기에 머물지 않고 조작 여부, 실제 발언, 내용 사실성, 공유 적절성을 나누어 확인한다. 이 절차는 원문의 인간–기계 상보성과 맥락 강조를 안전한 학습 행동으로 확장한 **설계 추론**이며, 연구가 한국 성인 학습 과정의 효과를 직접 검증한 것은 아니다.

## 교차 검증과 충돌

- 3단계 확정 주장 ID: `clm-information-source-media-ai-literacy-007`

- 본문 1쪽의 15,016명은 실험 1의 5,524명과 실험 2의 9,492명을 합한 값으로 일치한다. 실험 2는 모집 304명과 자연 유입 9,188명이다.
- 표 1의 모집 참가자 수는 229명이다. 이는 실험 2의 최초 모집 304명 전체가 아니라 주의점검 등 분석 조건을 통과해 해당 회귀에 들어간 수다. 모집 N과 결과별 분석 N을 구분한다.
- 실험 1의 “82%가 leading model보다 높다”는 동일 영상 직접 비교가 아니다. 보충 방법은 모델이 어려워한 후보를 사용했다고 밝히고 본문도 직접 비교는 실험 2에 둔다. 이 수치를 인간 우위의 보편 증거로 쓰지 않는다.
- 실험 2의 모델 80%와 DFDC 전체 65%는 충돌이 아니라 50개 표본과 4,000개 전체의 차이다. 작은 영상 표본에서 성능 변동이 크다는 한계 자체를 보여 준다.
- 모집 개인 66%, 군중 평균 74%, 모델 80%, 모델 조언 후 개인 시행 73%는 분석 단위가 다르다. 군중 평균은 영상별 집계이고 73%는 같은 참가자의 조언 후 정확한 식별 비율이다.
- 본문은 모집 군중 AUC .936과 모델 .957을 보고하고, 보충 그림 S2는 확신 구간별 군중·모델 조언 후 군중 AUC를 추가한다. AUC가 높다고 개별 확률이 보정됐거나 모든 운영 임계값에서 우월하다는 뜻은 아니다.
- 감정 처치는 실험 1에서 자기보고 감정을 유의하게 바꾸지 못했고 결과도 없었다. 실험 2의 전체 정확도 효과도 없고 실제 영상 하위 효과만 `P=.032`다. 저자도 두 실험에서 다른 결과라 강한 결론을 내리지 않는다.
- 피부색 분석에서 참가자 −8.8%p는 유의했지만 모델 −12.0%p는 `P=.192`였다. Bonferroni 설명은 사람 결과 일부가 남는다고 하지만 12개 영상의 관찰 관계이므로 인과·보편 차이로 바꾸지 않는다.
- 저자들은 모델이 정치인 영상에서 실패한 이유로 훈련된 face swap과 다른 lip-sync 조작을 제시하지만 “perhaps”라고 표현한 가설이다. 합성 방식별 직접 분해 실험이 아니다.
- [`src-0170`](./src-0170-synthetic-faces-trust.md)은 정지 합성 얼굴이 실제와 구별되지 않고 더 신뢰받을 수 있음을 보인다. `src-0169`의 10초 face-manipulation 영상 성능과 직접 비교할 수 없지만, 외형·첫인상만으로 출처와 신뢰를 결정하지 말아야 한다는 결론은 보완된다.
- [`src-0171`](./src-0171-deepfakes-disinformation-trust.md)은 딥페이크 노출이 특정 영상 판정 외에 전반적 불확실성과 신뢰에 미치는 영향을 다룬다. 탐지 정확도 향상과 사회적 신뢰 보존은 별도 결과로 평가해야 한다.
