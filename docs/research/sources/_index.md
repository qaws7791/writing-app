# 출처 연구 인덱스

## 책임

이 디렉터리는 자료별 서지 정보, 접근 범위, 상세 요약과 추출한 원리를 보존한다. 전체 목록과 다음 ID는 [`source-catalog.md`](./source-catalog.md)에서 확인한다. 새 자료는 [`source-note-template.md`](./source-note-template.md)를 복사해 `src-0001-short-title.md` 형식의 kebab-case 파일로 기록한다. 출처 ID는 등록 순서에 따라 `src-0001`부터 부여하고 파일명이 바뀌어도 ID는 유지한다.

## 접근 수준

| 수준        | 판정 기준                                                               | 사용할 수 있는 근거 범위                        |
| ----------- | ----------------------------------------------------------------------- | ----------------------------------------------- |
| 직접 근거   | 원문 전체 또는 필요한 본문 구간을 직접 확인하고 정확한 위치를 기록했다. | 확인한 본문 범위의 주장과 맥락                  |
| 제한적 근거 | 초록, 목차, 미리보기, 공식 소개처럼 원자료의 일부만 직접 확인했다.      | 실제로 확인한 일부가 명시적으로 뒷받침하는 내용 |
| 간접 근거   | 신뢰할 수 있는 제3자의 리뷰·요약으로 원자료의 존재나 논지를 파악했다.   | 탐색 단서와 제3자가 명시한 범위                 |

접근 수준은 출처의 권위나 연구 품질을 뜻하지 않는다. 신뢰도는 저자 전문성, 발행 주체, 심사·편집 절차, 연구 방법, 최신성과 현재 과제와의 관련성을 근거로 `높음`, `보통`, `낮음` 중 하나와 판단 이유를 함께 기록한다.

간접 근거만으로 원저자의 세부 주장이나 규범을 단정하지 않는다. 제한적·간접 근거를 사용한 주장은 확인 범위를 문장에 드러내며, 원문 확인이 필요한 경우 근거 공백으로 남긴다.

## 등록 규칙

- 같은 자료의 판본·번역·접근 URL이 달라도 내용 단위가 같으면 하나의 출처 ID 아래 접근 경로를 함께 기록한다.
- 내용이나 책임 저자가 실질적으로 다른 판본은 별도 출처로 등록하고 관계를 적는다.
- URL만 저장하지 않고 저자, 발행 주체, 연도와 영구 식별자를 우선 기록한다.
- 새 ID를 부여하기 전에 출처 카탈로그와 기존 노트를 검색해 중복과 ID 충돌을 확인한다.
- 직접 확인하지 않은 서지 정보와 해석은 각각 그 출처와 불확실성을 표시한다.
- 짧은 인용은 꼭 필요한 범위만 정확한 위치와 함께 기록하고 원문을 대체할 장문 전재는 저장하지 않는다.
