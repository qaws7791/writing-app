# 조직·일관성·응집성·표현 종합

## 종합 판단

조직은 목적에 맞게 정보를 선택하고 위계·순서·인과·비교 같은 관계로 배열하는 거시 수행이다. 일관성은 글의 의미 관계와 전체 목적이 독자에게 성립하는 정도이고, 응집성은 지시·반복·접속·어휘 관계처럼 그 연결을 표면에 드러내는 장치다. 응집 표지가 많다고 일관성이 자동으로 생기지 않는다.

명료하고 정확한 표현은 정확한 어휘, 자연스러운 문장 호응, 분명한 지시 대상과 관계 표지를 선택하면서 필수 의미를 보존하는 수행이다. 초기 `표현력`은 문체, 어휘, 문장, 수사와 창작을 모두 포괄해 평가 경계가 불명확하므로 이 수행으로 대체한다.

## 평가 경계

- 문장 수준의 정확성이 글 전체의 조직·일관성을 보장하지 않는다.
- 고정 템플릿은 초기에 관계를 외부화할 수 있지만 장르와 목적에 맞게 수정할 수 있어야 한다.
- 설명은 개념 관계와 예시를 독자의 지식 수준에 맞추는 별도 수사 수행이다.
- 장르별 채점 기준은 관찰 가능한 결과를 제공하지만 조사용 점수나 특정 문항을 일반 성인의 통과 기준으로 복제하지 않는다.

## 역량 판단에 미친 영향

조직, 일관성·응집성, 설명은 고유 결과가 있어 유지한다. 명료하고 정확한 표현을 새 ID로 두고 규범 정오, 거시 조직과 별도 평가한다.
