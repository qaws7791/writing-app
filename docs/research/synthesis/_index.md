# 원리 종합 인덱스

## 책임

이 디렉터리는 여러 출처에서 도출한 교육·언어·작문 원리를 주제별로 종합한다. 출처 하나의 요약은 `sources`에 두고, 이곳에서는 출처 사이의 공통점, 차이, 충돌과 적용 조건을 분석한다.

## 작성 규칙

- 파일은 하나의 응집된 주제를 다루고 kebab-case 이름을 사용한다.
- 외부 자료가 직접 말한 내용, 여러 자료로부터 도출한 종합, 근거가 부족한 추론을 문장에서 구분한다.
- 콘텐츠 설계를 정당화할 주장은 [`evidence/_index.md`](../evidence/_index.md)의 주장 ID와 출처 연결 규칙을 따른다.
- 규범, 기술 원리, 경험적 연구 경향과 작성자의 설계 판단을 같은 확실성으로 표현하지 않는다.
- 상반된 견해는 하나를 임의로 삭제하지 않고 적용 대상, 조건과 근거 강도의 차이를 함께 기록한다.
- 최종 코스 구조와 학습자용 문구는 기록하지 않는다.
