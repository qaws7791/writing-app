# 역량 연구 인덱스

## 책임

이 디렉터리는 조사 대상 역량의 정의, 상위·하위·인접 관계, 관찰 가능한 학습 성과와 관련 원리를 관리한다. 조사 시작점과 3단계 판정 결과를 다음 문서가 나누어 소유한다.

- [`initial-competencies.md`](./initial-competencies.md): 초기 26개 명칭과 보존 ID
- [`competency-analysis.md`](./competency-analysis.md): 초기 역량별 정의·제외 범위·성과·관계와 판정 근거
- [`final-competency-framework.md`](./final-competency-framework.md): 최종 24개 역량의 의미 경계와 근거
- [`initial-to-final-map.md`](./initial-to-final-map.md): 초기 ID와 최종 ID의 유지·병합·대체·제외·추가 관계
- [`competency-groups-category-candidates.md`](./competency-groups-category-candidates.md): 자료에서 도출한 역량군과 4단계 카테고리 입력 후보

최종 역량은 복수 근거와 관찰 가능한 차이를 바탕으로 병합·분리·추가한다. 용어가 비슷하다는 이유만으로 합치거나, 기존 목록에 있다는 이유만으로 독립 역량이라고 확정하지 않는다.

## 역량 문서 기준

- 정의와 제외 범위
- 상위·하위·인접 역량 관계
- 관찰 가능한 학습 성과
- 연결된 주장 ID와 출처 ID
- 근거의 강도, 충돌과 남은 공백
- 초기 역량과 최종 역량의 대응 관계

코스 배정과 학습자용 설명은 최종 콘텐츠의 권위 소스에 두고 이 디렉터리에 복제하지 않는다.
