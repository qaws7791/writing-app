# 초기 역량 분석

## 판정 기준

초기 26개를 정의·제외 범위·학습 대상·수행 과정·관찰 결과·선행 조건·관계·근거 강도로 분석했다. `유지`는 의미 경계가 그대로인 경우, `병합`은 고유 명칭보다 실제 수행이 같은 경우, `대체`는 평가 가능하게 실질 재정의한 경우, `제외`는 지식·환경·교수 방법인 경우다.

## `cmp-001-vocabulary` 어휘력

- 정의·제외: 문맥에서 단어의 의미·용법·관계를 구별하고 적절한 단어를 선택한다. 단어 수 암기나 한 번의 정의 회상은 제외한다.
- 학습 대상·과정: 생활·공공·설명·논증 글의 단어를 형태·문맥·의미 관계로 해석하고 대안을 비교한다.
- 관찰 결과: 낯선 문맥의 뜻을 근거와 함께 설명하고 의미를 보존한 대체어를 고른다.
- 선행 조건·관계: 기본 문자 해독이 필요하며 문장 이해와 읽기 의미 구성을 지원하지만 대신하지 않는다.
- 근거 강도·판정: `보통`; `clm-language-norms-sentence-clarity-001`, `clm-reading-meaning-construction-002`. 고유 수행이 있어 `유지`.

## `cmp-002-sentence-comprehension` 문장 이해력

- 정의·제외: 낱말·통사 구조·지시·논리 관계를 통합해 문장 의미와 모호성을 판단한다. 단어 뜻의 합산은 제외한다.
- 학습 대상·과정: 실제 문장의 성분 관계, 생략, 수식 범위와 연결을 분석하고 가능한 해석을 문맥으로 좁힌다.
- 관찰 결과: 문장의 행위자·대상·조건과 해석 근거를 복원하고 모호한 부분을 지적한다.
- 선행 조건·관계: 문자 해독과 기초 어휘가 필요하며 읽기 의미 구성과 명료한 표현의 기반이다.
- 근거 강도·판정: `보통`; `clm-language-norms-sentence-clarity-002`, `clm-reading-meaning-construction-002`. 별도 진단 결과가 있어 `유지`.

## `cmp-003-grammar-orthography` 문법·표기 능력

- 정의·제외: 형태소·단어 경계, 문법 범주와 현행 규범의 원칙·허용·예외를 문맥에 적용한다. 문체 선호와 가독성 전체는 제외한다.
- 학습 대상·과정: 판단 층위를 분류하고 형태·범주·조항·문맥 의미를 대조한 뒤 필요하면 공식 사전을 확인한다.
- 관찰 결과: 새 문장의 표기·띄어쓰기 오류를 고치고 적용 근거와 허용형을 설명한다.
- 선행 조건·관계: 기초 문장 이해가 필요하며 명료하고 정확한 표현과 인접하지만 정오 판단을 소유한다.
- 근거 강도·판정: 적용 범위 안 `높음`; `clm-language-norms-sentence-clarity-003`, `clm-language-norms-sentence-clarity-005`. 고유 규범 수행이 있어 `유지`.

## `cmp-004-reading-comprehension` 독해력

- 정의·제외: 텍스트 정보와 독자 지식을 목적에 맞게 통합해 의미를 구성·점검하는 상위 수행이다. 신뢰성 판단 전체는 제외한다.
- 학습 대상·과정: 낱말·문장·구조·추론을 조정해 텍스트베이스와 상황 모형을 만든다.
- 관찰 결과: 핵심·세부·관계와 해석 근거를 설명하고 이해 실패 지점을 수정한다.
- 선행 조건·관계: 어휘·문장 이해와 관련 지식이 필요하며 초기 핵심 내용 파악을 포함한다.
- 근거 강도·판정: `높음`; `clm-reading-meaning-construction-001`~`clm-reading-meaning-construction-006`. `cmp-005`와 경계가 중복되어 `cmp-027-reading-meaning-construction`으로 `병합`.

## `cmp-005-main-idea-identification` 핵심 내용 파악 능력

- 정의·제외: 주제와 세부를 구별하고 구조를 이용해 선택·일반화·통합한다. 표면 문장 복사는 제외한다.
- 학습 대상·과정: 중심 화제, 반복·상위 개념, 구조 신호와 글 목적을 대조한다.
- 관찰 결과: 새 글의 핵심을 근거와 함께 요약하고 중요하지 않은 세부를 배제한다.
- 선행 조건·관계: 읽기 의미 구성의 하위 수행이며 별도 일반 역량으로 평가하면 독해와 중복된다.
- 근거 강도·판정: `보통`; `clm-reading-meaning-construction-004`, `clm-organization-coherence-expression-005`. `cmp-004`와 `병합`.

## `cmp-006-inference` 추론 능력

- 정의·제외: 명시되지 않은 관계를 텍스트·자료와 관련 지식으로 정당화한다. 근거 없는 자유연상은 제외한다.
- 학습 대상·과정: 연결 공백, 원인·결과, 함축, 대안을 식별하고 필요한 추론과 선택적 정교화를 구분한다.
- 관찰 결과: 결론, 사용한 전제와 불확실성을 표시하고 반례가 나오면 수정한다.
- 선행 조건·관계: 문장·독해와 영역지식이 필요하며 비판적 판단과 논증의 구성 요소다.
- 근거 강도·판정: `보통`; `clm-inference-critical-judgment-001`, `clm-reading-meaning-construction-003`. 고유 수행이 있어 `유지`.

## `cmp-007-critical-thinking` 비판적 사고력

- 정의·제외: 분석·평가·추론과 자기교정을 목적에 맞게 사용해 판단의 질을 높인다. 무조건적 불신이나 오류명 붙이기는 제외한다.
- 학습 대상·과정: 쟁점·가정·근거·대안·불확실성을 검토하고 반대 근거로 자신의 결론을 시험한다.
- 관찰 결과: 근거 강도와 한계를 설명하고 결론을 보류·수정할 수 있다.
- 선행 조건·관계: 영역지식과 추론이 필요하며 구조적 분석·신뢰성 판단을 조정한다.
- 근거 강도·판정: 개념 `높음`, 일반 전이 `낮음`; `clm-inference-critical-judgment-002`, `clm-inference-critical-judgment-007`, `clm-inference-critical-judgment-008`. 의미를 유지해 `유지`.

## `cmp-008-logical-thinking` 논리적 사고력

- 정의·제외: 전제·관계·결론의 연결을 점검한다. 형식 논리 지식 전체나 오류명 암기는 제외한다.
- 학습 대상·과정: 조건, 인과, 비교와 주장–근거 관계를 명시하고 타당한 연결인지 시험한다.
- 관찰 결과: 생략 전제를 보충하고 관계 오류·대안을 설명한다.
- 선행 조건·관계: 추론·분석·종합과 실제 수행에서 왕복하며 독립 경계가 약하다.
- 근거 강도·판정: `보통`; `clm-inference-critical-judgment-003`, `clm-inference-critical-judgment-004`. `cmp-009`, `cmp-010`과 `cmp-028-structured-analysis-integration`으로 `병합`.

## `cmp-009-analysis` 분석력

- 정의·제외: 자료를 의미 있는 부분으로 구별하고 부분 간·전체 목적과의 관계를 조직한다. 단순 분할은 제외한다.
- 학습 대상·과정: 분류 기준을 정하고 요소·관계·기능·출처를 구분한다.
- 관찰 결과: 분석표나 구조도를 만들고 각 요소의 역할과 기준을 설명한다.
- 선행 조건·관계: 논리적 관계 판단과 종합이 한 과제에서 반복된다.
- 근거 강도·판정: `보통`; `clm-inference-critical-judgment-003`, `clm-inference-critical-judgment-006`. `cmp-008`, `cmp-010`과 `병합`.

## `cmp-010-synthesis` 종합력

- 정의·제외: 여러 정보·관점을 공통 질문 아래 연결해 새로운 전체 구조나 결론을 만든다. 자료 나열은 제외한다.
- 학습 대상·과정: 출처별 주장·근거·한계를 비교하고 일치·차이·빈틈을 통합한다.
- 관찰 결과: 관계가 드러나는 통합 설명과 충돌·미해결 지점을 제시한다.
- 선행 조건·관계: 분석과 논리 점검이 없으면 수행을 독립적으로 평가하기 어렵다.
- 근거 강도·판정: `보통`; `clm-inference-critical-judgment-003`~`clm-inference-critical-judgment-006`. `cmp-008`, `cmp-009`와 `병합`.

## `cmp-011-creative-thinking` 창의적 사고력

- 정의·제외: 새롭고 과제·독자에게 적절한 아이디어를 다양하게 생성·평가·개선한다. 아이디어 수나 자기효능감만은 제외한다.
- 학습 대상·과정: 발산, 기준에 따른 수렴과 변형을 순환한다.
- 관찰 결과: 서로 다른 후보를 만들고 선택·개선 이유를 독창성·적절성으로 설명한다.
- 선행 조건·관계: 관련 지식이 필요하며 비판적 판단은 평가 국면을 지원한다.
- 근거 강도·판정: 개념 `높음`, 성인 중재 `보통`; `clm-creativity-topic-content-generation-001`~`clm-creativity-topic-content-generation-007`. `유지`.

## `cmp-012-topic-setting` 주제 설정 능력

- 정의·제외: 목적·독자·요구·제약을 수사적 문제로 구성하고 다룰 수 있는 범위를 정한다. 제목 선택은 제외한다.
- 학습 대상·과정: 문제의 변화 가능성, 대상, 자료와 범위를 질문하고 주제문을 수정한다.
- 관찰 결과: 실행 가능한 주제와 제외 범위·선택 근거를 제시한다.
- 선행 조건·관계: 독자·목적 인식이 필요하며 내용 생성의 방향을 정한다.
- 근거 강도·판정: `높음`; `clm-creativity-topic-content-generation-003`, `clm-audience-purpose-genre-rhetoric-001`. `유지`.

## `cmp-013-content-generation` 내용 생성 능력

- 정의·제외: 기억·관찰·자료에서 관련 아이디어와 근거 후보를 만들고 확장한다. 검증되지 않은 자료의 그대로 옮기기는 제외한다.
- 학습 대상·과정: 질문·브레인스토밍·분류·관점 전환과 자료 탐색을 사용해 조직과 왕복한다.
- 관찰 결과: 목적에 관련된 여러 후보와 각 근거·출처·선택 이유를 제시한다.
- 선행 조건·관계: 주제, 관련 지식과 정보 탐색이 필요하며 조직 이전에 끝나는 고정 단계가 아니다.
- 근거 강도·판정: `보통`; `clm-creativity-topic-content-generation-004`, `clm-writing-process-self-regulation-004`. `유지`.

## `cmp-014-organization` 조직력

- 정의·제외: 목적에 맞는 정보를 선택하고 위계·순서·인과·비교 관계로 배열한다. 고정 서식 복제는 제외한다.
- 학습 대상·과정: 정보 단위를 분류하고 거시 구조·문단 순서를 설계해 독자 흐름으로 시험한다.
- 관찰 결과: 개요와 글에서 관계가 일치하고 재배열 이유를 설명한다.
- 선행 조건·관계: 내용 생성이 필요하며 일관성·응집성은 배열된 관계의 의미·표면 연결을 다룬다.
- 근거 강도·판정: `보통`; `clm-organization-coherence-expression-001`, `clm-organization-coherence-expression-005`, `clm-organization-coherence-expression-006`. `유지`.

## `cmp-015-coherence-cohesion` 일관성과 응집성

- 정의·제외: 전체 목적에 맞는 의미 관계를 만들고 지시·반복·접속으로 연결을 드러낸다. 접속어 수 늘리기는 제외한다.
- 학습 대상·과정: 주장·문단·문장 관계와 지시 대상을 추적하고 부족하거나 과도한 표지를 조정한다.
- 관찰 결과: 독자가 관계를 복원하며 끊김·모순·모호한 지시를 찾아 고친다.
- 선행 조건·관계: 조직·문장 이해가 필요하며 둘은 별도 지표지만 함께 평가한다.
- 근거 강도·판정: `보통`; `clm-organization-coherence-expression-002`, `clm-organization-coherence-expression-007`. `유지`.

## `cmp-016-expression` 표현력

- 정의·제외: 초기 명칭은 어휘·문장·문체·수사·창작을 모두 포함해 관찰 경계가 없다.
- 학습 대상·과정: 실제 교육 대상은 정확한 어휘, 문장 호응, 분명한 지시와 관계, 의미 보존 편집이다.
- 관찰 결과: 독자와 목적에 맞게 문장을 고치고 바뀐 의미와 근거를 설명한다.
- 선행 조건·관계: 어휘·문장 이해·규범과 인접하지만 소통을 위한 선택을 소유한다.
- 근거 강도·판정: `높음`; `clm-language-norms-sentence-clarity-004`, `clm-organization-coherence-expression-003`. `cmp-029-clear-accurate-expression`으로 `대체`.

## `cmp-017-explanation` 설명력

- 정의·제외: 개념·과정·관계를 독자가 이해·검증하도록 구조·근거·예시와 표현을 조정한다. 정보 나열은 제외한다.
- 학습 대상·과정: 독자 지식을 파악하고 핵심 관계를 구조화해 예시와 정의를 선택한다.
- 관찰 결과: 독자가 관계를 재구성할 수 있고 설명 범위와 근거를 확인할 수 있다.
- 선행 조건·관계: 조직·표현·독자 인식이 필요하며 논증처럼 입장 수용을 목표로 하지 않는다.
- 근거 강도·판정: `보통`; `clm-organization-coherence-expression-004`, `clm-audience-purpose-genre-rhetoric-004`. `유지`.

## `cmp-018-persuasion` 설득력

- 정의·제외: 초기 명칭은 근거 기반 정당화와 감정 유발·순응을 구별하지 못한다.
- 학습 대상·과정: 주장·근거·보증·반론을 구성하고 근거 강도와 한계를 평가한다.
- 관찰 결과: 경쟁 주장을 공정하게 다루며 결론이 근거 범위를 넘지 않는다.
- 선행 조건·관계: 추론·비판적 판단·출처 신뢰성 판단이 필요하다.
- 근거 강도·판정: 개념 `높음`; `clm-audience-purpose-genre-rhetoric-006`, `clm-inference-critical-judgment-004`. `cmp-030-evidence-based-argumentation`으로 `대체`.

## `cmp-019-audience-awareness` 독자 인식 능력

- 정의·제외: 실제·의도 독자의 지식·입장·요구와 텍스트가 호출하는 역할을 함께 고려한다. 독자에게 무조건 맞추기는 제외한다.
- 학습 대상·과정: 독자 자료를 조사하고 예상 반응·오해를 기록해 정보·근거·표현을 조정한다.
- 관찰 결과: 같은 내용을 다른 독자에게 다르게 쓰고 선택 근거와 한계를 설명한다.
- 선행 조건·관계: 목적·장르 인식과 상호의존하지만 독자 변인을 소유한다.
- 근거 강도·판정: `높음`; `clm-audience-purpose-genre-rhetoric-002`, `clm-audience-purpose-genre-rhetoric-005`. `유지`.

## `cmp-020-purpose-genre-awareness` 목적과 장르 인식 능력

- 정의·제외: 사회적 목적과 공동체 상황에 맞는 장르 관습을 분석·선택·변형한다. 형식 암기는 제외한다.
- 학습 대상·과정: 반복 상황, 독자 기대, 구조·표현 관습과 변이를 비교한다.
- 관찰 결과: 선택한 장르·관습과 변형 이유를 목적·공동체 근거로 설명한다.
- 선행 조건·관계: 독자 인식과 주제 설정이 필요하며 조직·표현 선택을 제약한다.
- 근거 강도·판정: `높음`; `clm-audience-purpose-genre-rhetoric-003`, `clm-audience-purpose-genre-rhetoric-007`. `유지`.

## `cmp-021-self-monitoring` 자기 점검 능력

- 정의·제외: 목표·증거·기준으로 수행을 평가하고 다음 행동을 조정한다. 막연한 다시 읽기·자신감 보고는 제외한다.
- 학습 대상·과정: 목표 설정, 과정 관찰, 기준 판정, 전략 변경과 결과 확인을 순환한다.
- 관찰 결과: 점검 기록에 문제·근거·기준·조치·결과가 연결된다.
- 선행 조건·관계: 과제 지식과 기준 이해가 필요하며 수정·피드백 활용을 조정한다.
- 근거 강도·판정: 개념 `보통`, 장기 전이 `공백`; `clm-writing-process-self-regulation-002`, `clm-writing-process-self-regulation-006`, `clm-writing-process-self-regulation-007`. `유지`.

## `cmp-022-background-knowledge` 배경지식

- 정의·제외: 과제와 관련된 사실·개념·장르·상황 지식이다. 지식 보유 자체는 관찰 가능한 조절 수행이 아니다.
- 학습 대상·과정: 필요한 지식의 공백을 확인하고 정확성·관련성을 검증해 읽기·생성·추론에 사용한다.
- 관찰 결과: 지식을 텍스트 근거와 연결하고 관련 없는 지식은 억제한다.
- 선행 조건·관계: 읽기·추론·창의·내용 생성의 자원이자 조건이다.
- 근거 강도·판정: 관계 `보통`; `clm-reading-meaning-construction-003`. 독립 능력에서 `제외`하고 각 역량의 선행 조건·학습 자원으로 조건화.

## `cmp-023-revision` 수정 능력

- 정의·제외: 목표와 현재 글의 차이를 진단해 의미·조직·표현을 생성·삭제·대체·재배열한다. 표면 교정만은 제외한다.

- 관찰 결과: 수정 전후의 의미 있는 변화와 선택 근거를 설명한다.
- 선행 조건·관계: 자기점검과 피드백 활용이 지원하지만 실제 글 변화는 별도 결과다.
- 근거 강도·판정: `높음`; `clm-feedback-revision-assessment-001`, `clm-feedback-revision-assessment-008`. `유지`.

## `cmp-024-information-search` 정보 탐색 능력

- 학습 대상·과정: 필요–질의–탐색–결과 검토–재탐색을 반복하고 원출처를 찾는다.

- 선행 조건·관계: 주제 설정이 필요하며 신뢰성 판단과 출처 통합보다 앞뒤로 왕복한다.

## `cmp-025-source-credibility` 정보 신뢰성 판단 능력

- 학습 대상·과정: 측면 읽기, 원출처 추적, 복수 보도와 방법·이해관계·불확실성 대조를 수행한다.

## `cmp-026-media-literacy` 매체 문해력

- 선행 조건·관계: 탐색·신뢰성 판단·출처 귀속을 통합하지만 대신하지 않는다.
- 근거 강도·판정: 개념·규범 `높음`, 특정 중재 `상충`; `clm-information-source-media-ai-literacy-003`~`clm-information-source-media-ai-literacy-010`. `cmp-033-digital-ai-media-literacy`로 `대체`.
