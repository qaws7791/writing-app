# 역량군과 코스 카테고리 후보

## 사용 범위

아래 묶음은 4단계에서 코스 카테고리를 검토하기 위한 입력 후보다. 근거의 주된 수행 관계에 따라 배치했으며 코스 수·제목·순서·역량 배정을 확정하지 않는다.

| 역량군 후보        | 포함 역량                                                                                                                                                  | 묶음의 공통 수행                                                 | 4단계 카테고리 후보 |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ------------------- |
| 언어와 읽기        | `cmp-001-vocabulary`, `cmp-002-sentence-comprehension`, `cmp-003-grammar-orthography`, `cmp-027-reading-meaning-construction`, `cmp-006-inference`         | 언어 단서와 지식을 통합해 의미를 구성·정당화한다.                | 언어와 읽기         |
| 판단과 발상        | `cmp-007-critical-thinking`, `cmp-028-structured-analysis-integration`, `cmp-011-creative-thinking`, `cmp-012-topic-setting`, `cmp-013-content-generation` | 문제를 구조화하고 판단하며 아이디어·내용 후보를 만든다.          | 사고와 발상         |
| 구성과 수사        | `cmp-014-organization`, `cmp-015-coherence-cohesion`, `cmp-029-clear-accurate-expression`, `cmp-017-explanation`, `cmp-030-evidence-based-argumentation`   | 내용을 관계로 배열하고 독자가 이해·검증할 수 있는 글로 표현한다. | 구성과 표현         |
| 상황과 과정        | `cmp-019-audience-awareness`, `cmp-020-purpose-genre-awareness`, `cmp-021-self-monitoring`, `cmp-023-revision`, `cmp-031-feedback-use`                     | 수사적 상황과 수행 증거에 따라 쓰기 행동을 조정한다.             | 독자와 쓰기 과정    |
| 정보와 디지털 책임 | `cmp-024-information-search`, `cmp-025-source-credibility`, `cmp-032-source-integration-attribution`, `cmp-033-digital-ai-media-literacy`                  | 정보를 찾고 검증·통합하며 디지털·AI 환경에서 책임 있게 사용한다. | 정보와 AI 문해      |

`cmp-022-background-knowledge`는 모든 역량군에 동원될 수 있는 내용 자원이므로 카테고리 후보에 독립 배치하지 않는다. 인접 역량이 여러 군과 관계하더라도 중복 배정은 4단계의 학습 목표와 코스 구조를 근거로 판단한다.
