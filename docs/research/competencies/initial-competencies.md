# 초기 역량 목록

## 상태

계획에 제시된 26개 명칭은 완전 일치 기준으로 중복되지 않는다. 아래 ID는 3단계 분석의 역사적 시작점이며 삭제하거나 다른 의미로 재사용하지 않는다. 현재 판정과 최종 의미 경계는 [`competency-analysis.md`](./competency-analysis.md), [`final-competency-framework.md`](./final-competency-framework.md), [`initial-to-final-map.md`](./initial-to-final-map.md)가 소유한다.
