# 최종 역량 체계

## 체계 원칙

최종 역량은 다른 역량으로 환원되지 않는 수행과 관찰 가능한 결과를 가진다. 지식·환경·교수법은 선행 조건이나 설계 원리로 분리했다. `높음`은 정의·규범 또는 관계가 직접적이고 독립 계열로 확인된 범위, `보통`은 대상·과제 전이 제한이 있는 범위, `낮음`은 중재 효과·장기 전이의 불확실성이 큰 범위다.

## `cmp-001-vocabulary` 어휘 의미·사용

- 정의·제외: 문맥에서 단어의 의미·용법·관계를 구별하고 적절한 단어를 선택한다. 어휘량·정의 암기만은 제외한다.
- 관계: 문장 이해와 읽기 의미 구성의 구성 요소이고 명료한 표현을 지원한다.
- 관찰 가능한 성과: 낯선 문맥의 뜻을 근거로 설명하고 의미를 보존한 대체어를 선택한다.
- 주장·한계: `clm-language-norms-sentence-clarity-001`, `clm-reading-meaning-construction-002`; 특정 조사 문항이 전체 어휘 능력을 대표하지 않는다.
- 근거 강도: `보통`.

## `cmp-002-sentence-comprehension` 문장 의미 구성

- 정의·제외: 낱말·통사 구조·지시·논리 관계를 통합해 문장 의미와 모호성을 판단한다. 낱말 뜻의 합산은 제외한다.
- 관계: 어휘를 사용하고 읽기 의미 구성과 명료한 표현의 기반이 된다.
- 관찰 가능한 성과: 행위자·대상·조건과 가능한 해석을 복원하고 문맥으로 모호성을 해소한다.
- 주장·한계: `clm-language-norms-sentence-clarity-002`, `clm-reading-meaning-construction-002`; 영어권 기초문해 결과의 직접 전이는 제한된다.
- 근거 강도: `보통`.

## `cmp-003-grammar-orthography` 문법·표기 적용

- 정의·제외: 문법 범주와 현행 규범의 원칙·허용·예외를 문맥에 적용한다. 문체 선호와 소통성 전체는 제외한다.
- 관계: 명료하고 정확한 표현과 인접하지만 규범 정오를 소유한다.
- 관찰 가능한 성과: 새 문장의 표기·띄어쓰기를 고치고 범주·조항·허용형을 설명한다.
- 주장·한계: `clm-language-norms-sentence-clarity-003`, `clm-language-norms-sentence-clarity-005`; 개별 표제어와 규범 상태는 사용 시점에 다시 확인한다.
- 근거 강도: 적용 범위 안 `높음`, 교수 전이 `공백`.

## `cmp-027-reading-meaning-construction` 읽기 의미 구성

- 정의·제외: 목적에 따라 낱말·문장·구조·지식과 추론을 조정해 텍스트베이스와 상황 모형을 구성·점검한다. 출처 신뢰성 판단 전체는 제외한다.
- 관계: `cmp-004`와 `cmp-005`의 병합이며 어휘·문장 이해·추론을 사용한다.
- 관찰 가능한 성과: 핵심·세부·관계와 해석 근거를 설명하고 이해 실패를 수정한다.
- 주장·한계: `clm-reading-meaning-construction-001`~`clm-reading-meaning-construction-007`; 대상별 곤란 프로필과 중재 효과가 이질적이다.
- 근거 강도: 개념 `높음`, 성인 중재 `낮음`.

## `cmp-006-inference` 근거 기반 추론

- 정의·제외: 명시되지 않은 관계를 텍스트·자료와 관련 지식으로 정당화한다. 자유연상과 확정되지 않은 예측은 제외한다.
- 관계: 읽기, 비판적 판단과 논증의 구성 요소다.
- 관찰 가능한 성과: 결론·전제·근거·불확실성을 표시하고 반례에 따라 추론을 수정한다.
- 주장·한계: `clm-inference-critical-judgment-001`, `clm-reading-meaning-construction-003`; 언어·장르·과제에 따라 필요한 추론이 다르다.
- 근거 강도: `보통`.

## `cmp-007-critical-thinking` 비판적 판단

- 정의·제외: 분석·평가·추론과 자기교정을 사용해 판단의 질을 높인다. 무조건적 불신과 오류명 붙이기는 제외한다.
- 관계: 구조적 분석, 정보 신뢰성 판단과 논증을 조정한다.
- 관찰 가능한 성과: 쟁점·가정·근거·대안을 비교하고 결론을 보류·수정한다.
- 주장·한계: `clm-inference-critical-judgment-002`, `clm-inference-critical-judgment-005`~`clm-inference-critical-judgment-008`; 특정 전공 중재의 생활 전이는 낮은 확실성이다.
- 근거 강도: 개념 `높음`, 일반 전이 `낮음`.

## `cmp-028-structured-analysis-integration` 구조적 분석과 통합

- 정의·제외: 자료를 목적에 맞는 요소와 관계로 분해하고 여러 정보·관점을 공통 구조로 통합한다. 분류나 자료 나열만은 제외한다.
- 관계: 초기 논리적 사고·분석·종합의 병합이며 추론과 비판적 판단을 지원한다.
- 관찰 가능한 성과: 기준이 명시된 구조도·비교표·통합 설명을 만들고 충돌·공백을 표시한다.
- 주장·한계: `clm-inference-critical-judgment-003`, `clm-inference-critical-judgment-004`, `clm-inference-critical-judgment-006`; 분류 기준과 통합 구조는 목적·관점에 따라 달라질 수 있다.
- 근거 강도: `보통`.

## `cmp-011-creative-thinking` 창의적 사고

- 정의·제외: 새롭고 적절한 아이디어를 다양하게 생성·평가·개선한다. 아이디어 수·자기효능감만은 제외한다.
- 관계: 주제·내용 생성에 후보를 제공하고 비판적 판단이 평가 국면을 지원한다.
- 관찰 가능한 성과: 다양한 후보와 선택·개선 이유를 독창성·적절성으로 설명한다.
- 주장·한계: `clm-creativity-topic-content-generation-001`, `clm-creativity-topic-content-generation-002`, `clm-creativity-topic-content-generation-005`~`clm-creativity-topic-content-generation-007`; 성인 중재 종합은 이질적이다.
- 근거 강도: 개념 `높음`, 중재 `보통`.

## `cmp-012-topic-setting` 수사적 주제 설정

- 정의·제외: 목적·독자·요구·제약을 수사적 문제로 구성하고 실행 가능한 범위를 정한다. 제목 선택은 제외한다.
- 관계: 독자·목적·장르 인식을 사용해 내용 생성의 방향을 정한다.
- 관찰 가능한 성과: 주제문, 제외 범위와 문제의 담화적 변화 경로를 설명한다.
- 주장·한계: `clm-creativity-topic-content-generation-003`, `clm-audience-purpose-genre-rhetoric-001`; 모든 시급한 문제를 담화로 해결할 수는 없다.
- 근거 강도: `높음`.

## `cmp-013-content-generation` 내용 생성

- 정의·제외: 기억·관찰·자료에서 관련 아이디어와 근거 후보를 생성·확장한다. 검증 없이 복제하는 것은 제외한다.
- 관계: 주제 설정, 정보 탐색과 지식을 사용하고 조직과 왕복한다.
- 관찰 가능한 성과: 목적에 관련된 여러 후보와 근거·출처·선택 이유를 제시한다.
- 주장·한계: `clm-creativity-topic-content-generation-004`, `clm-writing-process-self-regulation-004`; 익숙한 주제의 이점이 낯선 과제 전이를 보장하지 않는다.
- 근거 강도: `보통`.

## `cmp-014-organization` 정보 조직

- 정의·제외: 목적에 맞는 정보를 선택하고 위계·순서·인과·비교 관계로 배열한다. 고정 서식 복제는 제외한다.
- 관계: 내용 생성을 구조화하고 일관성·응집성의 거시 기반이 된다.
- 관찰 가능한 성과: 개요와 글의 관계가 일치하며 재배열 이유를 설명한다.
- 주장·한계: `clm-organization-coherence-expression-001`, `clm-organization-coherence-expression-005`, `clm-organization-coherence-expression-006`; 장르별 전형을 보편 구조로 고정하지 않는다.
- 근거 강도: `보통`.

## `cmp-015-coherence-cohesion` 일관성·응집성 구성

- 정의·제외: 전체 목적에 맞는 의미 관계를 만들고 지시·반복·접속으로 연결을 드러낸다. 표지 수 늘리기는 제외한다.
- 관계: 조직과 문장 표현 사이의 의미·표면 연결을 소유한다.
- 관찰 가능한 성과: 끊김·모순·모호한 지시를 찾아 관계를 보존하며 고친다.
- 주장·한계: `clm-organization-coherence-expression-002`, `clm-organization-coherence-expression-007`; 영어 응집 지표를 한국어에 그대로 적용하지 않는다.
- 근거 강도: `보통`.

## `cmp-029-clear-accurate-expression` 명료하고 정확한 표현

- 정의·제외: 정확한 어휘, 자연스러운 호응, 분명한 지시·관계로 필수 의미를 보존하며 표현한다. 규범 정오·거시 조직 전체는 제외한다.
- 관계: 초기 표현력을 대체하며 어휘·문장 이해·규범·독자 인식을 사용한다.
- 관찰 가능한 성과: 모호하거나 불필요하게 어려운 문장을 고치고 의미 변화와 독자 효과를 설명한다.
- 주장·한계: `clm-language-norms-sentence-clarity-004`~`clm-language-norms-sentence-clarity-007`, `clm-organization-coherence-expression-003`; 공공문서 지침의 장르 전이와 교수 효과는 제한된다.
- 근거 강도: 원리 `높음`, 장기 전이 `공백`.

## `cmp-017-explanation` 독자 중심 설명

- 정의·제외: 개념·과정·관계를 독자가 이해·검증하도록 구조·근거·예시와 표현을 조정한다. 정보 나열은 제외한다.
- 관계: 조직·표현·독자 인식을 사용하며 논증의 입장 정당화와 구별된다.
- 관찰 가능한 성과: 독자가 관계를 재구성하고 근거와 범위를 확인할 수 있는 설명을 만든다.
- 주장·한계: `clm-organization-coherence-expression-004`, `clm-audience-purpose-genre-rhetoric-004`; 특정 학술·공공 장르의 직접 일반화는 제한된다.
- 근거 강도: `보통`.

## `cmp-030-evidence-based-argumentation` 근거 기반 논증

- 정의·제외: 주장을 관련 근거와 추론으로 정당화하고 한계·반론·경쟁 주장을 다룬다. 단순 순응 유도는 제외한다.
- 관계: 초기 설득력을 대체하며 추론·비판적 판단·신뢰성 판단을 사용한다.
- 관찰 가능한 성과: 주장–근거–보증–반론의 관계와 결론의 확실성 범위를 설명한다.
- 주장·한계: `clm-audience-purpose-genre-rhetoric-006`, `clm-inference-critical-judgment-004`; 단일 이론·교수 자료에 의존해 교수 효과 강도는 확정하지 않는다.
- 근거 강도: 정의 `높음`, 교수 효과 `낮음`.

## `cmp-019-audience-awareness` 독자 인식

- 정의·제외: 실제·의도 독자의 지식·입장·요구와 텍스트가 호출하는 역할을 함께 고려한다. 독자에게 무조건 맞추기는 제외한다.
- 관계: 목적·장르 인식과 상호의존하며 설명·논증·표현 선택을 제약한다.
- 관찰 가능한 성과: 같은 내용을 다른 독자에게 조정하고 선택 근거와 예상 한계를 설명한다.
- 주장·한계: `clm-audience-purpose-genre-rhetoric-002`, `clm-audience-purpose-genre-rhetoric-005`; 실제 독자와 예상 독자는 완전히 일치하지 않는다.
- 근거 강도: `높음`.

## `cmp-020-purpose-genre-awareness` 목적·장르 판단

- 정의·제외: 사회적 목적과 공동체 상황에 맞는 장르 관습을 분석·선택·변형한다. 형식 암기는 제외한다.
- 관계: 독자 인식·주제 설정과 연결되고 조직·표현의 선택 범위를 정한다.
- 관찰 가능한 성과: 선택한 장르·관습과 변형 이유를 목적·공동체 근거로 설명한다.
- 주장·한계: `clm-audience-purpose-genre-rhetoric-003`, `clm-audience-purpose-genre-rhetoric-007`; 학교·학술 장르를 생활 글에 그대로 복제하지 않는다.
- 근거 강도: `높음`.

## `cmp-021-self-monitoring` 자기점검·조절

- 정의·제외: 목표·증거·기준으로 수행을 평가하고 다음 행동을 조정한다. 막연한 재독·자신감 보고는 제외한다.
- 관계: 쓰기 전 과정을 가로지르며 수정·피드백 활용·연습 선택을 조정한다.
- 관찰 가능한 성과: 문제·증거·기준·조치·결과가 연결된 점검 기록을 남긴다.
- 주장·한계: `clm-writing-process-self-regulation-002`, `clm-writing-process-self-regulation-005`~`clm-writing-process-self-regulation-007`; 한국어 성인의 장기·생활 전이는 근거 공백이다.
- 근거 강도: 개념 `보통`, 전이 `공백`.

## `cmp-023-revision` 의미 중심 수정

- 정의·제외: 목표와 현재 글의 차이를 진단해 의미·조직·표현을 생성·삭제·대체·재배열한다. 표면 교정만은 제외한다.
- 관계: 자기점검과 피드백 활용을 사용하지만 실제 글 변화를 별도 결과로 소유한다.
- 관찰 가능한 성과: 수정 전후의 의미 있는 변화와 선택·거부 이유를 설명한다.
- 주장·한계: `clm-feedback-revision-assessment-001`, `clm-feedback-revision-assessment-008`; 전략 효과는 숙련도·장르에 따라 달라진다.
- 근거 강도: `높음`.

## `cmp-031-feedback-use` 피드백 생성·판단·활용

- 정의·제외: 자기·동료·교사·도구의 조언을 생성·해석·평가하고 채택·변형·거부해 다음 수행에 사용한다. 코멘트 수집은 제외한다.
- 관계: 새 추가 역량이며 자기점검은 기준 판단을, 수정은 실제 글 변화를 소유한다.
- 관찰 가능한 성과: 조언의 근거·적합성, 처리 결정과 수정·후속 결과를 연결한다.
- 주장·한계: `clm-feedback-revision-assessment-002`~`clm-feedback-revision-assessment-007`; 주체별 품질 편차와 AI 효과의 이질성이 크다.
- 근거 강도: 개념·절차 `높음`, AI 효과 `보통`.

## `cmp-024-information-search` 반복적 정보 탐색

- 정의·제외: 정보 필요를 정의하고 질의·도구·범위를 선택해 결과에 따라 전략을 수정한다. 첫 결과 수용은 제외한다.
- 관계: 주제 설정과 왕복하며 신뢰성 판단·출처 통합에 자료를 제공한다.
- 관찰 가능한 성과: 검색 경로·질의 변경 이유·충분성·중단 기준을 설명한다.
- 주장·한계: `clm-information-source-media-ai-literacy-001`, `clm-information-source-media-ai-literacy-009`; 도구 인터페이스와 결과 순위는 변한다.
- 근거 강도: `높음`.

## `cmp-025-source-credibility` 정보 신뢰성 판단

- 정의·제외: 출처·주장·근거를 구분하고 독립 자료와 원맥락으로 신뢰 범위를 판단한다. 외양 체크리스트 합산은 제외한다.
- 관계: 정보 탐색·비판적 판단을 사용하고 출처 통합·디지털 문해를 지원한다.
- 관찰 가능한 성과: 판단, 근거 경로, 상충 자료와 확신 수준을 제시하고 새 근거에 따라 수정한다.
- 주장·한계: `clm-information-source-media-ai-literacy-002`, `clm-information-source-media-ai-literacy-005`~`clm-information-source-media-ai-literacy-008`; 오정보 중재와 합성 매체 판단의 효과는 조건부다.
- 근거 강도: 절차 `높음`, 중재 `상충·보통`.

## `cmp-032-source-integration-attribution` 출처 통합·귀속

- 정의·제외: 외부·AI 자료의 의미와 한계를 보존해 자신의 글에 통합하고 출처·변형·사용을 투명하게 표시한다. 링크 나열과 형식 암기는 제외한다.
- 관계: 새 추가 역량이며 탐색·신뢰성 판단 뒤 내용 생성·논증·설명에 자료를 연결한다.
- 관찰 가능한 성과: 원문 주장과 자신의 추론을 구분하고 인용·바꿔쓰기·변형·AI 사용의 출처와 범위를 표시한다.
- 주장·한계: `clm-information-source-media-ai-literacy-006`, `clm-information-source-media-ai-literacy-010`, `clm-audience-purpose-genre-rhetoric-004`; 구체 저작권·인용 규정은 관할·장르별로 확인한다.
- 근거 강도: 규범 `높음`, 일반 수행 `보통`.

## `cmp-033-digital-ai-media-literacy` 디지털·AI 매체 문해

- 정의·제외: 디지털·AI 매체의 기능·데이터·알고리즘·위험을 이해하고 결과를 검증하며 책임 있게 생산·공유·참여한다. 기기 조작만은 제외한다.
- 관계: 초기 매체 문해력을 대체하며 탐색·신뢰성 판단·출처 귀속을 통합하되 각 수행을 대신하지 않는다.
- 관찰 가능한 성과: 도구 선택, 결과 검증, 사용 공개, 개인정보·저작권·접근성·공정성 결정을 근거로 수행한다.
- 주장·한계: `clm-information-source-media-ai-literacy-003`~`clm-information-source-media-ai-literacy-010`; 프레임워크는 효과 연구가 아니고 오정보 중재는 상충한다.
- 근거 강도: 개념·규범 `높음`, 특정 중재 `상충·보통`.
