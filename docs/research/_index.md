# 연구 인덱스

## 목적과 권위 경계

`docs/research`는 한국어 글쓰기 교육 콘텐츠를 설계할 때 사용한 출처, 해석, 근거의 한계와 적용 경로를 영구 보존한다. 연구 문서는 현재 제품 정책이나 코스 콘텐츠의 권위 소스가 아니다. 제품 규칙은 `docs/product`가, 현재 콘텐츠 값은 curriculum repository의 persisted data가 소유한다.

연구 결과를 콘텐츠에 적용할 때는 학습자용 문구나 최종 코스 구조를 이 디렉터리에 복제하지 않고 `콘텐츠 ID → 주장 ID → 출처 ID`만 연결한다. 확정 제품 규칙이 생기면 관련 제품 권위 문서를 별도로 갱신한다.

## 탐색 순서

1. 자료의 서지 정보와 실제 접근 범위는 [`sources/_index.md`](./sources/_index.md)에서 시작한다.
2. 여러 자료를 종합한 원리와 충돌은 [`synthesis/_index.md`](./synthesis/_index.md)에서 확인한다.
3. 역량 정의와 관계는 [`competencies/_index.md`](./competencies/_index.md)에서 확인한다.
4. 주장과 출처·콘텐츠의 연결은 [`evidence/_index.md`](./evidence/_index.md)에서 확인한다.
5. 현재 스텝으로 표현하기 어려운 활동은 [`gaps/_index.md`](./gaps/_index.md)에서 확인한다.

## 디렉터리 책임

| 경로            | 책임                                                        |
| --------------- | ----------------------------------------------------------- |
| `sources/`      | 자료별 상세 노트, 출처 목록과 접근 수준                     |
| `synthesis/`    | 복수 자료에서 도출한 원리, 적용 조건과 상반된 견해          |
| `competencies/` | 초기 역량 분석, 최종 역량 체계와 관찰 가능한 학습 성과      |
| `evidence/`     | 내부 주장, 출처와 이후 JSON 콘텐츠 ID 사이의 근거 연결      |
| `gaps/`         | 현재 스텝 계약으로 자연스럽게 구현할 수 없는 교육 활동 공백 |

진행 일정, 검색 이력과 검증 결과는 이 디렉터리가 아니라 해당 `docs/work` 작업 단위에서 관리한다.
