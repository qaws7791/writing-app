# 1단계 실행 기록: 코스~레슨 골격

이 문서는 이 작업 단위 1단계의 실행 결과를 기록한다. 현재 제품 사실의 권위 소스가 아니다. 코스·유닛·레슨의 현재 값은 [`content-seed-data.json`](../../../packages/modules/content/src/infrastructure/persistence/content-seed-data.json)이 소유한다.

## 범위

기존 시드 코스 14개를 폐기하고 `한국어 글쓰기 입문 코스 10선 설계안` v3의 코스~레슨 골격으로 교체했다. 레슨 스텝은 이 단계에서 작성하지 않았다.

## 확정 수량

코스 10개, 유닛 52개, 레슨 308개를 넣었다. 설계안의 코스 순서, 코스·유닛·레슨 제목, 카테고리와 visualKey를 문자 단위로 대조해 일치를 확인했다.

## 레슨 필드 결정

레슨은 `id`, `title`, `time`, `steps` 네 필드만 가진다. `cat`, `desc`, `summary`는 넣지 않았다.

`time`은 전 레슨 `10분`이다. 이 값은 스텝 분량을 확정하기 전의 임시값이므로, 스텝을 채우는 단계에서 레슨별 실제 분량으로 다시 산정한다.

## 표기 교정

설계안 원문에서 확인된 오표기 1건을 고쳤다.

| 위치                                       | 원문                      | 교정                       | 근거                                                                                                                  |
| ------------------------------------------ | ------------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `lesson-paragraph-fake-support-repetition` | 뒷받침을 흉내낸 반복 문장 | 뒷받침을 흉내 낸 반복 문장 | 표준국어대사전에 `흉내`는 명사로 있고 `흉내내다`는 없다. `내다`가 본용언이므로 보조 용언 붙여쓰기 허용 대상이 아니다. |

`묶음`, `묶기`, `가려내기`, `덜어낸`, `걸러내기`, `벌리기`는 확인 결과 오표기가 아니어서 설계안 원문을 유지했다. `덜어낸`처럼 `본용언 + -어 + 내다` 구성은 한글 맞춤법의 보조 용언 붙여쓰기 허용에 해당한다.

## 알려진 제약

모든 레슨의 `steps`가 비어 있어서 다음 두 제약이 남는다. 스텝을 채우면 둘 다 해소된다.

1. 학습자 코스 상세와 진행률 화면은 500으로 실패한다. `learner-read-mapping.ts`의 `toLessonReference`가 스텝 없는 레슨에서 예외를 던지고, 이 경로는 코스를 시작하지 않은 학습자에게도 실행된다. 코스 목록 화면은 레슨 수만 읽으므로 정상 동작한다.
2. 관리자는 시드 코스의 draft를 저장할 수 있지만 발행할 수 없다. `curriculum.ts`의 `empty-step-content` 불변식이 스텝 없는 레슨을 거부한다.

## 후속 작업

- 레슨별 스텝 집필. 이 작업 단위 2단계 요청문은 [`master-prompt-v2.md`](./master-prompt-v2.md)가 정의한다.
- 레슨 `time` 재산정.
- `docs/research/evidence/`의 코스별 근거 문서 재작성. 이전 코스 ID를 가리킨 문서 14개는 이번에 제거했다.

## 함께 변경한 코드

`setup-e2e-content-database.ts`의 E2E fixture 코스 `sortOrder`가 시드 코스 5개를 전제한 상수였다. 시드 코스가 10개로 늘면 값이 겹치고, 학습자 코스 목록 cursor가 `sortOrder`를 페이지 키로 쓰므로 페이징이 어긋난다. 현재 최대 `sortOrder`에서 이어지는 값을 계산하도록 바꿔 시드 코스 수와의 결합을 없앴다.

## 로컬 확인 절차

시드는 코스 ID가 이미 있으면 그 코스를 건너뛴다. 기존 로컬 데이터베이스에는 폐기한 코스 14개가 남아 있으므로, 새 카탈로그만 보려면 초기화가 필요하다.

```sh
bun run db:reset
bun run dev:app:setup
```
