# AI 점검 인라인 마크

## 문서 상태

- 상태: 구현 중
- 영구 결정: [ADR-0038](../../engineering/adr/ADR-0038-inline-writing-check-marks.md)

이 문서는 한시 작업 범위다. 현재 제품 사실은 권위 문서를 따른다.

## 범위

- 고칠 일의 1차 표면은 본문 `MarkNode` 밑줄과 클릭 팝오버다.
- 점검 결과 패널은 잘된 점, 과제 미충족, 남은 고칠 일을 훑는 개요다.
- 저장 형식은 일반 텍스트를 유지한다.

## 완료 기준

- 점검 성공 직후 패널을 자동으로 열지 않는다.
- 본문에 있는 인용 구절에 밑줄이 남고, 그 자리에서 고칠 수 있다.
- 마크를 누르면 이유와 예문이 비모달 팝오버로 열리고 `제거`로 걷을 수 있다.
- 관련 권위 문서와 ADR-0038이 구현과 같다.
