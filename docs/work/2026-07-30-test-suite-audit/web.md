- 가장 시급한 3가지

1. `lesson-step-renderer.test.tsx:17-21`과 `:23-123`. 앞은 `lessonStepRendererByType`가 `satisfies Record<LessonStepType, unknown>`(`lesson-step-renderer.tsx:62`)로 이미 타입 강제하는 key 집합을 다시 단정하고, 뒤는 100줄 루프로 "렌더링 중 예외가 없다"만 확인한다. D-9·D-8·C-12·C-13에 정면으로 걸리는 가장 큰 순수 유지비다.
2. 실시간 타이머 debounce 대기. `lesson-experience.test.tsx:347`의 `{ timeout: 1_500 }`과 `learner-api-ui.integration.test.tsx:125`의 `{ timeout: 2_000 }`은 벽시계로 debounce를 넘긴다(C-3·C-11). 같은 규칙을 `use-lesson-draft-sync.test.tsx`가 fake timer로 799ms/800ms 경계까지 정확히 검증하고 있어 중복이면서 더 느리고 더 불안정하다.
