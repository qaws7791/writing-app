레슨 시작 화면, 시작하고 싶은 느낌

왜 밋밋한가

지금 화면은 레슨 목차를 읽게 한다. 학습자가 고치고 싶은 문장을 보여 주지 않는다.

  1. 본문이 세로 중앙에 떠 있어 빈 방이 된다.
  2. 제목이 학습 목표 문장이라 손이 가지 않는다.
  3. 활동 종류 여섯 줄은 숙제 목록처럼 읽힌다.
  4. 시작하기는 다음에 무엇을 하는지 말하지 않는다.
  5. 유닛 위치와 첫 활동이 보이지 않아 오리엔트가 없다.

듀오링고에서 가져올 것은 캐릭터가 아니다. 첫 조작까지 시간을 줄이는 일이다. 브릴리언트에서 가져올 것은 원색이 아니다. 개념을 공간으로 보여 주는 일이다. 글결은 과장된 보상 없이 문장 자체를 재료로 쓴다. 예상 시간은 시작 화면에 두지 않는다. 방향은 A다. 이번 스프린트는 C다. 제품에 넣을 조합은 C의 위 정렬, A의 문장 카드, C의 CTA 부제다.
