# 5단계 코스별 구축 현황

## 운영 기준

4단계에서 승인된 순서대로 한 코스씩 `근거 확인 → 구조 설계 → 집필 → 내부 검수 → 기술 검증 → 잠정 동결`한다. 잠정 동결 전에는 다음 코스를 집필하지 않으며 첫 코스는 사용자 승인도 받아야 한다.

| 순서 | 코스 ID                                 | 상태             |
| ---: | --------------------------------------- | ---------------- |
|    1 | `course-word-sentence-meaning`          | 사용자 검토 대기 |
|    2 | `course-reading-structure-main-ideas`   | 대기             |
|    3 | `course-clear-accurate-expression`      | 대기             |
|    4 | `course-grammar-orthography`            | 대기             |
|    5 | `course-idea-topic-development`         | 대기             |

|    7 | `course-audience-purpose-genre`         | 대기             |

|    9 | `course-evidence-based-inference`       | 대기             |
|   10 | `course-information-search-credibility` | 대기             |

첫 코스의 설계와 검수 기록은 [`course-word-sentence-meaning.md`](./course-word-sentence-meaning.md)에 둔다.

첫 코스는 격리 시드와 전체 레슨 브라우저 검증까지 마쳤다. 다음 코스는 첫 코스의 구조·깊이·활동 방식에 대한 사용자 승인 뒤에 시작한다.
