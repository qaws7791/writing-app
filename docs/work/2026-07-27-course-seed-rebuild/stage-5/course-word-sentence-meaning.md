# 어휘와 문장의 의미 정확히 읽기 구축 기록

## 범위와 설계

- 상태: 기술 검증 완료, 사용자 검토 대기
- 주역량: `cmp-001-vocabulary`, `cmp-002-sentence-comprehension`
- 보조 역량: `cmp-027-reading-meaning-construction`, `cmp-029-clear-accurate-expression`
- 종료 성과: 문맥에 맞는 단어 뜻과 쓰임을 근거로 설명하고, 문장의 참여자·조건·지시·논리 관계를 복원하며, 모호한 해석을 구분해 의미를 보존한 문장으로 고친다.
- 제외 범위: 어휘량 암기, 독해 전체, 문법·표기 정오, 일반 명료성 편집과 장기 전이 효과

| 유닛                          | 레슨                                                                                      | 설계 역할                       |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------- |
| 문맥에서 단어 의미 찾기       | 문맥 단서로 단어 뜻 좁히기, 뜻뿐 아니라 쓰임까지 구별하기, 필수 의미를 지키며 바꿔 쓰기   | 단어 의미 선택과 의미 보존      |
| 문장 안의 관계 복원하기       | 누가 무엇을 했는지 복원하기, 수식 범위와 조건 정확히 읽기, 지시 대상과 논리 관계 연결하기 | 문장 수준 관계 통합             |
| 이해 실패를 진단하고 해소하기 | 이해가 막힌 지점 진단하기, 근거로 해석하고 모호성을 해소하기                              | 구성 요소 진단과 통합 독립 수행 |

AI 피드백은 마지막 통합 쓰기 한 곳에만 연결했다. 가능한 지시 대상, 문맥 근거와 의미 보존을 함께 판단하는 복수 답안 과제여서 구체적 수정 조언이 유효하기 때문이다.

현재 10개 타입 가운데 9개를 사용했다. `ORDER`는 한국어 문장 성분의 여러 허용 가능한 배열을 하나의 정답 순서로 강제할 위험이 있어 이 코스 목표에는 사용하지 않았다.

## 자체 집필과 검수

코스·유닛·레슨의 설명, 41개 스텝의 예문·지문·선택지·해설·참조 답안은 모두 이번 작업에서 자체 집필했다. 외부 문구의 인용·각색과 사실 자료 재현은 사용하지 않았다. 연구 자료는 학습 목표와 판단 원리의 근거로만 사용했으며 연결은 [`course-word-sentence-meaning.md`](../../../research/evidence/course-word-sentence-meaning.md)에 기록한다.
