# 코스 시드 콘텐츠 전면 재구축 계획

## 목표

프로토타입인 현재 코스 시드를 폐기하고, 신뢰할 수 있는 국내외 자료에 근거한 한국어 글쓰기 역량 교육 콘텐츠로 전면 재구축한다. 조사 지식은 `docs/research`에 영구 보존하고, 실제 코스·유닛·레슨·스텝 콘텐츠는 [`content-seed-data.json`](../../../packages/modules/content/src/infrastructure/persistence/content-seed-data.json)만 단일 원천으로 관리한다.

완성도는 실제 외부 전문가 검수를 의미하지 않는다. 근거 추적, 국어, 교육 설계, 작문, 활동, 저작권과 기술 계약에 대한 내부 검수를 모두 통과한 서비스 투입 가능 수준을 목표로 한다.

## 확정 범위

- 핵심 학습자는 한국어가 모어인 일반 성인이다.
- 코스는 서로 독립적이며 다른 코스 수강을 전제로 하지 않는다.
- 특정 직업, 입시, 문학 창작이나 학술 논문 같은 분야별 코스는 만들지 않는다.
- 최초 26개 역량은 누락 방지 기준으로 보존하되 조사 결과에 따라 명칭, 계층, 묶음과 추가 역량을 확정한다.
- 코스 수는 자료 조사와 역량 분석 뒤 10~20개 내외에서 확정한다.
- 코스·유닛·레슨·스텝 수, 학습 시간, 이론·실습 비율과 레슨 흐름에는 공통 할당량을 두지 않는다.
- 읽기·이해·사고·정보 판단 역량은 반드시 직접 쓰기 결과물로 이어지지 않아도 독립적인 학습 목표가 될 수 있다.
- 종합 쓰기 과제와 AI 피드백은 필수가 아니며 코스 목표에 유효할 때만 사용한다.
- 현재 10개 스텝 타입만 사용한다. 더 적절한 활동은 구현하지 않고 후속 검토 대상으로 기록한다.
- 기존 5개 `visualKey`는 여러 코스가 공유한다.
- 코스·유닛·레슨 ID는 의미가 드러나는 안정적인 kebab-case로 전면 교체한다.
- 출처 연결은 내부 검수에만 사용하며 학습자용 콘텐츠에 기본 노출하지 않는다.

최초 역량 목록은 어휘력, 문장 이해력, 문법·표기 능력, 독해력, 핵심 내용 파악 능력, 추론 능력, 비판적 사고력, 논리적 사고력, 분석력, 종합력, 창의적 사고력, 주제 설정 능력, 내용 생성 능력, 조직력, 일관성과 응집성, 표현력, 설명력, 설득력, 독자 인식 능력, 목적과 장르 인식 능력, 자기 점검 능력, 배경지식, 수정 능력, 정보 탐색 능력, 정보 신뢰성 판단 능력, 매체 문해력이다.

## 변경 경계

- 제품 코드에서는 `content-seed-data.json`만 수정한다.
- 조사·분석·작업·권위 문서에 필요한 `/docs` 변경은 허용한다.
- 자료 분석과 JSON 검증을 위한 일회성 스크립트는 작업 디렉터리나 임시 디렉터리에서 작성·실행할 수 있다. 제품 런타임에는 포함하지 않는다.
- 새 스텝 타입, 계약, UI, 이미지 체계와 외부 전문가 검수는 이번 범위가 아니다.
- 실제 학습자가 없으므로 기존 ID와 시드 호환성은 보존하지 않는다.

## 연구 문서 구조

첫 조사 전에 다음 구조와 각 하위 인덱스를 만든다.

```text
docs/research/
  _index.md
  sources/
  synthesis/
  competencies/
  evidence/
  gaps/
```

- `sources`: 자료별 상세 연구 노트와 출처 목록
- `synthesis`: 여러 자료에서 도출한 원리, 쟁점, 상반된 견해와 적용 조건
- `competencies`: 최초 26개와 추가 역량의 정의, 관계와 관찰 가능한 학습 성과
- `evidence`: 내부 주장 ID, 출처 ID와 최종 JSON 콘텐츠 ID의 근거 연결
- `gaps`: 기존 스텝으로 표현하기 어려운 교육 활동과 제품 기능 공백

`docs/research`에는 최종 코스 구조나 학습자용 문구를 복제하지 않는다. 코스 정보의 단일 원천은 JSON이며, 연구 문서에는 근거와 JSON ID의 연결만 둔다. 진행 계획과 검증 기록은 이 작업 디렉터리에 두고 완료 후 `docs/archive`로 이동한다.

## 자료 수집 기준

### 포함

1. 국립국어원, 교육부, 한국교육과정평가원 등 공공기관 자료
2. 국내외 학술 논문, 학술 단행본, 대학과 연구기관 자료
3. 국어학, 작문교육, 수사학과 관련된 전문서 및 일반 출판 도서
4. 대학 공개강의와 저자·제작 주체를 확인할 수 있는 전문 강의
5. 저자와 출판·제작 주체가 명확한 전문 매체 자료
6. 초록, 목차, 출판사 상세 페이지, 공식 강의 소개, 신뢰할 수 있는 제3자의 리뷰와 요약

일반 블로그와 커뮤니티는 검색·수집 대상에서 제외한다. 발행 연도 제한은 두지 않되 현재 규범은 최신 권위 자료를 우선하고, 오래된 이론은 현재 유효성과 시대적 전제를 확인한다.

### 자료별 기록

각 자료 노트에는 다음을 기록한다.

- 출처 ID, 제목, 저자·전문성, 기관·출판사, 자료 유형
- 발행 연도, URL·DOI·ISBN, 접근일과 검색 경로
- `직접 근거`, `제한적 근거`, `간접 근거` 중 접근 수준
- 원문을 다시 열지 않고도 분석할 수 있는 상세 요약과 핵심 논지
- 추출한 원리, 근거, 예시의 요지, 적용 조건과 한계
- 관련 역량 ID, 상충 자료와 교차 검증 상태
- 필요한 최소한의 짧은 인용과 정확한 위치

원문 파일, 장문 전재, 강의 자막 전문과 사실상 원문을 대체하는 복제는 저장하지 않는다. 간접 자료로 파악한 내용을 원저자의 직접 주장처럼 단정하지 않는다.

### 수집 종료 조건

- 모든 초기 역량에 관련 근거가 확보된다.
- 핵심 원리는 가능한 경우 독립된 두 자료 이상으로 확인된다.
- 한국어 고유 원리에는 국내 권위 자료가 포함된다.
- 상반된 견해와 적용 조건이 정리된다.
- 반복 검색에서 새로운 핵심 원리나 관계가 거의 추가되지 않는다.
- 남은 근거 부족 영역은 억지로 채우지 않고 `근거 공백`으로 기록한다.

## 실행 단계

### 1. 연구 기반 마련

상태: 2026-07-27 완료. 연구 자료 수집은 아직 시작하지 않았다.

1. `docs/research` 구조와 인덱스를 만들고 `docs/_index.md`와 `docs/authority-map.md`에 비권위 연구 지식의 역할을 연결한다.
2. 중복을 제거한 최초 26개 역량에 임시 ID를 부여한다.
3. 출처 노트 형식, 접근 수준, 주장 ID와 근거 연결 규칙을 확정한다.
4. 검색어, 대상 데이터베이스, 포함·제외 사유를 기록할 조사 로그를 연다.

### 2. 전체 자료 수집

상태: 2026-07-27 완료. 사용자 제공 후보 294건을 전수 판정해 무료 원문·차별적 학습 근거를 충족한 125건을 채택하고, 기존 43건과 합친 활성 출처 168건의 원문 상세 추출과 전수 감사를 마쳤다. 오픈 액세스 서지만 확인되고 전문을 직접 검증하지 못한 `src-0114`는 미활성 ID로 보존하고 채택 수에서 제외했으며 다음 신규 ID는 `src-0175`다. 상세 결과는 [`source-extraction-audit.md`](./source-extraction-audit.md)에 기록했다.

1. 국내 공공기관·학술·도서·강의 자료를 역량별로 탐색한다.
2. 해외 작문교육·수사학·인지과학·정보 문해력 자료를 함께 탐색한다.
3. 웹 검색을 우선 사용하고, 동적 페이지나 기존 브라우저 접근 상태가 필요한 경우 Chrome을 사용한다.
4. 자료마다 상세 마크다운 노트를 작성하고 접근 수준과 신뢰도를 표시한다.
5. 원리별로 교차 검증하며 포화도 기준을 충족할 때까지 빈 영역을 반복 조사한다.

### 3. 자료 분석과 역량 체계 확정

상태: 2026-07-27 완료. 활성 출처 168건을 75개 원자적 주장으로 종합하고 최종 24개 역량과 초기–최종 대응표를 확정했다. 3단계 신규 출처는 없으며 상세 결과는 [`stage-3-analysis-audit.md`](./stage-3-analysis-audit.md)에 기록했다.

1. 자료별 주장을 원리 단위로 분해하고 중복, 충돌, 규범과 실제 사용을 구분한다.
2. 최초 26개 역량을 정의하고 상위·하위 및 인접 관계를 분석한다.
3. 복수 근거가 있는 독립 역량만 제한적으로 추가한다.
4. 각 역량에 관찰 가능한 학습 성과와 관련 원리를 연결한다.
5. 역량군과 카테고리 후보를 자료에서 도출하되 이 단계 전에는 확정하지 않는다.
6. 최초 목록과 최종 역량 체계의 대응표를 완성한다.

### 4. 전체 코스 구상

상태: 2026-07-27 완료. 14개 코스, 24개 주역량 배정, 제목·설명·카테고리·추천 순서와 `visualKey` 재사용을 첫 번째 사용자 검토에서 승인받았다. 상세 결과는 [`stage-4-course-catalog.md`](./stage-4-course-catalog.md)에 기록했다.

1. 역량×코스 후보 행렬을 만들고 각 코스에 1~3개 주역량과 필요한 보조 역량을 배정한다.
2. 독립성, 충분한 근거, 고유한 학습 목표와 다른 코스와의 중복 정도를 기준으로 병합·분리한다.
3. 10~20개 내외의 최종 코스 수, 제목, 설명, 카테고리와 정렬 순서를 확정한다.
4. 모든 코스가 독립적으로 이해 가능한지 확인하고 특정 분야에 치우친 코스를 제거한다.
5. 승인된 전체 카탈로그는 4단계 작업 문서에 고정하고, 빈 published 코스를 피하기 위해 JSON에는 5단계에서 검수 완료된 코스부터 반영한다.
6. 첫 번째 사용자 검토 지점에서 전체 코스 구성과 역량 배정을 승인받는다.

### 5. 코스별 순차 구축

상태: 첫 코스 `course-word-sentence-meaning`의 내부·기술 검증을 완료하고 두 번째 사용자 검토를 기다린다. 사용자 승인 전에는 두 번째 코스를 시작하지 않는다.

상태와 순서는 [`stage-5/_index.md`](./stage-5/_index.md)에서 관리한다. 한 코스를 `근거 확인 → 구조 설계 → 집필 → 내부 검수 → 기술 검증 → 잠정 동결`까지 완료하기 전에는 다음 코스를 집필하지 않는다.

1. 승인된 주·보조 역량, 주장, 근거 강도와 한계를 다시 확인하고 종료 성과·제외 범위·대표 평가 활동을 고정한다.
2. 유닛은 종료 성과의 하위 단계로, 레슨은 하나의 관찰 가능한 목표로 설계한다. 공통 수량을 맞추지 않고 목표 달성에 필요한 최소 구성만 둔다.
3. 레슨별로 설명, 분석, 판단, 안내 연습과 독립 수행 가운데 필요한 활동을 선택한다. 교수 원리를 고정 공식이나 효과 보장으로 표현하지 않는다.
4. 학습자용 문구는 `content-seed-data.json`에만 작성한다. 코스·유닛·레슨 ID는 의미 기반 kebab-case로 만들고 선택형 항목과 AI 피드백 참조는 stable ID를 사용한다.
5. 첫 코스가 검수를 통과할 때 기존 프로토타입 코스를 제거하고 첫 완성 코스만 원자적으로 반영한다. 이후에는 동결 코스를 보존하며 승인 순서대로 완성 코스를 추가한다.
6. 예문, 지문, 선택지, 해설과 참조 답안은 자체 집필을 기본으로 하고 코스별 기록에 콘텐츠 ID 단위의 자체 집필·각색·짧은 인용 판정을 남긴다.
7. 설명은 `-습니다`, 활동은 `-해 보세요`를 기본으로 하며 규범·권장·선택·조건부 연구 결과를 구분한다. 효과와 생활 전이를 보장하지 않는다.
8. AI 피드백은 복수의 타당한 답이 있고 구체적인 수정 조언이 유용한 선행 `WRITE`에만 연결한다.
9. 코스별 evidence 문서에는 `콘텐츠 ID → 주장 ID → 적용 방식 → 근거 한계`만 기록하고 학습자 문구나 전체 구조를 복제하지 않는다.
10. 현재 스텝으로 부자연스러운 활동은 구현하지 않고 `docs/research/gaps`에 기록한다.
11. 내부 검수와 격리 DB·브라우저 검증을 통과하면 코스 객체의 정규화 SHA-256을 기록하고 잠정 동결한다. 이후 변경은 6단계 전체 감사에서 발견된 문제로 제한한다.
12. 첫 코스 `course-word-sentence-meaning` 동결 후 전체 구조, 렌더링, 대표 활동과 감사 결과를 두 번째 사용자 검토 지점에서 승인받는다.

사용자 결정에 따라 기존 시드 수량과 `c1`·`l1`을 고정한 두 테스트 파일은 5단계에서 수정하지 않는다. 임시 감사로 현재 JSON의 전체 DTO 계약과 시드 결과를 별도 검증하고, 전체 테스트에서는 두 파일의 예상된 시드 기대값 실패 외 다른 실패를 허용하지 않는다. 이 선택은 전체 테스트 green과 저장소 완료 조건을 충족하지 못하는 명시적 기술 부채이며 별도 승인 없이 해소하거나 완료로 표현하지 않는다.

### 6. 전체 카탈로그 감사와 확정

1. 모든 최초·추가 역량의 실질적 반영 여부와 과소·과다 배분을 확인한다.
2. 코스 간 중복, 용어·문체, 예시 편향, 난이도와 카테고리 일관성을 확인한다.
3. 최종 감사에서 발견된 문제에 한해 동결된 코스를 수정하고 코스 검수를 다시 실행한다.
4. 지원되지 않는 활동 제안 전체를 사용자가 검토할 수 있게 정리한다.
5. 세 번째 사용자 검토 지점에서 전체 카탈로그와 스텝 공백을 승인받는다.
6. 최종 코스·유닛·레슨·스텝 수와 목록에 맞춰 제품 권위 문서를 갱신한다.
7. 영구 결론은 제품·연구 문서에 반영하고 이 작업 디렉터리는 `docs/archive`로 이동한다.

## 코스 완료 조건

각 코스는 다음 항목을 모두 통과해야 한다.

- 근거: 핵심 원리와 내부 근거의 연결 및 근거 강도 표현이 정확하다.
- 국어: 최신 공식 규범, 실제 사용, 권장과 문체 선택을 구분한다.
- 교육 설계: 목표, 설명, 예시와 활동이 정렬되고 불필요한 반복이 없다.
- 작문: 성인에게 자연스럽고 명료하며 정확한 한국어를 사용한다.
- 활동: 정답과 오답의 이유가 명확하고 해설이 판단 근거를 설명한다.
- 예시: 목표 원리를 정확히 보여주며 편향, 사실 오류와 출처 없는 복제가 없다.
- 저작권: 인용, 각색과 자체 작성이 내부 기록에서 구분된다.
- 기술: 의미 기반 ID, 정렬, 스텝 계약과 AI 피드백 대상이 모두 유효하다.

## 기술 검증

1. 일회성 감사로 중복 ID, 빈 필수 필드, 잘못된 참조, 비정상 글자 수 기준, 중복 선택지와 정답 모호성을 탐지한다.
2. 콘텐츠 모듈 테스트로 JSON 정규화와 모든 스텝 DTO 계약을 검증한다.
3. 테스트 전용 인증과 격리된 데이터베이스로 시드를 적용해 코스 목록, 상세와 모든 스텝 유형을 브라우저에서 확인한다.
4. `bun lefthook run pre-commit`, `bun run typecheck`, `bun run test`, `bun run build`를 최종 실행한다.
5. 시작한 개발 서버와 보조 프로세스를 모두 종료한다.

## 완료 판정의 한계

이 계획은 근거 기반 집필과 내부 검수의 품질을 보장하는 절차다. 실제 전문가 검수나 실제 학습자의 성취 향상은 검증하지 않으므로 그런 표현을 사용하지 않는다. 출시 후 학습 데이터와 사용자 피드백에 따른 교육 효과 검증은 별도 후속 작업이다.
