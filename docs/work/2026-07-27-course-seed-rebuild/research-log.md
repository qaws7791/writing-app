# 코스 시드 재구축 조사 로그

## 상태

- 개설일: 2026-07-27
- 상태: 기존 43건과 신규 무료 원문 125건의 상세 추출 완료, 2단계 완료·3단계 미착수
- 영구 연구 결과 위치: [`../../research/_index.md`](../../research/_index.md)

이 로그는 검색의 재현성과 포함·제외 판단을 남기는 한시 작업 기록이다. 채택한 자료의 상세 내용은 `docs/research/sources`에 출처 노트로 옮기며, 작업 완료 후 이 로그는 작업 디렉터리와 함께 `docs/archive`로 이동한다.

사용자 제공 추가 후보 294건의 전수 판정, 무료 원문 확인과 영역별 상세 결과는 [`supplemental-source-review.md`](./supplemental-source-review.md)에서 시작한다.

## 추가 수집 완료

사용자 제공 후보 294건을 전수 판정해 무료 전문과 차별적 근거를 모두 충족한 125건을 추가했다. 판정 결과는 채택 125건, 기존 중복 17건, 유료·초록만 89건, 근거 중복 35건, 범위 제외 26건, 원문 재접속 미해결 2건이다. 미해결 자료는 내용을 추정하거나 대체 자료로 수를 맞추지 않았다.

신규 125건은 모두 본문·표·그림·부록의 실제 확인 위치를 포함한 직접 근거 노트로 작성했다. 기존 43건과 합친 최종 활성 출처는 168건이며 직접 근거 164건, 제한적 근거 4건, 국내 74건, 해외 94건이다. `src-0114`는 전문 미확인 상태로 미활성 보존하고 다음 신규 ID는 `src-0175`로 유지한다.

전수 구조·추출·중복·링크·집계 결과는 [`source-extraction-audit.md`](./source-extraction-audit.md), 최종 자료 집합과 역량별 연결 수는 [`collection-audit.md`](./collection-audit.md)에 기록한다. 자료 사이의 주장 분석, 역량 체계 확정과 코스 설계는 3단계이므로 이 로그에서는 시작하지 않는다.
