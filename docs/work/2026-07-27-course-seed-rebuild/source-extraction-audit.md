# 원문 기반 학습 내용 추출 감사

## 목적

활성 출처 168건이 단순 서지·초록 요약이 아니라 원문을 다시 열지 않고도 학습 설계 입력을 검토할 수 있는 수준인지 확인한다. 이 감사는 2단계 자료 수집의 완결성만 판정하며, 자료 간 주장 분석·역량 체계 확정·코스 설계는 다루지 않는다.

## 출처별 완료 기준

각 출처 노트는 다음을 모두 충족해야 한다.

1. 실제로 연 원문 PDF·HTML·전자책의 정확한 URL과 형식을 기록한다.
2. 원문 분량, 실제 확인한 장·절·쪽·표·그림·부록과 전체·부분 확인 여부를 기록한다.
3. 원문의 논증 구조를 장·절 단위로 설명하고 저자 주장과 적용 추론을 구분한다.
4. 가르칠 개념·원리와 혼동하기 쉬운 개념의 경계를 설명한다.
5. 학습자가 수행할 전략, 판단 질문과 멈춤 조건을 제시한다.
6. 원문의 사례·과제·도식·관찰 결과를 장문 전재 없이 재서술한다.
7. 오류·오개념의 진단 단서와 교정 방법을 연결한다.
8. 관찰 가능한 수행, 평가 기준과 피드백 초점을 제시한다.
9. 연구 대상·언어·연령·과제·매체·설계와 한국어 모어 일반 성인에게 전이할 때의 한계를 기록한다.
10. 관련 역량별 학습 내용·활동·성과와 다른 역량과의 경계를 연결한다.
11. 교차 확인 자료, 상충점과 미확인 내용을 기록한다.
12. 필요한 짧은 인용만 정확한 위치와 함께 사용한다.

신규 125건에는 서로 다른 원문 위치의 추출 행을 5개 이상 요구한다. 5행은 최소 감사 기준이며 관련 내용이 더 많으면 모두 기록한다.

## 접근 실패 처리

- 공식 원문 접근이 실패하면 PMC·ERIC·기관 저장소·저자 원고 순으로 합법적인 공개 판본을 찾고 판본 관계를 기록한다.
- 끝내 전문을 열지 못하면 확인한 초록·목차·서지·공식 소개의 범위와 미확인 부분을 구체적으로 적는다.
- 미확인 본문의 방법·수치·사례를 추정하거나 다른 출처의 내용으로 채우지 않는다.
- `src-0114`는 오픈 액세스 서지만 확인하고 전문을 직접 검증하지 못해 미활성으로 보존한다.

## 원문 표본 대조

신규 작성 담당자의 전수 확인과 별도로 영역별 표본을 다시 대조했다.

- A 영역은 `src-0100`의 PMC 저자 원고와 `src-0101`의 Utrecht CC BY 출판본에서 실제 표제·방법·표·효과크기·한계를 확인했다. 후보 제목과 실제 표제가 다른 `src-0100`, `src-0101` 초록과 표 3의 소수점 차이는 노트에 충돌로 보존했다.
- B·C 영역은 `src-0126`~`src-0129`의 KCI·학술지 무료 PDF 전 페이지와 표·그림을 대조했다. `src-0126`의 후보 발행 연도는 원문과 KCI 서지에 따라 2014년으로 교정했다.
- E 영역은 `src-0160`~`src-0166`의 공개 본문, 보충자료와 정정 이력을 대조했다. 공식 호스트 장애가 있던 `src-0165`·`src-0166`은 동일 공개 판본과 공식 서지를 함께 확인하고 접근 차이를 기록했다.
- 기존 신규분에서는 `src-0066`의 10개 학습기법 상대 효용, `src-0099`의 실제 저자·표제와 40쪽 원고, `src-0159`의 표 1–9·보충 표와 이질성 한계를 원문과 다시 대조했다.

표본 대조는 모든 연구 결과의 재분석이나 효과 재추정을 뜻하지 않는다. 원문 식별, 기록 위치, 수치 방향, 적용 한계가 노트와 일치하는지만 확인했다.

## 판정

활성 출처 168건에서 확인 가능한 원문 내용을 2단계 분석 입력으로 사용할 수 있는 수준으로 추출했다. 전문을 확보하지 못한 4건은 확인 범위와 미확인 범위를 분리했고, 전문을 검증하지 못한 `src-0114`는 활성 자료에 포함하지 않았다. 구조·위치·중복·카탈로그·링크 감사 결과 문제는 0건이므로 2단계 전체 자료 수집을 완료로 판정한다.

이 판정은 문헌 추출의 완료다. 출처 사이의 주장 상태, 최종 역량 구조, 코스 구성과 교수 효과의 판단은 미착수한 3단계 범위다.
