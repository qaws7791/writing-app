## 정보 구조 원칙

글숨 Labs의 정보 구조는 첫 문장 루프를 방해하지 않는 데 집중한다.

핵심 루프:

> 사진 업로드 → 표현 재료 선택 → 문장 씨앗 조립 → 한 문장 작성 → 표현 카드 저장

창작 화면에서는 글로벌 내비게이션, 업그레이드, 최근 업로드, 전체 진행 지도, 도움말 카드, 저장 공간 표시를 기본 노출하지 않는다.

## 모바일 하단 탭

모바일 하단 탭은 4개로 제한한다.

```
[ 홈 ]  [ 사진 ]  [ 정원 ]  [ 더보기 ]
```

| 탭     | 역할                                          | 기본 노출                                            |
| ------ | --------------------------------------------- | ---------------------------------------------------- |
| 홈     | 사용자의 에너지 상태에 맞는 시작점 제안       | 오늘의 진입 카드 3개, 최근 작업 1개, 정원 요약 1개   |
| 사진   | 사진 한 장에서 표현 재료를 고르는 창작 진입점 | 업로드, 분석 상태, Calm Mode                         |
| 정원   | 저장한 표현 자산을 다시 찾고 재사용하는 공간  | 오늘 저장한 카드, 최근 문장 카드, 다시 써볼 카드 1개 |
| 더보기 | P1 이후 기능과 설정의 보조 진입점             | 장면 원정, 문장 아케이드, 설정, 데이터 관리          |

## V1 상위 내비게이션

V1에서 제품이 가질 수 있는 주요 목적지는 최대 5개다.

1. 홈
2. 사진 글감
3. 장면 원정
4. 문장 아케이드
5. 문체 정원

리듬룸과 문장 지문은 독립 메뉴가 아니다. 문체 정원 또는 저장 문장 상세에서 진입한다.

MVP에서는 홈, 사진 글감, 문체 정원 Lite만 구현한다. 장면 원정과 문장 아케이드는 더보기 또는 홈 카드의 비활성/예정 항목으로만 남긴다.

## 전체 화면 구조

```text
앱
├── 홈
│   ├── 인사 문장
│   ├── 오늘의 진입 카드 3개
│   │   ├── 사진으로 시작
│   │   ├── 저장한 재료 이어가기
│   │   └── 짧은 문장 훈련
│   ├── 최근 작업 1개
│   └── 문체 정원 요약 1개
│
├── 사진
│   ├── 사진 글감 Empty State
│   ├── 사진 글감 Analyzing State
│   ├── 사진 글감 Ready State: Calm Mode
│   ├── 재료 바구니
│   ├── 문장 씨앗 조합기
│   └── 한 문장 에디터
│
├── 정원
│   ├── 오늘 저장한 카드
│   ├── 최근 문장 카드
│   ├── 다시 써볼 카드 1개
│   └── 카드 상세
│
└── 더보기
    ├── 장면 원정 Lite (P1)
    ├── 문장 아케이드 (P1)
    ├── 리듬룸 진입 안내 (P1)
    ├── 문장 지문 진입 안내 (P1)
    └── 설정과 데이터 관리
```

## 창작 Shell

창작 화면에서 표시하는 것:

- 현재 화면명
- 나가기 또는 뒤로 가기
- 현재 작업 상태 한 줄
- 현재 Primary CTA

창작 화면에서 숨기는 것:

- 업그레이드 카드
- 저장 공간
- 최근 업로드 목록
- 전체 메뉴 확장
- 여러 개의 도움말 카드
- 전체 진행 지도
- 보상과 통계 카드

## 사진 글감 상태

```text
idle
→ uploading
→ analyzing
→ ready
→ collecting
→ seed_ready
→ drafting
→ saved
```

| 상태       | 핵심 행동                       | 화면 원칙                            |
| ---------- | ------------------------------- | ------------------------------------ |
| idle       | 사진 선택                       | 업로드 영역과 짧은 안내 문장 1개     |
| uploading  | 기다리기 또는 취소              | 사진 미리보기와 취소만 제공          |
| analyzing  | 기다리기                        | 진행 배지를 여러 개 나열하지 않음    |
| ready      | 재료 고르기                     | 활성 레이어 칩 3~5개                 |
| collecting | 재료 더 고르기 또는 씨앗 만들기 | 접힌 재료 바구니 표시                |
| seed_ready | 한 문장으로 쓰기                | 조합기가 중심, 오버레이는 축소       |
| drafting   | 문장 저장하기                   | 사진, 선택 재료, 입력창, 미션만 유지 |
| saved      | 정원에 저장됨                   | 저장 결과와 다음 행동 1개            |

## 패널 규칙

- 우측 패널과 하단 패널은 동시에 열리지 않는다.
- 재료 바구니 상세는 사용자가 열 때만 표시한다.
- 팁 패널은 사용자가 20초 이상 행동하지 않거나 도움말을 눌렀을 때만 나타난다.
- 보상과 요약은 행동 중이 아니라 행동 후에 보여준다.
- 최근 업로드는 홈 또는 업로드 모달에서만 보인다.
