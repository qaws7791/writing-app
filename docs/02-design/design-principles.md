## 원칙 1. Calm Mode가 기본값이다

모든 창작 화면의 기본 상태는 Calm Mode다.

Calm Mode에서는 현재 행동에 필요한 최소 정보만 보여준다. 전체 자산, 진행 지도, 보상, 최근 항목, 도움말, 빠른 액션은 기본 화면에 동시에 노출하지 않는다.

적용 기준:

- 사진 위 칩은 기본 3~5개만 보인다.
- 재료 바구니는 기본 접힌 하단 바로 시작한다.
- 상세 패널은 사용자가 명시적으로 열 때만 보인다.

## 원칙 2. 한 화면에는 하나의 의도만 둔다

보기, 고르기, 수집하기, 조립하기, 쓰기, 듣기, 저장하기는 단계적으로 분리한다.

| 항목              | 기준                   |
| ----------------- | ---------------------- |
| 한 화면의 주 행동 | 최대 1개               |
| 보조 행동         | 최대 2개               |
| Primary CTA       | 최대 1개               |
| 동시에 열린 패널  | 최대 1개               |
| 상태 배지         | 1문장 상태 표시로 대체 |

CTA 문구는 결과를 말해야 한다. "다음"보다 "문장 씨앗 만들기", "한 문장으로 쓰기", "정원에 저장하기"를 사용한다.

## 원칙 3. 생성보다 선택을 먼저 둔다

AI가 완성문을 주기 전에 사용자가 먼저 관찰하고 선택한다.

나쁜 흐름:

> 사진 업로드 → AI 완성문 선택 → 저장

좋은 흐름:

> 사진 업로드 → 표현 재료 선택 → 문장 씨앗 조립 → 직접 작성 → 저장

## 원칙 4. Focus Mode는 쓰기와 듣기에만 사용한다

사용자가 직접 문장을 쓰거나 문장을 듣는 순간에는 화면을 더 줄인다.

Focus Mode에서 남기는 것:

- 사진 또는 사진 썸네일
- 선택 재료
- 현재 미션 1개
- 입력창 또는 듣기 컨트롤
- Primary CTA 1개

숨기는 것:

- 사이드바
- 보상
- 진행 지도
- 업그레이드
- 저장 공간
- 최근 업로드

## 원칙 5. Expanded Mode는 사용자가 열 때만 제공한다

모든 자산 보기, 원정 기록 보기, 재료 바구니 상세 보기, 문장 지문 상세 보기 같은 화면은 사용자가 직접 열 때만 보인다.

확장은 기본 화면을 대체해야 한다. 한 화면에 기본 패널과 확장 패널과 팁 패널을 동시에 쌓지 않는다.

## 원칙 6. 보상은 표현 자산으로 남긴다

글숨 Labs의 보상은 점수, 랭킹, 배지가 아니라 저장 가능한 표현 카드다.

MVP에서 사용자가 세션 후 얻는 것은 다음이다.

- 단어 카드
- 감각 카드
- 질문 카드
- 문장 씨앗 카드
- 문장 카드
- 장면 카드

## 원칙 7. 모바일 사용자를 먼저 설계한다

모바일에서는 한 손으로 다음 행동을 찾을 수 있어야 한다.

- 주요 CTA는 하단 근처에 둔다.
- 텍스트는 버튼과 카드 안에서 줄바꿈되어야 한다.
- 창작 화면은 탭 바보다 작업 상태와 현재 행동을 우선한다.
- 긴 설명보다 1문장 상태와 직접 행동을 제공한다.

## 자체 점검 질문

사용자 테스트 또는 리뷰에서 다음 세 질문 중 2개 이상을 사용자가 스스로 답할 수 있어야 한다.

1. 지금 이 화면에서 해야 할 가장 중요한 행동은 무엇인가?
2. 이 행동을 하면 무엇이 생기는가?
3. 더 많은 정보를 보고 싶을 때 어디를 눌러야 하는가?
