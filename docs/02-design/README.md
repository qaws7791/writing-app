## 문서 목적

이 섹션은 글숨 Labs 제품의 상세 설계를 다루는 허브다.

제품 의도, UX 구조, 화면 명세, 상태 정의, 기능 설계를 포함한다. 구현 방식, API, 데이터 모델, 프론트엔드 아키텍처는 제외한다.

모든 설계 판단의 기준은 [[00-prd/v3]]이다.

## 제품 개요

글숨 Labs는 사진 한 장에서 사용자가 표현 재료를 고르고, 문장 씨앗을 조립하고, 직접 쓴 한 문장을 문체 정원에 저장하게 만드는 AI-native 한국어 표현 플랫폼이다.

핵심 루프:

> 사진 업로드 → 표현 재료 선택 → 문장 씨앗 조립 → 한 문장 작성 → 표현 카드 저장

핵심 개념:

- **사진 글감:** 사진 한 장을 표현 재료로 바꾸는 창작 진입점
- **표현 재료:** 보이는 것, 감각, 분위기, 움직임, 질문, 문장 씨앗 후보
- **재료 바구니:** 사용자가 선택한 재료를 부담 없이 확인하는 접힌 하단 바
- **문장 씨앗:** 선택 재료를 한 문장 작성 직전의 작은 구조로 바꾼 후보
- **한 문장 에디터:** 사용자가 직접 한 문장을 작성하는 Focus Mode 화면
- **문체 정원:** 저장된 표현 카드와 출처를 조용히 축적하는 아카이브

## 피벗 상태

기존 글필의 여정, 세션, 스텝, 서재, 글감 상세, 게이미피케이션 중심 문서는 현행 기준이 아니다. 구현 단계에서 새 화면 명세와 기능 문서로 교체하거나 `docs/99-archive`로 이동한다.

## 작성 규칙

- 파일명은 `lowercase-kebab-case`를 사용한다.
- 모든 문서는 한국어 `title`, `description`, `status` frontmatter를 가진다.
- 모든 문서는 H2 이하 제목만 사용한다.
- 모바일 우선으로 작성한다.
- 화면당 Primary CTA는 하나로 제한한다.
- screen 문서는 empty, analyzing, ready, collecting, seed_ready, drafting, saved 같은 상태를 사용자 행동 기준으로 나눈다.
