# 코스 상세 미시작 UX

## 시작

- 미시작 코스에서 `이어서 학습하기`와 `이어하기`가 표시되는 문제를 해결한다.
- 사용자가 아직 학습을 시작하지 않았다면 진행률 데이터는 행동 판단에 도움이 되지 않으므로 노출하지 않는다.
- 학습을 시작한 뒤에는 기존 진행률과 이어하기 흐름을 유지한다.

## 완료

- 미시작 상태에서는 진행률 헤더, 진행 바, `0 / N 완료` 문구, 구분선을 숨긴다.
- 같은 카드 안에서 첫 학습 행동만 `첫 레슨 시작`과 `시작하기`로 보여준다.
- 진행 중 상태에서는 기존 `전체 진행률`, 진행 바, `이어서 학습하기`, `이어하기` UI를 그대로 유지한다.
