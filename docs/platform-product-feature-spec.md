# 플랫폼 제품 기능 명세서

## 문서 정보

- 작성일: 2026-05-26
- 대상 독자: 기획자, 디자이너, 개발자 등 제품팀 전체
- 기준 자료: `apps/web` 하이파이 프로토타입, 현재 `/docs` 문서, API 기반 문서
- 문서 상태: 초안

## 변경 이력

### 2026-05-26 시작

- `apps/web`에 구현된 홈, 코스 목록, 코스 상세, 레슨 플레이어 화면을 기준으로 제품 기능을 추출한다.
- 직접 확인되는 기능은 확정 기능으로 정리한다.
- 실제 출시 플랫폼에 필요해 보이지만 프로토타입에서 직접 확정되지 않은 기능은 추가 검토 후보로만 분리한다.

### 2026-05-26 완료

- 학습자 중심의 확정 기능 범위를 정리했다.
- 레슨 활동 유형 20개를 제품 기능 관점으로 분류했다.
- 데이터와 상태 요구사항을 코스, 커리큘럼, 레슨, 학습 진행, 작성 답변, 피드백 기준으로 정리했다.
- 인증, 프로필, 검색, 실제 AI 평가, 관리자, 결제 등은 확정 기능이 아니라 추가 검토 후보로 분리했다.

### 2026-05-26 레슨 완료 범위 조정 시작

- 제품 기능 명세에서 레슨 완료 화면의 범위를 조정한다.
- 레슨 완료는 학습 흐름 종료와 다음 행동 선택 기능으로만 설명한다.

### 2026-05-26 레슨 완료 범위 조정 완료

- 레슨 시작, 레슨 완료, 레슨 활동 유형, 데이터 요구사항, 추가 검토 후보, 오픈 질문에서 완료 화면 범위를 중립적으로 정리했다.

### 2026-05-26 후보 기능 결정 반영 시작

- 후보 기능으로 분리했던 인증, 프로필, 검색, 학습 진행 저장, AI 평가 범위를 제품 기능으로 반영한다.
- 제외하거나 어드민 명세서로 분리할 항목을 제품 명세서의 제외 범위로 정리한다.
- 후보 기능 테이블을 삭제한다.

### 2026-05-26 후보 기능 결정 반영 완료

- 이메일 로그인, Google 로그인, 프로필 학습 현황과 설정 메뉴, 코스 검색, 학습 진행 영속 저장, OpenAI API 기반 AI 평가, AI 평가 재시도 3회 제한을 확정 기능으로 반영했다.
- 작성 답변은 레슨 내부 상태로만 유지하고, 저널과 하이라이트는 별도 저장하지 않는 것으로 정리했다.
- 알림과 리마인드, 결제와 구독을 제외하고, 관리자 콘텐츠 관리와 콘텐츠 검수는 어드민 기능 명세서로 분리했다.
- 후보 기능 테이블을 삭제했다.

## 목적

이 문서는 현재 웹 하이파이 프로토타입에서 확인되는 제품 기능을 팀 공통 언어로 정리한다. 화면 구현 세부사항보다 사용자가 어떤 일을 할 수 있어야 하는지, 어떤 데이터와 상태가 필요한지, 어떤 기능은 아직 확정하지 않았는지를 명확히 하는 것이 목적이다.

## 범위 원칙

### 확정 기능

확정 기능은 현재 `apps/web` 하이파이 프로토타입에서 직접 확인되는 기능과 제품팀이 채택을 확정한 기능이다. 확정 기능에는 인증, 홈, 프로필, 검색, 코스 탐색, 코스 상세, 커리큘럼, 레슨 플레이어, 레슨 활동 유형, 학습 진행 저장, 레슨 내부 작성 답변, OpenAI API 기반 AI 피드백, 레슨 완료 흐름이 포함된다.

### 제외 범위

- `/prototype` 디렉터리의 실험 코드는 기준으로 삼지 않는다.
- 알림과 리마인드는 우선 지원하지 않는다.
- 결제와 구독은 지원하지 않으며, 플랫폼은 완전 무료로 제공한다.
- 관리자 콘텐츠 관리와 콘텐츠 검수는 이 문서가 아니라 어드민 기능 명세서에서 다룬다.
- 운영 정책, 콘텐츠 제작 워크플로, 실제 AI 모델 품질 기준은 이 문서에서 확정하지 않는다.
- 백엔드 구현 상세나 개발 태스크 분해는 이 문서의 목적이 아니다.

## 사용자 유형

### 학습자

학습자는 현재 프로토타입의 명확한 주 사용자다. 학습자는 진행 중인 코스를 확인하고, 새 코스를 탐색하며, 코스 상세에서 커리큘럼을 보고, 레슨을 수행하고, 작성 답변에 대한 피드백을 확인하고, 다음 레슨으로 이어갈 수 있어야 한다.

### 운영자와 콘텐츠 제작자

운영자와 콘텐츠 제작자는 어드민 기능 명세서의 사용자 유형으로 다룬다. 이 문서는 학습자가 사용하는 플랫폼 기능만 다룬다.

## 제품 개체

| 개체 | 설명 | 현재 확인되는 주요 속성 |
| --- | --- | --- |
| 코스 카테고리 | 코스를 주제별로 묶는 단위 | ID, 제목, 코스 목록 |
| 코스 | 학습자가 선택하는 학습 묶음 | ID, 제목, 설명, 썸네일, 레슨 수, 진행률 |
| 단원 | 코스 상세 안에서 레슨을 묶는 커리큘럼 단위 | ID, 라벨, 제목, 레슨 목록, 완료 수 |
| 레슨 | 학습자가 실제로 수행하는 학습 단위 | ID, 제목, 코스 ID, 단원 번호, 다음 레슨 ID, 스텝 목록 |
| 레슨 스텝 | 레슨 안의 개별 활동 단위 | ID, 타입, 순서, 필수 여부, 콘텐츠 |
| 작성 답변 | 레슨 안에서 짧은 쓰기와 긴 쓰기에 입력한 내부 상태 | 스텝 ID별 텍스트 |
| AI 피드백 | 작성 답변을 바탕으로 OpenAI API가 생성하는 평가와 조언 | 원본 작성 스텝, 평가 초점, 점수 범위, 퇴고 허용 여부, 재시도 횟수 |
| 학습 진행 | 학습자의 학습 위치와 완료 정도 | 완료 레슨 수, 전체 레슨 수, 퍼센트, 다음 레슨, 현재 레슨 위치 |

## 확정 기능

### 1. 전역 앱 셸과 내비게이션

- 데스크톱에서는 상단 내비게이션을 제공한다.
- 모바일에서는 하단 탭 내비게이션을 제공한다.
- 기본 내비게이션 항목은 홈과 배우기다.
- 프로필 진입점과 검색 버튼은 전역 UI에 노출된다.
- 현재 경로에 따라 활성 메뉴 상태를 표시한다.
- 일반 화면은 공통 앱 셸을 사용하고, 레슨 화면은 몰입형 전체 화면 학습 셸을 사용한다.

### 2. 인증

- 학습자는 이메일로 로그인할 수 있다.
- 학습자는 Google 계정으로 로그인할 수 있다.
- 로그인한 학습자의 학습 진행은 계정에 연결된다.
- 인증은 학습 진행 저장과 복귀 흐름을 지원하기 위한 필수 기능이다.

### 3. 홈과 진행 중인 코스

- 학습자는 진행 중인 코스 목록을 볼 수 있다.
- 각 진행 중인 코스는 썸네일, 제목, 설명, 진행률, 완료 퍼센트를 보여준다.
- 진행 중인 코스 아래에는 최근 또는 다음 학습 대상 레슨이 표시된다.
- 레슨 상태는 완료, 다음 학습, 잠김으로 구분된다.
- 학습자는 홈에서 코스 상세 또는 특정 레슨으로 이동할 수 있다.

### 4. 프로필

- 학습자는 프로필 페이지에서 학습 현황을 확인할 수 있다.
- 프로필 페이지는 프로토타입 방향처럼 학습 현황 영역과 설정 메뉴를 제공한다.
- 설정 메뉴는 계정과 앱 사용에 필요한 설정 진입점을 제공한다.

### 5. 검색

- 학습자는 검색 기능으로 코스를 찾을 수 있다.
- 검색 결과는 코스 제목과 설명을 기준으로 코스 탐색을 돕는다.
- 검색 기능은 전역 검색 진입점에서 접근할 수 있다.

### 6. 코스 탐색

- 학습자는 학습 코스를 카테고리별로 둘러볼 수 있다.
- 현재 카테고리는 입문자를 위한 코스, 문법 심화, 실전 글쓰기다.
- 코스 카드는 썸네일, 제목, 레슨 수, 설명을 제공한다.
- 학습자는 코스 카드를 선택해 코스 상세로 이동할 수 있다.
- 카테고리별 전체 보기 진입점이 제공된다.

### 7. 코스 상세

- 학습자는 코스의 대표 이미지, 제목, 설명을 확인할 수 있다.
- 코스 상세는 전체 진행률, 완료 레슨 수, 전체 레슨 수를 보여준다.
- 학습자는 다음 학습 레슨 정보를 확인하고 이어하기 버튼으로 레슨을 시작할 수 있다.
- 코스 상세는 커리큘럼을 단원 단위로 보여준다.
- 단원은 접고 펼칠 수 있다.
- 각 단원은 완료 레슨 수와 전체 레슨 수를 표시한다.
- 완료된 단원은 완료 상태로 표시된다.
- 각 레슨 행은 완료 여부를 시각적으로 표시하고 레슨 화면으로 연결한다.
- 존재하지 않는 코스 ID에 대해서는 코스 없음 화면을 제공한다.

### 8. 레슨 진입과 이동

- 레슨 화면은 `lesson_id` 기준으로 특정 레슨을 연다.
- `lesson_id`가 없으면 기본 레슨을 보여준다.
- 존재하지 않는 레슨 ID에 대해서는 레슨 없음 화면을 제공한다.
- 레슨 완료 후 다음 레슨이 있으면 다음 레슨으로 이동할 수 있다.
- 다음 레슨이 없으면 코스 목록으로 이동할 수 있다.

### 9. 레슨 학습 셸

- 레슨 화면은 어두운 몰입형 UI를 사용한다.
- 상단에는 나가기 버튼, 레슨 진행률, 남은 생명 표시가 있다.
- 하단에는 현재 스텝에 맞는 주요 행동 버튼이 고정된다.
- 스텝 전환 시 학습 콘텐츠 영역은 상단으로 스크롤된다.
- 학습자가 나가기를 누르면 확인 대화상자를 보여준다.
- 나가기 확인 대화상자는 계속 학습과 나가기 선택지를 제공한다.
- 학습 진행은 영속적으로 저장되어야 한다.
- 네트워크 연결이 끊기거나, 화면을 이탈하거나, 새로고침한 뒤 복귀해도 학습자는 저장된 위치에서 이어서 학습할 수 있어야 한다.

### 10. 레슨 시작 스텝

- 레슨 시작 화면은 레슨 제목, 카테고리, 배울 내용, 예상 시간, 전체 스텝 수를 보여준다.
- 학습자는 시작하기 버튼으로 첫 학습 활동에 진입한다.

### 11. 개념 학습

- 개념 스텝은 소제목, 본문, 강조 콜아웃을 제공한다.
- 핵심 용어가 있는 경우 접고 펼치는 방식으로 용어 정의를 확인할 수 있다.
- 학습자는 이해했어요 버튼으로 다음 스텝으로 이동한다.

### 12. 읽기 지문

- 읽기 스텝은 안내 문구, 예상 읽기 시간, 지문 제목, 본문, 출처를 제공한다.
- 집중 질문이 있는 경우 읽기 전에 생각할 질문을 보여준다.
- 하이라이트 가능 여부를 안내할 수 있다.
- 하이라이트는 별도로 저장하지 않는다.

### 13. 예시 공개와 비교 학습

- 예시 공개 스텝은 나쁜 예시 또는 기준 예시를 먼저 보여주고, 학습자가 분석 보기를 눌렀을 때 좋은 예시와 분석을 공개한다.
- 비교 스텝은 둘 이상의 버전을 탭으로 전환하며 비교할 수 있게 한다.
- 비교 결과에 대한 분석과 생각해볼 질문을 제공할 수 있다.

### 14. 객관식 문제

- 객관식 스텝은 문제, 선택지, 선택 상태, 확인 버튼을 제공한다.
- 학습자는 선택지를 하나 고르고 확인할 수 있다.
- 확인 후 정답과 오답 상태가 표시된다.
- 확인 후 해설을 보여준다.
- 해설 확인 후 다음 스텝으로 이동한다.
- 현재 타입은 복수 선택을 허용하지 않는 형태로 정의되어 있다.

### 15. 빈칸 채우기

- 빈칸 채우기 스텝은 문장 템플릿과 단어 은행을 제공한다.
- 학습자는 단어를 탭해 빈칸에 순서대로 넣을 수 있다.
- 학습자는 채운 빈칸을 다시 탭해 취소할 수 있다.
- 모든 빈칸을 채워야 확인할 수 있다.
- 확인 후 정답 여부와 해설을 보여준다.

### 16. 단어 선택

- 단어 선택 스텝은 문장 안의 선택 가능한 구간을 제공한다.
- 학습자는 맞다고 생각하는 구간을 선택하거나 해제할 수 있다.
- 확인 후 맞게 선택한 구간, 놓친 구간, 잘못 선택한 구간을 구분해 보여준다.
- 전체 해설을 제공한다.

### 17. 순서 배열

- 순서 배열 스텝은 문장 또는 항목을 올바른 순서로 재배열하게 한다.
- 현재 UI는 드래그 기반 이동을 제공한다.
- 확인 후 정답 순서와 해설을 보여준다.
- 번호 힌트 표시 여부를 콘텐츠에서 제어할 수 있다.

### 18. 매칭

- 매칭 스텝은 왼쪽 항목과 오른쪽 항목을 연결하게 한다.
- 학습자는 항목을 선택해 짝을 만들 수 있다.
- 오른쪽 항목은 섞어서 표시할 수 있다.
- 확인 후 연결 결과와 해설을 보여준다.

### 19. 분류

- 분류 스텝은 여러 항목을 카테고리에 배정하게 한다.
- 각 카테고리는 라벨과 시각적 톤을 가진다.
- 학습자는 항목마다 카테고리를 선택한다.
- 확인 후 정오답과 전체 해설을 보여준다.

### 20. 짧은 쓰기

- 짧은 쓰기 스텝은 안내 문구, 프롬프트, 참고 원문, 최소 글자 수, 최대 글자 수를 제공한다.
- 학습자는 텍스트를 입력하고 제출할 수 있다.
- 최소 글자 수를 만족해야 다음 단계로 진행할 수 있다.
- 제출 후 참조 답안을 보여줄 수 있다.
- 작성 답변은 레슨 내부 상태로 보관되어 이후 AI 피드백 스텝에서 참조된다.
- 작성 답변은 별도 학습 자산이나 저널로 저장하지 않는다.

### 21. 긴 쓰기

- 긴 쓰기 스텝은 주제, 맥락, 구조 가이드, 최소 글자 수, 목표 글자 수, 최대 글자 수를 제공한다.
- 학습자는 긴 문단을 작성한다.
- 최소 글자 수를 만족해야 제출할 수 있다.
- 드래프트 저장 가능 여부는 콘텐츠 속성으로 표현된다.
- 작성 답변은 레슨 내부 상태로 보관되어 이후 AI 피드백 스텝에서 참조된다.
- 작성 답변은 별도 학습 자산이나 저널로 저장하지 않는다.

### 22. AI 피드백

- AI 피드백 스텝은 특정 작성 스텝의 답변을 평가 대상으로 삼는다.
- 피드백은 명확성, 표현력 같은 평가 초점을 가질 수 있다.
- 점수 표시 여부와 점수 범위를 콘텐츠에서 제어할 수 있다.
- 학습자는 피드백을 본 뒤 다음으로 진행하거나 퇴고로 돌아갈 수 있다.
- AI 평가는 OpenAI API와 연결해야 한다.
- AI 평가 재시도는 최대 3회로 제한한다.
- 재시도 횟수를 초과하면 학습자에게 평가를 다시 요청할 수 없음을 안내한다.

### 23. 퇴고

- 퇴고 스텝은 원문, 퇴고 과제, 힌트, 참고 퇴고문을 제공한다.
- 학습자는 기존 글을 기준에 맞게 고쳐 쓰는 활동을 수행한다.
- AI 평가 가능 여부와 평가 기준을 콘텐츠에서 표현할 수 있다.

### 24. 체크리스트

- 체크리스트 스텝은 학습자가 기준 항목을 확인하게 한다.
- 항목별 필수 여부와 팁을 제공할 수 있다.
- 완료 조건은 전체, 최소 개수, 임의 선택 방식으로 표현된다.
- 응답 저장 여부는 콘텐츠 속성으로 표현된다.

### 25. 회고

- 회고 스텝은 질문, 맥락, 작성 시작 문구, 최소 글자 수를 제공한다.
- 학습자는 배운 내용을 자신의 글쓰기 습관과 연결해 작성할 수 있다.
- 회고 답변은 별도 저널로 저장하지 않는다.
- 건너뛰기 가능 여부를 콘텐츠에서 표현한다.

### 26. 요약

- 요약 스텝은 레슨 핵심 포인트 목록을 보여준다.
- 다음 레슨 정보와 공유 가능한 문구를 제공할 수 있다.
- 학습자는 다음 버튼으로 완료 단계로 이동한다.

### 27. 필사

- 필사 스텝은 원문을 보고 그대로 입력하는 활동을 제공한다.
- 학습자는 필사 입력 후 원문과의 일치율을 확인할 수 있다.
- 대소문자와 문장부호 민감도는 콘텐츠에서 제어된다.

### 28. 레슨 완료

- 완료 스텝은 레슨 종료 화면을 제공한다.
- 학습자는 코스로 돌아가거나 다음 레슨으로 이어갈 수 있다.

## 레슨 활동 유형 카탈로그

## 데이터와 상태 요구사항

### 코스 데이터

- 코스는 카테고리에 속한다.
- 코스는 목록 카드와 상세 화면에서 공통으로 사용할 수 있는 제목, 설명, 썸네일, 레슨 수를 가진다.
- 코스 상세는 단원과 레슨 목록을 포함한다.
- 코스 상세는 완료 레슨 수와 전체 레슨 수로 진행률을 계산한다.
- 코스 상세는 다음에 학습할 레슨을 계산해 이어하기에 사용한다.

### 레슨 데이터

- 레슨은 코스와 연결되어야 한다.
- 레슨은 순서가 있는 스텝 목록으로 구성된다.
- 레슨은 첫 스텝이 시작 안내이고 마지막 스텝이 완료 안내여야 한다.
- 레슨은 다음 레슨 ID를 가질 수 있다.
- AI 피드백 스텝은 참조할 작성 스텝 ID가 필요하다.

### 학습 진행 상태

- 홈과 코스 상세는 완료 레슨 수, 전체 레슨 수, 진행률을 표시한다.
- 레슨 화면은 현재 스텝 위치로 진행률을 계산한다.
- 레슨 상태는 완료, 다음 학습, 잠김으로 표현될 수 있다.
- 학습 진행은 계정에 연결되어 영속적으로 저장되어야 한다.
- 저장 대상에는 최소한 진행 중인 코스, 완료한 레슨, 현재 학습 중인 레슨, 현재 레슨 스텝 위치가 포함된다.
- 네트워크 연결이 끊기거나 화면을 이탈하거나 새로고침한 뒤 복귀해도 저장된 학습 위치에서 이어서 학습할 수 있어야 한다.

### 작성 답변 상태

- 짧은 쓰기와 긴 쓰기는 레슨 내부 상태로 스텝 ID별 답변을 보관한다.
- AI 피드백은 해당 답변을 참조한다.
- 작성 답변은 별도 학습 자산, 저널, 작성 기록으로 저장하지 않는다.
- 작성 답변은 레슨 흐름 안에서 AI 피드백과 퇴고를 처리하는 데만 사용한다.

### 피드백 상태

- 문제형 스텝은 확인 전, 확인 후 상태를 구분한다.
- 확인 후 정답, 오답, 해설을 표시한다.
- AI 피드백은 작성 답변을 바탕으로 점수와 조언을 보여주는 형태를 가진다.
- AI 평가는 OpenAI API를 사용한다.
- AI 평가 재시도는 최대 3회로 제한한다.

### 인증 데이터

- 학습자는 이메일 로그인 또는 Google 로그인을 사용할 수 있다.
- 인증된 학습자 ID는 학습 진행 저장과 복귀 흐름의 기준이 된다.

### 검색 데이터

- 검색 대상은 코스다.
- 코스 검색은 코스 제목과 설명을 기준으로 결과를 제공한다.

### 프로필 데이터

- 프로필 페이지는 학습 현황과 설정 메뉴를 제공한다.
- 학습 현황은 저장된 학습 진행 데이터를 바탕으로 표시한다.

### 저장하지 않는 데이터

- 회고 답변은 별도 저널로 저장하지 않는다.
- 읽기 지문의 하이라이트는 별도로 저장하지 않는다.
- 작성 답변은 레슨 외부의 독립 기록으로 저장하지 않는다.

## 콘텐츠 범위

현재 프로토타입에는 한국어 글쓰기 학습을 위한 코스가 포함되어 있다.

- 기초 문장 만들기
- 감정 표현 글쓰기
- 비즈니스 이메일 작성법
- 문장 구조의 기본
- 어휘 확장 입문
- 독해와 요약
- 문법 완성
- 표현력 향상
- 에세이 쓰기
- 비즈니스 글쓰기
- 창의적 글쓰기

코스 목록 화면에는 입문, 문법, 실전 글쓰기 중심의 탐색 코스가 보이고, 홈 화면에는 진행 중인 코스가 별도로 노출된다. 현재 API 기반 문서에 따르면 일부 홈 전용 코스도 콘텐츠 조회가 끊기지 않도록 시드에 포함되어 있다.

## 제외와 별도 문서화

- 알림과 리마인드는 우선 지원하지 않는다.
- 결제와 구독은 지원하지 않는다. 플랫폼은 완전 무료로 제공한다.
- 관리자 콘텐츠 관리는 어드민 기능 명세서에서 다룬다.
- 콘텐츠 검수는 어드민 기능 명세서에서 다룬다.
- 저널은 별도 기능으로 제공하지 않는다.
- 하이라이트 저장은 별도 기능으로 제공하지 않는다.
- 작성 답변은 레슨 외부의 독립 기록으로 제공하지 않는다.
