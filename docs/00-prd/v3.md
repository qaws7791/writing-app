## 제품 문장

글숨 Labs는 사진 한 장에서 사용자가 단어를 줍고, 장면을 더 깊게 보고, 자기 손으로 한 문장을 만들고, 그 표현을 자기 언어의 정원에 저장하게 만드는 AI-native 한국어 표현 플랫폼이다.

사용자 언어로는 다음처럼 설명한다.

> 사진과 생각을 나다운 한국어 문장으로 바꾸는 조용한 표현 작업실

## MVP 목표

MVP의 목표는 전체 세계관을 구현하는 것이 아니라 첫 문장 루프가 실제로 작동하는지 검증하는 것이다.

핵심 루프:

> 사진 업로드 → 표현 재료 선택 → 문장 씨앗 조립 → 한 문장 작성 → 표현 카드 저장

이 루프는 5~10분 안에 자연스럽게 완료되어야 한다. 성공 기준은 신규 사용자의 35% 이상이 첫 세션에서 직접 작성한 문장 1개를 저장하는 것이다.

## 핵심 문제

| 문제             | 설명                                                                         | 제품의 답                                                 |
| ---------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------- |
| 빈 화면          | 사용자는 글쓰기 의지가 없어서가 아니라 시작점이 없어 멈춘다.                 | 사진 한 장에서 바로 고를 수 있는 단어와 감각을 제공한다.  |
| 관찰의 언어화    | 사진은 많지만 사물, 빛, 거리감, 분위기를 문장 재료로 바꾸는 훈련이 부족하다. | 장면을 작은 표현 재료와 질문으로 쪼갠다.                  |
| 한국어 표현 감각 | 조사, 어미, 생략, 호흡, 정서적 거리감의 차이를 직접 만질 기회가 적다.        | 완성문보다 선택, 조립, 수정 힌트를 먼저 둔다.             |
| AI 대필          | AI가 매끈한 문장을 대신 주면 사용자는 자기 문장 소유감을 잃는다.             | AI는 대필자가 아니라 관찰 가능성과 수정 힌트 제공자다.    |
| UI 피로          | 많은 기능이 한 화면에 보이면 사용자는 글쓰기 전에 UI를 해석해야 한다.        | Calm Mode를 기본값으로 두고 한 화면에 하나의 의도만 둔다. |

## 타겟 사용자

| 우선순위 | 사용자                           | 필요한 것                                                           |
| -------- | -------------------------------- | ------------------------------------------------------------------- |
| 1차      | 쓰고 싶은데 시작하지 못하는 사람 | 사진 앞에서 바로 고를 수 있는 작은 단어와 첫 문장까지 이어지는 흐름 |
| 2차      | AI 티 나는 글을 싫어하는 사람    | AI 대필 없이 자기 문장을 조율하는 표현 도구                         |
| 3차      | 짧은 글을 자주 쓰는 창작자       | SNS 캡션, 블로그 도입부, 리뷰, 내레이션에 쓸 표현 자산              |

## 제품 원칙

- 사용자가 문장의 주인이다.
- 깊이는 유지하되 표면은 조용하게 만든다.
- 한 화면에는 하나의 의도만 둔다.
- 생성보다 선택을 먼저 둔다.
- 정답이 아니라 뉘앙스를 다룬다.
- 장시간 체류는 낮은 피로도 행동의 순환으로 만든다.
- 보상은 점수가 아니라 표현 자산이다.
- 사용자를 단정하지 않는다.

| Primary CTA         | 최대 1개                                  |
| 동시에 열린 패널    | 최대 1개                                  |
| 사진 위 오버레이 칩 | 기본 3~5개, 확장 시 최대 7개              |
| 팁, 보상, 최근 항목 | 기본 상시 노출 금지                       |

## MVP 범위

| 기능           | 포함 범위                                                   |
| -------------- | ----------------------------------------------------------- |
| 홈             | 에너지 상태 기반 진입, 최근 작업 1개, 오늘의 짧은 제안 1개  |
| 사진 글감      | 사진 업로드, 활성 레이어 1개, 칩 3~5개, 재료 선택           |
| 재료 바구니    | 접힌 하단 바, 선택 재료 수 표시, 상세는 사용자 요청 시 열림 |
| 문장 씨앗      | 재료 3개 이상 선택 후 등장, 조합 후보 1~3개                 |
| 한 문장 에디터 | 선택 재료 기반 직접 작성, AI 힌트 최대 3개                  |
| 문체 정원 Lite | 저장한 단어, 문장, 장면 카드 목록과 출처 표시               |
| 데이터 출처    | 모든 카드에 사진, 게임, 문장, 리듬 출처 기록                |
| 안전/개인정보  | 사진 삭제, 저장 동의, 민감 추론 금지, 인물 식별 금지        |

## MVP 비범위

- 긴 글 전체 대필
- AI 문장 그대로 삽입하는 기본 버튼
- SNS 피드, 좋아요, 랭킹
- 풀 기능 문장 실험실
- 독자 극장
- 교육자/기관용 대시보드
- 복잡한 업적/배지 시스템
- 창작 화면의 상시 업그레이드/저장 공간 표시
- 모든 레이어와 모든 자산을 한 화면에 동시에 보여주는 대시보드형 UI

## 정보 구조

V1 내비게이션은 최대 5개로 제한한다.

1. 홈
2. 사진 글감
3. 장면 원정
4. 문장 아케이드
5. 문체 정원

모바일 하단 탭은 4개로 제한한다.

1. 홈
2. 사진
3. 정원
4. 더보기

리듬룸과 문장 지문은 독립 메뉴가 아니라 문체 정원 또는 저장 문장 상세에서 진입한다.

## 첫 문장 루프

1. 사용자가 홈에서 사진으로 시작을 선택한다.
2. 사진을 업로드한다.
3. 앱이 3초 안에 첫 글감 3~5개를 보여준다.
4. 사용자는 마음에 드는 재료를 3개 선택한다.
5. 앱은 선택 재료를 바탕으로 문장 씨앗을 보여준다.
6. 사용자는 한 문장 에디터에서 직접 문장을 쓴다.
7. AI는 대필하지 않고 수정 힌트를 제공한다.
8. 사용자가 문장을 저장한다.
9. 문체 정원에 카드가 생성된다.

## 사진 글감 상태 머신

```text
idle
→ uploading
→ analyzing
→ ready
→ collecting
→ seed_ready
→ drafting
→ saved
```

| 상태       | 사용자에게 보이는 핵심 행동      |
| ---------- | -------------------------------- |
| idle       | 사진 선택                        |
| uploading  | 기다리기 또는 취소               |
| analyzing  | 기다리기                         |
| ready      | 재료 고르기                      |
| collecting | 재료 더 고르기 또는 씨앗 만들기  |
| seed_ready | 한 문장으로 쓰기                 |
| drafting   | 문장 저장하기                    |
| saved      | 정원에 저장됨 또는 리듬 들어보기 |
